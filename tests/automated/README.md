# 자동 검사

이 폴더의 `test_*.py`는 실행기·드롭 처리·UI 부품의 자동 검사다. 직접 조작용 샘플은 상위 폴더의 `basic_flow.py`다.

`test_health_trail.py`는 HP 감소 구간의 연속 피격 위치 보존·시간 재시작·가속·회복/초기화 계약을 확인하도록 준비했다. 추가 후 실행하지 않았다.

프로젝트 루트에서 실행한다.

```text
python -m unittest discover -s tests/automated -v
```

검사 경로는 이동한 위치에 맞게 수정했다. 폴더 분리 후 검사는 실행하지 않았다.

2026-11-03 Runner·UI 실행 경계 분리에 맞춰 GUI 검사 항목을 별도 프로세스 기준으로 수정하고 `test_runner_processes.py`를 추가했다. 부모에서 테스트 코드를 실행하지 않는지, 이전 자식 정리·오류 출력·같은 타임스탬프의 보조 모듈 소스 갱신·Runner 없는 UI import를 확인하도록 준비했다. **이번 수정 후 검사와 실제 창 실행은 수행하지 않았다.** 기존 호환 규약 검사와 새 독립 실행 경계 검사를 구분하며, 과거 통과 결과는 새 구조의 통과를 뜻하지 않는다.
