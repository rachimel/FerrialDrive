# UI 테스트 폰트

- `s_core_dream/`: 현재 UI 전체에 사용하는 에스코어 드림. `SCDream2.otf`~`SCDream6.otf`를 보관하며 Medium·Bold도 포함한다. [공식 배포처](https://s-core.co.kr/company/font/)의 `S-Core_Dream_OTF.zip` 원본 파일이다. 저작권 안내는 `LICENSE.txt`에 함께 보관한다.
- `kkakdugi_drafting/`: 이전에 사용한 깍두기 도면체 Regular. 현재 UI에는 적용하지 않는다. [공식 저장소](https://github.com/dynamic-potato/kkakdugi-drafting)의 원본 파일과 OFL·저자·변경 기록을 보존한다.

확인일은 2026-11-03이다. 폰트 바이너리는 수정하지 않았다. UI 역할별 경로와 크기는 `samples/ui_unit_test/ui_config.json`에서 설정한다.
