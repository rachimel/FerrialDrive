# Ferrial HUD Square Wide

Ferrial HUD Square를 바탕으로 한 **가로 확장·전체 윤곽 각진 사본**이다. 이전 숫자 수정본과 학교안심 운동장 원본을 보존한다.

현재 게임 UI에서는 전투 텍스트·피해·카운터 외에 일시정지 헤더 26px·로드아웃 번호 14px에도 비교 적용한다. 무기 이름·탄약은 가물치 무료고딕을 사용한다. 역할별 크기·표시 배율은 [전체 폰트 안내](../README.md)와 UI 설정을 따른다.

## 현재 형태

- **가로 120%, 세로 100%**. 사용자가 “납작하게”의 의미를 **글자 폭 넓히기**로 지정했다. 20%는 첫 비교본의 구현상 선택이며 추후 조절할 수 있다.
- 한글·영문·기호 등 기존에 실제 윤곽이 있는 글리프 전체를 대상으로 한다. 둥근 모서리는 직선과 짧은 사선으로, 복잡한 곡선은 윤곽을 따라 분할한 직선으로 바꾼다.
- `ㅇ`의 모서리에 사선을 남겨 위쪽이 직각인 `ㅁ`과 구분하며 기존 사선 획은 유지한다. 숫자 0의 사선 제거도 유지한다.
- 가로 윤곽과 글자 진행 폭·사이드베어링을 함께 확장한다. 기준선·세로 배율·줄 간격은 유지한다.
- 연결/속공간 변화가 감지된 복잡한 기호 17개는 더 촘촘한 직선 분할로 형태를 우선 보존한다. 고정된 기준 원본과 항목은 생성 도구와 `manifest.json`을 따른다.

## 확인 범위

- 글리프 12,614개의 순서·문자 매핑, 외곽/속공간 윤곽 12,734개와 감기는 방향, 저작권 고지·세로 메트릭을 확인한다. 윤곽이 있는 글리프는 3,788개이며 원본에서 빈 8,826개는 그대로 보존한다. 원본에 없는 문자를 새로 그린 것은 아니다.
- 매핑된 비어 있지 않은 글리프 3,787개를 96px로 실제 렌더링해 소실과 세로 범위 이상이 없음을 확인했다. 나머지 윤곽 1개는 매핑되지 않은 글리프다.
- 128/256px의 픽셀 연결/속공간 비교도 수행했다. 복잡한 전용 기호 `U+E038`과 일부 저해상도 기호에는 크기별 픽셀 차이가 남으므로 검사 통과를 모든 크기에서의 동일한 외형으로 해석하지 않는다. 원본 자체의 픽셀 연결도 크기에 따라 달라진다.
- 폰트 전반의 비교 이미지와 검사 결과는 로컬 `output/font-preview/wide-font-comparison.png`, `wide-raster-check.json`, `wide-topology-check.json`에 둔다. 게임 HUD에서의 직접 조작·최종 시각 승인은 별도다.
