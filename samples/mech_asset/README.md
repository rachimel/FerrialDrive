# 분리 메카 시연 데이터

`make_sample.write_sample(출력폴더)`는 직접 정의한 사각형으로 8방향·4프레임의 본체·좌우 손+무기·칼집 색상 시트 4종과 본체/칼집 마스크 2종을 생성한다. 게임 모델이나 외부 이미지가 필요하지 않다.

Pico2D 환경에서 FDrive 에셋 로더의 **메카 설정 → 동작·순서 또는 조립 미리보기 → 도형 예제**로 실행한다. 임시 예제는 `output/asset_loader/mech_sample/`에 생성하며 편집 중인 작업본을 덮어쓰지 않는다. 순서 프리셋이나 목록의 앞뒤 변경에 따라 색상 도형의 가림이 달라지는지 확인한다.

내보내기 시연은 생성한 각 JSON을 출력 단위의 분리 시트에 연결하고, 동작의 클립 이름을 `equipped_idle`, 프레임을 `1,3,5,7`로 지정한다. 분리 시트 내보내기 후 색상·마스크 파일이 각각 남고 조립 미리보기로 다시 열리는지 확인한다. 자동 검사는 이 경로와 게임 공통 표시기의 실제 픽셀 겹침을 확인한다.

이 예제의 방향별 그림은 순서 확인용 기본 도형이다. 실제 기체의 자세·조형·리깅·발도·사격을 재현하는 데이터가 아니다. 사용 방법과 구현 범위는 [메카 에셋](../../docs/tool-usage/mech_assets.md)을 따른다.
