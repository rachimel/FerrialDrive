# 시연 · 시각과 출처 구분

- 기록 ID: `FDLOG-DEMO-TIME`
- 시연 데이터: 실제 인물·대화와 관계없는 가짜 기록이다.

## 1. 사용자가 제안한 것

- U1: 당시 날짜와 보완한 날짜를 구분한다.

## 2. AI가 제안한 것

- A1: 원문 확인과 회고를 나눠 표시한다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 시연 대상으로 수용한다.

## 4. AI 제안 중 사용자가 수용한 것

- 추가 실제 대화는 없다.

## 5. 반영 후 발견한 문제

- 당시 시각 — 모름 `[[FDLOG_MISSING_TIME:FDLOG-DEMO-TIME:I1]]`. 보완 검색: 날짜만 기억하면 YYYY-MM-DD로 입력한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 당시 시각에 2026-01-01처럼 날짜만 넣으면 날짜 수준으로 보존한다.

## 7. AI 해결 제안과 실제 해결 과정

- 현재 보완 시각을 과거 사건 시각으로 바꾸지 않는다.
