# 시연 · 기록 검색과 누락 보완

- 기록 ID: `FDLOG-DEMO-PROPOSAL`
- 시연 데이터: 실제 대화가 아닌 공개 가능한 가짜 기록이다.

## 1. 사용자가 제안한 것

- **U1 — 시연 데이터**
  - 내용·의도: 테스트 결과를 쉽게 다시 찾을 수 있게 한다.
  - 이유 — 모름 `[[FDLOG_MISSING_REASON:FDLOG-DEMO-PROPOSAL:U1]]`. 보완 검색: 시연용 이유를 직접 입력한다.

## 2. AI가 제안한 것

- A1: 검색과 누락 필터를 제공한다. 시연용 제안이다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 시연 대상으로 수용한다.

## 4. AI 제안 중 사용자가 수용한 것

- 수용 여부 — 모름 `[[FDLOG_MISSING_ACCEPTANCE:FDLOG-DEMO-PROPOSAL:A1]]`. 보완 검색: 시연용 확인 내용을 입력한다.

## 5. 반영 후 발견한 문제

- 실제 문제를 기록한 것이 아니다. 입력·저장·되돌리기를 확인하는 가짜 데이터다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 이유를 ‘찾는 시간이 길어져서’처럼 입력하고 적용·되돌리기를 확인한다.

## 7. AI 해결 제안과 실제 해결 과정

- 원본 샘플은 수정하지 않고 workspace/demo_logs 복사본을 사용한다.
