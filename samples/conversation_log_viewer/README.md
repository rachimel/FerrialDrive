# 대화 기록 시연 데이터

두 Markdown은 실제 인물이나 대화와 관계없는 가짜 기록이다. 게임 에셋·세이브·개인 채팅 없이 검색·출처·보완 저장·되돌리기를 확인한다.

```text
python Tools/conversation_log_viewer/run.py --demo
```

실제 기능 경로로 workspace/demo_logs 복사본을 연다. 원본 샘플과 실제 docs/ai-dev-log는 수정하지 않는다. 이유 필드에 한글을 입력하고 적용 후 누락 수가 줄어드는지, 다시 열어 보완이 남는지, 마지막 보완 취소로 복구되는지 확인한다. 시각 필드에는 날짜만 입력해 자정 시각을 만들어 넣지 않는지도 확인한다.
