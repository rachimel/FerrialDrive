# 대화 기록 시연 데이터

실제 Codex 기록 없이 요약 보완과 원문 검색·시각 가져오기를 시연한다. `codex_demo/`는 직접 작성한 가짜 프로젝트·채팅·발언 데이터다. 계정 정보와 실제 원문은 포함하지 않는다.

기존 두 Markdown도 실제 인물이나 대화와 관계없는 가짜 기록이다. 이유 필드의 한글 입력 → 적용 → 다시 열기 → 마지막 보완 취소로 저장·복구를 확인한다. 시각 필드에 날짜만 입력하면 자정 시각을 만들어 넣지 않는지도 확인한다.

Pico2D가 설치된 Python에서 프로젝트 루트 기준으로 실행한다.

```text
python Tools/conversation_log_viewer/run.py --demo
```

시각 누락 기록을 선택하고 **원문 찾기**를 연다. `시연용` 검색 → 발언 선택 → 선택 근거 가져오기 → 기존 적용 버튼 순서로 확인한다. 두 발언 사이의 범위는 첫 발언에서 **범위 시작 선택**, 마지막 발언에서 **선택 근거 가져오기**로 가져온다. **결과 JSON 저장**은 현재 검색 결과를 로컬 workspace/exports/에 저장한다.

직접 채팅 추가는 `22222222-2222-2222-2222-222222222222`를 입력해 확인한다. 두 가짜 채팅의 작업 폴더가 같아도 기본 프로젝트 검색에는 첫 채팅만 나온다.

샘플 원본은 읽기만 하며, 보완·취소·내보내기는 도구 workspace에 남는다. `--demo`는 실제 계정의 Codex 프로젝트나 원문을 읽지 않는다.
