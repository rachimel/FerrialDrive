# 도형 기체 1대1 전투

공개 도형·수치 데이터만 사용하는 Pico2D 전투 프로토타입이다. 실제 게임 이미지·모델·Blender·Unreal·세이브 파일을 요구하지 않는다. 기존 UI 샘플의 표현 설정과 공개 폰트를 재사용한다.

## 실행

Python 3.11 이상과 루트 `requirements-ui.txt`의 Pico2D가 필요하다. 프로젝트 루트에서 실행한다.

```text
python tests/combat_test.py
```

Unit Test Runner의 탐색 목록에서 `tests/combat_test.py`를 선택하거나 열린 Runner 창에 드롭해도 된다. 테스트는 별도 창에서 실행한다. 최초 화면은 시작 대기 상태다.

| 입력 | 동작 |
| --- | --- |
| Enter | 시작·일시정지 해제 / 실행 중 일시정지 |
| WASD | 이동. 입력을 놓으면 즉시 정지 |
| Shift + 이동 | 달리기 |
| Space | 짧은 슬라이딩 대시. 이동 입력이 없으면 조준 방향 사용 |
| 마우스 | 조준 |
| 좌클릭 | 검 공격. 회수 구간에서 재입력하여 4단 연계 |
| 총 장착 중 좌클릭 유지 | 기관단총 연사 |
| 총 장착 중 우클릭 유지 | 탄 퍼짐을 줄이는 조준 사격 |
| E | 검·기관단총 전환 |
| Esc | 일시정지·계속 |
| R | 전투 상태를 초기화하고 즉시 재시작 |
| F10 / 창 X | 해당 테스트 종료 |

포커스를 잃으면 일시정지하고 누른 키·마우스 상태를 비운다. 총은 45발 탄창이며 예비 탄약은 무한이다. **수납 여부와 관계없이 마지막 실제 발사 1초 뒤부터 탄약이 천천히 회복하고 점점 빨라진다.** 다시 발사하면 대기 시간과 회복 속도를 초기화한다. 일부 탄약만 회복돼도 발사할 수 있으며, 탄창이 비었을 때 전탄을 한 번에 채우는 재장전은 없다. HUD에 회복 대기 시간과 현재 회복 속도를 표시한다.

## 확인할 결과

- 화면 중앙의 청회색 기체를 조작하며, 적색 근접 기체 한 기가 장애물을 돌아 접근한다.
- 일반 적은 별도 공격 범위·경고 표시 없이 준비 동작→공격→회수 동작을 반복한다.
- 이동 방향과 조준 방향은 독립적이며, 대시 도중 조준을 바꿔도 추진 방향은 유지한다. 일반 대시는 무적이 아니다.
- 일반 검 공격의 준비·타격·회수를 대시로 캔슬한다. 대시와 검 공격을 동시에 누르거나 시작 직후 입력하면 대시 방향으로 공격한다.
- 플레이어와 적이 실제로 피해를 받고, 적 HP가 0이면 성공·플레이어 HP가 0이면 패배한다. R로 HP·탄약·투사체·공격·표시 상태를 초기화한다.
- 벽이 이동·대시·탄환·근접 타격을 막고, 기체와 벽을 앞뒤 순서로 표시한다.

## 조정과 출력

`combat_config.json`의 `combat`은 전투 수치, `arena`는 출현 위치·맵 경계·사각 장애물, `presentation`은 도형·투영 설정이다. 누락된 전투 수치는 `ferrial_drive/combat/config.py`의 기본값을 사용한다. 거리 단위는 월드 단위, 시간은 초다. 밸런스가 확정된 값이 아니다.

현재 보행/달리기는 300/480, 적 이동은 220 월드 단위/초다. 대시는 0.2초 동안 250, 검 사거리는 125 월드 단위다. 검 한 동작은 준비·타격·회수를 합해 0.28초다. 탄약 회복은 초당 2발에서 시작하고 회복 시작 후 경과 초를 `t`라 할 때 `2 × exp(1.6 × t)` 발/초로 가속한다. 빈 탄창은 마지막 발사 후 약 3.26초에 완충한다. 설정 변경은 테스트 창을 재실행해야 적용된다.

다른 설정 파일은 `--config 파일.json`으로 전달한다. 기본 파일은 실행 위치에 관계없이 진입점 기준으로 찾는다. 실행은 원본 JSON을 수정하지 않는다.

```text
python tests/combat_test.py --profile output/combat_prototype/timing.json
```

계측은 선택 사항이다. `--frames 180`은 종료·렌더링 확인용 표시 프레임 제한이며 게임 속도나 전투 제한시간이 아니다. 출력·계측은 `output/`에 보관한다.

구현 범위·검증 상태·남은 기능은 [전투 프로토타입 명세](../../docs/unit-tests/combat_prototype.md)를 따른다.
