# 메뉴·전투 HUD 직접 테스트

`tests/ui_test.py`가 공통 실행기의 `TestProgram` 규약으로 메뉴·전투 HUD를 연결한다. 게임·세이브·AI 생성 에셋 없이 공개 폰트와 기본 도형을 사용한다.

기존 실행기를 닫고 `tests/Unit Test Runner.lnk`로 다시 연 뒤, 같은 폴더의 **`ui_test.py`를 열린 Python GUI 창에 드롭**한다. [공통 실행기 안내](../../Tools/unit_test_runner/README.md)를 따른다.

## 포함 파일

- `ui_config.json`: 1280×720 창, 배치·문구·색·폰트 역할·버튼 동작 ID, 피해량·애니메이션 시간. `panel_style.fill_opacity`는 0.45, `colors.panel_border`는 선명해진 테두리 색이다.
- `hud_sample.json`: 가짜 HP·타겟·콤보·누적 가한 피해·레이더 상대 좌표. 파일 변경 후 `ui_test.py`를 다시 드롭해 반영한다.
- `../../data/fonts/`: 현재 UI 전체는 에스코어 드림을 사용한다. 굵기 제한은 없고, 이번·누적 피해와 콤보 숫자에는 Bold를 적용한다. 폰트와 이용 조건을 함께 보관하며 경로는 설정 파일 위치를 기준으로 해석한다.
- `../../ferrial_drive/ui/`: 표시용 데이터·입력·위젯 표현·이동·페이드·독립 피해 숫자. 게임 엔티티나 테스트 실행기를 import하지 않는다.
- `../../tests/ui_test.py`: 가짜 상태 공급·버튼·Esc 연결과 실행 규약 어댑터. 본편은 이 파일을 거치지 않고 재사용 UI 모듈에 실제 상태를 전달한다.

메뉴 좌표의 원점은 왼쪽 위이며 단위는 픽셀이다. 시간은 초다. `buttons`의 `label`은 표시명, `action`은 동작 식별자다. 현재 버튼 판정 영역은 겹치지 않아야 한다. `hit_padding`은 표시 크기와 별개다.

장면 제목의 위치는 `layout.combat_heading`(기본 `[28, 24]`), 크기는 `fonts.combat_title.size`(기본 44)로 조절한다. 전용 Bold 역할을 사용해 메뉴의 `heading` 크기와 독립적이다. 아래 설명 위치는 `layout.combat_notice`에서 조절한다.

## 직접 실행

Python 3.11과 `requirements-ui.txt`의 Pico2D 1.5.1 환경을 사용한다. GUI에 드롭하거나 프로젝트 루트에서 다음처럼 직접 실행한다.

```text
python tests/ui_test.py
```

직접 실행은 메뉴의 테스트 종료로 창을 닫고, GUI에서 실행하면 실행기 대기 화면으로 돌아온다. 창 X는 실행기 전체를 종료한다. 샘플 원본은 실행 중 저장·수정하지 않는다.

## 조작과 기대 결과

1. 최초 화면은 메뉴다. 전투 HUD 보기 또는 **Esc**로 전환한다.
2. **0.32초**의 SmoothStep 이동·페이드가 진행된다. 전환 중 Esc·좌클릭은 소비하며 완료 후 다시 받는다.
3. 플레이어 HP는 **860/1200**, 표적 A는 **540/800**으로 시작한다. 중앙 플레이어 주변의 레이더 링과 적 방향 화살표, 원+십자 크로스헤어가 표시된다. 별도 레이더 패널과 점은 없다.
   플레이어 도형은 창 크기에서 계산한 화면 중앙에 고정하며 HUD가 전환되는 동안에도 옆으로 이동하지 않는다. 플레이어 피해 숫자도 같은 위치를 기준으로 표시한다.
4. **적 피해 +120**: 적 근처에 빨간 Bold 120, 표적 HP 420/800, 오른쪽의 큰 숫자와 작은 글자로 `1 COMBO`, 누적 가한 피해 120이 표시된다. 콤보·누적 피해에는 패널이 없고, 이번 피해 숫자는 위로 이동하며 1.15초 안에 사라진다.
5. **플레이어 피해 +75**: 플레이어 근처에 빨간 75, 플레이어 HP 785/1200이 표시된다. 누적 가한 피해는 바뀌지 않는다.
6. 적 피해는 남은 HP까지만 적용한다. 표적 HP가 60일 때 누르면 빨간 60과 합계 +60으로 반영된다. HP가 0이면 해당 피해 버튼을 비활성화한다.
7. **타겟 유무**: 타겟 없음·빈 게이지를 표시하고 적 피해 버튼을 비활성화한다. 다시 누르면 이전 타겟 HP로 복원한다. 누적 가한 피해는 유지한다.
8. Esc로 메뉴에 다녀와도 HP·누적 값은 유지한다. **표시 초기화**는 JSON의 초기 상태와 콤보·합계를 복원하고 피해 숫자를 지운다.
9. 메뉴의 **테스트 종료**로 마친다.

이 값과 동작은 UI를 확인할 가짜 상태다. 샘플 콤보는 적 피해 버튼의 유효 적용 횟수이며 실제 전투·이동·발사·타겟 선택·콤보 규칙이 아니다.

상단 브랜드·UI 테스트 표시·구분선과 하단 조작 안내는 제거했다. 타겟 제목은 `TARGET`만 표시한다. 공유 UI 모듈이 바뀌므로 실행기 창을 완전히 닫고 다시 열어 확인한다.

이번 피해 숫자의 좌표는 왼쪽 위 원점의 픽셀이다. 레이더 상대 좌표는 x 양수가 오른쪽, y 양수가 위다. 샘플 감지 거리는 1.0이며 범위 안의 적 2개만 화살표로 표시한다. 범위 밖 적과 아군은 표시하지 않는다. 적 거리가 달라도 화살표는 동일한 화면 링 반경에 배치한다.

`ui_config.json`의 `radar.range_units`는 상대 좌표와 같은 거리 단위, `radius_pixels`는 화면 링 반경이다. 기본 반경은 110px이며 화살표 크기·링 투명도도 같은 설정에 있다. 실제 게임의 감지 거리와 현재 적 목록은 게임 연결부에서 제공한다.
