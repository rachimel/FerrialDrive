# UI Unit Test 샘플 준비

현재는 공통 UI 모듈과 **메뉴 렌더링 초안**까지 구현했다. 두 장면을 직접 조작하는 독립 실행 진입점과 HUD 가짜 상태값은 아직 연결하지 않았다.

게임과 독립된 공통 실행 도구와 별도의 두 화면 샘플은 [Unit Test 실행기](../../Tools/unit_test_runner/README.md)에서 실행할 수 있다. 이 UI 메뉴·HUD와의 연결은 후속 작업이다.

## 포함 파일

- `ui_config.json`: 1280×720 창, 메뉴 배치·표시 문구·색·폰트 역할·버튼 동작 ID. HUD 관련 문구는 확인 대기 중인 초안이며 동작에 연결하지 않았다.
- `../../assets/fonts/`: 지정 폰트와 이용 조건. 폰트 경로는 설정 파일의 위치를 기준으로 해석한다.
- `../../ferrial_drive/`: 재사용 애니메이션·입력·표현 모듈. import 시 창을 열지 않는다.

메뉴 좌표의 원점은 왼쪽 위이며 단위는 픽셀이다. 시간은 초다. `buttons`의 `label`은 표시명, `action`은 동작 식별자다. 현재 버튼 판정 영역은 겹치지 않아야 한다. `hit_padding`은 표시 크기와 별개다.

## 현재 가능한 확인

Python 3.11과 `requirements-ui.txt`의 Pico2D 1.5.1 환경을 사용한다. 프로젝트 루트에서 핵심 자동 검사는 다음처럼 실행한다.

```text
python -m unittest discover -s tests -v
```

이 검사는 시간 진행·버튼 판정 계약을 확인한다. 실제 UI 창의 조작 검증을 대신하지 않는다. 현재 샘플에는 게임 에셋·세이브·개인 절대 경로가 필요 없다. 샘플 원본을 수정하거나 저장하는 시연 기능은 추가하지 않았다.

## 남은 연결

HUD 표시 규칙과 전환 중 입력 정책을 확인한 뒤, 가짜 상태값·실행 진입점·조작 순서와 기대 결과를 추가한다. 현재 상태와 확인 결과는 [구현 기록](../../docs/ai-dev-log/2026-11-03-ui-unit-test-implementation.md)을 따른다.
