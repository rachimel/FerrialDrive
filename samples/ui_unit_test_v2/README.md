# ui-unit-test-v2

`concept/ui-concept-v2.png`를 바탕으로 배치와 스타일을 다듬는 독립 UI 테스트다. 도안 이미지는 실행 입력이 아니며, 샘플 도형·수치와 저장소에 배포하는 폰트만 사용한다. 기존 v1과 별도 설정을 사용한다.

## 실행

Pico2D 1.5.1이 설치된 Python 3.11 환경에서 프로젝트 루트 기준으로 실행한다.

```text
python tests/ui_unit_test_v2.py
```

Unit Test Runner에서 `tests/ui_unit_test_v2.py`를 선택하거나 Runner 창에 드롭해도 실행한다. 최초 화면은 1280×720 전투 HUD다. `Esc`로 일시정지를 열고 `타이틀로`를 누르면 타이틀 화면을 확인한다. 설정은 아직 비활성이다.

## 조절 위치

- `ui_config.json`의 `v2.layout`: 미니맵·록온·타겟 HP·플레이어 HP·에너지·필살기 아이콘·레벨·무장·카운터 배치.
- `v2.layout.hp_bar`·`energy_bar`·`ultimate_center_x`·`ultimate_radius_pixels`: 바의 높이/오른쪽 끝과 아이콘 위치·크기. 두 바의 왼쪽 경계는 마름모 변에 맞춰 계산한다. HP 안쪽 여백은 없고 수치/HP는 바 위에 자동 정렬한다.
- `v2.layout.energy_level_width_pixels`·`v2.style.level_curve_radius_pixels`: HP 옆에 붙는 레벨 영역의 폭과 곡선 강도. HP/에너지 공유 경계와 레벨 왼쪽 사선은 함께 계산한다.
- `v2.style.counters`: HIT/DAMAGE의 원근 `depth`(0~1)·기울기 `lean`/`slope`·고정 `text_scale`·원근 기준 폭 `perspective_width_pixels`·오른쪽 여백. 기준 폭은 최대 표시 폭이 아니다. 숫자를 축소하지 않고 받침판과 잔상 조각을 왼쪽으로 확장한다. 오른쪽 기준 투영은 자릿수와 무관하게 유지한다.
- `v2.style.panel_cut_pixels`·`surface_opacity`: 사선 외곽과 일반 패널의 최대 배경 불투명도 0.55. 활성/비활성·버튼 상태의 기존 투명도도 함께 적용한다.
- `v2.style.panel_border`: 기본/좌상단·우하단 두께 `thin_width_pixels`·`corner_width_pixels`는 1/5px다. `corner_hold_pixels=3`까지 최대 두께를 유지한 뒤 직선으로 가늘어진다. 일반 패널의 변화 구간은 `reach_pixels=180`이며 짧은 변에서는 길이에 맞춘다. 곡선 보간은 제거했다.
- `v2.style.panel_frame`: 통신 패널 레퍼런스 테두리·공통 면 형상. `bevel_pixels`·`corner_join_pixels`는 꺾임, `upper/lower_side_ratio`·`upper/lower_rail_ratio`는 세로/가로선 길이, `fragment_*`는 분리된 사선 조각을 조절한다. 미니맵은 테두리를 그리지 않는다.
- `v2.style.panel_scanlines`: 배경 불투명도는 맵 0.42·가이드 0.6, 선 불투명도는 맵 0.07·가이드 0.08·일반 패널 0.06이다. 4px 간격·1px 두께의 가로 패턴이 **화면 전체 좌표에서** 스크롤하고 패널 안에만 표시된다. 패널별 `line_opacity=0`으로 두 스캔 효과를 끈다. 글자·지형·표식에는 적용하지 않는다.
- `panel_scanlines.motion`: 기본 선 5px/s·밝은 띠 60px/s, 띠 높이 24px·불투명도 0.22다. 속도는 **화면 픽셀/초**이며 배율이 다른 패널도 같은 화면 높이에서 밝아진다. 밝은 띠는 현재 보이는 패널의 Y 구간만 이동하고 빈 세로 구간을 건너뛴다. 주기는 `(겹침을 합친 Y 구간 길이 + 24) / 60`이며 기본 전투 샘플에서는 약 5.66초다. 밝은 띠만 끄려면 `highlight_opacity=0`으로 둔다.
- `v2.style.panel_film_grain`: 무기·로드아웃·에너지 바 빈 배경에만 옅은 흑백 White noise를 표시한다. 불투명도 0.035·64px 화면 타일·입자 1.25px이며 seed 173의 8개 프레임을 10회/초로 반복한다. `opacity=0`으로 끈다.
- `v2.style.weapon_text_opacity=0.82`: 무기 구분·잔탄·로드아웃 번호의 활성/비활성 불투명도에 곱한다. `weapon_text_neon`은 원래 글자색과 별개인 청록 광 `#65DCC8`·가우시안 반경 4 논리 px·세기 0.12를 조절한다. 광은 흐린 마스크를 재사용하며 `glow_opacity=0`으로 끈다.
- 공통 적용 대상: 무기·로드아웃·에너지 바 빈 배경·카운터 받침판·메뉴/일시정지 패널과 버튼. HP·필살기 아이콘/단축키/보조 레벨·에너지 레벨에서는 스캔을 제외하고 투명도만 유지한다.
- `panel_border.filter_samples=2`: 공통 패널 면/테두리를 2배로 그린 뒤 선형 필터로 축소한다. 2~4의 정수를 받으며 최대 32개의 도형 텍스처를 재사용한다. 게임·Pico2D 원본은 변경하지 않는다.
- `v2.layout.dialogue`·`v2.style.dialogue_padding_pixels`: 대화창 위치·크기와 안쪽 여백. 위쪽 표적/HUD 일부를 덮는다. 게임에서는 `DialogueInfo`를 표시 상태로 공급한다.
- `v2.style.dialogue_motion`: 최초 표시·F5·D 재표시에서 중앙 세로 펼침 0.2초 후 글자를 즉시 표시한다(`text_seconds=0`). 닫을 때는 글자를 먼저 숨기고 세로 압축 0.05초·가로선 축소 0.03초·중앙점 소멸 0.02초, 총 0.1초로 종료한다. 열림/닫힘 총시간은 사용자 지정이다. `line_thickness_pixels=1.2`·`dot_width_pixels=3`은 종료 빛의 두께/최소 폭이며 세부 단계와 빛 모양은 1차 시안이다.
- 패널의 샘플 내용은 `hud_sample.json`의 조작 가이드다. 헤더는 `조작 가이드`이며 `fonts.dialogue_heading`의 24px를 사용한다. 헤더/본문 위 여백은 8px이며 `dialogue_body_role=small`·`dialogue_body_offset_pixels=28`·`dialogue_line_spacing_pixels=20`으로 4줄을 표시한다. 기존 F1 별도 안내창은 제거했다.
- 본문 문자열에서 `**R**`처럼 표시한 조작키만 볼드로 출력한다. `rich_text()`는 일반/볼드 구간을 실제 글자 폭과 같은 기준선으로 배치하고, `rich_text_size()`는 표시된 전체 폭을 반환한다. 본문 최대 폭은 볼드 적용 후 392px이며 가용 폭은 504px다. 설명과 헤더의 굵기는 유지한다. 개별 텍스트는 공통 `text(..., bold=True)`·`text_size(..., bold=True)`를 사용하며 v2의 투영/네온 텍스트도 같은 옵션을 지원한다. 별도 Bold 폰트 파일 대신 SDL_ttf 합성 볼드를 사용한다.
- 최종 배치: 미니맵 (20,20), 논리 크기 240×160·표시 배율 0.9. 대화창 (360,20), 560×130. 위쪽 여백은 같으며 패널 헤더는 `조작 가이드`다.
- `v2.layout.target_hp_offset_pixels`: 선택한 몸통 중심 기준 HP 위치. HP 폭·높이는 `target_hp`의 마지막 두 값을 사용한다.
- `v2.targeting_sample`: 샘플 획득 거리 330·우클릭 거리 460이다. 줌 없는 1:1 월드 단위를 사용하며 각도 동률 값은 자동 선택에 사용하지 않는다. `v2.auto_targeting.switch_margin_seconds=1`은 새 후보의 유지 대기다. `v2.camera`는 데드존 80px·변위 20%·최대 오프셋 120·응답 시정수 0.15초다. 본편 밸런스 확정값이 아니다.
- `v2.style.hud_scale`: 일반 전투 HUD 배율 0.81. `map_scale`·`equipment_scale`은 0.9로 미니맵·웨폰·로드아웃의 현재 크기를 유지한다. 레이더는 별도로 반경 144px와 표시 치수를 조정했다. 기체·메뉴는 조정 대상이 아니다.
- `v2.style.inactive_weapon_scale`: 비활성 무기 카드를 오른쪽 중앙 기준으로 추가 축소하는 배율 0.8. 카드의 면·외곽·무기 그림·문구를 함께 줄이며 활성 카드는 기본 크기다.
- `v2.style.resource_label_gap_pixels`·`ultimate_label_gap_pixels`: 바 위 HP 표기와 마름모 왼쪽 문구의 간격. 에너지 레벨은 오른쪽 정렬, V와 `LV. 01`은 각각 마름모 왼쪽 위/왼쪽 아래에 두고 오른쪽 끝을 맞춘다.
- `v2.layout.dash_x=870`: 대시/SPACE의 기존 가로 위치다. `v2.style.dash_icon`은 겹친 꺾쇠 2개의 크기·간격·두께와 키 안내 간격을 조절한다. `bottom_margin_pixels=12`는 글자 영역 아래 끝에서 윈도우 아래까지의 화면 픽셀 거리다. 높이와 HUD 배율을 반영해 배치하며 현재 글꼴의 실제 잉크 여백은 15px다. 비활성은 기존 불투명도 0.25를 유지한다.
- `v2.style.ultimate_label_padding_pixels`: 필살기 단축키·레벨 뒤 사선 패널의 가로/세로 안쪽 여백. 기본값은 4/2 논리 px이며 글자 크기에 맞춰 테두리 없이 면만 그린다. 필살기 LV 패널은 아래쪽이 오른쪽으로 뻗는 ＼ 방향이며 패널과 글자는 위치·투명도를 공유한다.
- 에너지 레벨 숫자는 `colors.muted`, 작은 LV 표기는 `colors.ui_accent`로 한 톤 어둡게 표시한다.
- `colors.panel_surface`: 무기 행과 필살기 단축키·레벨 패널의 면 색상(`#22343F`). 일반 패널보다 한 단계 밝게 표시하며 기존 활성/비활성 투명도를 유지한다.
- `v2.style.counter_plaque_height_pixels`·`counter_plaque_slant_pixels`: 숫자 아래 평행사변형 받침판의 두께와 사선. 색은 `colors.counter_plaque`다.
- `v2.style.lock_body_scale`·`lock_thickness_pixels`·`lock_accent_pixels`: 몸통 대비 테두리 배율과 기본/강조선 두께.
- `v2.style.lock_text_gap_pixels`·`lock_text_end_gap_pixels`: 강조선에 끝점을 맞추는 글자의 수직 간격과 끝 여백. 크기 값은 HUD 축소 전 논리 픽셀이다.
- `v2.style.weapon_outer_edge_pixels`: L자 대신 강조하는 무장 왼쪽 외곽의 두께.
- `ui_config.json`의 `colors`·`fonts`: 색상과 글꼴 역할·크기.
- `hud_sample.json`: HP·에너지·Overdrive·HIT/DAMAGE·무장, 적 3기의 고유 ID·위치·개별 HP, 대화 문구.
- 변경 뒤 Runner에서 재실행한다. 실행 중 샘플 원본을 저장하거나 수정하지 않는다.

## 샘플 조작

| 입력 | 확인할 표시 |
| --- | --- |
| 1 / 2 | 표적 / 플레이어 피해, HP 감소 효과·피해 숫자 |
| 3 / 4 | 에너지 10% 감소 / 증가·흡수 Trail |
| 5 / 6 | 에너지 레벨 / Overdrive 표기 변경 |
| 7 | 몸통 크기와 록온 테두리의 비례 비교: 1→1.5→0.75배 |
| G | 필살기 아이콘을 통과해 에너지 바로 향하는 흡수 Trail |
| 마우스 이동 | 시선 카메라 오프셋·마우스 월드 좌표 최근접 후보가 1초 유지되면 자동 선택 |
| 우클릭 유지 | 자동 획득거리 증가. 발사/탄 퍼짐은 이 샘플에 미연결 |
| T | 후보 전체 비활성/활성. 표적·대기 후보 초기화, 활성 뒤 새 후보를 1초 확인 |
| D | 조작 가이드 패널 열기/TV 종료 닫기, 위쪽 표적과 록온 부분 가림 비교 |
| C / Space | COUNTER / 대시 가능 표시 변경 |
| E / F | 활성 무기 / 로드아웃 변경 |
| F5 | 표시 초기화 |
| Esc | 일시정지 / 계속 |

도안 배치를 바로 볼 수 있도록 최초부터 98 HIT·12,004 DAMAGE·COUNTER를 표시한다. 이 값은 전투 규칙·자동 카운터 판정이 아니다. 에너지 조절·레벨·Overdrive 표기도 서로 독립적인 샘플 조작이다. V는 필살기 키 **후보 표기**이며 필살기를 발동하지 않는다. 무기 전환은 표시 상태를 바꾸며 v1의 전환 궤도 애니메이션을 복제하지 않았다.

미니맵 지형과 플레이어·적은 기본 도형이다. 최초 A는 시연용 선택이며 첫 마우스 입력 전에는 유지한다. 마우스를 움직이면 월드 좌표 최근접 후보를 자동 확인하고 1초 뒤 교체한다. R 선택은 제거했다. 기체·록온·레이더·피해 숫자는 같은 카메라로 투영하고 HUD는 고정한다. 적별 HP는 보존한다. 합의한 규칙과 연결 범위는 [자동 표적 명세](../../docs/ranged_targeting.md)를 따른다.

대화창은 표시용 샘플이다. 위쪽 적·록온·HP 위에 그려 UI 가림을 재현하며, 후보 선택은 유지한다. 실제 대화 진행·선택지·월드 장애물의 시야 차단은 포함하지 않는다.

몸통 크기는 `target_body_size_pixels`로 공급한다. 게임에서는 전체 스프라이트 경계 대신 실제 몸통의 화면 Rect를 `HudV2State.target_body`로 전달한다. 무기 카드의 위/아랫변과 01·02 번호·무기 구분·잔탄은 수평이며 입체 기울임/회전 표현은 제거했다. 사선 옆변과 비활성 카드 80% 크기는 유지한다.

## 검증

## 등장 효과 연결 지점

글자 점멸은 `v2.style.text_flicker`의 최소 불투명도 0.5·주기 `period_seconds=0.3`·감광 시간 `dim_seconds=0.15`다. 평소 밝기 0.15초와 50% 밝기 0.15초를 페이드 없이 반복한다. 수치는 시험값이며 모든 대상 글자가 같은 시간·위상을 사용한다. 호흡은 `energy_breathing`의 최소 0.65·주기 2.4초다. 각각 최소 불투명도를 1로 두면 해당 변화가 정지한다. 기존 `ScanlineVisual.elapsed_seconds`를 사용하며 글자 명도는 패널에 적용하지 않는다.

피해 숫자의 실제 펼침 설정은 `damage_popup.width_expand_seconds=0.025`·`height_expand_seconds=0.035`다. 각 등장/퇴장 0.06초이며 총 표시 시간은 유지한다. COUNTER는 `IndicatorFade`를 갱신해 `view.combat(counter_message_opacity=...)`로 공급한다. 시간은 `counter_message_motion`의 등장 0.06초·퇴장 0.05초다. 이는 HIT/DAMAGE의 숫자 자리 갱신 시간이나 록온 개폐 시간과 별개다.

HP flash는 `HealthDamageFlash.trigger(피해 전 비율, 피해 후 비율)`·`update(delta_seconds)`로 관리하고 `visuals`를 `view.combat(player_damage_flashes=..., target_damage_flashes=...)`에 공급한다. 실제 피해가 0이면 발생시키지 않는다. 상태는 실제 HP·빨간 Trail과 분리하며 샘플에서는 Trail과 함께 일시정지한다. 표적 교체와 F5는 해당 flash를 비운다. `v2.style.health_damage_flash`의 등장/유지/퇴장은 0.02/0/0.08초다. 흰 구간은 이번 실제 피해량이다. 에너지의 스캔·밝은 띠·노이즈는 `panel_layer(effect_surface=...)`로 사선 채널 마스크를 공유한다.

록온은 `LockOnMotion.select(target_id, body)`·`update(delta_seconds)`로 제어하고 `visuals`를 `view.combat(lock_visuals=...)`에 공급한다. 몸통 Rect는 카메라 투영 후 좌표다. 선택 유지 중과 퇴장 중에도 적의 월드 위치를 현재 카메라로 투영한다. 자동 선택 규칙은 `MouseAutoTargeting`, 좌표 변환은 `LookAheadCamera`가 맡는다. 새 선택 ID에서 기존 표시 퇴장과 신규 등장을 재생한다. `view.combat(player_screen=...)`는 레이더 중심을 실제 플레이어 화면 위치에 맞춘다.

`v2.style.lock_motion`은 등장 0.4초·캐럿 0.2초·퇴장 0.25초·강조선 이동 0.4초/정지 0.25초·시작 배율 0.25/퇴장 배율 1.5를 조절한다. 기본형은 정사각형이며 등장 완료 45°는 마름모다. 가이드 조작키 색/설명 투명도는 `dialogue_key_color`·`dialogue_description_opacity`다.

등장 중 취소도 역재생하지 않는다. 취소 시점의 실제 회전값/배율을 저장해 그 값부터 회전은 2배, 크기는 `exit_scale`배까지 확대하며 흐려진다. 완료 뒤 취소는 기존 45→90°·1→1.5배와 같다.

곡선 정의는 Flutter 공식 [elasticOut](https://api.flutter.dev/flutter/animation/ElasticOutCurve-class.html), [easeInOutCubicEmphasized](https://api.flutter.dev/flutter/animation/Curves/easeInOutCubicEmphasized-constant.html), [easeInOut](https://api.flutter.dev/flutter/animation/Curves/easeInOut-constant.html)를 따른다. Flutter 런타임 의존성은 추가하지 않는다.

`ferrial_drive/ui_v2/panels.py`의 `build_panel_geometry()`는 `surface`와 `border_parts`를 따로 반환한다. 테두리 ID는 `upper_corner`·`upper_rail`·`upper_fragment_0~2`, `lower_corner`·`lower_rail`·`lower_fragment_0~2`다. 면은 `panel_surface()`, 테두리는 `panel_border()`로 그린다. `part_opacities`로 각 조각을 독립 표시할 수 있다. 입력·시간·등장 순서는 형상 모듈에 넣지 않는다.

Scanline 시간은 `effects.py`의 `ScanlineMotion`이 관리한다. 같은 `visual`을 `UiV2View.combat/menu/pause(scanline_visual=...)`에 공급한다. 테스트 실행부는 일시정지 중에도 UI 시계를 갱신하고 게임 갱신만 멈춘다.

대화창은 `DialoguePanelMotion.request(opened)`·`update(delta_seconds)`로 제어하고 `visual`을 `view.combat(dialogue_visual=...)`에 공급한다. 닫힘 중에는 `DialogueInfo`를 유지하고 `phase == "closed"`가 된 뒤 제거한다. 조회와 실제 출력은 같은 표시값을 사용해 펼쳐지는 패널의 Y 구간도 밝은 띠 경로에 반영한다. 글자를 압축하지 않고 완성 뒤 표시하며, 다른 패널의 개폐와 테두리 조각별 순차 등장은 후속 범위다.

프레임 출력 전에 `view.prepare_panel_effects(draw_panels)`로 그릴 UI를 한 번 조회한다. 이 단계는 도형을 출력하지 않고 보이는 패널의 Y 구간을 수집하므로 콜백 안에서 입력·시간·게임 상태를 갱신하지 않는다. 실제 출력과 같은 레이아웃·배율·clip을 사용하며 등장/퇴장 중인 패널도 반영한다.
