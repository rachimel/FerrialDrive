# FDrive Pose Tool

Asset Tool 안에서 기존 리그의 포즈를 직접 편집한다. Blender는 창을 열지 않고 IK 계산과 Workbench 미리보기 생성만 수행한다. 기존 `animation_pipeline.py`의 출력 계약을 재사용한다. Blender 전용 패널도 독립 실행 경로로 유지한다. 별도 플러그인 설치나 사용자 설정 변경은 필요 없다.

## Asset Tool에서 편집

Asset Tool 상단의 **포즈 편집** 또는 3D 렌더 설정의 **포즈 편집**을 누른다. 모델/작업본을 찾은 뒤 **모델 / 작업본 열기**를 누른다. 실제 에셋이 없으면 **도형 샘플**을 사용한다.

```powershell
python Tools/asset_loader/run.py --pose
python Tools/asset_loader/run.py 모델.blend --pose
python Tools/asset_loader/run.py --pose-sample
```

왼쪽 **파츠** 탭에서 몸체·IK / 손가락 / 총·칼·칼집 / 기타 파츠를 선택한다. 검색창으로 이름을 좁힌다. **동작** 탭에는 기존 동작 목록이 표시된다. 손잡이는 손바닥 중앙에 있으며 내부 손목 목표와 분리한다. 기존 손목 작업본을 열면 컨트롤 키를 옮겨 기존 자세를 보존한다.

중앙 손잡이를 끌면 현재 시점의 평면 안에서 이동한다. 색상으로 구분한 X/Y/Z 화살표를 끌면 **월드 축 하나로만 이동**한다. 오른쪽 **월드 이동 / 월드 회전**을 선택하고 축별 화살표를 누르면 입력한 이동량·회전각만큼 조절한다. 정면/측면/위 시점으로 바꿔 깊이를 확인한다. 손목 볼은 손의 회전을 함께 따라간다.

손이나 손가락을 고르면 손가락 굽힘/펴기 조작이 나타난다. 손 전체, 특정 손가락, 특정 관절을 지정한다. 손가락 관절을 목록에서 직접 선택하면 해당 관절이 기본 대상이 된다. 굽힘 단축 조작은 모델의 로컬 굽힘 축을 사용하며 일반 X/Y/Z 회전은 월드 축을 사용한다. 연결된 손가락의 평행이동은 거부하고 회전으로 조절한다.

총은 한 조립 파츠, 칼과 칼집은 각각 별도 파츠다. 편집 작업본에서 본체/손과 자동 부착을 해제하고 프레임별 기존 월드 배치를 보존한다. **칼 → 칼집 자동 정렬**은 제작된 수납 기준점 `Sword_StowAnchor`와 칼집 좌표 관계로 현재 프레임의 칼을 한 번 정렬한다. 정렬 후에도 독립 파츠이며 칼집에 부모로 연결하지 않는다. 자동 인출 모션이나 충돌 없는 삽입 경로를 생성하지 않는다. 이전의 수납/파지 전환·보조손 고정·고정 본 선택 버튼은 내부 편집 화면에서 제거했다.

**이전 프레임 파츠 복제**는 선택한 파츠만 현재 프레임으로 복사한다. 몸체 컨트롤과 독립 무기는 월드 배치, 손가락은 손에 대한 로컬 자세를 복사한다. 손 전체를 선택하면 손가락 자세도 함께 복사한다. 이전 프레임이 다른 동작에 속해도 복사하며, 이전 프레임이 없으면 안내한다.

**Ctrl+Z** 또는 **되돌리기**로 이동·회전·손가락·복제·자동 정렬을 되돌린다. 한 번의 드래그는 한 단계다. 현재 세션에서 최대 48단계이며 작업본을 다시 열면 이력은 초기화된다. 저장/출력 뒤에도 메모리 이력은 유지한다. 되돌린 상태를 파일에 반영하려면 다시 저장한다.

현재 포즈 키를 저장한 뒤 프레임/동작을 변경한다. **작업본 저장**은 현재 키까지 저장하며, 저장 경로는 화면 하단에 표시한다. 상단 입력창은 선택한 모델 경로를 유지하며, 제목에는 현재 연 파일명이 표시된다. 찾기에서 파일을 열면 해당 파일을 바로 읽는다. 다른 모델을 선택하면 이전 세션보다 새 선택을 우선하며, 미저장 편집이 있으면 저장 안내를 표시하고 기존 작업을 보존한다. 패널을 닫았다 열어도 같은 모델에서는 작업자가 유지된다. 앱 종료 전에 파일을 저장한다. 편집 중인 임시 키는 작업자 메모리에만 존재하며 파일 저장과 구분한다.

팔꿈치·무릎 손잡이는 평가된 실제 관절 위치에 마름모로 표시한다. 내부 IK 방향 제어점은 관절과 떨어진 위치에 유지하되 화면에는 별도 노드로 표시하지 않는다. 관절 위 손잡이를 끌면 손/발 목표를 유지하며 굽힘 방향을 회전한다. 짧은 선은 현재 방향을 나타낸다. 관절이 완전히 펴져 있으면 골반이나 손/발 위치를 조절해 먼저 굽힘을 만든다.

**동작 출력 → 출력 → 3D 렌더** 순서로 현재 동작을 기존 프리렌더 설정으로 전달한다. 신규 출력 기본 크기는 240×240이다. 출력 자체는 기존 리그로 굽는 단계이며 게임 이미지 렌더는 기존 렌더 시작 버튼으로 수행한다.

미리보기는 비동기 Workbench 이미지이므로 손을 움직이는 동안 연속 3D 렌더와 같은 응답성을 보장하지 않는다. 확인한 로컬 메카에서 변경 후 미리보기 응답은 약 0.4초였다. 일반 성능 기준은 아니며 모델·장비·해상도에 따라 달라진다. 현재 시점은 사선/정면/측면/후면/위의 고정 시점을 제공한다.

독립 화면 검사: `python tests/pose_tool_test.py`. 실제 메카의 드래그→키 저장→파일 저장→동작 출력→렌더 설정 전달을 실제 Pico2D/OpenGL 창에서 검사하고 캡처했다. 작업자 저장·출력·재개와 기존 35개 동작의 손바닥 컨트롤 이전도 별도로 확인했다.

## Blender 패널 독립 실행

`run_pose_tool.cmd`를 실행한다. 현재 로컬 메카 동작 파일이 있으면 해당 파일을 읽고, 없으면 기본 도형 샘플을 만든다. 원본은 보존하고 `workspace/<실행시각>/pose_work.blend`를 생성한다. Blender 5.2.3 LTS에서 확인했다.

```powershell
python Tools/pose_tool/run.py
python Tools/pose_tool/run.py --sample
python Tools/pose_tool/run.py 모델.blend --profile 매핑.json
```

작업을 재개할 때는 저장한 작업본을 실행기에 전달한다. 같은 파일을 계속 사용하려면 `--work`에도 같은 경로를 지정한다. 파일만 Blender에서 직접 열면 포즈·컨트롤은 유지되지만 전용 패널은 등록되지 않는다.

```powershell
python Tools/pose_tool/run.py 작업본.blend --work 작업본.blend
```

## 편집

1. 오른쪽 사이드바의 **Pose Tool** 탭을 연다. 탭이 안 보이면 뷰포트에서 `N`을 누른다.
2. 동작을 선택하고 **선택 동작 열기**를 누른다. 처음 읽는 동작은 편집 컨트롤을 생성하므로 잠시 기다린다. 이미 연 동작은 저장한 편집값을 사용한다.
3. 손·발·골반·몸통·어깨 버튼으로 컨트롤을 선택한다. `G`로 이동하고 `R`로 회전한다. `X/Y/Z`로 축을 제한한다. 팔꿈치·무릎 컨트롤은 굽힘 방향을 조절한다.
4. 발은 골반과 독립적으로 움직인다. 골반을 낮춰도 해당 프레임의 발 목표를 유지한다. **발 위치 고정 키**는 현재 프레임의 발 목표만 기록한다.
5. **현재 프레임 포즈 키 저장**으로 편집을 키에 기록한 뒤 **작업본 저장**으로 파일을 저장한다. 프레임/동작을 바꾸기 전에 키를 저장한다. 저장하지 않은 프레임의 변환은 Blender 재생 시 기존 키 값으로 돌아간다.

좌우는 기체 기준이다. 현재 모델은 +X 전방/+Z 상방이며 대칭축은 Y다. 좌우 복사와 전체 반전은 몸통·팔다리 컨트롤에 적용한다. 손가락/무기 장치/이벤트의 좌우 변경은 포함하지 않는다. 반전 시 보조손 고정은 해제한다.

무기 수납 값은 기존 장비 속성에 연결한다. 버튼은 순간적인 수납/파지 상태를 바꾸며, 연속 발도·수납 경로를 생성하지 않는다. **보조손 고정**은 현재 양손 간격을 주 손 기준으로 유지하는 편집 보조다. 자동으로 총 손잡이를 찾거나 손가락을 파지시키지 않는다. 해제한 자세를 유지하려면 현재 포즈 키를 저장한다.

## 출력

**현재 동작 출력**에서 존재하지 않는 새 폴더를 선택한다. 키 저장 후 사용한다.

- `poses.json`: 기존 애니메이션 파이프라인용 포즈 표본과 이벤트.
- `base.blend`: 원본 리그의 중복 제약을 뮤트한 출력용 기반 사본.
- `baked/animations.blend`: 편집 컨트롤 없이도 원래 리그로 재생할 수 있는 출력.
- `baked/clips.json`, `baked/export_configs/`: 기존 Asset Tool 프리렌더 경로용 정보.

출력 후 편집 작업본으로 돌아온다. 게임 프리렌더·이미지 패킹은 별도 단계다. 현재 출력은 선택한 동작 하나이며 전체 동작 병합 기능은 제공하지 않는다.

## 구조와 범위

| 파일 | 책임 |
| --- | --- |
| `profile.py` | 본 이름 매핑, 동작 범위, 이벤트 프레임 해석. Blender 미의존 |
| `scene.py` | 편집용 리그, 컨트롤, 원본 리그 결과 전달, 동작별 Action 보관, 저장/출력 |
| `addon.py` | Blender 패널과 사용자 명령 |
| `bootstrap.py` | 별도 Blender에서 모델/작업본 준비와 패널 등록 |
| `run.py` | Blender 탐색과 프로세스 실행 |
| `worker.py` | 비표시 Blender의 포즈 명령·미리보기·저장·출력 |
| `session.py` | 비동기 작업자 프로세스·순차 명령·드래그 요청 병합·수명 |
| `part_editing.py` | 손–볼 연결·손가락·독립 무기·이전 프레임 복제·칼집 정렬 |
| `history.py` | 변환과 Action 키를 함께 복구하는 세션 Undo |
| `../asset_loader/pose_panel.py` | Asset Tool 안의 모델 표시·손잡이·동작·저장·렌더 전달 |
| `../asset_loader/pose_controls.py` | 파츠 목록·선택별 버튼·월드 축 화살표 |

매핑은 `default_profile()`의 JSON 구조를 따른다. upper/lower는 직접 연결된 두 본이어야 하며 end의 원점은 lower의 끝과 맞아야 한다. rest 본/웨이트/메시를 수정하지 않는다. 원본 파일 해시를 기록하고 같은 원본 경로로 작업본 저장을 거부한다.

검사: 기본 도형의 IK·발 고정·좌우 복사·보조손 고정·동작 전환·저장/재로딩·출력, 로컬 메카 35개 동작의 시작/중간/끝 불러오기 비교, 실제 창의 손 이동/팔꿈치 추종/키 저장/파일 저장을 확인했다. 전체 연속 간섭, 무기 핏, 관절 가동 한계, 사용자 최종 사용감 승인은 별도다. 도달 불가 목표는 IK가 길이를 늘리지 않고 가까운 자세를 사용하며 패널에 표시한다.

파츠 확장 검사는 `tests/blender/check_pose_parts.py`, 실제 창 조작은 `tests/pose_parts_test.py`를 사용한다. 독립 무기를 내보내면 렌더 설정의 `extra_root_objects`에 포함해 본체와 함께 방향을 회전시킨다. 출력은 별도 Blender 프로세스에서 굽고 편집 작업자의 객체/Undo 참조를 유지한다.

```powershell
& $blender_exe --background --factory-startup --python-exit-code 1 --python tests/blender/test_pose_tool.py
& $blender_exe --background --factory-startup --python-exit-code 1 --python tests/blender/check_pose_tool_asset.py -- --source 모델.blend --output 새검사폴더
& $blender_exe --background --factory-startup --python-exit-code 1 --python tests/blender/check_pose_tool_export.py -- --work 작업본.blend --clip 동작이름 --output 새출력폴더
```

외부 코드/에셋을 추가하지 않았다. Blender 네이티브 IK와 기존 프로젝트 파이프라인을 재사용하며, [Action 슬롯 공식 문서](https://docs.blender.org/api/5.0/bpy.types.ActionSlot.html)의 슬롯 기반 API를 따른다. 도형 샘플은 직접 작성한 수치와 기본 큐브만 사용한다.
