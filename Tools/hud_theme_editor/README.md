# HUD 테마 편집기

외부 창에서 팔레트와 위젯별 색 연결을 편집한다. 툴 내부에 실제 Pico2D HUD를 표시하며 편집한 색을 바로 반영한다.

## 실행

프로젝트 루트에서 `python automate/run.py hud-theme`로 실행한다. 현재 프로젝트의 Python 환경은 `.venv-capability-test`다. Windows용 `HUD 테마 편집기.lnk`도 사용할 수 있다.

Python의 Tkinter, Pico2D와 Pillow가 필요하다. 도구 색·글꼴은 `Tools/theme_reference/theme.json`을 읽는다. 게임 모듈은 도구 모듈을 import하지 않는다.

## 사용

1. 왼쪽 **색상 그리드**에서 색을 선택한다. 아래에 전체 이름과 내장 컬러피커가 표시된다. 색면은 채도·명도, 세로 무지개 띠는 색상, RGB·HEX는 정밀 입력이다. 칩에 마우스를 올리면 전체 이름·HEX를 확인하며 방향키로 이동한다.
2. 오른쪽 큰 미리보기에서 선택 색의 **적용 부위 테두리·이름**을 확인한다. 아래 사용처 버튼의 **●**는 현재 프레임에 그려진 연결 부위다. 부위 버튼이나 강조 영역을 클릭하면 해당 부위·색 역할을 선택한다. 현재 장면에 없는 부위는 해당 상태로 바꿔 확인한다.
3. **편집 부위 → 색 역할 → 연결 색**으로 연결을 편집한다. **선택 색 연결**은 왼쪽에서 고른 색을 해당 역할에 연결한다. **Fallback**은 해당 연결을 해제한다. 개별 연결이 없으면 전체 기본값, 전체 기본값도 없으면 원래 HUD 설정의 해당 역할 색을 사용한다. 같은 팔레트 색을 수정하면 연결된 모든 부위가 함께 바뀐다.
4. HUD·메뉴·일시정지·명중·피격·Overdrive·무장 전환·대화로 상태를 바꾼다. **선택 부위 확대**는 현재 렌더링한 부위 범위를 잘라 확대한다. 선택 부위가 없는 장면은 전체 화면을 유지한다.
5. **저장·게임 적용**을 누르면 현재 테마 파일과 `data/settings/hud_theme.json`에 저장한다. 실행 중인 훈련장도 갱신한다. **다른 이름으로 저장**은 사본만 저장한다.

팔레트 추가·이름 변경·삭제, 파일 열기와 편집 되돌리기를 지원한다. **기본색·연결 중인 색·마지막 색도 삭제할 수 있다.** 삭제한 색의 모든 연결은 해제하여 Fallback으로 전환한다. 팔레트를 전부 비워도 저장·불러오기·미리보기가 가능하며 기본색 목록을 자동으로 다시 채우지 않는다. 삭제된 역할은 편집 목록에 유지한다.

Fallback 선택 시 피커에는 해당 역할의 기본색을 표시한다. 피커로 수정하면 부위용 사용자 색을 만들어 현재 역할에 연결한다. 기본색 원본을 덮어쓰지 않는다. Fallback의 미리보기 강조는 선택한 부위·역할만 표시한다. 에너지 레벨의 Trail 색과 Overdrive 상태색은 테마와 분리한다. PNG 아이콘은 원래 명암을 유지하며 선택한 밝은 글자색으로 조절한다.

## 미리보기와 파일

- 기본 미리보기는 게임 에셋 없는 공개 도형이다. **실제 게임 에셋 사용**을 켜고 다시 시작하면 로컬 기체·아이콘을 사용한다.
- 최초 공개 시연 준비: `python automate/run.py trail-texture --demo`. 공개 입력과 확인 사항은 [샘플 안내](../../samples/hud_theme_editor/README.md)를 따른다.
- 미리보기 프로세스는 기존 `tests/sword_movement_test.py`와 실제 HUD 렌더러를 재사용한다. 별도 SDL 창은 숨기고 원본 해상도 PNG(기본 1920×1080)와 팔레트 출처·화면 범위 JSON을 0.2초 간격으로 전달한다. 실제 배율·이동·clip을 적용한 부위별 그리기 범위를 안내하며 픽셀 단위 선택 마스크가 아니다. 플레이 FPS나 정밀 애니메이션 검수용 실시간 화면과 구분한다.
- 작업본·시연 설정·요청은 `Tools/hud_theme_editor/workspace/`, 재생성 가능한 화면·로그·보고는 `output/hud_theme_editor/`에 둔다. 두 경로는 Git 제외 대상이다.
- 실제 게임은 기본 `data/settings/hud_theme.json`, 미리보기는 `--theme-file`로 지정한 별도 파일을 읽는다. 잘못된 파일은 마지막 정상 색을 유지한다. 저장은 임시 파일 교체 방식이다.
- 29개 기본 팔레트와 14개 위젯 범위를 제공한다. 모든 색 역할이 모든 위젯에서 쓰이는 것은 아니다. 해당 위젯이 그리는 역할에 연결한다.

## 확인

`python automate/run.py hud-theme --self-check`는 파일 구조만 확인한다. `--verify output/verification/원하는폴더`는 실제 HUD의 색 변화·그리드 선택·부위 확대·연결·Fallback 복원·내장 피커·기본색/마지막 색 삭제·빈 팔레트·배치를 확인하고 `verification.json`, HUD 프레임과 별도 테마를 저장한다. 검증 작업본·미리보기 출력은 지정한 검증 폴더의 `workspace/`와 `runtime/`로 분리하여 일반 편집기와 공유하지 않는다. 편집기 캡처가 검거나 실패하면 `editor_capture_valid=false`로 구분한다. 실제 게임 설정은 덮어쓰지 않는다. 편집기 자체 함수 호출 검사·화면 확인·사용자의 직접 조작과 색감 승인은 구분한다.
