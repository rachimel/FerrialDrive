# 대화 기록

프로젝트의 Markdown 요약을 대화형 화면으로 읽고 누락 필드를 직접 보완한다. 원시 채팅 원문이나 게임 코드를 읽거나 실행하지 않는다. 프로젝트 루트의 **대화 기록.lnk**에서 연다. 링크 위치나 작업 폴더와 관계없이 프로젝트 `docs/ai-dev-log/`를 연다.

## 사용

- 왼쪽: 검색, 전체/누락 필터, 기록 선택. 날짜가 같으면 확인한 사용자 발언 시각으로 정렬한다.
- 가운데: 사용자·AI·기록 필터, 말풍선 요약, 이전 형식 기록 열람. **요약을 실제 원문 발언처럼 재구성한 화면이 아니다.** `요약 · 원문 연결`과 `사용자 보완`을 구분한다.
- 오른쪽: 누락 필드 선택 → 사용자 회고/원문 확인 선택 → 보완 내용 입력 → 적용.
- 누락 필드를 클릭하면 가운데 필터를 전체 요약으로 바꾸고 해당 태그로 이동한다. 머리말의 누락도 기록 정보 말풍선에 표시한다. 모든 누락은 강조색·밑줄, 선택한 누락은 밝은 배경으로 구분하며 줄바꿈돼도 같은 필드로 추적한다. 오른쪽의 중복 설명 대신 보완 입력칸을 넓혔다.
- `원문 확인`이면 근거·원문 위치를 입력한다. 이는 사용자의 확인 표시이며 자동 원문 검증이 아니다.
- Codex 근거는 대화 ID·UTC 시각·발언자·짧은 원문 인용을 함께 입력한다. 턴/메시지 ID를 알면 추가한다. [작성 예와 확인 범위](../../docs/tool-usage/conversation_log_evidence.md)를 따른다. Codex 기록 자동 연결은 아직 없다.
- 시각 항목은 당시 시각도 입력한다. `YYYY-MM-DD`, `YYYY-MM-DD HH:MM`, `YYYY-MM-DD HH:MM:SS`를 지원한다. 날짜만 입력하면 자정 시각을 만들어 넣지 않는다.
- `적용`은 선택한 누락 하나를 보완하고 Markdown·MISSING_INDEX.md를 함께 갱신한다. 원기록 영역은 보존한다. 입력 출처·보완 시각·당시 시각을 따로 남긴다.
- `마지막 보완 취소`는 선택 기록의 마지막 보완을 취소한다. 다른 기록의 보완은 유지하고 인덱스를 현재 상태로 다시 만든다. 프로그램을 다시 열어도 이력을 이용한다.
- 휠은 포인터가 있는 목록/대화/누락 목록을 스크롤한다. F5는 새로고침, Tab은 입력창 이동, Ctrl+Enter는 적용이다. Ctrl+A/C/X/V와 방향키·Home/End·Backspace/Delete를 지원한다.

입력은 적용 전까지 문서를 바꾸지 않는다. 기록/필드를 옮겨도 임시 입력을 유지하고 종료 시 로컬 workspace/drafts.json에 보관한다. 외부에서 바뀐 파일은 덮어쓰지 않고 새로고침을 요청한다. 저장/되돌리기 이력은 `workspace/history/`에만 두며 Git에 올리지 않는다. Markdown의 보완 내용은 프로젝트 문서에 남는다.

## 실행 환경

Python 3.11 이상·Pico2D 1.5.1과 기존 SDL 환경을 사용한다. 이번 도구에 새 패키지는 추가하지 않는다. 창·기본 이벤트는 기존 실행기 어댑터를 재사용하며 실행기 GUI나 게임 모듈을 import하지 않는다. 같은 프로젝트의 `theme_reference/`, `unit_test_runner/` 공통 모듈이 필요하다.

```text
python Tools/conversation_log_viewer/run.py
python Tools/conversation_log_viewer/create_launcher.py
python Tools/conversation_log_viewer/run.py --demo
```

`--demo`는 공개 샘플을 `workspace/demo_logs/`로 한 번 복사한다. 원본 샘플과 실제 개발 로그는 수정하지 않는다. `--logs`와 `--workspace`로 별도 로그/로컬 이력 폴더를 지정할 수도 있다.

`--frames N`·`--screenshot 경로`·`--select 파일명`은 자동 실행/렌더링 확인용이다. 실제 실행 화면과 검증 결과는 [개발 기록](../../docs/ai-dev-log/README.md)에 구분한다.

## 테마

[공통 기준](../../docs/theme_reference.md)의 JSON을 Unit Test Runner와 함께 읽는다. 제목은 Cafe24 써라운드 일반형, 본문·보조 문구는 에스코어 드림 Regular다. 폰트 파일은 프로젝트 공개 OTF를 읽고, 툴만 복사한 경우에는 Pico2D 기본 폰트를 사용한다.

실제 키보드 한글 조합 입력·클립보드·긴 문서 탐색의 사용감은 직접 확인 전이다. 자동 검사와 합성 입력 이벤트 확인을 실제 창 조작 완료로 취급하지 않는다.
