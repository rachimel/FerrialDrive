# 도구 공통 테마

`theme.json`이 도구 공통 색상·글꼴·여백의 기준이다. `load_theme()`로 읽고 `rgb()`로 SDL 색상값을 구한다. 게임 코드는 import하지 않는다.

현재 적용 도구는 Unit Test Runner와 대화 기록이다. 기존 표정 스튜디오의 외형은 이번에 바꾸지 않았다. 게임 UI는 별도 표현 설정을 유지하며 같은 기준색을 사용한다.

역할과 적용 원칙은 [theme_reference](../../docs/theme_reference.md)를 따른다. 공통 값 변경 후 두 도구를 다시 열어 확인한다. 도구 폴더를 따로 복사할 때 이 폴더도 함께 복사한다.
