# UI 작업 정리

기준일: 2026-11-03, 한국 시간. 세부 동작은 [UI 명세](ui_unit_test.md), 실행·조작은 [샘플 안내](../../samples/ui_unit_test/README.md), 변경 과정은 [개발 로그](../ai-dev-log/README.md)를 따른다.

현재 UI Unit Test는 사용자 승인을 받았다. 승인된 표현을 유지하며 반복 계산·객체 생성·렌더링 상태 설정을 줄이는 최종 정리를 반영했다. 정리 후 실행·성능 측정은 별도 확인이 필요하다.

## 목적

Unit Test는 기능을 독립 실행해 직접 조작·시각 확인하고, 다듬은 모듈을 본편에 연결하기 위한 작은 테스트 프로그램이다. 자동 검사와 수동 조작은 검증 방식으로 구분한다. 본편은 테스트 실행부나 가짜 데이터를 거치지 않고 재사용 모듈에 실제 상태·이벤트를 공급한다.

## 현재 상태

| 범위 | 현재 결과 | 남은 일 |
| --- | --- | --- |
| 전투 HUD | 사용자 결정으로 UI 시안 마감 | 실제 전투 상태·카메라 좌표 연결 |
| HIT·DAMAGE | 적중 시 표시, 자리별 밀기·페이드·방향성 블러, 완전 숨김 뒤 0으로 초기화 | 실제 적중 이벤트 연결 |

| HP | 공격 반대편 플레이어 세로 바, 타겟 가로 바, 빨간 감소 구간 t² 가속 | 실제 HP·공격 방향·타겟 전환 연결 |

| 크로스헤어 | 흰색 원 3px·십자 2px, 전환·일시정지 중에도 위치 갱신 | 실제 입력 연결 |
| 타이틀 | 현 UI 승인, 전투 HUD 보기·설정·테스트 종료 | 실제 게임 메뉴 기능 연결 |
| 일시정지 | 현 UI 승인, 계속·설정·타이틀로·테스트 종료, 전투 효과 정지·재개 | 게임의 장면·종료 동작 연결 |
| 설정 | 타이틀·일시정지 양쪽에 비활성 버튼 배치 | 설정 항목·저장·적용 동작 결정과 구현 |
| Runner | 별도 자식 프로세스 실행·교체·종료, 오류 요약, 기존 규약 호환 | 최신 구조의 실행·재드롭·종료 확인 |

훈련 표적 A는 고정 샘플이며 조준에 따른 선택·전환·적중 판정은 없다. 플레이어·훈련 표적 도형과 기체 아래 이름표·하단 조작 버튼은 테스트 전용이다. 본편 메인 컬러는 [PRE-PRD 5.6절](../Ferrial_Drive_PRE_PRD_v0.1.md)의 **Pantone 20-0011 TPM Bezel**을 레퍼런스로 정했다. 회색 기반 쿨톤 청회색 방향이며 게임용 HEX/RGB 값·세부 팔레트는 미정이다. 실제 씬·UI 적용은 3D 프리렌더 씬 제작 뒤의 별도 과제다.

게임 연결부 → 표시 데이터·효과 상태 → UI 뷰 → 렌더러 방향으로 연결한다. Runner는 게임·테스트 코드를 부모 GUI에 import하지 않는다. UI 테스트는 Runner 없이 직접 실행하며 실제 게임은 샘플 실행부를 import하지 않는다.

## 확인 상태와 실행 조건

- 사용자 결정으로 현재 UI Unit Test를 승인했다. 이후 코드 정리는 글자 측정·링 계산의 제한된 캐시, 동일 색상 상태 설정 감소, 변하지 않은 상태·버튼 객체 재사용, 고정 설정의 초기 검증에 한정했다. 실제 속도 개선 수치와 화면 동일성을 확인한 것은 아니다.
- 최근 작업의 자동 검사·프로그램 실행·렌더링은 수행하지 않았다. 준비한 자동 검사 파일은 통과 결과가 아니다. 정리 과정에서는 소스·설정·문서·변경 파일을 읽어 대조하고 커밋 전 공백 오류를 확인했다. 라이선스 PDF 2개는 바이너리로 관리하며 원본과 Git 스테이징의 바이트 일치도 확인했다.
- Python 3.11·`requirements-ui.txt`의 Pico2D가 필요하다. 현재 사용하는 [역할별 폰트](../../data/fonts/README.md)는 모두 Git에 포함한다. Cafe24 2종·학교안심 운동장의 OTF와 폰트별 저작권 고지·OFL 전문을 추가했으며, Cafe24 공식 라이선스 PDF는 `docs/licenses/`에 유지한다. 사용하지 않는 TTF·패키지 ZIP은 제외한다.
- 실행 확인은 메뉴·설정 비활성 클릭·일시정지·크로스헤어·카운터 만료와 재적중·연속 피격·레이더 경계·Runner 재드롭/종료 순서로 진행한다.

## 다음 작업

1. 승인 후 정리 버전의 화면·입력·수명 동작을 확인한다. FPS·CPU/GPU 병목은 실행 환경에서 별도로 측정한다.
2. 설정 항목·기능을 사용자가 정한 뒤 구현한다. 현재 비활성 설정 버튼에 임의 옵션을 넣지 않는다. OpenGL 렌더러 연결의 독립 검증은 별도 과제다.
3. 실제 전투 연결을 시작할 때 타겟 선택·적중·HP 이벤트와 카메라 투영 좌표를 전달한다.

## 커밋 범위

기존 UI 정리는 실행기 분리, 전투 HUD·일시정지 구현, 문서 정리로 나눠 커밋했고 사용자 요청으로 원격 main에 반영했다. 후속 폰트 업데이트는 기존 깍두기 도면체 4개 파일 삭제와 현재 사용 중인 Cafe24 2종·학교안심 운동장 OTF 및 이용 조건을 포함해 별도 커밋·push한다. 생성물·개인 경로가 든 바로가기는 제외한다.

- `cdded3d`: 테스트 실행기를 별도 프로세스 실행으로 분리
- `75b3a74`: 전투 HUD 시안과 일시정지 UI를 정리
- `0c09f4d`: UI 작업 상태와 개발 기록을 정리
- 사용자 승인 후의 반복 비용·코드 정리는 후속 커밋으로 기록한다.
- `54c96b6`: 승인된 UI의 반복 렌더링 비용과 상태 갱신을 정리

## 선택적 실측 도구

후속 요청으로 게임·테스트 공통 `TimingRecorder`와 반복 벤치마크·JSON 로그를 준비했다. UI는 `--profile` 선택 실행에서만 연결한다. 모듈·UI 연결·최소 예제·자동 검사 파일은 실행 전이며, 구현한 계측 경로를 실제 수집 결과로 표시하지 않는다. 사용법과 해석은 [공통 계측 안내](../tool-usage/performance_timing.md)를 따른다.

## 후속 패널 색상 시연

사용자 요청으로 타이틀·타겟·일시정지 패널 채움에 Bezel 화면용 근사색 `#39444A`를 임시 적용한다. `colors.panel_surface`로 버튼·임시 기체 색과 분리하고 기존 알파를 유지한다. 참고 이미지에 맞춰 반사 띠·가로 결을 제거하고 아래쪽 중심에서 넓게 퍼지는 부드러운 방사형 그라데이션을 저장해 재사용한다. Pantone 공식 디지털 값·본편 최종 팔레트·실제 조명 기반 금속 재질의 확정과 구분한다. 실행·화면 확인은 수행하지 않았다.

## 후속 카운터 배치 시안

사용자 정정에 따라 HIT 숫자는 76px로 복원하고 HIT·DAMAGE 레이블을 18px로 조정한다. 레이블은 숫자 아래 3px 간격으로 좁히고 추가 자간은 5px로 넓힌다. 숫자·레이블의 오른쪽 끝과 카운터 묶음 사이 8px 여백의 중심 높이(360px)를 유지한다. 갱신 효과·표시 수명·초기화 규칙은 그대로이며 새 배치는 사용자 화면 확인 전이다.

## 후속 스틸 블루 배색

UI 포인트·일반 레이블·패널 테두리는 스틸 블루 `#91AEBB`로 맞춘다. 패널의 Bezel 바탕·방사형 명암을 유지하며, HUD 하단 테스트 버튼은 Bezel·타이틀과 일시정지 메뉴 버튼은 스틸 블루로 구분한다. 메뉴 버튼 위 글자는 짙은 청회색이다. UI 강조용 `ui_accent`를 별도로 두어 전투 숫자·HP·피해·레이더의 기존 상태색은 유지한다. 설정·뷰·문서는 반영했고 실행·화면 확인은 수행하지 않았다.

## 후속 폰트 배포 정리

현재 설정의 서로 다른 폰트 6개 경로가 모두 존재함을 확인했다. Cafe24 2종 OTF·라이선스 PDF는 공식 패키지와 일치하고, 새 폰트 3종의 저작권 정보·재배포 조건·OFL 전문을 보관한다. 폰트 바이너리·역할·크기는 변경하지 않고 누락된 저장소 배포만 맞춘다. 파일 대조와 Git 범위 검사는 수행했으며 UI 실행·렌더링은 수행하지 않았다.

## 후속 레이더 가독성 조정

화살표 기준 밑변 폭 60px·최소 자체 알파 0.25→0.3을 적용하고 높이·거리별 크기 감소를 유지한다. 최종 반지름은 플레이어 시선 고정 상태에서 주변 형체·표식 방향을 안정적으로 구분하는 최대 실용 범위로 평가한다. 200px는 임시 유지하며 최종값·통과 기준은 미정이다. 현재 변경은 실행·화면 확인 전이며 시선·인지 성능을 실측한 결과가 아니다.
