# UI Unit Test v2

- 무기 카드는 [무기 카드 v2 표시 규격](weapon_card.md)을 따른다. 기본 속성은 하단 띠 안의 큰 배경 글자, 추가 속성은 작은 아이콘이다. 굵은 아래 선 끝과 가는 위 선 시작을 띠 윗선에서 붙이고, 원의 오른쪽 끝은 가는 사선 중점에서 왼쪽으로 12px 띄운다. 장비 배율 1.0·원본 카드 420×132px·원 80px와 역할별 글꼴 원본 크기를 사용한다. 속성별 색은 미정이며 기존 공통색으로 비교한다.

- 플레이어 피격 시 HP·에너지·LV·필살기 아이콘과 부착 문구를 한 레이어로 그려 약한 중심형 모션 블러를 한 번 적용한다. `v2.style.resource_hit_blur`는 셔터 0.008초·최대 3 화면 px·세기 0.22·33샘플·영역 여백 8 논리 px다. 속도가 낮아지면 길이·세기도 줄며 방향 전환 끝점에서는 필터를 건너뛴다. HP 개별 블러는 제거했으며 대시·록온·흡수 입자는 이 필터 밖이다.

- 카운터 블러는 `counter_motion_blur.forward_bias=1`로 이동 방향 쪽에 치우쳐 표시한다. 기본 여백은 사방 48px이며 편향을 반영한 전체 번짐 길이+8px까지 자동으로 넓힌다. 최대 길이는 128px·이동량 배율은 1.3이다. 노출 0.06초·전환 0.18초는 유지한다. 로드아웃·무기·HP 블러는 기본 `forward_bias=0`의 중심형을 유지한다.

- 에너지 오브의 평균 이동시간은 0.9875초다. 고정 도착 간격 대신 `v2.energy_absorption.duration_variation=0.18`로 최대 ±18% 변동을 생성 Compute에서 적용한다. 짝의 증감을 상쇄하고 홀수 요청의 마지막은 평균값을 사용해 요청당 평균을 보존한다. 개별 도착 시 분할 회복·동적 목표는 유지하며 추가 입자 상태 버퍼나 프로그램은 없다.
- HIT·DAMAGE는 로드아웃과 같은 순간 속도×노출 시간으로 연속 GPU 블러를 계산한다. 노출 0.06초·세기 0.85·최대 128px, 숫자 전환은 0.18초다. `counter_motion_blur.overscan_pixels=48`는 최소 여백이며 실제 번짐 반경에 따라 사방으로 늘려 합성 결과가 숫자 상자에 잘리지 않게 한다. 원래 숫자 전환의 문자 마스크는 유지하며 레이블·고정 자릿수는 필터 밖이다.

- 필살기 쿨다운 동안 아이콘·외곽은 밝기 22%로 어둡게 표시한다. `ultimate_cooldown_seconds / ultimate_cooldown_duration_seconds`로 남은 비율을 계산해 아래에서 위로 원래 밝기를 드러낸다. 남은/전체 시간은 게임이 공급하며 예제는 5초다. 완료 flash·LV3/쿨다운 0 강조선 조건은 유지한다.
- `v2.style.ultimate_border_width_pixels`·`resource_border_width_pixels`는 필살기 외곽·HP/에너지/LV 외곽의 3px 두께다. 쿨다운 밝기는 `ultimate_cooldown_dim_opacity=0.22`다. 내부 아이콘 그림·채움 끝선의 기존 두께와 구분한다.
- LV 영역 윗선은 HP 바 윗선과 같은 높이다. 오른쪽 위/아래 사선은 `v2.layout.level_right_bevel_pixels=7`로 짧게 하고 같은 길이를 유지한다. 레벨 왼쪽과 HP 오른쪽은 같은 수직선으로 연결한다. `level_bevel_pixels`는 기존 접합 위치의 수평 여유를 유지한다. LV 레이블은 숫자 왼쪽 아래에 맞춘다.

- 록온·필살기 강조선은 `v2.style.accent_profile`의 공통 분절형이다. 경로 뒤쪽의 가는 꼬리 → 작은 조각 2개 → 앞쪽의 긴 본체 순서이며 최대 굵기는 `lock_accent_pixels=4.5`다. `sections`는 각 조각의 시작/끝 길이 비율과 시작/끝 굵기 비율이다. 조각 사이에는 기본 테두리가 보이며 번짐을 추가하지 않는다. `length_sides=1.0`으로 한 변 길이를 차지하고 모서리를 지나는 단면을 공유한다. 이전 `accent_hatching`은 비활성이다. 공통 순환은 5차 보간에 등속 성분을 섞어 시작/끝 속도를 평균 속도의 25%로 유지하고 중간 t=0.5에서 최대 속도이며 이동 0.5초·대기 0초로 반복한다. 양끝에서도 느린 속도로 이동하며 가속·감속을 반복한다.
- `v2.energy_fill_seconds=0.12`는 에너지 증가 표시 시간이다. 실제 충전량·레벨·필살기 준비·Overdrive 판정은 즉시 반영하고 누적 에너지 표시만 현재 위치에서 새 목표로 보간한다. 연속 도착은 진행 중인 보간의 남은 시간을 공유하며 완료 시각을 뒤로 미루지 않는다. 레벨 경계에서는 채운 뒤 다음 구간으로 넘어가며 역방향 축소 보간을 하지 않는다. 기본 게이지·Overdrive 추가 게이지·끝선·경계 입자 위치에 표시 값을 사용한다. 흡수 입자의 도착 판정·회복량은 기존 경로를 유지한다. 감소·초기화는 즉시 반영하고 일시정지 중에는 표시도 멈춘다.
- `EnergyTintMotion`은 논리 충전량과 별개로 표시 색을 0.24초 동안 보간한다. 바·회복 flash·흡수 입자에 같은 `energy_tint_ratio`를 공급한다. `v2.style.energy_tint_seconds`로 시간을 조절하며 정지 중 멈춘다. 충전/Overdrive 판정은 지연하지 않는다.
- Overdrive 완충 뒤에도 채움 끝의 불꽃을 유지한다. 일반 40개/초·0.8초 수명에서 Overdrive 96개/초·1초·강도 1.8로 전환한다. `energy_boundary.overdrive_*`로 조절한다. 생성 강도는 GPU 속도·크기에 적용하며 생성/갱신 Compute 두 개를 유지한다.
- HIT·DAMAGE의 바뀌는 자릿수는 별도 투명 레이어에 그리고 실제 원근 투영 이동축을 따라 연속 GPU 방향성 필터를 적용한다. 고정 자릿수·레이블·받침판은 필터 밖이다. `v2.style.counter_motion_blur`는 노출 0.06초·세기 0.85·49샘플·최대 128px·이동량 배율 1.3이다. LV 숫자의 기존 잔상은 유지한다.

- `v2.style.overdrive_entry_streak`: 등장 순간 중앙에서 수평으로 뻗는 빛을 한 번 표시한다. 0.045초 확장·0.025초 유지·0.17초 fade-out, 최대 길이는 바 폭의 88%다. Overdrive 퇴장 투명도를 함께 적용하며 일시정지 때 등장 시계도 멈춘다.


- 오른쪽 LV 외곽의 위·아래 사선은 같은 가로/세로 변화량을 사용한다. 가운데 수직선은 전체 높이에서 두 사선 높이를 뺀 길이다.
- `v2.style.energy_boundary`: 채움과 빈 공간의 경계에 흰 선과 GPU 불꽃을 표시한다. `energy_boundary.color=#FFFFFF`는 채움 끝선·경계 광의 공통 색이다. 십자 반짝임 도형은 표시하지 않는다. 초당 40개·수명 0.8초이며 위로 상승하고 옆으로 흩어진다. 생성/갱신 Compute의 효과 종류 1을 사용하며 CPU는 요청 주기만 관리한다. 회복량은 0이고 빈 게이지에서는 새 불꽃을 만들지 않는다. Overdrive 완충 뒤에는 강화된 불꽃을 유지한다. Overdrive 추가 충전 중에는 그 추가 채움 경계를 사용한다.
- `HealthHitMotion.damping`·`lock_motion.hit_damping`의 기본값은 1.8이다. 지수 감쇠와 종료 구간 완화를 함께 사용하며 위치·속도는 종료 때 0이다. 0이면 지수 감쇠만 끈다. 피격·연타는 진폭 상한을 누적하지 않는다.
- 필살기 준비 조건은 `energy_level == 3`과 `ultimate_cooldown_seconds == 0`이다. `HudV2State.ultimate_ready`로 확인하며 준비 중에만 마름모에 강조선 두 개를 그린다. 록온과 같은 `accent_position`·`outline_segment` 및 `lock_motion.move_seconds/hold_seconds`를 공유한다. 준비 상태로 바뀌면 0.28초 flash가 한 번 재생된다.
- 샘플의 **V**는 준비됐을 때만 필살기를 사용하며 에너지는 유지하고 5초 쿨다운을 시작한다. 재입력으로 남은 시간을 초기화하지 않는다. `v2.ultimate_sample.cooldown_seconds/flash_seconds`는 예제 수치다. 본편은 실제 남은 쿨다운을 상태로 공급한다. 쿨다운·피격·Overdrive 전환·입자 시간은 일시정지 중 멈춘다.


- 에너지는 `EnergyCharge`의 누적 충전량으로 계산한다. 한 게이지마다 LV1→LV2→LV3으로 오르고, **LV3 게이지 완충 후 추가 한 게이지**를 채워야 Overdrive에 진입한다. 추가 충전은 기본 채움 위의 밝은 영역으로 표시하며 `overdrive_charge_ratio` 0→1에 따라 바·흡수 오브·리본·회복 flash가 청록→빨강으로 변한다. 빨강은 `v2.style.overdrive_red`다. 샘플 기본 상태는 LV3·72%이며 Overdrive 전이다. 6은 완충/Overdrive 비교용 조작이다.
- HIT·DAMAGE와 LV 상승 숫자는 v01의 탄성 이동·방향성 잔상을 사용한다. `damage_counter.duration_seconds=0.18`이며 `vertical_easing`·`elastic_*`·`outgoing_fade_power`를 공유한다. HIT/DAMAGE 필터는 `counter_motion_blur`, LV 잔상은 `damage_counter.blur_*`를 사용한다. COUNTER! 메시지는 이 숫자 전환과 별개다.
- HP·LV 접합부는 곡선 없이 사선으로 연결하고 오른쪽 외곽은 `\`·`|`·`/` 순서다. `v2.style.level_bevel_pixels`는 모서리 크기, `level_text`는 숫자와 왼쪽 아래 LV 레이블의 간격/크기, `counter_label_*`는 HIT/DAMAGE 레이블의 오른쪽 여백·받침판 아래 간격이다.
- 타겟 선택 변경·해제 때도 현재 HP 비율을 보존한 채 독립적으로 페이드아웃한다. 처치 시 HP는 0에서 페이드하며 록온 마커의 기존 회전·확대 퇴장은 유지한다.


상태: **HP 피격 반응·좌우 흡수 VFX와 생성/갱신 Compute Ubershader 연결. 직접 조작·본편 연결·최종 외관 검토는 별도다.**

사용자가 요소와 큰 배치를 정하고 실행 화면에서 UI를 다듬는다. 기준 입력은 로컬 `concept/ui-concept-v2.png`이며, 도안을 이미지로 붙이는 대신 개별 표시 요소를 그린다. v1의 승인·검증 상태를 v2에 적용하지 않는다.

## 현재 구성

- 1280×720, 왼쪽 위 미니맵, 중앙 플레이어와 방향 인디케이터, 왼쪽 록온 표적·HP, 오른쪽 HIT/DAMAGE·COUNTER, 오른쪽 아래 무장 2행·로드아웃.
- F 로드아웃 전환은 v1 공통 `LoadoutSlide`의 0.5초 퇴장→세트 교체→등장과 이동 방향의 GPU 블러를 사용한다. 무기 카드·그림·구분·잔탄만 오른쪽으로 움직이며 01·02 패널은 위치·표시 투명도를 고정하고 선택 강조만 즉시 갱신한다.
- E 무기 교체는 공통 `WeaponSwap`의 표시 가중치로 0.12초 동안 활성 카드를 앞·왼쪽·밝게, 비활성 카드를 뒤·오른쪽·어둡게 전환한다. 근접 위·원거리 아래 순서를 유지한다. 가로 이동 차이는 22 논리 px, 불투명도는 0.5↔1이다. 현재 카드를 한 번 렌더한 뒤 순간 속도 방향으로 GPU 블러를 적용한다. 대칭 가중 커널로 표시 중심을 유지하며 시작·끝과 로드아웃 반환 지점에서 번짐 폭이 0으로 줄어든다. `v2.style.weapon_swap_blur`는 샘플 49개·셔터 0.075초·세기 0.9·최대 길이 24px, `loadout_blur`는 샘플 49개·셔터 0.075초·세기 0.85·최대 길이 48px다. 두 전환이 겹치면 로드아웃 설정으로 두 순간 속도를 합친다. 01·02는 필터에서 제외한다. OpenGL 이외의 소프트웨어 렌더러는 필터 없이 그린다. 두 시간 상태는 실행부가 갱신해 뷰에 전달하며 일시정지 중에는 멈추고 F5로 초기화한다. 연속 입력은 진행 중 전환을 마친 뒤 최신 목표로 이어진다.
- 하단 HP 수치·게이지, 그 아래 **플레이어 에너지 게이지**와 오른쪽 에너지 레벨을 연결한다. HP 채움 높이는 16 논리 px이며 채움과 외곽에 별도 안쪽 여백을 두지 않는다. HP 수치와 HP 표시는 바 왼쪽 위에 자동 정렬한다. 에너지 레벨 숫자와 LV는 오른쪽 정렬이며, 숫자는 `muted`, LV는 `ui_accent` 색상이다.
- HP 아랫변과 에너지 윗변을 공유해 틈 없이 붙이며, HP 오른쪽과 레벨 왼쪽은 수직 경계를 공유한다. 필살기 마름모 반경은 43 논리 px로 키우고, 바의 각 높이가 마름모 변과 만나는 접점을 계산한다. 레벨은 공유 수직선의 오른쪽에 있어 HP를 침범하지 않는다.
- 적·플레이어 피해가 실제 발생하면 해당 HP 바의 이번 감소 구간만 흰색으로 강조한다. 구간은 피해 전/후 실제 HP 비율이며 누적 빨간 Trail 전체가 아니다. 등장 0.02초·유지 0초·퇴장 0.08초이며 `v2.style.health_damage_flash`에서 조절한다. 연속 피해는 구간별 시간을 유지한다. 흰색은 현재 보이는 빨간 Trail 안으로 자르며 기존 0.6초 Trail 축소와 실제 HP 갱신은 그대로 유지한다. 기체에는 flash를 적용하지 않는다.
- HIT·누적 데미지 묶음은 각 `v2.style.counters`의 `ui_scale=0.9`로 숫자·레이블·받침판·정적 잔상을 함께 표시한다. 일반 HUD 배율 0.81과 곱한 최종 배율은 0.729다. 오른쪽 여백 14px, 기준 Y는 HIT 276·DAMAGE 366이며 간격은 90px다. 기본 샘플 98 HIT·12,004 DAMAGE의 전체 표시 범위는 화면 Y 288~432로 중앙 360px에 정렬한다. 숫자 변경에 따라 배치 좌표를 다시 계산하지 않는다.
- HIT/DAMAGE 숫자·레이블은 같은 각도의 원근면으로 그린다. 글자 배율과 오른쪽 기준 원근면을 고정해 자릿수가 늘어도 오른쪽 숫자의 모양·위치를 유지한다. 숫자 아래의 받침판은 어두운 평행사변형이며 글꼴의 숫자 잉크 기준선에 붙고 자릿수에 따라 왼쪽으로 길어진다. 왼쪽 조각은 받침판 끝을 따라 이동하는 정적 잔상이다. 시간에 따라 사라지는 애니메이션은 구현하지 않았다. 바뀌는 숫자는 잉크 기준선에서 잘라 받침판 아래로 내려가지 않는다.
- 왼쪽 아래 큰 문양은 **마름모 테두리 안의 필살기 아이콘**이다. 임시 기본 도형을 사용하며 키 표시는 V이며 아래의 `LV. 03`은 준비에 필요한 에너지 레벨이다. V는 마름모 왼쪽 위, `LV. 03`은 왼쪽 아래에 두고 두 문구의 오른쪽 끝을 맞춘다. 각 문구 뒤에는 글자 크기에 맞춘 테두리 없는 사선 패널을 두며 문구와 위치·투명도를 함께 적용한다. 필살기 LV 패널은 아래쪽이 오른쪽으로 뻗는 ＼ 방향이다.
- 무기 행과 필살기 단축키·레벨 패널의 면은 `colors.panel_surface`(`#22343F`)를 사용한다. 일반 패널의 `colors.panel`(`#101E27`)보다 한 단계 밝은 색이며 활성/비활성 투명도는 유지한다.
- 실제 HP 감소 시 `HealthHitMotion`을 재시작한다. 타겟 HP바는 0.28초·18Hz·화면 `(0, ±5px)`, 플레이어의 연결된 HP·에너지 바·레벨·필살기 아이콘/문구는 0.34초·16Hz·화면 `(0, ±7px)` 범위에서 함께 진동한다. 분리된 대시 표시는 고정한다. 연타로 진폭을 누적하지 않으며 연결된 자원 묶음 전체에 수직 블러를 한 번 적용한다. `resource_hit_blur`는 셔터 0.008초·세기 0.22·최대 길이 3 화면 px다. 피격 진동은 일시정지 중 멈춘다.
- **록온 마커는 일반 피격 때** `lock_motion.hit_seconds=0.26`초 동안 `hit_scale=1.5`를 사용해 커졌다 돌아온다. 감쇠 1.8 기준 실제 피크는 약 1.24배이며 `hit_shake_pixels=2.2` 화면 px 이내로 약하게 진동한다. **처치 때는 기존 회전·확대·페이드 퇴장 효과**를 사용한다. 0이 된 HP바는 선택 변경과 독립된 표시 상태로 0.32초 동안 페이드아웃한다. 타겟이 없을 때 빈 HP바를 남기지 않는다.
- **에너지 오브·흡수 Trail**은 유효 적 피해당 예제 6개를 생성하며 풀은 256개다. 좌우 모두 에너지 바 아래를 돌아 채움 끝점으로 들어온다. 필살기 아이콘은 필수 경유점이 아니다. `v2.energy_absorption`의 아래 여백 10 화면 px·접근 가로 간격 85px·평균 이동 0.9875초·최대 ±18% 변동를 조절한다.
- 예제 총 회복량은 유효 적중 1회당 10%이며 `energy_absorption.gain_ratio`다. 최종 게임 수치·피해량 비례식으로 확정하지 않는다. GPU에서 이 양을 1/1,000,000 비율 단위로 파티클에 나눠 나머지까지 분배한다. 도착 때만 한 번 회복 집계에 더하고, 뒤따르는 파티클은 최신 채움 끝점을 따른다. 회복 때 에너지 채널을 에너지 색으로 0.16초 flash한다. 최대값은 100%이며, 풀 포화로 제거된 미도착 입자에는 회복을 지급하지 않는다.
- `v2.absorption_routes.paths_by_side`에 왼쪽·오른쪽 각각 6개 경로의 제어점을 미리 지정한다. 후보별 제어점 4개는 접근 구간 2개·바 진입 구간 2개의 화면 px 오프셋이다. 생성 Compute가 경로 번호를 선택하고 경로 좌표 201개를 GPU에서 계산해 고정한다. 이동 시간은 0.85초다. 갱신 Compute가 수명·현재 위치·24개 구간 리본의 좌표·거리 기반 필압을 계산한다. 오브 반경 3.5px·머리 폭 4px·꼬리 비율 0.3은 `v2.style.absorption_trail`에서 조절한다.
- 기본 `v2.style.absorption_trail.renderer=compute`는 OpenGL 4.3 이상을 요구한다. CPU는 생성 요청·시간·에너지 바 목표 좌표를 전달하며 생성/갱신 Compute Ubershader 두 개가 입자를 관리한다. GPU 활성 목록과 간접 그리기 명령으로 출력한다. 개별 입자 상태·활성 수는 프레임 중 읽지 않는다. 회복이 대기 중일 때만 GPU의 16바이트 누적 집계를 staging buffer와 fence로 비동기 수신한다. 일반 루프는 timeout=0으로 완료 여부만 확인하며, CPU UI의 회복·flash는 집계 수신 후 반영돼 짧은 프레임 지연이 있을 수 있다. F5는 이전 세대의 미수신 집계를 버린다.
- 공용 128×64 아틀라스·좌우 경로 제어점은 로딩 시 한 번 업로드한다. 생성/갱신 셰이더도 로딩 시 컴파일·링크한다. 캐시는 현재 프로세스의 프로그램 재사용이며 디스크 바이너리 캐시는 구현하지 않는다. 일시정지는 시간 요청을 중단하고 F5는 다음 GPU 처리 때 풀과 생성 카운터를 비운다. 버퍼·텍스처·셰이더·타이머 쿼리는 종료 시 해제한다. 방향성 블러 최종 합성은 화면 픽셀 기준 1:1이다.
- 히트(HIT)·누적 데미지(DAMAGE) 카운터의 숫자/레이블만 0.12초 주기로 100%와 90% 불투명도를 공통 타이밍으로 왕복한다. 각 전환은 0.06초 smoothstep으로 이어지며 유지 구간은 없다. `minimum_opacity=0.9`·`period_seconds=0.12`·`dim_seconds=0.06`·`transition_seconds=0.06`이다. MAP·HP 글자·무기/잔탄·COUNTER 메시지·개별 피해 숫자·패널·HP 채움·받침판에는 이 점멸을 적용하지 않는다. `text_flicker.minimum_opacity=1`이면 정지한다.
- 에너지 채움·끝선·OVERDRIVE 문구는 2.4초 주기로 불투명도 65~100%를 왕복한다. 게이지 길이·에너지 값·레벨·필살기 아이콘은 바꾸지 않는다. `energy_breathing.minimum_opacity=1`이면 정지한다. 두 장식은 기존 UI 시계를 공유해 일시정지 중에도 갱신한다.
- OVERDRIVE 문구만 SUITE Regular 18px로 게이지 중앙에 표시한다. ENERGY 문구는 표시하지 않는다. 문구 폭은 바 폭의 60%(`overdrive_width_ratio=0.6`)다. 등장 때 불투명도는 0.065초에 올라가고 0.42초 동안 글자가 중앙에서 퍼지며 개별 반짝임·에너지색 Bloom을 낸다. 퇴장은 0.18초 fade-out만 사용한다. 시간은 `v2.style.overdrive_motion`, Bloom은 `overdrive_bloom`으로 조절한다. 준비된 네온 텍스처를 재사용한다.
- 피해 숫자의 가로/세로 펼침은 0.025/0.035초로 등장과 퇴장을 각각 총 0.06초에 수행하며 전체 수명 1.15초는 유지한다. COUNTER 메시지는 `IndicatorFade` 표시값으로 등장 0.06초·퇴장 0.05초에 투명도를 전환한다. 논리 상태가 꺼져도 퇴장 표시값이 남은 동안 그린다. 록온 등장/퇴장 시간은 별도로 유지한다.
- 부스트 아이콘은 오른쪽을 향한 겹친 꺾쇠 2개이며 `SPACE` 안내 위에 중앙 정렬한다. 가로 위치는 `v2.layout.dash_x=870` 논리 px로 유지한다. 글자 영역의 아래 끝은 윈도우 아래에서 12 화면 px이며 HUD 배율을 역산해 계산한다. 현재 글꼴의 실제 잉크 아래 여백은 15px다. `v2.style.dash_icon`은 Space 부스트 표시를 위한 호환 식별자이며, 여기서 크기·간격·두께·안내 간격·하단 여백을 조절한다. 준비 상태는 기존 색, 비활성은 불투명도 0.25다.
- 기존 금속 사각 패널 대신 비대칭 사선·열린 외곽·얇은 받침선을 사용한다. 무장·미니맵·타이틀·일시정지·도움말에도 적용한다. 타이틀·일시정지의 기본 배치는 기존 화면을 시작점으로 유지하며 두 화면의 새 도안은 아직 없다.
- 조작 가이드 패널은 사용자가 제시한 레퍼런스를 따라 좌상단·우하단의 짧은 꺾임, 가늘어지는 가로선, 떨어진 사선 조각 3개씩으로 테두리를 구성한다. 면은 강조한 두 꼭짓점을 짧게 자른 사선 6각형이다. 미니맵은 같은 면의 사선 외곽을 사용하되 테두리는 그리지 않는다. `v2.style.panel_frame`에서 꺾임/가로선 길이 비율·절단·조각 간격/크기를 조절한다.
- 배경 불투명도는 맵 0.42·조작 가이드 0.6·나머지 일반 패널 최대 0.55다. Scanline은 4px 간격·1px 두께로 아래로 5px/s, 밝은 띠는 높이 24px·불투명도 0.22로 60px/s 이동한다. 선 불투명도는 맵 0.07·가이드 0.08·일반 패널 0.06이다. `v2.style.panel_scanlines`와 `surface_opacity`에서 조절한다.
- 패턴과 밝은 띠는 **화면 전체 좌표·한 개의 UI 시계**를 공유하며 패널 내부에만 표시한다. 배율·이동량을 적용한 화면 Y를 사용하므로 서로 다른 패널에서도 같은 높이에 정렬된다. 밝은 띠는 현재 프레임에서 스캔 대상 패널이 보이는 Y 구간을 합친 경로를 이동하며 빈 세로 구간을 건너뛴다. 겹친 구간은 한 번만 센다. 속도 단위는 화면 픽셀/초이며 주기는 `(보이는 Y 구간 길이의 합 + 띠 높이) / 속도`다.
- 적용 대상은 맵·가이드·무기 카드·로드아웃·에너지 바 빈 배경·카운터 받침판·메뉴/일시정지 패널과 버튼이다. HP 게이지·필살기 아이콘/단축키/보조 레벨·에너지 레벨은 스캔 효과에서 제외하고 반투명 배경만 유지한다. 글자·무기 이미지·게이지 채움은 스캔 처리하지 않는다.
- Film grain은 무기 카드·로드아웃·에너지 바 빈 배경에만 적용한다. 고정 seed의 흑백 White noise를 화면 좌표 64px 타일로 반복하며 입자 크기 1.25px·불투명도 0.035다. 8개 프레임을 초당 10회 갱신하며 텍스처는 재사용한다. 글자·아이콘·게이지 채움보다 먼저 그린다. 값은 `v2.style.panel_film_grain`에서 조절한다.
- 무기 구분·잔탄·로드아웃 번호의 본문 불투명도는 활성 상태 불투명도에 0.82를 곱한다. 원래 글자색을 유지하고 별도 청록색 `#65DCC8` 광을 가우시안 반경 4 논리 px·세기 0.12로 먼저 그려 은은하게 번지게 한다. `weapon_text_opacity`와 `weapon_text_neon`에서 색·번짐·세기를 조절한다. 흐린 마스크는 캐시하며 종료 시 해제한다.
- `ScanlineMotion`은 메뉴·전투·일시정지에서 계속 갱신하며 모든 장면이 같은 `ScanlineVisual`을 받는다. 일시정지 중에도 UI 스캔은 이어지고 게임 시간·피해·흡수 Trail은 멈춘다. F5는 두 이동량을 초기화한다. 위상과 무관한 반복 텍스처를 공유하며 현재 화면에서는 2개를 사용한다.
- 테두리의 최대 두께는 5px이며 꼭짓점에서 3px까지 유지한다. 이후 두께는 직선으로 줄인다. 곡선 보간은 사용하지 않는다. 일반 패널의 변화 거리·두께는 `v2.style.panel_border`에서 조절한다.
- `panels.py`는 패널 면과 10개의 독립 테두리 조각 형상을 반환한다. `UiV2View.panel_surface()`와 `panel_border()`를 따로 호출하며 조각별 표시 투명도도 외부에서 공급할 수 있다. 대화창 개폐는 외부 `DialoguePanelMotion`의 표시값으로 면·테두리를 함께 변형한다. 개별 조각의 순차 등장과 다른 패널의 개폐는 후속 범위다.
- 대화창은 중앙 가로선에서 폭을 유지한 채 위아래로 0.2초 동안 펼친다. 목표 높이에 도달하면 별도 페이드 없이 헤더·본문을 표시한다. 닫을 때는 글자를 즉시 숨기고 세로 압축 0.05초→가로선 축소 0.03초→중앙점 소멸 0.02초, 총 0.1초의 TV 종료 효과를 재생한다. 최초 표시·F5·D 재표시에 연결하며 닫힘이 끝나면 표시 데이터를 제거한다. 중간 반전 입력도 현재 높이에서 이어진다. 열림/닫힘 총시간은 사용자 지정이며 세부 시간 배분과 빛 두께는 `v2.style.dialogue_motion`의 시안 값이다.
- 공통 패널의 면과 테두리는 2배 해상도로 렌더한 뒤 선형 필터로 축소한다. 도형 텍스처는 위치·표시 투명도와 분리해 최대 32개 재사용한다. 생성 중 렌더 대상·배율·viewport·clip·그리기 색/블렌드를 복원하며 종료 시 해제한다.
- 적은 기존 왼쪽·오른쪽·위쪽에 1기씩 표시한다. 적별 HP와 고유 ID를 보관하고, 선택한 적의 몸통·이름·HP·피해 숫자가 실제 위치를 따른다. 위쪽 적과 록온 표시 일부는 대화창 뒤로 가리며 D로 가림 전후를 비교한다. 대화 데이터는 `HudV2State.dialogue`로 전달한다.
- 미니맵의 논리 크기는 240×160이며 0.9배 표시한다. MAP 레이블은 전용 `v2_map_label` 20px로 표시한다. 화면 왼쪽/위 여백은 20px다. 대화창은 (360,20)의 560×130이며 미니맵과 위쪽 여백을 맞춘다.
- 조작 가이드는 4줄로 표시하고 헤더는 `조작 가이드`만 남긴다. 헤더 글꼴은 전용 `dialogue_heading` 24px이며 표적명 크기와 분리한다. 기존 F1 별도 안내창과 단축키는 제거했다. 헤더·본문은 패널 위 8px 여백으로 맞추며 본문은 `small` 역할·20px 줄 간격을 사용한다. `D`로 가이드 표시를 바꾼다. 문구는 샘플 데이터, 여백·본문 역할/간격은 `v2.style.dialogue_*`에서 관리한다.
- 가이드 본문의 조작키 16개만 볼드로 표시한다. 샘플 문자열의 `**키 이름**`을 `rich_text()`가 일반/볼드 구간으로 나눠 출력한다. 같은 줄의 설명은 일반 굵기이며 각 구간의 실제 폭과 공통 기준선으로 이어 붙인다. 공통 렌더러의 `text()`·`text_size()`·`text_ascent()`와 v2의 `warped_text()`·`neon_text()`는 `bold=True`를 지원한다. SDL_ttf 합성 볼드이며 측정/텍스처 캐시는 굵기를 구분하고 폰트 상태는 작업 후 복원한다.
- 조작키 색은 `dialogue_key_color=#F0FCFF`, 설명은 기본 텍스트 색에 `dialogue_description_opacity=0.78`을 곱한다. 헤더와 기존 볼드는 유지한다.
- 록온은 몸통 중심과 큰 쪽 치수에 비례한 **정사각형**을 기본형으로 사용한다. 등장 0.32초 동안 0→45° 회전(`elasticOut`)·0.25→1배 확대(`easeInOutCubicEmphasized`)한다. 완성 후 0.16초 동안 캐럿이 글자 왼쪽에서 오른쪽으로 지나가며 `LOCK ON`을 표시한다.
- R로 실제 선택이 바뀌면 이전 표시의 몸통 위치를 보존해 퇴장시키고 새 표시는 별도로 등장한다. 취소 순간 등장 곡선의 실제 각도 A·배율 S를 저장하고, 글자를 즉시 숨긴 뒤 0.2초 동안 A→2A 회전·S→1.5S 확대·페이드한다. 등장 중 취소도 이 경로를 사용하며 역재생하지 않는다. 등장 완료 뒤에는 캐럿/글자 표시 여부와 관계없이 45→90°·1→1.5배 퇴장이 된다.
- 두꺼운 강조선 두 개는 반대편을 유지하며 얇은 정사각형 외곽을 시계 방향으로 따라 서로의 자리로 이동한다. 이동 0.32초에 `easeInOut`을 적용하고 도착 후 0.2초 정지한다. 모서리를 지날 때도 외곽을 따르며 중심을 가로지르지 않는다. 값은 `v2.style.lock_motion`에서 관리한다.
- [자동 표적 선택](../ranged_targeting.md)은 획득거리 안의 활성 적 중 마우스 월드 좌표와 가장 가까운 적을 고른다. 새 후보가 연속 1초 유지되면 교체하고 사망·범위 이탈은 즉시 해제한다. R 입력과 순환 이력은 사용하지 않는다. 기본/조준 거리는 샘플 330/460이며 우클릭으로 범위를 확대한다.
- 카메라는 플레이어를 기준으로 마우스 방향에 시선 오프셋을 둔다. 샘플 값은 80px 데드존·변위 20%·최대 120 월드 단위·응답 0.15초다. 적·플레이어·몸통·록온·레이더·피해 숫자는 월드/화면 변환을 공유하고 HUD는 고정한다. 일시정지는 카메라와 자동 선택 대기도 멈춘다.
- 에너지 Scanline·밝은 띠·Film grain은 사선 채널 형상으로 마스킹한다. 배경 면과 효과 마스크를 분리한다.
- COUNTER·메뉴 버튼 글자는 수평이다. 무기 카드의 위/아랫변과 로드아웃 번호·무기 구분·잔탄 글자는 수평으로 그리며 입체 기울임/회전 표현은 사용하지 않는다. 무기 카드는 오른쪽 수직·왼쪽 사선이며 높이는 둘 다 70 논리 px(배율 0.9에서 63 화면 px)다. 위 카드 밑변과 아래 카드 윗변은 260px로 일치하고 아래 카드 밑변은 278px다. 차이는 `weapon_card_cut_pixels=18`이며 선택 상태와 무관하게 변 길이를 유지한다. 활성 상태는 가로 위치·밝기로 구분한다.
- HIT/DAMAGE의 기준 오른쪽 여백은 14px다. 긴 숫자를 폭에 맞춰 축소하지 않는다. COUNTER는 고정 샘플 위치이며 긴 DAMAGE와의 겹침에 따른 자동 재배치는 하지 않는다. LOCK ON 글자는 기본 정사각형의 왼쪽 변 바깥에 정렬하고 회전한 테두리의 방향을 따른다. 강조선은 글자와 독립적으로 외곽을 순환한다. 무장 외부 L자는 제거하고 왼쪽 외곽을 3px로 강조한다.
- 록온은 `HudV2State.target_body`에 제공한 **카메라 투영 후 몸통 Rect**의 중심과 크기를 사용한다. 고정 크기 테두리를 제거하고 몸통에 비례해 기존보다 작게 표시한다. 몸통 정보가 없으면 테두리를 그리지 않는다. 외곽은 축소 전 2px, 표적 HP 채움 높이는 6px다. 샘플의 7 키로 0.75/1/1.5배 표적을 비교한다.
- 일반 전투 HUD 배율은 0.81이다. 미니맵·웨폰·로드아웃은 별도 0.9배이며 두 무기 카드의 표시 배율은 같다. `v2.style.weapon_card_shape=trapezoid`가 현재 시안이고 `slanted`로 바꾸면 기존 사선·비활성 축소 형태를 복원한다. 깊이 이동은 `weapon_depth_offset_pixels=22`, 이전 비활성 축소값은 `inactive_weapon_scale=0.8`이다. 레이더 반경은 144px, 필살기 마름모 반경은 43 논리 px다. 흡수 Trail은 실제 흡수 위치에서 아이콘·에너지 바의 화면 좌표로 향한다.

프레임을 그리기 전에 `view.prepare_panel_effects(draw_panels)`에 같은 프레임의 UI 그리기 함수를 공급한다. 이 단계는 도형을 출력하지 않고 패널 구간만 수집한다. 입력·시간·게임 상태 갱신은 이 함수 밖에 둔다. 수집을 생략한 기존 직접 호출은 화면 전체 높이 경로와 호환된다.

## 연결할 범위

자동 선택과 시선 카메라는 재사용 모듈을 샘플 적 3기에 연결한 상태다. 거리와 카메라 수치는 샘플값이며 본편 밸런스는 미정이다. UI에 가린 적도 후보에 남는다. 실제 전투·발사·탄 퍼짐·미니맵 지형·본편 에너지/Overdrive/필살기 연결은 후속 작업이다. 사용자 외관 승인과 실제 전투 사용감을 별도로 확인한다.

조작·검증의 세부 범위는 [샘플 안내](../../samples/ui_unit_test_v2/README.md)를 따른다.

- `v2.camera_motion_blur`: 카메라 속도에 따른 노출 길이를 `amount / target_fps`초로 계산한다. 기본 `amount=0.75`·`target_fps=60`은 0.0125초이며 최대 24 화면 px·33샘플이다. 선명한 원본을 별도로 섞지 않고 노출 구간을 중심형으로 적분한다. 기체·적 레이어만 합성하며 HUD·록온·피해 숫자·흡수 효과·타이틀은 필터 밖이다. 정지·일시정지·장면 전환에는 생략한다. 기존 OpenGL 필터를 재사용하며 소프트웨어 렌더러는 필터 없이 그린다. 픽셀별 물체 속도·깊이·가림 복원은 없는 2D 카메라 평행 이동 근사다.
