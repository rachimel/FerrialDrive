# UI Unit Test v2

상태: **연결형 자원부·원근 카운터·사용자 외관 피드백 반영 / v2 자동 검사 12개·기존 UI 포함 67개 통과 / 화면 없는 실제 렌더링 확인 / 직접 조작·수정본 외관 승인 미확인**.

사용자가 요소와 큰 배치를 정하고 실행 화면에서 UI를 다듬는다. 기준 입력은 로컬 `concept/ui-concept-v2.png`이며, 도안을 이미지로 붙이는 대신 개별 표시 요소를 그린다. v1의 승인·검증 상태를 v2에 적용하지 않는다.

## 현재 구성

- 1280×720, 왼쪽 위 미니맵, 중앙 플레이어와 방향 인디케이터, 왼쪽 록온 표적·HP, 오른쪽 HIT/DAMAGE·COUNTER, 오른쪽 아래 무장 2행·로드아웃.
- 하단 HP 수치·게이지, 그 아래 **플레이어 에너지 게이지**와 오른쪽 에너지 레벨을 하나의 외곽으로 연결한다. `energy_level_size`는 에너지 바 끝점에 종속된다. HP 높이는 에너지 바와 동일하고, 실제 HP·빨간 감소 구간 모두 외곽과 평행한 사선 끝단으로 채운다.
- HIT/DAMAGE 숫자·받침선·레이블은 같은 각도의 원근면으로 그린다. 받침선은 축소 전 3px다. 바뀌는 자리의 위아래 회전은 투영 전 평면에서 잘라낸다. 원근 강도·기울기·최대 폭은 `v2.style.counters`에서 조절한다.
- 왼쪽 아래 큰 문양은 **마름모 테두리 안의 필살기 아이콘**이다. 임시 기본 도형을 사용하며 키 표시는 V 후보, 필살기 자체 성장 레벨은 샘플 1이다.
- 날렵한 선은 **에너지 흡수 Trail**이다. 흡수 위치→필살기 아이콘 통과→에너지 바 채움 끝점 순서로 이동한다. 게임의 에너지 획득량은 계산하지 않는다.
- 기존 금속 사각 패널 대신 비대칭 사선·열린 외곽·얇은 받침선을 사용한다. 무장·미니맵·타이틀·일시정지·도움말에도 적용한다. 타이틀·일시정지의 기본 배치는 기존 화면을 시작점으로 유지하며 두 화면의 새 도안은 아직 없다.
- COUNTER·메뉴 버튼 글자는 수평으로 표시한다. LOCK ON은 작은 다이아몬드와 분리된 왼쪽 사선에 배치하며 외곽 두께는 축소 전 2px, 표적 HP 채움 높이는 6px다.
- 레이더 반경은 160px다. 레이더·기체를 제외한 전투 HUD는 사용자 선택으로 90% 크기를 적용한다. 메뉴는 이번 축소 대상이 아니다. 흡수 Trail은 실제 흡수 위치에서 축소된 아이콘·에너지 바의 화면 좌표로 향한다.

## 책임

| 경로 | 책임 |
| --- | --- |
| `tests/ui_unit_test_v2.py` | 독립 실행·장치 입력·샘플 변경·창/렌더러 수명 |
| `ferrial_drive/ui_v2/state.py` | 게임에서 직접 공급할 표시 데이터 |
| `ferrial_drive/ui_v2/view.py` | v2 배치·기존 Pico2D 표현 재사용 |
| `ferrial_drive/ui_v2/geometry.py` | 원근 투영·에너지와 레벨의 공통 외곽 |
| `ferrial_drive/ui_v2/pico_renderer.py` | 기존 글자 캐시·Pico2D/SDL 렌더러 위의 텍스처 투영 |
| `ferrial_drive/ui_v2/effects.py` | 흡수 Trail 시간·경로, 입력·게임 규칙과 분리 |
| `samples/ui_unit_test_v2/` | 독립 수치·도형·배치·폰트 설정·실행 안내 |

게임은 v2 뷰와 표시 데이터를 직접 연결하며 테스트 실행부를 import하지 않는다. v2 모듈 import와 샘플 객체 생성만으로 창을 열지 않는다. 기존 `tests/ui_test.py`·v1 설정·공유 표현 코드를 이번 작업에서 수정하지 않았다.

## 연결할 범위

R 샘플 표적명 순환은 본편의 [표적 획득·재획득 규칙](../ranged_targeting.md) 구현이 아니다. 실제 전투·조준 거리·탄 퍼짐·대상별 HP·미니맵 지형·에너지·Overdrive·필살기 연결은 후속 작업이다. 사용자 외관 승인과 실제 전투 사용감을 별도로 확인한다.

조작·검증의 세부 범위는 [샘플 안내](../../samples/ui_unit_test_v2/README.md)를 따른다.
