# UI Unit Test v2

상태: **사용자 도안 기반 독립 테스트 구현 / 자동 검사 8개·화면 없는 실제 렌더링 확인 / 직접 조작·사용자 외관 승인 미확인**.

사용자가 요소와 큰 배치를 정하고 실행 화면에서 UI를 다듬는다. 기준 입력은 로컬 `concept/ui-concept-v2.png`이며, 도안을 이미지로 붙이는 대신 개별 표시 요소를 그린다. v1의 승인·검증 상태를 v2에 적용하지 않는다.

## 현재 구성

- 1280×720, 왼쪽 위 미니맵, 중앙 플레이어와 방향 인디케이터, 왼쪽 록온 표적·HP, 오른쪽 HIT/DAMAGE·COUNTER, 오른쪽 아래 무장 2행·로드아웃.
- 하단 HP 수치·게이지, 그 아래 **플레이어 에너지 게이지**, 에너지 레벨과 대시 가능 표시.
- 왼쪽 아래 큰 문양은 **필살기 아이콘**이다. 임시 기본 도형을 사용하며 키 표시는 V 후보, 필살기 자체 성장 레벨은 샘플 1이다.
- 날렵한 선은 **에너지 흡수 Trail**이다. 흡수 위치→필살기 아이콘 통과→에너지 바 채움 끝점 순서로 이동한다. 게임의 에너지 획득량은 계산하지 않는다.
- 타이틀·일시정지 화면은 v1 표현 모듈을 시작점으로 재사용한다. 이 두 화면의 새 도안은 아직 없다.

## 책임

| 경로 | 책임 |
| --- | --- |
| `tests/ui_unit_test_v2.py` | 독립 실행·장치 입력·샘플 변경·창/렌더러 수명 |
| `ferrial_drive/ui_v2/state.py` | 게임에서 직접 공급할 표시 데이터 |
| `ferrial_drive/ui_v2/view.py` | v2 배치·기존 Pico2D 표현 재사용 |
| `ferrial_drive/ui_v2/effects.py` | 흡수 Trail 시간·경로, 입력·게임 규칙과 분리 |
| `samples/ui_unit_test_v2/` | 독립 수치·도형·배치·폰트 설정·실행 안내 |

게임은 v2 뷰와 표시 데이터를 직접 연결하며 테스트 실행부를 import하지 않는다. v2 모듈 import와 샘플 객체 생성만으로 창을 열지 않는다. 기존 `tests/ui_test.py`·v1 설정·공유 표현 코드를 이번 작업에서 수정하지 않았다.

## 연결할 범위

R 샘플 표적명 순환은 본편의 [표적 획득·재획득 규칙](../ranged_targeting.md) 구현이 아니다. 실제 전투·조준 거리·탄 퍼짐·대상별 HP·미니맵 지형·에너지·Overdrive·필살기 연결은 후속 작업이다. 사용자 외관 승인과 실제 전투 사용감을 별도로 확인한다.

조작·검증의 세부 범위는 [샘플 안내](../../samples/ui_unit_test_v2/README.md)를 따른다.
