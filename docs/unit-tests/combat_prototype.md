# 전투 프로토타입

상태: **임시 도형 1대1 전투 구현 / 전투 자동 검사 28개·기존 UI 검사 55개 통과 / SDL dummy 렌더·실제 시작 화면 확인 / 실제 조작·사용감은 사용자 테스트 예정**.

정식 에셋 제작을 기다리지 않고 이동·회피·반격과 승패를 확인한다. 독립 실행 진입점은 `tests/combat_test.py`이며, 조작과 샘플 환경은 [샘플 안내](../../samples/combat_prototype/README.md)를 따른다. Runner가 소스를 실행하지 않고 `standalone`으로 판별하는 것을 확인했다. Runner GUI 드롭 자체는 이번 작업에서 조작하지 않았다.

## 모듈 책임

| 위치 | 책임 |
| --- | --- |
| `ferrial_drive/combat/config.py` | 전투 수치·훈련장·설정 로드 및 기본 검증 |
| `ferrial_drive/combat/simulation.py` | 입력 요청을 받아 고정 주기로 이동·충돌·공격·피해·승패 처리 |
| `ferrial_drive/combat/application.py` | 실제 장치 입력·일시정지·포커스·재시작·HUD 상태 연결 |
| `ferrial_drive/combat/view.py` | 월드→화면 투영·임시 도형·기존 HUD 표현 |
| `tests/combat_test.py` | 실행 옵션·공통 실행부 연결 |
| `samples/combat_prototype/` | 개인 에셋이 필요 없는 훈련장·임시 수치·실행 안내 |

규칙 모듈은 Pico2D·UI·테스트·Tools를 import하지 않는다. 화면이 없는 본편 상태에서도 `CombatWorld`와 `CombatInput`을 사용한다. 기체·탄환·사거리는 월드 좌표로 계산하고 화면에서 Y축을 압축·반전한다. 카메라는 플레이어 중심이므로 기존 HUD의 중앙 플레이어 앵커를 유지한다. 적 HP는 유일한 적 한 기에 연결하며 일반적인 타겟 선택 기능은 아니다.

## 구현 범위

- WASD 보행·Shift 달리기·마우스 독립 조준. 보행 입력 해제 즉시 정지.
- Space의 고정 방향·고정 거리 대시. 재입력에 의한 방향 변경·중첩·입력 예약·별도 무적 없음. 종료 후 추가 쿨타임 없음.
- 일반 검 공격 전 구간 대시 캔슬, 대시 시작 0.08초 이내 입력의 별도 대시 공격. 이후 입력은 조준 방향의 일반 검 공격이다. 이 입력 구간은 임시값이다.
- 검 4단 연계와 입력 예약. 내려베기·가로베기·찌르기·뽑아베기를 단순 선분 동작으로 구분한다. 최종 메카 애니메이션을 검증한 결과가 아니다.
- E 검/총 전환. 일반 검 공격 중 전환 캔슬은 이번에 열지 않았다. 대시 캔슬 후에는 전환할 수 있다. 전환 쿨타임 0.28초는 임시값이다.
- 45발 기관단총, 우클릭 조준 시 탄 퍼짐 감소, 자동 재장전·무한 예비 탄약. 재장전은 비활성 무기에서도 진행한다.
- 이동·탄환·근접의 벽 차단, 기체 간 몸체 충돌, 연속 선분 기반 탄환 명중으로 얇은 벽·대상 건너뛰기 방지.
- 적 근접 기체 한 기. 접근→공격 준비 동작→방향 고정 근접 공격→회수 흐름. 공격 시작 시 방향을 고정한다. 별도 경고 표시 없음.
- 작은 사각 장애물 장면의 모서리 후보에 A*를 적용한 적 우회. 대규모 격자 맵·동적 장애물·다수 기체 길찾기 검증은 아니다.
- 실제 피해 기반 플레이어/적 HP·무장·잔탄·피해 숫자·HIT/DAMAGE·레이더. HIT/DAMAGE는 이번 교전의 누적값이며 일반적인 콤보 유지·시간 초과 초기화 규칙은 미정이다.
- 시작 대기·일시정지·포커스 상실 시 입력 해제·승패·재시작·종료·선택적 공통 계측.

걷기·대시·공격·탄약 수치와 경계 접촉 시 정지 처리 등은 이 프로토타입의 잠정 구현이다. 대시는 경계·벽·기체를 통과하지 않으며 정해진 시간 후 끝난다. 대시와 달리기는 에너지를 사용하지 않는다.

## 후속 범위

에너지·자동 가드·근접 우클릭 투사체 차단·스왑 카운터·Break·Break Assault·Overdrive·스킬·필살기·두 번째 로드아웃·보스·교관 ADV·정식 프리렌더 에셋 연결은 이번에 구현하지 않았다. 일반 적 경고 표시는 제외하며 보스급 특정 공격의 경고 표시는 대상·방식 미정이다. 생략을 현행 전투 규칙의 폐기로 취급하지 않는다.

## 검증 구분

- 자동: 전투 규칙 22개, 실제 Pico2D/SDL dummy 연결 6개, 기존 UI 55개 통과. 30/60/144 FPS 입력의 동일 이동 거리, 대시·캔슬·탄약·벽/판정·적 우회·승패/초기화·포커스/재시작·자원 해제를 포함한다.
- 렌더링: SDL dummy 3프레임 실행·계측 저장과 실제 창의 시작 대기 화면·HUD 배치를 확인했다. 실제 창 실행은 OpenGL 경로다.
- 실제 조작: AI의 키 입력 도구 호출만으로 반영 여부를 확정하지 않았다. 사용자가 직접 테스트하겠다고 요청해 추가 조작을 중단했다. 입력 반응·전투 사용감·시각 품질·전체 흐름은 사용자 확인 전이다.
- 성능: 프레임 계측 출력 경로만 확인했다. 목표 기기 60FPS·GPU 시간·다수 적·전체 메모리 목표 달성은 검증하지 않았다.
