# 무기 카드 v2 표시 규격

## 구성

- 카드는 굵은 아래 사선·가는 위 사선, 무기 이름·실루엣·잔탄 수와 하단 띠로 구성한다.
- 잔탄 숫자에는 글자 내부의 세로 그라데이션을 적용한다. 구형 카드의 네온 광은 이전 카드 표시 경로에만 적용한다.
- 위·아래 사선의 기울기는 같다. 굵은 아래 선의 오른쪽 위 끝과 가는 위 선의 아래 시작점을 하단 띠 윗선에서 붙인다. 두 선의 끝 단면은 수평이며 별도의 가로 연결부는 없다. 하단 띠는 굵은 아래 선과 연결한다. 하단 띠 오른쪽 끝도 사선으로 자르며 얇은 외곽선은 그리지 않는다.
- 보조 슬롯은 HP·에너지 영역 오른쪽과 무기 카드의 기본 왼쪽 끝 사이 중앙에 하나만 표시한다. 슬롯은 카드 이동·블러와 분리한다.
- 원 테두리는 `v2.style.weapon_card.auxiliary_border_pixels=3.5`·`auxiliary_border_opacity=0.6`이다. 공통 슬롯의 지름 120px·아래 여백 30px·내부 도안 배율 1.28은 `v2.style.shared_swap_slot`에서 조절한다.
- 미사일·카운터는 투명 PNG 문양을 UI 공통 원형 패널 위에 합성한다. 패널과 미사일 원 테두리는 기존 도형 텍스처 캐시를 재사용하며 문양은 이미지 1회로 표시한다. 카운터에는 원 테두리를 표시하지 않는다. `images`는 UI 설정 파일 위치 기준이며 로컬 명세는 절대 해석한 경로를 공급한다. `samples/ui_unit_test_v2/make_slot_icons.py`가 공개 도형 샘플의 원본이다. 이미지 색은 테마의 밝은 글자색으로 조절하며 패널·원 테두리는 해당 위젯의 역할색을 따른다.
- E 사용키 안내는 사용자 설정에서 켜고 끄며 아이콘의 위치·크기는 유지한다.
- 기본 속성은 하단 띠보다 큰 글자를 띠 안에서 잘라 표시한다. 오른쪽 `MELEE/RANGED` 영역과 분리하고 잔탄보다 낮은 대비를 사용한다.
- 추가 속성이 제공된 경우에만 작은 아이콘을 표시한다. 기본 무장 샘플에는 추가 속성이 없다. 표시용 도안과 실제 게임 효과 판정은 분리한다.
- 속성·근접/원거리 구분은 가물치 무료고딕을 사용한다. 속성별 고유색은 미정이며 현재 UI 공통색을 사용한다. IMPACT·SLASH는 자간 10px·획 안쪽 축소 0.55px로 표시한다. 글꼴 원본 파일은 수정하지 않는다.
- 공통 슬롯은 현재 로드아웃에서 다음 E 스왑으로 실행할 반대쪽 무기의 `auxiliary_kind`·`auxiliary_image_path`를 표시한다. 사용·교체·충전 판정과 실제 장착은 별도다.

## 연결

- 실행 진입점은 `tests/sword_movement_test.py`다. 기존 E 무기 교체·F 로드아웃 전환·일시정지·초기화 입력을 사용한다.
- `ferrial_drive/ui_v2/weapon_card.py`는 카드 내용과 슬롯 도형을 제공한다. `UiV2View.weapon_cards()`는 카드의 배율·이동·투명도·블러, `shared_swap_slot()`은 다음 스왑 아이콘을 담당한다.
- 무기 교체 0.12초·로드아웃 0.5초, 곡선·입력 예약·일시정지 및 고정 번호 탭은 기존 제어를 따른다. 이동 거리는 카드의 실제 왼쪽 끝으로 계산한다.
- `v2.style.weapon_card_shape=concept`가 현재 카드다. 기존 `trapezoid/slanted` 표시 경로도 보존한다.
- 카드 배치와 도형 치수는 `v2.layout.weapons`·`v2.style.weapon_card`, 글꼴은 `v2_weapon_attribute`·`v2_weapon_kind`에서 조절한다.
- 장비 표시 배율은 `equipment_scale=1.0`이다. DPI-aware 캔버스의 물리 픽셀 기준으로 카드 원본 420×132px·공통 슬롯 지름 120px·하단 띠 28px·아래/위 선 18/7px를 사용한다. 글꼴 원본 크기도 이름 18px·속성 48px·구분 18px·잔탄 54px로 정한다. 긴 이름·속성 폭 초과 때만 해당 텍스트를 영역에 맞춘다. 밝은 글자 코어에는 아래쪽 밝기 93%의 미세한 세로 그라데이션을 적용한다.
- FHD 카드 기준 영역은 `[1484,792,420,132]`이며 2행을 8px 간격으로 놓아 오른쪽·아래 기준 여백 16px를 유지한다. 이름은 `v2_weapon_name`, 잔탄은 `v2_ammo` 역할이다. 다른 DPI/해상도의 실제 표시 검증과 이번 FHD 캡처를 구분한다.

## 표시 데이터

`WeaponInfo`의 기존 이름·잔탄·이미지 인자는 그대로 유지한다. 선택 필드는 다음과 같다.

| 필드 | 역할 |
| --- | --- |
| `base_attribute` | 기본 속성 표시 문자열. 빈 문자열이면 생략 |
| `additional_attributes` | 추가 속성 표시 목록. 생성 시 불변 tuple로 보관 |
| `auxiliary_kind` | `back_weapon`·`counter` 또는 `None` |
| `auxiliary_image_path` | 원형 슬롯 안에 표시할 선택 이미지 |

- 샘플은 근접 `SLASH`·원거리 `IMPACT`를 표시한다. 카운터·백웨폰은 다음 스왑 아이콘의 임시 도형이며 실제 무기별 장비 규칙은 미정이다.
- 재사용 모듈 import만으로 창·입력·실행 루프를 시작하지 않는다. 실제 게임은 같은 표시 데이터에 실제 상태를 공급한다.
- 고정 패널 면·테두리·그레인은 텍스처로 재사용하고 글자·스캔라인·상태 채움은 현재 값으로 그린다. 자동 검사·실제 렌더·직접 조작·사용자 외관 승인은 구분한다.
