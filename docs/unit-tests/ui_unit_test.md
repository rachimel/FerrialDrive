# 이동·UI 훈련장

`tests/sword_movement_test.py`에서 이동·검 공격과 UI v2를 함께 확인한다. Runner 파일 선택·드롭과 직접 실행을 지원한다.

~~~text
python tests/sword_movement_test.py
python tests/sword_movement_test.py --demo
~~~

`--demo`는 공개 도형·수치로 실행하며 실제 게임 기체가 필요 없다. 실제 기체·보간·그림자·지면 효과는 로컬 에셋을 사용하는 일반 실행에서 확인한다.

## 연결 범위

- WASD 이동·대시·부스트·검 4타·프레임 보간·훈련 표적 A/B/C.
- 일반 검 공격의 타격당 1회·기본 발걸음 대비 30% 발 디딤, 대시 진입 가속/고음 지속 분사·충격 부스트·3타 바람·재질별 명중음과 베임선/금속 입자. 몸 검풍은 비활성화한다. 접지 시각·최종 음색은 청취 조정 대상으로 둔다.
- 표적 명중에 따른 시연용 HP·HIT/DAMAGE·피해 숫자·피격 반응·에너지 흡수.
- 자동 표적 선택·우클릭 조준 범위·록온·레이더와 훈련장 카메라 공유.
- 에너지 표시·레벨·Overdrive·필살기 쿨다운·COUNTER·대화창·무장/로드아웃 전환 효과.
- 타이틀·일시정지·설정. 텍스처 품질 높음 75%·보통 50%·낮음 25%, 화면 해상도 1280×720·1600×900·1920×1080과 사용키 표시를 저장 즉시 적용한다.

화면 해상도는 실제 창·출력 픽셀 수를 변경한다. UI·월드의 논리 좌표와 화면 구도는 유지하며 SDL의 논리 크기 변환으로 마우스 이동·클릭도 같은 위치에 대응한다. `data/settings/game_settings.json`의 `graphics.screen_resolution`에 저장한다. 기존 설정에 항목이 없으면 실행 프로그램의 기본 창 크기를 사용한다. 뒤로는 선택을 취소하고, 저장 실패는 이전 출력 크기로 복귀한다. 기체 텍스처 품질은 별도 설정이며 해상도를 바꿀 때 에셋을 다시 불러오지 않는다. 화면 캡처와 성능 보고서에는 실제 출력 픽셀 크기를 기록한다.

피해량·에너지 회복·필살기 쿨다운은 UI 시연 수치다. 이동·UI 훈련장은 무기 수납/인출·기관단총 연사·탄약·실제 탄환 명중을 연결하며 [이동 명세](sword_movement.md)를 따른다. 첫 록온은 즉시 획득하고 다른 마우스 최근접 후보로 교체할 때만 1초를 확인한다. 명중은 선택을 변경하지 않는다. 록온 중 플레이어·표적 중간점을 카메라로 추적한다. 적 AI·본편 전투 밸런스·미니맵 지형은 별도 범위다.

## 현재 표시

- 피해 팝업은 같은 대상의 첫 피해부터 실제 0.1초 동안 합산해 숫자 하나로 표시한다. 예를 들어 같은 적의 직격 25와 폭발 13은 38, 다른 적의 폭발 13은 별도 13이다. 연속 공격은 첫 피해의 마감을 연장하지 않고 다음 묶음을 만든다. HP·HIT/DAMAGE·피격 반응·에너지 흡수는 명중마다 즉시 반영한다. 합산 대기만 최대 0.1초 늦으며 표시는 합계 자릿수로 크기·배치를 계산한다. 일시정지·메뉴 중 대기는 멈추고 초기화하면 대기 피해도 제거한다. `damage_popup.accumulation_seconds`로 조정하며 0이면 기존 개별 즉시 표시다. Overdrive에서도 합산 구간은 실제 초를 사용하고 기존 숫자 등장·퇴장 애니메이션 속도는 유지한다.

- 중앙 레이더의 정지 반경은 260px다. 일반 이동 90%·대시 75%·부스트 70%로 0.2초 SmoothStep 전환하며 대시·부스트에서는 링과 방향 화살표를 불투명하게 표시한다. 상태가 바뀌면 현재 표시 값에서 새 목표로 이어진다. 메뉴·일시정지의 전체 화면 전환 투명도는 유지한다.
- 카메라 줌은 정지·일반 이동 1배, 대시 0.9배·부스트 0.85배의 임시 수치다. 월드 배경·기체·그림자·이펙트를 함께 축소하며 HUD 크기는 유지한다. `samples/sword_movement/movement_config.json`의 `camera_zoom`에서 배율·전환 시간을 조정한다.
- HP 바와 무기 패널 사이 중앙의 통합 아이콘으로 다음 E 스왑 기능을 표시한다. 대시 꺾쇠는 HP 왼쪽에 붙여 필살기 마름모의 중심 높이에 맞춘다. SPACE·필살기 레벨 안내가 겹치지 않도록 간격을 둔다.
- 미사일·카운터 슬롯은 120px로 표시한다. 투명 문양 PNG를 UI 원형 패널 위에 합성하며 미사일의 원 테두리는 3.5px, 카운터에는 원 테두리를 표시하지 않는다. 문양·패널·테두리 텍스처를 재사용하며 선마다 그리지 않는다. 설정의 사용키 표시를 저장하면 E·SPACE·필살기 키 안내를 즉시 켜고 끈다.
- 검·PDW·미사일은 기존 모델에서 직접 촬영한 로컬 아이콘을 연결한다. 카운터는 좁은 타원 방어막·입사선·직선 반사 화살표의 단색 문양이다. `hud.icon_manifest`는 일반 실행에서만 읽으며 `--demo`는 공개 도형 아이콘을 사용한다.
- [외부 테마 편집기](../../Tools/hud_theme_editor/README.md)는 색상 그리드·내장 컬러피커·위젯별 색 연결과 큰 실제 Pico2D HUD 미리보기를 제공한다. 선택 색의 적용 부위·사용처를 표시하고 선택 부위를 확대한다. 저장한 `data/settings/hud_theme.json`은 실행 중에 갱신하며 `--theme-file`로 미리보기 작업본을 분리한다. 에너지 레벨·Overdrive 상태색은 유지한다.
- 에너지 게이지·흡수색은 검 Trail의 레벨별 하늘색 설정을 공유한다. 흰 경계 스파크는 레벨 1/2/3에서 초당 40/64/88개·강도 1/1.3/1.65로 증가하며 흰 halo와 점멸을 강화한다. 경계 빛띠는 가장자리 알파가 0까지 감소하는 둥근 마스크를 텍스처로 재사용한다. Overdrive의 빨간색 전환은 유지한다.
- 고정 패널은 텍스처로 재사용한다. IMPACT·SLASH 자간 10px·약한 획 축소, 잔탄 54px·미세 그라데이션을 사용한다.
- 잔탄 본문은 54px의 1배 해상도로 생성한다. Overdrive의 기본 팔레트는 초기화·테마 변경 시 미리 준비하며, 무지개·편집 중 색 변경은 값으로 구분한 제한 캐시에서 재사용한다.
- HIT의 변하는 숫자에 적용하는 모션블러 타깃은 가로·세로 반해상도를 사용한다. 멈춘 숫자·HIT 레이블·DAMAGE와 다른 UI 블러는 기존 해상도를 유지한다. `v2.style.counters.combo.blur_resolution_scale`에서 배율을 설정한다.
- HIT·DAMAGE는 오른쪽부터 등장·퇴장하고 레이블 자간을 펼친다.
- Standby의 기체·검 빨간 림과 호흡, 레벨별 파란 Trail·잔상 0/4/8개, 명중 베임선·금속 마찰 입자는 [이동 명세](sword_movement.md)를 따른다.

## 일시정지 메뉴

- 기존 계속·설정·타이틀로·테스트 종료 기능을 유지한다. 420×94px 버튼을 `(72, 438)`·`(528, 548)`·`(984, 658)`·`(1440, 768)`에 배치하여 화면 가로 전체에 계단식으로 펼친다. 호버 중에도 입력 Rect는 이 위치에 고정한다.
- 시안 1번의 연결부·겹친 베젤·하단 레일을 얇은 중성 회색 금속 텍스처로 표시한다. 광택은 중앙에서 양끝으로 부드럽게 감쇠한다. 로컬 원본은 `data/runtime/images/ui/pause_menu/bezel_v005.png`이며 없으면 공개 도형 경로를 사용한다. 표면 Scanline·Energy band·글자·연결부 발광은 텍스처와 분리한다.
- 호버는 0.14초 SmoothStep으로 8px 왼쪽 이동하고 연결부는 1.4초 주기로 호흡한다. 벗어나면 현재 위치에서 복귀한다. 일시정지 제목은 48px다.
- 왼쪽 아래에는 로컬 `data/runtime/images/ui/logo.png`를 원본 비율·색으로 표시한다. 로고가 없는 공개 시연은 제목 텍스트를 사용한다. 오른쪽 아래에는 일시정지 제목을 표시한다.
- 표현은 `ferrial_drive/ui_v2/pause_menu.py`, 글꼴·스캔/띠 수치·하단 배치는 `samples/ui_unit_test_v2/ui_config.json`의 `pause`에서 관리한다. 현재 등장은 기존 0.16초 전체 페이드이며 단계별 펼침 애니메이션은 제안 단계다.

## 타이틀과 팝업

- 타이틀은 왼쪽 위 실제 로고, 왼쪽 세로 CONTINUE·START·LOAD·CONFIG·EXIT, 오른쪽 아래 VER. 표시다. 배경 아트와 버전 숫자는 미정이다. 메뉴·서브 메뉴·버전 글꼴은 SUITE다.
- CONTINUE는 테스트에서 현재 테스트의 위치·HP·탄약·적·남은 시간을 유지한 채 복귀한다. 타이틀·화면 전환 중에는 전투 상태와 Overdrive·쿨다운 시간을 갱신하지 않는다. START를 펼쳐도 CONTINUE와 START 위치는 고정한다.
- 본편에는 `ContinueSession(mode="game", has_last_save=확인함수, load_last_save=불러오기함수)`를 `HudPreview(..., continuation=...)`에 전달한다. 확인 함수는 마지막 세이브의 유무를 반환하고, 불러오기 함수는 해당 세이브의 실제 상태 복원을 완료한 뒤 `True`를 반환해야 한다. 세이브 없음·로더 미연결은 비활성, 로딩 실패는 타이틀 유지다. 타이틀 진입과 클릭 시 다시 확인하며 저장 목록이 바뀌면 `refresh_continue()`로 표시를 갱신한다. 본편 저장 형식·저장 시점·실제 로더는 아직 구현하지 않았다.
- START를 선택하면 NEW GAME·SURVIVAL이 아래로 펼쳐지고 LOAD·CONFIG·EXIT가 144px 내려간다. 다시 선택하면 접힌다. 0.2초 SmoothStep을 사용하며 표시 위치와 클릭 영역을 함께 갱신한다. 미구현 NEW GAME·SURVIVAL·LOAD는 비활성이고 CONFIG는 설정을 연다.
- 타이틀의 활성 메뉴는 호버 시 0.18초 exponential-out으로 자간이 최대 12px까지 벌어진다. 벗어나면 동일 곡선의 진행 시간을 역재생하며 재진입도 현재 진행점에서 이어진다. 클릭 영역은 고정한다.
- 설정 등 팝업의 바탕은 곧은 사각형이며 바깥 테두리·모서리 절단·Scanline을 사용하지 않는다. 설정은 760×560px를 유지하고 옵션 버튼의 선택 테두리는 보존한다.
- 팝업은 0.16초 SmoothStep으로 투명도 0→1, 중심 배율 0.97→1을 함께 전환한다. 등장 중에는 클릭을 포획하지 않으며 Esc 취소는 유지한다.
- 설정의 고정 안내 두 줄과 `선택` 문구는 표시하지 않는다. `graphics_settings.restart_required_fields`에 등록된 값이 저장값과 달라졌을 때만 뒤로·저장 사이 중앙에 `다시 시작시 적용`을 표시한다. 현재 두 설정은 즉시 적용이므로 등록 목록은 비어 있다. 적용 중·실제 오류 표시는 유지한다.

## Standby Trail

- Standby의 검 Trail만 기존 에너지 표시색에서 Overdrive 빨강으로 65% 추가 혼합한다. 일반·발동 상태의 색 선택, 기체 마스크·전신 잔상·UI는 기존 경로를 유지한다. 생성된 Trail 조각은 생성 시점의 색을 보존한다.
- `samples/sword_movement/movement_config.json`의 `sword_effects.standby_tint_ratio`로 조정한다.

## HUD 배치 제출

- `ferrial_drive/rendering/hud_batch.py`의 `HudBatchQueue`가 메뉴·일시정지·전투 HUD의 그리기 순서를 유지한다. 같은 상태의 연속 도형만 합치며 투명 도형을 텍스처별로 전역 정렬하지 않는다.
- 삼각형·투영 글자·패널 스캔라인·노이즈는 정점/인덱스 버퍼에 쌓고, 같은 텍스처의 연속 구간을 `SDL_RenderGeometry`로 제출한다.
- 채운 사각형과 1:1 배율의 링 span은 같은 색의 연속 구간을 `SDL_RenderFillRects`로 제출한다. 링의 배율이 1:1이 아니면 기존 선 경로를 사용한다.
- 즉시 선·텍스트/이미지 복사, 클리핑·viewport·배율·렌더 대상 변경, 블러·Compute 파티클·GL 전환 전에 대기 도형을 제출한다. 전체 HUD를 단일 GPU draw call로 만든다는 뜻이 아니다.
- SDL_Vertex 배열과 position/color/UV view, 정수 인덱스 배열, SDL_Rect 배열은 렌더러 수명 안에서 재사용한다. 다음 프레임에는 카운트와 값을 갱신한다. 중첩 클리핑·배율 복원용 구조체는 별도로 유지한다.
- 스캔라인·노이즈는 독립 삼각형 인덱스로 SDL software의 사각형 복사 재해석을 막는다. 제출 실패·예외는 대기 명령을 폐기하고 렌더 상태를 복원한다.
- 큐·소프트웨어/실제 GL 픽셀 검사는 `tests/automated/test_hud_batch.py`, 성능 대조는 `--compare no_hud_batch baseline`을 사용한다. 자동 픽셀 동일성과 사용자의 직접 조작·최소 사양 FPS 달성은 구분한다.

## 책임

- `ferrial_drive/combat/movement_application.py`: 창에 전달된 입력·이동·공격·표적 명중과 공유 카메라 연결.
- `ferrial_drive/ui_v2/movement_hud.py`: 훈련장 상태와 시연용 HUD 연결.
- `ferrial_drive/ui_v2/preview.py`: 시연 상태 조작·UI 효과 갱신과 표시.
- `ferrial_drive/ui_v2/state.py`·`view.py`: 본편에서 직접 사용하는 표시 데이터·배치·렌더링.
- `samples/sword_movement/`: 이동 설정과 재현 입력.
- `samples/ui_unit_test_v2/`: HUD 설정·시연 상태·폰트 연결.

공통 모듈 import만으로 창이나 실행 루프를 시작하지 않는다. 본편은 테스트 파일을 거치지 않고 재사용 모듈을 연결한다. 자동 검사·지정 입력 렌더·직접 조작·사용자 외관 승인은 구분한다.

세부 이동은 [이동 명세](sword_movement.md), UI 배치는 [UI v2 명세](ui_unit_test_v2.md), 실행 옵션은 [훈련장 안내](../../samples/sword_movement/README.md)를 따른다.
