# 이동·UI 훈련장

## 전투 수치

`samples/sword_movement/movement_config.json`을 공유하는 이동 훈련장·Combat Test v1.5의 현재 시험값이다.

| 항목 | 1단계 | 2단계 | 3단계 | Overdrive |
| --- | ---: | ---: | ---: | ---: |
| 검 1타 피해 | 60 | 80 | 100 | 150 |
| 기관단총 직격 피해 | 15 | 20 | 25 | 25 |

- 기관단총 탄창 60발·초당 15발·Overdrive 초당 30발/탄약 무소모·사거리 75m.
- 탄환은 한 번 관통해 서로 다른 적 최대 2기를 거리 순서로 타격한다. 관통 후 피해 감소는 없으며 같은 탄환은 같은 적을 다시 맞히지 않는다.
- Overdrive 탄환은 각 명중점에서 반경 3m, 추가 피해 13의 폭발을 발생시킨다. 직격 대상도 범위 안이면 폭발 피해를 받는다. 두 명중점의 폭발 범위가 겹치면 각각 적용한다. 거리별 감쇠·연쇄 폭발은 없다. 발사 당시 피해·폭발 속성은 비행 중 상태 변경과 무관하게 유지한다. 적 중심의 지면 좌표와 명중점 오프셋으로 범위를 검사한다.
- 폭발에는 에너지색 발광·타원 충격파·방사 파편을 표시한다. 일반 피격은 금속 불꽃 10개·광륜·방사 섬광을 사용한다. 수명·개수 상한은 `weapons.contact_effects`로 조정하며 표시 중 새 텍스처를 생성하지 않는다.
- 명중·폭발의 SDL 정점 버퍼와 원형 표본을 재사용하고, 카메라 배율·평행이동은 프레임당 한 번 평가한다. 효과별 수명·정점 수·색·제출 순서는 유지한다.
- 실제 발사 시 탄도 반대 방향으로 최대 2px·0.09초 반동을 표시한다. 빗나가도 발생하며 빈 탄창 시도에는 발생하지 않는다. `weapons.effects.fire_recoil`로 조정한다. 명중 충격과 분리해 각각 감쇠하며 연사 진폭을 누적하지 않는다.
- 검·총 직격·폭발의 명중 후 흡수 에너지는 기존의 50%다. `energy.absorption_gain_multiplier=0.5`를 CPU/GPU 입자 도착 경로에 동일 적용한다. 용량·자연 감소·디버그 충전은 별도다.

자동 검사·VFX 분리 렌더 확인과 실제 전투의 사용감·외관 승인은 구분한다.

## 효과음

기관단총의 실제 발사 시 `gun_fire`, 탄약이 없는 발사 시도 시 `gun_empty`를 재생한다. 누르는 동안은 기존 연사 간격에 따라 사건을 발생시키며 단발 요청·무기 전환·일시정지 규칙을 따른다. 현재 발사음은 사용자가 VARCO AI로 생성한 `futuristic_gun(GEN_3).mp3` 버스트에서 나눈 31~44ms 샘플 네 개다. 발사마다 무작위로 선택하고 직전 샘플은 제외하며 사건 음량 배율은 0.85다. 빈 탄창은 `moniker_subriquet-gunshot_smg_loop_end-203470.mp3` 원본을 유지한다. 클릭 입력만으로 발사음을 재생하지 않으며 빈 탄창 시도는 탄약 회복 유예를 재시작하지 않는다.

부스트 발동음은 `jet_boost.ogg`의 약한 앞부분 0.29초를 제외하고 앞 3ms만 페이드한 WAV를 사용한다. 정규화·끝 페이드·피치 편집 없이 남은 꼬리를 보존한다. 사건 음량 0.85·기존 재생률 변주 ±1.5%·cooldown 0.12초를 유지하며 부스트 발동 시점을 옮기지 않는다.

대시가 활성일 때 지속 마찰음 `scrape`에 `motion.dash_scrape_gain=0.85`를 적용한다. 두 마찰 레이어의 비율은 유지한다. 대시 이외의 쓸림은 gain 1로 복귀하며 부스트 발동음·지속 분사음·자갈은 이 배율로 줄이지 않는다.

탄약은 마지막 실제 발사 뒤 1초부터 `4 × exp(1.6 × t)` 발/초로 회복한다. `t`는 회복 시작 후 경과 초다. 회복률 설정은 `weapons.gun.ammo_recovery_initial_rounds_per_second`이며 연사 속도·회복 유예·성장 계수와 별개다.

달리기 발 디딤·지속 마찰/자갈·검 활성 구간·실제 명중·부스트 준비 종료에 소리를 연결한다. 카운터 표시 시연과 필살기 쿨다운 진입에도 선택 음원을 연결한다. 실행·원본 보존·라이선스·레벨별 실시간 레이어 혼합은 [사운드 안내](../../samples/sound_effects/README.md)를 따른다. 현재 목표는 낮은 발 디딤의 무게, 스키처럼 쓸리는 마찰, 물리적인 휘두르기 바람 소리다. 음색과 실제 접지 동기화는 청취 조정 대상으로 둔다.

일반 검 공격에는 타격마다 1회의 발 디딤을 기존 발걸음의 30% 음량으로 연결한다. 타수별 임시 위상은 공통 sound bank의 `motion.attack_step_phases`에서 조정한다. 대시·부스트 구간의 공격은 제외한다. 부스트음의 원본·가공 기준은 [사운드 안내](../../samples/sound_effects/README.md)를 따른다.

그림자 PNG의 알파 전용 제작 데이터는 [준비 안내](../tool-usage/alpha_textures.md)를 따른다. PNG 재출력 뒤 준비 명령을 다시 실행하면 시작 시 RGBA 변환을 건너뛴다. 원본 변경·전용 데이터 부재 시 PNG 호환 경로를 사용한다.

검·총을 든 기체의 달리기·접지 대시·부스트·사격·조준·수납/인출을 1km 정사각형 흙바닥에서 직접 조작한다. Energy Mask는 레벨·Overdrive의 HUD 표시색을 공유한다. [실행·입력·설정·시연 안내](../../samples/sword_movement/README.md)를 따른다.

총 연사는 `weapons.gun.shot_interval_seconds` 기준 900 RPM(초당 15발), 탄속은 5,500 투영 월드 픽셀/초다. 판정은 이전 위치부터 새 위치까지의 선분으로 검사한다. `weapons.swap_speed=2`는 수납·인출 모션에만 적용하며 Overdrive 애니메이션 배율과 곱한다. 대시·부스트에서도 기존 `gun_aim_enter`/`gun_aim_exit`를 재생한 뒤 해당 조준/비조준 대시 반복으로 복귀한다. 이동·사격은 전환 중에도 유지한다. 새 대시 전용 전환 에셋을 제작한 상태와 구분한다.

탄환은 `PicoGunEffects`가 로딩 중 한 번 준비하는 64×16 RGBA 텍스처로 표시한다. 밝은 탄두와 감쇠하는 꼬리를 진행 방향에 맞춰 회전하며, 현재 표시 길이·폭은 108×6 투영 월드 픽셀이다. 꼬리는 실제 누적 비행 거리까지만 늘려 총구 뒤로 뻗지 않으며 한 프레임 이동량으로 제한하지 않는다. `weapons.effects`의 길이·폭·꼬리색·중심색으로 조정한다. 텍스처와 표시 크기는 명중 반경과 독립이며 종료 시 GPU 자원을 해제한다.

록온이 없으면 첫 유효 후보를 즉시 획득한다. 다른 적으로 바꿀 때만 마우스 월드 좌표에 더 가까운 후보를 연속 1초 확인한다. `targeting.acquisition=visible`로 현재 화면에 본체 표시 영역이 일부라도 보이는 적만 획득·교체 후보로 사용한다. 조준 여부에 따른 획득 거리 차이는 없다. 기존 표적은 거리 제한 없이 유지하고, 사망·비활성 또는 플레이어 기체의 표시 사각형 전체가 현재 화면 밖으로 나가면 해제한다. 줌은 반영하며 피격 흔들림·그림자·잔상은 제외한다. 화면 이탈로 해제한 표적의 반복 재획득은 플레이어 중심 화면에서 해당 적이 보일 때까지 막는다. 획득 가시성은 현재 카메라·줌·적 본체 표시 영역으로 계산하고 피격 흔들림은 제외한다. 총은 록온 좌표를 향해 발사하되 탄 퍼짐과 앞 표적의 충돌을 유지한다. 적중만으로 록온을 바꾸지 않는다. 카메라는 록온 중 플레이어·표적 중간점을, 미획득 중 기존 시선 오프셋을 추적한다. 상세는 [원거리 표적 규칙](../ranged_targeting.md)을 따른다. 새 획득·교체 후보는 플레이어 중심 화면에서도 보여야 하며, 복귀 중인 록온 카메라에만 보이는 먼 적은 제외한다.

실제 시선·머리·팔·상체는 조준 목표 방향으로 보간하며 먼저 반응한다. 하체는 상체와의 방향 차이가 ±45°를 넘으면 보간 추종을 시작하고 정렬될 때까지 이어간다. 45° 차이를 유지하거나 경계에 강제 고정하지 않는다. 현재 훈련장은 [상·하체 입력용 출력](upper_lower_aim.md)을 선택한다. 내부 각도는 연속이며 화면은 8방향·12fps 원본 프레임을 사용한다.

`weapons.aim_speed=2`는 조준 진입·해제 모션만 2배로 재생한다. 기본 8프레임/12fps 클립은 약 0.333초, Overdrive에서는 약 0.167초다. 실제 모션 시간과 보간 재생 속도에 같은 배율을 적용하며 이동 반복·연사·자동 표적 선택 대기 시간은 별도로 유지한다.

## 구성

Q는 화면 내 주변 후보 중 커서에 가장 가까운 적으로 즉시 록온한다. 선택은 자동 교체로부터 1초 보호하며 후보가 없으면 기존 표적을 유지한다. Q는 종료 키로 사용하지 않고 F10으로 종료한다. `targeting.screen_distance_switch.enabled=true`로 화면 거리 교체를 시험한다. 화면 반폭·반높이로 정규화한 간격 0.7에서 시작·0.55에서 복귀하며, 기존보다 25% 이상 가까운 후보가 0.25초 유지되면 교체한다. 대체 후보가 없으면 유지한다. 모든 대기 시간은 Overdrive와 무관한 실제 초다. 세부 조건은 표적 규칙을 따른다.

Trail 결은 실행 전에 `python automate/run.py trail-texture`로 파일을 준비한다. `--demo`는 같은 명령에 `--demo`를 추가해 게임 에셋 없이 샘플 폴더에 준비한다. 게임 로딩의 `Trail 준비` 단계가 결 적재·셰이더 컴파일·버퍼 예약·첫 GPU 실행을 담당한다. [준비와 검증 범위](../tool-usage/trail_texture_preparation.md)를 따른다.

## 동작 기준

- 검 실제 명중 시 화면 기준 최대 일반 12px·Overdrive 18px의 카메라 충격을 사용한다. 표적에 가까운 검끝 이동 방향으로 화면을 밀고, 반동이 지수 감쇠하며 끝에서 부드럽게 0으로 복귀한다. 지속 0.2초·진동수 12Hz·감쇠 1.8은 사용감 확인 전 시험값이다. `camera_impact.enabled`·`amplitude_pixels`·`overdrive_amplitude_pixels`·`duration_seconds`·`frequency_hz`·`damping`으로 조정한다. 진폭은 명중 순간의 Overdrive 상태로 결정하고 복귀 중 상태가 바뀌어도 유지한다. 충격 시간은 Overdrive에서 가속하지 않는다. 같은 타격은 표적 수·명중 프레임과 관계없이 한 번만 반응하고 새 타격도 진폭을 합산하지 않는다. 빈 휘두르기·사망 표적·F1 피해 시연에는 발생하지 않는다. 조준·자동 타겟 선택·추적 속도·줌은 충격과 분리하며, 월드·적 HP·록온·피해 숫자는 함께 움직이고 고정 HUD·레이더 중심은 충격에 영향받지 않는다. 일시정지 중 수명을 멈추고 초기화 시 제거한다.
- 월드 줌은 정지·일반 이동 1배, 대시 0.9배·부스트 0.85배를 임시 사용한다. `movement_config.json`의 `camera_zoom.scale_by_state`와 `transition_seconds`로 조정하며 기본 0.2초 SmoothStep으로 전환한다. 좌표의 정방향·역방향 변환에 동일한 줌을 사용하고 판정·이동 거리 자체는 바꾸지 않는다. 레이더의 화면 반경·불투명도는 카메라 줌과 독립이며 [UI 기준](ui_unit_test.md)을 따른다.
- 확정 설계: 검·총과 조준 여부에 관계없이 이동·공격 중에도 상체의 기준 방향은 현재 시선을 보간 추종한다. 하체는 상·하체 차이 ±45° 초과 때 추종을 시작해 정렬까지 이어간다. 이동 입력·공격 전진 경로와 몸의 회전은 분리한다. 현재 검 대기·이동·대시·4타와 총 비조준·정지 조준에 새 자료를 연결했다. 부스트·무기 전환·조준 이동/사격은 기존 출력이며 접지·직접 조작감은 별도 확인 대상이다.
- 검의 옆걸음·뒷걸음 전용 모션 제작은 향후 과제다. 상체 추종 시정수와 정렬 오차는 검토용 설정이며 최종 조작감은 미확정이다.
- 일반 부스트의 몸 방향은 마우스 조준을 따른다. 부스트 이동 방향은 시작 시 고정하며 재입력은 종료 전까지 받지 않는다. 이번 검 달리기·대시 방향 통일의 범위에 부스트 규칙 변경은 포함하지 않는다.
- 대각선 이동은 정규화한다. 기본 이동 입력 해제 시 현재 방향으로 0.2초 SmoothStep 관성 감속하고, 부스트 종료 후 남은 프레임 시간은 일반 이동에 사용한다.
- 맵 경계는 반경 2.5m를 남겨 중심 위치를 제한한다. 이 경계 처리는 훈련장용이며 본편의 장애물·기체 충돌 정책을 확정하지 않는다.
- 화면 배율은 전폭 5m/128px 기준 25.6px/m, 바닥의 세로 투영은 기존 Unreal 카메라 고도에 맞춘 약 0.3209다. 기체 PNG는 기존 128/202 배율이다.
- 모션 전환은 시험용 0.12초다. 기존 전신 출력에는 양방향 벡터 보간을 사용하며 새 상·하체 표는 원본 12fps 프레임을 선택한다. UI v2·좌클릭 4타·부스트 중 공격 유지를 연결한다. 기본 이동은 30m/s·대시는 100m/s다. 부스트는 0.08초 준비 후 250m/s에서 0.2초 동안 일반 30·대시 100·입력 없음 0m/s로 감속한다. 공격 중에는 타격의 이동 입력이 있으므로 일반/대시 목표를 사용한다. 훈련 표적의 검 명중·시연용 HP·피해 숫자·HIT/DAMAGE·에너지 흡수는 연결한다. 지형 IK·본편 피해 규칙/적 AI·전용 부스트 공격은 미연결이다.
- WASD는 화면의 고정 방향으로 이동한다. W 위, A 왼쪽, S 아래, D 오른쪽이다. 검 기본 이동의 전진 주기는 보존하며 몸의 시선은 마우스·목표 추종 상태를 따른다. 옆걸음·뒷걸음 전용 검 모션은 제작하지 않았다.
- 방향별 월드 이동 속도는 동일하다. 세로 투영에 따른 화면 속도 차이를 실제 속도 증폭으로 보정하지 않는다.
- 상·하체 분리의 연결 범위·출력 방식·미지원 동작과 검증 한계는 [상·하체 검토](upper_lower_aim.md)를 따른다.

## 우선 과제: 첫 화면 로딩 지연

현재 OpenGL 훈련장은 Oodle BC7 색상·무손실 벡터 공유 아틀라스를 사용한다. 기존 일반 PNG 본체와 보간 본체를 중복 적재하지 않으며, 그림자는 원해상도 알파만 R8로 올린다. 기존 RGBA 그림자의 검정 RGB는 저장하지 않는다. 소프트웨어/기본 도형 시연 경로와 구분한다. 독립 비교의 계측 범위·한계는 [압축 Unit Test](texture_compression.md)를 따른다.

- 실행부터 첫 화면 표시까지의 지연을 우선 분석한다. 기존 `--profile`은 이동 update/draw·화면 표시·프레임 대기를 계측하며 초기 로딩 내부 구간 계측은 미연결이다.
- 파일 읽기·이미지 디코딩·보간 데이터 변환·GPU 전송을 구분하고 시작부터 첫 화면 표시와 조작 가능 시점까지 각각 측정한다.
- 시작 시 준비 범위 축소·중복 읽기/변환 제거·사전 가공 캐시를 검토한다. 현행 훈련장은 사전 알파 변환·공유 아틀라스·BC7을 연결했으며 병렬 이미지 로딩은 미구현이다.
- 보간 벡터는 RG/BA에 16비트 수치를 담으므로 색상 이미지와 압축 정책을 분리한다. 병렬화는 파일 읽기·CPU 준비와 메인 스레드의 렌더러/GPU 작업을 구분한다. 계측 결과와 조사 근거는 [방향 규칙·로딩 과제 기록](../ai-dev-log/2026-11-13-movement-direction-loading.md)을 따른다.

## 일반 이동 가감속과 관성

- `movement.movement_acceleration_seconds=0.2`는 일반 이동의 목표 속도 전환과 키 해제 감속에 공통 적용한다. idle→달리기 0→30m/s, idle→대시 0→100m/s, 달리기↔대시는 현재 속도에서 새 목표로 SmoothStep 전환한다.
- 방향 변경은 속도 가속을 재시작하지 않는다. 키를 놓으면 마지막 이동 방향으로 감속하며, 새 입력은 즉시 이동 방향과 목표 속도를 갱신한다. 감속 완료 후 Idle로 전환한다. 별도 걷기 모드는 없다.
- 일정한 최고 속도에서 놓을 때 관성 거리는 달리기 약 3m·대시 약 10m다. 가속 도중 해제하면 현재 속도에 비례해 줄어든다. 모션 전환 0.12초와 위치 가감속 0.2초를 구분한다.
- 위치는 곡선의 구간 적분으로 갱신한다. `speed_mps`는 실제 프레임 평균 속도, `movement_speed_mps`는 구간 종료의 순간 속도다. 다음 목표 전환은 종료 속도에서 시작한다. 달리기 반복과 블러 노출도 변화한 속도를 따른다.
- 부스트 준비 중에는 일반 이동을 이어간다. 이동 방향은 요청 시 고정하며 추진 속도는 SmoothStep 구간 적분으로 계산한다. 고정 목표의 추진 구간 거리는 일반 28·대시 35·입력 없음 25m이고 준비 중 이동은 별도다. 부스트 도중 목표가 바뀌면 현재 속도에서 남은 시간 동안 새 목표로 감속한다. 종료 뒤 남은 프레임 시간은 일반 이동에 사용한다.
- 재현 입력은 `samples/sword_movement/acceleration_input.json`이다. 캡처 항목이 있으므로 `--report`와 함께 실행한다. 사전 지정 입력과 실제 키보드 사용감 승인은 구분한다.

## 공격 이동과 품질 설정

공격 재생은 `combat.playback_speed=1.5`와 `combat.easing=linear`의 전체 위상 `p(t)=t`를 사용한다. 타격 전체 시간을 유지하며 준비·휘두르기·복귀를 원본 시간에 선형 대응한다. 공격 이동은 `combat.acceleration=constant`로 가속 없이 지정 속도를 즉시 적용한다. 모션 재생 위상과 위치 이동 속도를 구분한다. 본체·그림자·검 궤적·판정 구간은 같은 재생 위상을 사용한다.

- 공격 중 이동 키 없이 자동 전진한다. 각 타격 시작의 마우스 방향을 타격 끝까지 유지하며 예약 클릭 당시 방향과 구분한다. 일반 공격 전진은 WASD로 조종하지 않는다. 부스트를 요청하면 위치 이동은 고정된 부스트 방향을 우선한다.
- 공격 이동 속도는 1·2·4타 일반 50m/s·Shift 유지 90m/s, 3타 70/120m/s다. 첫 프레임부터 고정 속도로 이동하며 Shift 변경은 진행 중인 타격에도 적용한다. 일반 달리기/대시의 0.2초 가감속과 부스트의 추진 곡선은 별도다.
- Space는 콤보를 초기화하지 않는다. 준비·추진 중에도 공격 시간·명중 구간·Trail·잔상·다음 타격 예약과 자동 반복을 진행한다. 부스트 종료 후에는 해당 타격의 공격 이동으로 이어진다. 연결 대기 자세에서는 공격 전진을 멈추지만 부스트 이동과 다음 공격 입력은 유지한다. 부스트가 없는 대기에서는 WASD로 일반 이동에 복귀한다.
- 타이틀 또는 Esc 일시정지의 **설정**에서 원본 기준 높음 75%·보통 50%·낮음 25%를 선택한다. 기본은 낮음 25%이며 저장하면 현재 실행에 적용한다. 취소/Esc는 저장하지 않는다.
- 기본 저장 경로는 `data/settings/game_settings.json`, 검증용 분리는 `--settings-file`을 사용한다. `texture_quality_profiles`가 로컬 후보를 가리킨다. 품질 옵션은 색상·보간 벡터 해상도를 선택하며 원본 시트·애니메이션·HUD·바닥은 바꾸지 않는다. 그림자는 별도 제작 단계에서 50% R8로 준비하고 원본 좌표로 표시한다.
- 사용자 설정의 `interface.show_key_hints`는 스왑 E·부스트 SPACE·필살기 키 안내를 함께 조절한다. 기본 켬이며 설정 메뉴에서 저장 즉시 적용한다. 다음 실행에도 유지하며 품질 선택·다른 사용자 설정과 독립적으로 저장한다.
- 현재 160클립 보간 GPU Storage는 높음 약 508.69MiB·보통 236.06MiB·낮음 65.96MiB다. 그림자는 별도 50% R8 약 67.04MiB다. UI/바닥/입자·드라이버는 별도이며 물리 VRAM 점유량과 구분한다.
- OpenGL 품질 교체는 새 색상·보간 아틀라스를 준비한 뒤 설정 저장 성공 때 적용하고 이전 자원을 해제한다. 월드·공격 진행·HP·HUD는 초기화하지 않는다. 준비/저장 실패 때는 기존 자원과 저장값을 유지하고 설정 화면에 오류를 표시한다.
- 그림자는 프레임의 원래 위치·피봇을 유지하고 화면 반경 최대 5px로 가장자리를 부드럽게 한다. 접지 원점에 가까운 영역은 번짐을 줄이는 2D 근사다. `shadow_softness_pixels`·`shadow_contact_radius_pixels`는 표현 설정이며 보간 토글과 독립적으로 적용한다.
- 보간을 끄면 몸체·그림자는 같은 선형 위상의 정수 프레임을 사용한다. 그림자는 전용 경로에서 한 번 표시하고 몸체 출력에서는 제외해 중복 합성을 막는다. 그림자 전용 경로가 없는 환경은 원본 그림자 출력을 사용한다.
- 페이지별 독립 Work가 읽기·해시 검사·압축 해제를 수행한다. 기본 동시 준비 수는 4개이며 GPU 적재·캐시는 렌더 스레드가 소유한다. 동기화·오류·취소 계약은 [병렬 적재 안내](../tool-usage/texture_page_loading.md)를 따른다.
- 실제 연결 대상은 공유 게임 메뉴와 이동·UI 훈련장이다. 사용감·모든 모션 품질 승인은 별도다.

## 검 Trail·에너지 레벨·명중 확인

`1/2/3`으로 훈련용 에너지 레벨을 바꾼다. HUD 시연 상태의 에너지·레벨을 검 효과에도 공급한다. 게이지 자동 회복·소모·레벨 승강 요구량은 여기서 확정하지 않는다. `sword_effects`의 값은 외관과 사용감을 비교하기 위한 시험값이다.

| 레벨 | 칼날 길이 배율 | 대시 공격 배율 | Trail 수명 | 전신 잔상 상한 |
| --- | --- | --- | --- | --- |
| 1 | 2.4 | 3.24 | 0.26초 | 0 |
| 2 | 3.6 | 4.86 | 0.36초 | 4 |
| 3 | 5.0 | 6.75 | 0.48초 | 8 |

- 길이 배율은 검날 시작점을 고정하고 끝점을 연장하는 값이다. 대시는 해당 레벨 배율에 1.35를 곱한다. 레벨별 색·알파·수명도 달라진다. 본체의 모델·파지·원래 공격 모션을 수정하지 않는다.
- Unreal의 실제 120Hz `cutting_edge_root`/`cutting_edge_tip`을 지면 root 기준으로 투영하고 본체와 같은 가속 재생 위상을 적용한다. 파란 칼등 좌표와 구분한다. 모션 클립의 실제 경과 구간·타격 ID·이동 전후 위치·Shift 상태를 재사용한다.
- 최대 1/240초 간격으로 검날이 쓸어간 면을 만들고, 연계 경계를 넘어 서로 다른 타격의 면을 잇지 않는다. 베기는 휘두른 궤적을 따라 길게 겹쳐 흐르고 양끝이 가늘어지는 곡선형 검빛으로 표시한다. 3타 찌르기는 진행 방향을 향하는 `>` 모양이며 양쪽 날개도 실제 판정 면에 포함한다.
- 1레벨 일반 찌르기의 V 전체 폭은 원래 칼날 표시 길이의 약 46.15%다. 레벨 상승은 1레벨 대비 범위 배율, 대시는 추가 1.35배를 적용한다. `thrust_width_ratio`로 비율을 조정한다. 두 선 전체에 해당 레벨의 파란색 코어와 외곽을 겹쳐 표시하고 선 굵기·꼬리 알파는 `thrust_*` 설정으로 조정한다.
- 찌르기 표시는 타격마다 최신 궤적 하나만 사용한다. 양쪽 날개는 꼭짓점과 텍스처 좌표를 공유하며 끝점에서 검빛이 끊기지 않는다. 다음 타격이 시작되면 `thrust_transition_fade_seconds=0.08` 동안 지운다.
- `thrust_visual_scale=2.5`는 찌르기 Trail의 끝점을 고정하고 양쪽 날개 길이·폭과 빛줄기 굵기를 키우는 표시 배율이다. 레벨별 확대에 함께 곱하며 실제 명중 범위와 독립이다.
- 찌르기 빛줄기의 기준 반폭은 외곽 약 7.38px·코어 약 2.36px다. `thrust_outer_half_width_pixels`·`thrust_core_half_width_pixels`에 표시 배율과 레벨별 확대를 함께 적용한다.
- 판정은 투영된 2D 궤적과 원형 표적의 접촉이다. 화면의 모양에 적용한 에너지/대시 배율을 함께 사용하며, `hit_y_margin_m=1.5`로 위아래 ±1.5m의 추가 여유를 준다. 현재 평면 투영에서는 약 ±12.3px다. 이는 3D 높이 충돌이나 지형 높이 판정이 아니다.
- 활성 구간은 시험용으로 원본 위상 기준 1~3타 1/3~1/2, 4타 0~3/8이다. 준비/복귀/연결 대기에는 새 판정을 만들지 않는다. 제작 궤적의 과거 `combat_hit_windows_approved=false`를 최종 승인으로 바꾸지 않는다.
- 기존 기본 표적 A/B/C 배치는 제거했다. 외부에서 표적을 주입하면 명중 시 잠시 밝아지고 횟수가 증가한다. 같은 타격은 같은 표적을 한 번만 맞힌다. 남아 있는 시각 Trail과 전신 잔상에는 추가 판정을 주지 않는다. 명중에 시연용 HP·피해 숫자·HIT/DAMAGE·흡수를 연결한다. 본편 피해량·에너지 회복 규칙은 별도 범위다.
- 훈련장 검 1회 명중의 피해량은 에너지 1/2/3단계에 따라 60/80/120이다. `combat.damage_by_energy_level`에서 조정하며 명중 당시 레벨로 선택한다. 표적 HP·피해 숫자·누적 DAMAGE는 같은 실제 적용 피해를 사용하고, 남은 HP보다 큰 피해는 남은 HP까지만 적용한다. F1의 고정 피해 시연은 HUD 설정을 따른다.
- 전신 잔상은 실제 과거 공격 자세·방향·월드 위치와 생성 당시 에너지색을 저장한다. 1/2/3레벨은 원래 명암과 에너지색을 55/70/85%로 혼합하고 알파 0.30/0.40/0.50에서 페이드한다. 공유 아틀라스/텍스처를 재사용하며 본체의 색·알파와 분리한다. 잔상 자체는 추가 모션 블러 없이 과거 자세를 표시한다. 수명이 줄수록 투명도뿐 아니라 RGB 명도도 100→16%로 낮춘다. 일시정지 시 수명도 멈추고 R 초기화에서는 제거한다. `--demo`는 공개 수치 궤적으로 Trail·판정·레벨 입력을 시연하며 실제 기체 전신 잔상은 게임 에셋 경로에서 확인한다.
- 재현 입력은 `samples/sword_movement/energy_trail_input.json`이다. 400프레임 동안 레벨 1~3·레벨 3 대시·베기/찌르기를 비교한다. 캡처 항목 때문에 `--report`가 필요하다. 같은 프레임의 초기화는 이동·에너지·공격 입력보다 먼저 적용한다.

구현·검사·실제 캡처와 미검증 범위는 [UI·Standby·검풍 기록](../ai-dev-log/2026-11-15-ui-standby-body-wind.md)을 따른다.

## 검 Trail과 Standby 림

- 실제 에너지 용량은 LV1/LV2/LV3 각각 100/200/400, Overdrive 추가 200이다. `energy.level_capacities`·`overdrive_capacity`로 설정하고 `EnergyAmount`에서 실제 양과 화면 비율을 변환한다. 훈련장 명중 흡수에는 `energy.absorption_gain_multiplier=0.5`를 적용하며 본편의 최종 밸런싱과 구분한다.
- 마지막 실제 회복 후 2초(`energy.decay_margin_seconds`)부터 일반 에너지를 초당 0.5(`decay_per_second`) 줄인다. 입자 생성이나 감소만으로 유예를 재시작하지 않는다. 추가 Overdrive 충전량은 보존하며 Standby·Overdrive 발동·일시정지·설정·메뉴 중에는 자연 감소와 유예 시계를 멈춘다. Standby 만료 시 2초 유예를 다시 시작한다. 레벨 하락은 이전 레벨 게이지 최대치−1 규칙을 적용하고 LV1·0 아래로 내리지 않는다. 반영·검증 범위는 [에너지 용량·자연 감소 기록](../ai-dev-log/2026-11-16-energy-capacity-decay.md)을 따른다.
- 선택적 무지개색 시험은 `tests/overdrive_rainbow_test.py`로 실행한다. Overdrive 발동 중 기체 림·검 Trail·잔상·HUD를 실제 경과 시간 기준 3초 주기로 순환하며 설정은 `overdrive_rainbow.cycle_seconds`다. 고정된 새 테마를 저장하지 않는다. F6 강제 발동·해제와 R의 Standby 발동, 10초 지속·강화 수치·일시정지 규칙은 공통 훈련장을 따른다. 종료·초기화는 원래 팔레트로 복원한다. 기본 훈련장의 붉은 Overdrive와 별도 선택 가능한 시험이다.
- Trail 색은 레벨별 하늘색 `#50B8F2`·밝은 하늘색 `#78D0FF`·연한 하늘색 `#A0E6FF`, 기본 알파는 0.50·0.65·0.80이다. 색상과 밝기를 함께 구분하며 흰색 코어를 사용하지 않는다. `flow_strands=18`·`flow_softness=0.018`은 진행축에 길게 겹치는 가닥 수와 폭 방향 번짐을 조절한다. `trail_inner_ratio=0.62`는 검빛 띠의 안쪽 경계이며 판정 면의 축소 비율이 아니다.
- 몸 주변 검풍은 `sword_effects.body_wind.enabled=false`로 표시와 추가 판정을 끈다. 검날 Trail과 검날 궤적의 명중 판정은 유지한다.
- Trail 표시 곡선은 타격별로 분리해 완만하게 연결한다. 표시 보간은 실제 명중 면을 수정하지 않으며 서로 다른 타격이나 찌르기 날개를 연결하지 않는다.
- 칼날 투영이 접히거나 표시 면의 진행 방향이 뒤집히는 구간은 별도 띠로 분리한다. `trail_min_sweep_ratio=0.12`보다 좁게 투영되는 구간과 매우 짧은 조각은 표시에서 제외한다. 4타의 투영 특성 때문에 폭을 강제로 늘리지 않는다. 명중 궤적·유효 시간은 표시 분리와 독립이다.
- 추가 게이지 완충 시 3초의 Standby에 진입하고 R로 Overdrive를 발동한다. Standby 진입부터 재진입 쿨다운 30초를 계산한다. 추가 회복·R 재입력은 시간을 연장하지 않는다. 쿨다운 중 완충되면 종료 후 Standby에 진입한다. Standby 만료는 LV3·일반 게이지 0, 발동 10초 후 종료는 LV1·게이지 0으로 돌아간다. 3초·10초·30초는 실제 시간이며 일시정지에서는 멈춘다.
- Standby의 검 Trail에는 붉은색을 18% 혼합하고 기체·검 실루엣의 붉은 Rim은 기존 강도의 25%로 표시한다. 발동 중에는 Trail을 `#FF4044`로 표시하고 범위·실제 판정을 1.15배로 확대한다. Rim은 `overdrive_rim`의 색 `#FF263D`·최대 강도 1.0·호흡 1.8초·최소 강도 비율 0.65를 사용한다. Rim은 OpenGL 아틀라스·프레임 보간 경로의 2D 알파 외곽 표현이다.
- Overdrive 발동 중 검 피해량은 150이다. 전체 UI는 기존 밝기를 기준으로 붉은 팔레트로 전환하며 종료 후 원래 테마로 복원한다. 저장된 테마는 변경하지 않는다.
- Overdrive의 요구사항은 공격·대기·이동 전환·HUD·스왑 애니메이션 2배, 일반 이동·대시·부스트·공격 전진 속도 1.5배다. Trail·잔상·지면 효과·피격 불꽃 등 VFX 자체의 재생 속도·입자 갱신·수명·소멸 시간은 가속하지 않는다. 검 Trail의 위치와 생성 타이밍은 가속된 공격 동작을 따른다. 일시정지에서는 VFX 시간도 멈춘다. VFX 가속 제외의 코드 반영·검증은 [결정 기록](../ai-dev-log/2026-11-16-overdrive-vfx-time.md)을 따른다. 애니메이션 배율과 이동 배율은 중복 적용하지 않는다. 일반 스킬·필살기·백웨폰 쿨다운 감소 속도는 2배다. 백웨폰 발사와 쿨다운 시작 사건은 미연결이며 외부에서 공급한 쿨다운 상태의 갱신만 준비돼 있다.
- Overdrive 중 효과음 재생률은 1.1배다. 새 효과음에 적용하며 지속음은 전환 시 한 번 재시작한다. SDL 재생률 변환이므로 Pitch와 재생 길이가 함께 바뀐다. 이미 재생 중인 단발음의 중간 Pitch는 변경하지 않는다.
- 수치는 이동 설정의 `overdrive`에서 조절한다. F6은 충전 조건을 건너뛰는 훈련장 강제 발동/해제이고 R은 Standby에서만 발동한다. 초기화는 F5다.
- 에너지 마스크의 레벨별 밝기 제어는 실제 마스크 출력본이 없어 보류한다. 머리 분리·록온 시 머리/몸 회전 여유는 검토 범위이며 구현 완료로 보지 않는다.

## 로딩과 자동 스윙

- 시작 시 `data/runtime/images/ui/logo.png`와 준비 단계/진행 막대를 표시한다. 이 파일은 사용자가 덮어쓴 로고다. 로딩 화면과 자원/GPU 업로드는 메인 스레드에서 처리하고 묶음·페이지마다 화면을 갱신한다. 실제 시간 비율이나 남은 시간을 표시하는 막대는 아니다.
- 좌클릭 유지 시 1→2→3→4→1을 반복한다. 버튼 해제 시 자동 예약만 취소하고 현재 타격은 마친다. 클릭으로 명시 예약한 타격은 유지한다. 포커스 상실·일시정지·메뉴/설정 진입에서 누름 상태를 해제한다. 부스트 취소 후에는 준비/추진을 마친 뒤 자동 공격을 재개한다.
- R8 그림자 업로드는 입력 행 간격·행/열 건너뛰기를 명시적으로 설정하고 호출 전 상태를 복구한다. 로딩 화면의 SDL 이미지 업로드 상태에 의존하지 않는다.

## 프리렌더 인계

현재 대상은 `movement_config.json`의 카탈로그다. 대기·달리기와 해당 전환 32방향 클립을 유지하며 대시·부스트는 바깥 손목 보정 후보를 사용한다. 부스트 진입 3모션×8방향은 `BoostPrepare_20261113`의 수직 준비→수평 전환을 사용한다. 손 목표와 파지는 유지한다. 전신 `body`와 `shadow`는 기존 패킹·로더를 사용한다. 그림자 보간은 각 시트의 잘림·기준점·텍스처 크기를 각각 적용한다. H로 그림자를 켜고 끈다.

## 접지 효과와 백웨폰

- `ground_effects` 설정에서 발생 간격·상한·크기·수명·강도를 조정한다. 현재 흙바닥에는 회색 마찰·흙 파편·노즐 연기를 표시한다. `metal` 프로필의 불꽃/연기는 준비돼 있지만 실제 금속 지형 판별은 미연결이다.
- 발에는 마찰/연기/암석을, 다리 노즐에는 둥근 분사 연기와 에너지 Trail을 표시한다. 발 효과는 반복 바닥 텍스처의 발생 지점 주변 색을 합성한다. 원형 연기는 수명 동안 커지며 내부 질감을 약하게 유지한다. 마찰 본체는 0.05초, 암석은 0.3초다.
- 대시·부스트와 대시 공격 중에는 양발의 현재 발바닥 좌표에 마찰 효과를 계속 겹쳐 그린다. `appearance.foot_friction`으로 기본 크기 64×32px·기본 색·알파·표면 질감·변형 속도를 조정하며 동작 강도를 곱한다. 바닥색 함수가 있으면 좌우 발의 현재 위치에서 텍스처 주변 평균색을 따로 읽어 적용한다. 현재 `ground_color_blend=0.8`로 흰색에 바닥색을 80% 섞으며, 함수가 없을 때는 설정의 기본 회색을 사용한다. 발별 한 개씩 유지하고 발생 간격과 무관하게 매 프레임 위치를 갱신하며, 본체보다 앞에 그린다. 원본 왼쪽 위 좌표와 투명 여백을 사용해 이미지 경계 잘림을 방지한다. 동작 종료 시 즉시 제거하며 바닥에 남는 마찰/먼지와 구분한다.
- 등 분사는 준비가 끝난 실제 부스트 동안만 발생하며 다리와 같은 각도, 더 큰 크기를 사용한다. 부스트 중 다리 Trail도 길게 표시한다. 길이와 강도는 각각 0.03초 선형 보간으로 빠르게 켠다. 분사 종료 후 0.12초 유지·0.35초 Fade out하며 길이/폭도 줄어든다. 다리 부스트 Trail은 별도 잔상으로 남긴다.
- 다리·등 Trail과 잔상은 가는 흰 중심선에서 가장자리의 에너지색으로 부드럽게 이어진다. 꼬리에는 분사축을 따라 길게 늘인 결·약한 휨·폭 감쇠를 적용해 Smudge처럼 번지는 인상을 만든다. 시간 표본 모션 블러와 구분하며 금속 불꽃과 원형 입자의 색상 처리는 별도로 유지한다.
- 발 추종 마찰 이미지는 오른쪽 방향을 기준으로 회전하지 않는다. 기체가 왼쪽을 바라볼 때만 좌우 미러하며, 반대 방향으로 이동하더라도 표시 기준은 기체가 바라보는 방향이다. 위아래 형상과 발 부착 중심은 유지한다.
- Trail과 함께 에너지색의 작은 원형 입자를 분사 방향 양옆으로 비산한다. 최대 효과 수는 160개이며 설정으로 조정한다.
- 일반 공격 3·4타와 대시 공격 네 타격에 효과를 발생시킨다. 실제 부스트 이동 중에도 유지한다. 연결 입력 대기·정지에서는 새 입자를 발생시키지 않는다. 일시정지에서는 입자 시간도 멈춘다.
- 발·다리/등 노즐은 Unreal 120Hz 좌표를 사용하고 공격 부착점은 본체의 가속 재생 위상과 동기화한다. 반대 방향으로 이동할 때는 노즐 앞 12px 주변만 본체 앞, 나머지 꼬리는 뒤로 그린다. 경계를 완만하게 합성하고 발 효과/잔상은 뒤에 둔다. 일반 방향에서는 기존 방향별 전후 순서를 사용한다.
- CPU 발생/수명 목록과 OpenGL cutout·알파 셰이더를 사용한다. GPU 시뮬레이션·Instancing·overdraw 절감 측정을 완료한 것으로 취급하지 않는다. 소프트웨어/`--demo`에는 이 표현을 연결하지 않는다.
- 백웨폰은 중앙 승강·좌우 확장의 7단계를 8방향 파츠로 출력했다. 제어 모듈은 스왑한 슬롯의 `back_weapon_equipped`가 참일 때만 전개하고 빈 슬롯에서는 복귀한다. 실제 백웨폰 장착 데이터·스왑 이벤트·이동/공격 중 전개 파츠 합성은 아직 연결하지 않았다. 현재 파츠 출력은 검 대기 자세 기준이다.

검토·검증 근거는 [손목·지면 효과·그림자와 백웨폰 출력 기록](../ai-dev-log/2026-11-13-wrist-ground-effects-shadow-back.md)을 따른다.

공통 `python automate/run.py unreal-directional --profile 제작JSON --unreal 실행파일 --project 프로젝트`가 기존 장면·렌더 경로와 패킹을 연결한다. `--stage plan/render/pack`으로 단계를 나눌 수 있다. `--stage shadows`는 완료된 장면에 같은 포즈·광원의 무그림자 기준 장면과 그림자 패스를 추가한다. 제작 입력과 장면 보고는 `automate/workspace/`, 최종 로컬 에셋은 `data/`, 재생성 가능한 렌더는 `output/`에 둔다. 버전별 Python 제작 파일을 추가하지 않는다.

검증 결과와 미검증 범위는 [초기 훈련장 준비](../ai-dev-log/2026-11-13-sword-movement-training-ground.md), [UI v2·보간·4타·입력 연결](../ai-dev-log/2026-11-13-sword-movement-ui-v2-interpolation-combo.md)에 둔다. 자동 검사·실제 렌더 캡처·직접 조작·사용자 사용감 승인을 구분한다.

## 검 명중 표현과 이동 음원

- `sword_effects.contact_effects`는 표적이 베인 위치에 실제 검 진행 방향의 `/`, `\`, `—` 리본을 짧게 표시한다. 현재 확대 시험값은 길이 배율 4.5·반너비 9px다. 가는 직선이 0.1초 동안 Smoothstep으로 목표 길이·두께까지 커진다. 이후 0.1초 동안 가는 꼬리부터 굵은 앞쪽으로 지우며 전체 알파도 Smoothstep으로 1에서 0까지 줄인다. 전체 길이·두께·위치는 유지하고 지워지는 경계의 두께와 투명도를 보간한다. 지움 진행은 지수 계수 6이며 국소 두께 보간은 지수 계수 10을 사용한다. `fade_opacity_ratio=0.1`은 경계의 Smoothstep 투명도 보간 폭이며 블러를 꺼도 적용한다. 지움 마스크를 진행축으로 8회 표본화해 길이의 18% 범위에 방향성 블러를 별도로 적용한다. 진행 방향 앞쪽 82.5% 지점이 가장 굵고 뒤는 가는 꼬리다. 전체 0.2초 효과다.
- `SwordTarget.material=metal`인 표적에만 금속 마찰 입자를 생성한다. 명중당 22개·기준 속도 1800px/s·기준 반너비 3.2px·최대 수명 0.55초·총 176개 상한이다. 속도축에 정렬한 2D 화면 평면 사각형이며 별도 3D Billboard는 아니다.
- `contact_effects.level_size_scales`는 에너지 1/2/3단계의 피격 베임선 길이·두께와 금속 입자 길이·두께에 1.00/1.25/1.50배를 적용한다. 명중당 크기 변주와 곱하며 생성 당시 배율을 유지한다. 입자 수·속도·수명은 이 배율로 바뀌지 않는다.
- 상태·생성은 `ferrial_drive/combat/sword_contact.py`, 그리기는 `pico_sword_effects.py`에 둔다. 본편은 명중 사건·표적 재질·카메라만 연결할 수 있다.
- 대시 진입 가속/고음 지속 분사, 충격을 더한 부스트, 3타 바람과 명중 시 푸슉·정지음·금속 파이프/마찰은 `samples/sound_effects/README.md`를 따른다. 기존 사용자 OGG는 보존하고 현재 로컬 선택은 사용자 제공 VARCO GEN 1~3의 조합 후보 8개를 타수별 두 개씩 사용한다. 원본과 사건별 실시간 조합을 분리한다.
- 몸 검풍 제거는 3타 바람 SFX 제거를 뜻하지 않는다. 자동 검사·실제 렌더링과 최종 청감/외관 수용은 구분한다.

- 위 크기를 표준으로 명중당 크기 90~110%, 베임선 방향과 입자 분사축 각각 ±6°를 한 번 선택한다. 재생 중 다시 추첨하지 않는다. 베임선은 한 리본의 둥근 단면 가상 법선·시선각으로 Rim Lighting을 계산한다. 중앙은 흰색을 유지하며 금속은 강한 노란색 림(`#FFD228`, metal_power=0.6), 다른 재질은 푸른 림을 사용한다. 겹친 금빛 띠·외부 광륜 합성은 사용하지 않는다. 실제 3D 메시 법선 조명은 아니다.

## SMG 피격과 적 도형 렌더링

총구 화염은 로딩 중 96×64 RGBA 텍스처 한 장을 생성·전송하고 모든 발사에서 재사용한다. `weapons.effects.muzzle_flash`의 기본 표시 크기는 탄도 방향 길이 84px·탄도에 수직인 폭 90px이며 카메라 줌을 함께 적용한다. 실제 발사마다 별도의 표현 난수로 크기 80~120%를 한 번 선택하고, 0.045초 동안 축소·페이드한다. 현재 에너지색을 정점에 공급하므로 Overdrive에서는 붉게 표시하며 색이 바뀌어도 텍스처를 다시 생성하지 않는다. 현재 총구 좌표와 실제 발사 방향을 사용하며 빈 탄창 입력 자체는 화염을 만들지 않는다. 일시정지에서는 실제 발사 경과 시간이 정지하고, 렌더 자원 해제 시 총탄·화염 텍스처를 함께 해제한다.

Combat v1.5의 총탄 명중은 실제 탄도 방향을 월드 좌표로 역투영해 약한 넉백을 적용한다. 0.06초 동안 소형 0.3m·중형 0.14m·인간형 0.07m를 밀며 `samples/combat_test_v1_5/encounter.json`의 `gun_knockback`에서 조절한다. 이동·공격 상태를 중단하지 않고 재명중은 속도를 누적하지 않으며 진행 중인 검 넉백을 덮어쓰지 않는다. 정지 표적 훈련장에는 적 이동을 추가하지 않는다.

총탄 사거리는 총구에서 월드 거리 75m이며 `weapons.range_m`으로 조절한다. 실제 발사 방향을 역투영해 투영 좌표상의 이동 한도를 계산하므로 방향·카메라 줌과 무관하게 같은 월드 거리에서 소멸한다. 록온 거리는 별도다. Bullet Trail은 LV1/LV2/LV3에서 108/135/162 투영 px이며 Overdrive도 현재 레벨의 길이를 따른다. `weapons.effects.length_pixels`와 `length_scales_by_energy_level`로 조절하며 실제 누적 이동 거리보다 길어지지 않는다.

SMG 피해는 LV1/LV2/LV3/Overdrive에서 15/20/25/35이며 발사 시 고정한다. Overdrive는 실제 10초, 빈 탄창에서도 탄약 소모 없이 사격한다. Bullet Trail은 현재 에너지색을 사용한다. 금속 명중 불꽃은 10개·폭 3.2px·최대 0.24초이며 주황색 외곽과 흰 중심을 가산 합성한다. 카메라 명중 진폭은 일반 10px·Overdrive 16px이며 발사 반동은 별도 최대 2px다. 관통·국소 폭발은 위 전투 수치를 따른다. 적 도형 배치·인스턴싱 및 설정은 [Combat v1.5 안내](../../samples/combat_test_v1_5/README.md)를 따른다.

총탄의 실제 충돌점에는 모든 재질에서 에너지 명중 VFX를 0.16초 동안 표시한다. 기본 반경 36px의 광륜·탄도 축의 십자형 섬광을 현재 에너지색으로 가산 합성하며, 금속에서는 불똥과 함께 표시한다. `weapons.contact_effects.energy_impact`에서 수명·반경·동시 표시 상한(64개)을 조절한다. 일시정지에서는 갱신을 멈추며 F5 초기화와 교전 종료 후 소멸은 기존 총 피격 효과의 시계를 따른다.
