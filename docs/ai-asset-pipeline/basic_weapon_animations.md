# 기본 무기 애니메이션 사양

## 공통

- 플레이어 재생 기준은 **12fps**다. 동작 길이를 12프레임으로 제한하지 않는다.
- 준비와 끝 자세를 충분히 유지하고, 타격 구간은 짧고 명확하게 표현한다.
- 골반·지지발·발 스텝으로 체중을 표현한다. 팔만 움직이는 공격은 피한다.
- 작은 장갑 겹침은 허용한다. 실제 표시 크기에서 관통이 튀거나 실루엣이 깨지는 부분을 우선 수정한다.
- 작업용 뷰포트는 베벨을 끈 상태를 사용한다. 최종 렌더의 베벨 사용 여부는 별도 결정이다.
- 기본 포즈를 먼저 만들고 사용자가 동작과 타이밍을 후보정한다.

## 필요한 동작

| 구분 | 동작 |
| --- | --- |
| 대기 | 검 준비, 총 이완, 총 양손 조준 유지 |
| 전환 | 검→총, 총→검, 한손 지향↔양손 조준 |
| 발사 | 한손 지향 발사, 양손 조준 발사 |
| 이동 | 검/총 상태의 전진·후진·좌측·우측 걷기와 달리기 |
| 속도 전환 | 걷기↔달리기, 달리기→대시 |
| 근접 | 검 4단 콤보, 공격 후 대기 복귀 |

## 검 4단 콤보

**내려베기 → 가로베기 → 찌르기 → 뽑아베기. 네 동작 모두 유효타다.**

| 타수 | 동작 | 기본 포즈에서 보여줄 것 |
| --- | --- | --- |
| 1 | 위에서 아래로 내려베기 | 발을 내딛고 무릎으로 무게를 받으며 검을 내려친다. |
| 2 | 몸통을 돌려 가로베기 | 지지발을 유지하며 골반·허리 회전과 검의 가로 궤적을 연결한다. |
| 3 | 앞으로 내딛으며 찌르기 | 앞다리에 체중을 싣고 뒤다리로 밀어 검을 전방으로 보낸다. |
| 4 | 찌른 검을 빼면서 베기 | 검을 몸 쪽으로 당겨 회수하는 구간에도 타격이 발생한다. 회수하는 발·체중과 검을 연결한다. |

- 전체 흐름은 **검 대기 → 1타 내려베기 → 2타 가로베기 → 3타 찌르기 → 4타 뽑아베기 → 검 대기**다.
- **1타는 검 대기 자세에서 시작하고, 4타는 같은 검 대기 자세로 끝난다.** 시작·끝 대기의 팔·골반·발 위치를 맞춰 자연스럽게 이어지게 한다.
- 4타는 뽑아베는 구간에 유효타가 있으며, 그 뒤 대기 자세로 회복한다. 회수 타격 자체를 비공격 복귀 동작으로 바꾸지 않는다.
- 사용자 측면 스케치를 기준으로 하며 자연스러운 연결을 위해 세부 자세를 조절할 수 있다.
- 타당 8프레임 사용을 허용했으며, 필요하면 늘린다. 타격 판정의 정확한 프레임·범위는 아직 정하지 않았다.

## 파지와 수납

- 검은 허리를 조금 숙여 공격을 준비한다. 파지한 팔을 적절히 벌리고 반대손은 이완한다.
- 총은 평소 이완하고 지향 사격은 한손, 조준 사격은 양손으로 잡는다. 조준 시 팔을 조금 앞으로 뻗는다.
- 스와핑은 한손으로 수행한다. 무기는 사용하는 손의 반대쪽 허리에 수납한다.
- 칼집은 허리에서 뒤로 거의 수평하게 뻗고 끝이 조금 내려가는 사용자 수정 각도를 기준으로 한다.
- 발도는 칼집 길이 방향으로 먼저 빼고, 칼끝이 빠진 뒤 다음 자세로 전환한다.
- 검은 수납 시 기본 길이로 돌아간다. 사출 안전장치·버튼은 칼집에 수납된 상태에서만 사용할 수 있다.

## 작업·출력

- 현재 수동 편집본의 리그와 무기 장착 구조를 유지한다. 포즈 제작을 위해 원본 메시를 합치지 않는다.
- 핵심 포즈는 타이밍이 확정된 완성 애니메이션과 구분한다.
- 출력은 기존 Asset Tool의 프레임 목록·FPS·이벤트·렌더 설정 형식에 맞춘다.
- 프레임 수나 무기 전환 시점을 바꾸면 출력 프레임과 이벤트도 함께 갱신한다.
