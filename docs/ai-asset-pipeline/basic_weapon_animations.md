# 기본 무기 애니메이션 사양

## 공통

- 전투 동작의 입력·이동·캔슬 규칙은 [PRE-PRD 4.8절](../Ferrial_Drive_PRE_PRD_v0.1.md)을 따른다. 아래는 제작 요구사항이며 실제 모션 제작·시트 출력·게임 연동의 완료 상태와 구분한다.
- 모델링은 Blender, 새 리깅·포즈·키·타이밍 편집은 Unreal에서 수행한다. 기존 Blender 본·웨이트·Constraint는 재사용하지 않는다. 프리렌더는 Unreal에서 수행하고 PNG 파츠+JSON을 툴의 2D 조립·패킹으로 인계한다.  이후 파츠·레이어 분리와 출력은 기존 경로를 따른다. [역할·인계 조건](unreal_pipeline.md)을 기준으로 한다. 기존 41개 초안의 소스는 `data/source/models/basic_weapons/base_pose.blend`이며 새 Unreal 리그의 확정 규격은 아니다. 어깨 상부 → 하부 → 상완 연결 의도를 유지한다.
- 모든 애니메이션에서 팔다리의 이동 폭·주요 포즈·어깨와 허리 회전·스텝과 체중 이동을 과장해 작은 출력에서도 의도가 읽히게 한다. 달리기와 대시에만 적용하는 규칙이 아니다.
- 이완한 팔은 완만한 곡선 또는 거의 일직선으로 이어진다. 과장 때문에 관절을 비틀거나 손의 파지·발의 접지를 깨뜨리지 않는다.
- 핵심 자세뿐 아니라 중간 프레임에서도 어깨·팔꿈치·손목·무릎의 비틀림과 강체 장갑 변형을 확인한다. 회전값이 0이라는 수치만으로 정상 파지를 판정하지 않는다.
- 대략적인 키포즈도 전체 실루엣과 자연스러운 관절 굽힘을 먼저 검토한다. 기존 각도 제한이 있으면 평가된 실제 자세의 범위 준수도 확인한다. 기존 초안의 임시 허용각을 새 리그의 규칙으로 이월하지 않으며 미정인 관절 허용각을 임의 확정하지 않는다. 각도 제한의 적용·통과와 외형 검토를 혼동하지 않는다.

- 플레이어 재생 기준은 **12fps**, 개별 동작 길이는 **최대 12프레임**이다. 대기 반복 동작도 이 범위 안에서 구성한다.
- 같은 기체의 상부·하부 동작은 공통으로 재사용한다. 파츠 분리 구조를 활용하며, 조합 시 골반·허리 연결과 가림 관계·접지를 함께 확인한다. 동작 제작 원칙과 실제 분리 출력·게임 조합의 완료 상태를 구분한다.
- 준비와 끝 자세를 충분히 유지하고, 타격 구간은 짧고 명확하게 표현한다.
- 메카의 무게감과 빠른 조작 반응을 함께 유지한다. 접지·체중 이동·골반과 몸통의 반응으로 무게를 표현한다. 준비·끝 자세를 읽을 수 있게 하되 부스트 기동이나 새 이동 입력을 막는 강제 대기시간으로 사용하지 않는다.
- 골반·지지발·발 스텝으로 체중을 표현한다. 팔만 움직이는 공격은 피한다.
- 작은 장갑 겹침은 허용한다. 실제 표시 크기에서 관통이 튀거나 실루엣이 깨지는 부분을 우선 수정한다.
- 작업용 뷰포트는 베벨을 끈 상태를 사용한다. 최종 렌더의 베벨 사용 여부는 별도 결정이다.
- [애니메이션 제작 흐름](animation_workflow.md)에 따라 Unreal에서 짧은 동작 초안 → 전체 재생 검수 → 수정·재검수로 진행한다. KeyPose는 제작·진단 수단이며 별도 사전 승인 단계가 아니다. 상박·하박의 지나치게 좁은 V자 접힘·비틀림·장갑 간섭을 본 연결·수치 검사 통과만으로 정상 판정하지 않는다. 기존 AI 통과 결과도 재확인 없이 사용하지 않는다.

## 필요한 동작

| 구분 | 동작 |
| --- | --- |
| 대기 | 검 준비, 총 이완, 총 양손 조준 유지 |
| 전환 | 검→총, 총→검, 한손 지향↔양손 조준 |
| 발사 | 정지·달리기·대시 중 한손 지향 발사와 양손 조준 발사, 부스트 중 사격 |
| 이동 | 검 상태는 몸 전체를 이동 방향으로 돌리는 전진 달리기, 총 상태는 전진·후진·좌측·우측 달리기, 검/총 상태의 대시 |
| 이동 전환 | 대기↔달리기/대시, 달리기↔대시, 입력 해제 시 정지·하중 수용 자세 |
| 대시 | Shift 유지 중 양발을 접지한 지속 스러스터 슬라이딩 |
| 부스트 | 정지/달리기/대시에서 슬라이딩 부스트 진입·추진·종료, 부스트 종료 후 달리기·대기 연결 |
| 부스트 중 전환 | 고정된 추진 방향을 유지한 조준 전신 회전·사격·검↔총 전환 |
| 근접 | 검 4단 콤보, 공격 후 대기 복귀, 달리기에서 공격 스텝으로 전환 |
| 근접 부스트 공격 | 부스트 방향으로 이동하며 베기, 공격 종료 후 현재 조준 방향 복귀 |
| 공격 중 부스트 | 준비·타격·회수 중 부스트 이동을 시작하고 콤보를 계속 재생 |

검·총과 조준 여부에 관계없이 대기·달리기·대시·공격 중에도 상체의 기준 방향은 현재 시선을 먼저 보간 추종한다. 상·하체 차이가 ±45°를 넘으면 하체도 보간 추종을 시작해 정렬까지 이어간다. 45° 차이를 유지하거나 회전을 제한하지 않는다. 이동 경로와 공격 전진 방향은 몸의 시선 회전과 분리한다. 기존 전신 게임 출력과 새 분리 후보를 구분하며 검 옆걸음·뒷걸음의 발 접지·사용감을 검증 완료로 취급하지 않는다. 파지·총구·장갑 가림·회전 후 검 궤적·실제 표시 크기를 새 Unreal 동작과 프리렌더에서 확인한다. 현재 제작·연결 범위는 [상·하체 분리 검토](../unit-tests/upper_lower_aim.md)를 따른다. 재장전·막기·피격/쓰러짐/복귀·Break Assault 등 나머지 전투 표현의 개별 모션과 제작 순서는 별도 구체화한다.

## 기본 달리기와 정지

- 기본 이동은 달리기로 표현한다. 양팔의 앞뒤 스윙·지지발·다리 회수·골반의 체중 이동이 함께 읽혀야 하며, 의도하지 않은 발 미끄러짐과 다리만 움직이는 표현을 확인한다.
- idle→달리기·idle→대시·달리기↔대시는 0.2초 SmoothStep으로 속도를 전환한다. 이동 입력을 놓으면 현재 방향으로 짧게 관성 이동하며 같은 시간 동안 감속해 멈춘다. 제동 중 새 이동·공격·부스트 입력을 막지 않는다. 달리기 반복의 재생 속도는 실제 이동 속도를 따르며, 새 전용 제동 애니메이션 제작과 게임 위치의 감속 연결을 구분한다.
- 한손 지향·양손 조준 사격을 달리기·대시 모두에서 지원한다. 양손 조준 중 대시도 포함하며 파지와 하체 동작이 함께 유지되는지 확인한다.
- 검 공격은 각 타격 시작 때의 마우스 방향으로 전진하고 다음 타격에서 방향을 다시 읽는다. 일반/대시 속도는 1·2·4타 50/90m/s, 3타 70/120m/s이며 첫 프레임부터 가속 없이 적용한다. Shift 유지 여부로 속도를 고른다. 부스트 중에는 위치 이동을 부스트 방향으로 우선하면서 공격·연계·Trail을 계속 재생한다. 연결 대기에서는 공격 전진을 멈추고 다음 입력을 받는다. 기존 공격의 스텝·체중 이동과 전용 하체 모션 제작의 완료 상태는 구분한다.
- 검·총의 달리기와 대시는 WASD 이동과 상체 시선 추종을 분리한다. 하체는 ±45° 초과 시 시작해 정렬까지 이어지는 추종 규칙을 사용한다. 검 달리기의 기존 전진 모션과 새 분리 후보의 옆걸음·뒷걸음 품질은 별도로 검수한다. 현재 게임 전신 출력의 동작과 새 설계를 구분한다.

## 지속 대시와 이동 전환

- **대시는 Shift 유지 중의 지속 스러스터 기동**이다. 양발을 지면에 붙여 스키처럼 미끄러지며, 달리기 주기로 표현하지 않는다. 낮은 자세·상체 전경으로 추진 상태를 읽게 한다.
- 검을 든 대기↔달리기·대기↔대시·달리기↔대시 전환 모션을 제작한다. 지지발·무게 이동·팔과 몸통의 연결을 포함한다.
- 달리기·대시·부스트는 팔 각도·하체 굽힘·상체 기울기로 구분한다. 부스트는 대시보다 과장된 전경·골반 하강과 강한 순간 추진을 표현한다.
- 진입·복귀 모션은 조작 반응을 막는 강제 대기시간으로 사용하지 않는다.

## 순간 부스트와 부스트 공격

- **부스트는 Space로 스러스터 출력을 순간적으로 높이는 짧은 가속 기동**이다. 발은 지면에 닿은 채 스키처럼 미끄러진다. 달리기의 비의도적 발 미끄러짐과 구분하며, 공중 부유·착지 동작으로 바꾸지 않는다.
- 시작 순간의 WASD 방향으로 추진 방향을 고정한다. 이동 입력이 없으면 시작 순간의 조준 방향을 사용한다. 키를 놓아도 정해진 거리까지 진행하며 부스트가 끝나야 다음 부스트가 가능하다. 장애물·맵 경계 처리는 미정이다.
- 일반 부스트·부스트 사격은 전신이 현재 마우스 조준 방향을 따른다. 옆이나 뒤로 미끄러지는 중에도 추진 방향·지면 접촉·파지를 유지한다. 전신 회전으로 이동 궤적을 바꾸지 않는다.
- 부스트 중 사격과 검↔총 전환을 지원한다. 무기 전환 시에도 반대쪽 슬롯 수납·인출 경로와 손/무기 연결을 유지한다.
- 별도 부스트 공격은 부스트와 공격의 동시 입력 또는 부스트 시작 직후 입력으로 발동한다. 정확한 입력 허용 시간은 미정이며, 부스트 중 사격 허용을 임의 시점의 부스트 공격 발동으로 확대하지 않는다.
- 근접 부스트 공격은 추진력을 이용해 부스트 방향으로 베어 나간다. 공격 방향·자세는 부스트 방향을 기준으로 하며, 공격 종료 후 현재 조준 방향으로 복귀한다. 마우스 방향으로 베기 궤적을 돌리지 않는다.
- 부스트 종료 시 이동 입력이 있으면 달리기·대시로 바로 연결하고, 없으면 정지 자세로 연결한다. 별도 착지 없이 짧게 하중을 받으며 연결한다.
- 부스트 속도·거리·지속시간·추가 쿨타임·입력 예약, 공격 궤적·타격 판정·동작 길이와 부스트 이동의 관계는 미정이다.
- 부스트 공격은 Break Assault와 구분한다. Break Assault의 돌진·공격·반동 점프 규칙을 일반 부스트에 적용하지 않는다.

## 일반 공격과 부스트 동시 연결 검수

- 일반 공격의 준비·타격·회수 중 어느 구간에서도 부스트 이동을 시작하며, 공격과 콤보 연계를 중단하지 않는다. 끝 자세까지 기다리지 않는다.
- 동시 진행 중의 실루엣·관절·파지·지면 관계를 확인한다. 이 규칙을 무기 전환 캔슬이나 스킬·필살기·전용 부스트 공격의 동작으로 확대하지 않는다.
- 검수에는 검 달리기·대시의 이동 방향 전신 회전, 총 달리기의 조준 방향을 유지한 후진·측면 이동, 양손 조준 대시, 부스트 중 측면/후방 조준과 사격, 무기 전환, 근접 부스트 공격 후 조준 복귀, 부스트 종료 후 달리기 복귀를 포함한다. 검의 옆걸음·뒷걸음과 마우스/록온 방향 유지 이동은 후속 제작 시 별도로 검수한다.
- 동시 입력·부스트 시작 직후 입력·허용 구간 이후 입력을 구분하고, 일반 이동 입력 해제 후 관성 감속과 부스트 중 입력 해제 시 고정 거리 유지도 구분해 확인한다. 정확한 입력 허용 시간은 합의 후 검증한다.

## 검 4단 콤보

**내려베기 → 가로베기 → 찌르기 → 뽑아베기. 네 동작 모두 유효타다.**

현재 기본 검의 **파란 발광 부분은 칼등**, **커터칼 형태의 부분은 실제 칼날**이다. 검 길이축·칼날 방향·칼등 방향을 구분해 검수한다. 발광 부분을 칼날로 해석하지 않는다.

| 타수 | 동작 | 기본 포즈에서 보여줄 것 |
| --- | --- | --- |
| 1 | 위에서 아래로 내려베기 | 발을 내딛고 무릎으로 무게를 받으며 검을 내려친다. |
| 2 | 몸통을 돌려 가로베기 | 지지발을 유지하며 골반·허리 회전과 검의 가로 궤적을 연결한다. |
| 3 | 지면을 밀며 중앙 찌르기 | 하체를 낮추고 허리를 굽혀 몸 중앙 쪽에서 검을 뻗는다. 양발은 지면에 붙여 앞으로 미끄러지며, 반대 손도 찌르기에 적극적으로 연동한다. |
| 4 | 찌른 검을 빼면서 후방까지 베기 | 베는 각도를 넓혀 뒤쪽까지 검이 지나가게 한다. 회수 타격과 체중 이동을 연결하고, 복귀하는 발은 지면에 붙여 미끄러지는 느낌을 유지한다. |

- 전체 흐름은 **검 대기 → 1타 내려베기 → 2타 가로베기 → 3타 찌르기 → 4타 뽑아베기 → 검 대기**다.
- **1타는 검 대기 자세에서 시작하고, 4타는 같은 검 대기 자세로 끝난다.** 시작·끝 대기의 팔·골반·발 위치를 맞춰 자연스럽게 이어지게 한다.
- 4타는 뽑아베는 구간에 유효타가 있으며, 그 뒤 대기 자세로 회복한다. 회수 타격 자체를 비공격 복귀 동작으로 바꾸지 않는다.
- 콤보에서는 하체를 더 낮추고 허리 굽힘·양팔의 연동을 분명히 표현한다. 반대 손이 고정된 채 검을 든 팔만 움직이는 인상을 피한다.
- 사용자 측면 스케치를 기준으로 하며 자연스러운 연결을 위해 세부 자세를 조절할 수 있다.
- 타당 8프레임을 기준으로 필요하면 최대 12프레임 안에서 조정한다. 타격 판정의 정확한 프레임·범위는 아직 정하지 않았다.

## 파지와 수납

- 검 대기에서는 허리를 조금 숙여 공격을 준비한다. 파지한 팔을 적절히 벌리고 반대손은 이완한다. 공격 중에는 각 타수에 맞춰 반대 손도 적극적으로 움직인다.
- 총은 평소 이완하고 지향 사격은 한손, 조준 사격은 양손으로 잡는다. 조준 시 팔을 조금 앞으로 뻗는다.
- 총 파지는 손가락이 전방을 향하고 손바닥 면이 세워진 방향이다. 손가락을 아래로 향하게 한다는 뜻이 아니다.
- 총은 몸에서 앞으로 뻗어 머리와 적당한 거리를 둔다. 스코프에 머리를 붙이려고 허리를 크게 숙이지 않고 약하게만 기울인다.
- 스와핑은 한손으로 수행한다. 무기는 사용하는 손의 반대쪽 허리에 수납한다.
- 수납과 인출은 무기군별 독립 동작으로 관리한다. 무기 전환은 현재 무기의 수납 완료 뒤 다음 무기의 인출을 연결한다. 공통 빈손 연결 자세와 부착 상태를 맞추고, 다양한 무기군의 조합을 특정 두 무기 전용 동작에 종속시키지 않는다.
- 칼집은 허리에서 뒤로 거의 수평하게 뻗고 끝이 조금 내려가는 사용자 수정 각도를 기준으로 한다.
- 발도는 칼집 길이 방향으로 먼저 빼고, 칼끝이 빠진 뒤 다음 자세로 전환한다.
- 검은 수납 시 기본 길이로 돌아간다. 사출 안전장치·버튼은 칼집에 수납된 상태에서만 사용할 수 있다.

## 작업·출력

- 모델 원본과 승인된 무기 장착 관계를 보존한다. 리깅은 Unreal 후보에서 새로 수행하고 결정한 인계 파일의 부품·UV·재질 대응과 분리 가능성을 확인한다. 기존 골격 왕복 성공을 새 리그 출력 완료로 취급하지 않는다.
- 핵심 포즈는 타이밍이 확정된 완성 애니메이션과 구분한다.
- 출력은 기존 Asset Tool의 프레임 목록·FPS·이벤트·렌더 설정 형식에 맞춘다.
- 프레임 수나 무기 전환 시점을 바꾸면 출력 프레임과 이벤트도 함께 갱신한다.
