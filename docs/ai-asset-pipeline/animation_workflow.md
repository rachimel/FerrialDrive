# 애니메이션 제작 흐름

**AI 키포즈 후보 제시 → 사용자 검수 → AI 수정·재제시 → 키포즈 확정 → AI 사이 동작 연결 → 연결 동작 검수** 순서로 제작한다. 여기서 Key Animation 후보는 동작의 주요 순간을 정지 자세로 표현한 키포즈 후보를 뜻한다.

메카의 관절·강체 장갑 기준은 [메카 디자인·제작 규칙](mech_design_rules.md), 원본 보존·이미지 검토와 승인 기록은 [모델 제작 흐름](model_workflow.md)을 따른다. 개별 동작과 출력 기준은 [기본 무기 애니메이션 사양](basic_weapon_animations.md)을 따른다.

## 1. 짧은 동작 하나로 제작 방식 확인

- 처음에는 짧은 동작 하나를 키포즈 검수부터 연결 동작 검수까지 완료한다. 이 과정이 확인된 뒤 다른 동작으로 확장한다.
- AI가 동작 목적, 시작·끝 자세, 주요 순간의 순서, 보존할 리그·장착 구조와 확인 항목을 정리한다. 사용자가 후보 포즈를 직접 만들거나 수정하는 것을 필수 단계로 요구하지 않는다.
- 기준 모델·해시와 수정 범위를 고정하고 별도 후보에서 작업한다. 기존 미승인 동작 초안을 승인된 키포즈로 취급하지 않는다.

## 2. AI 키포즈 후보 제시

- AI가 동작을 읽는 데 필요한 핵심 자세를 골라 제작한다. 포즈 개수는 동작에 맞추며 이 단계에서 전체 타이밍을 확정하지 않는다.
- 후보마다 식별자, 동작에서의 역할, 순서, 지지발·체중 방향, 손과 무기 접촉·수납 상태를 함께 제시한다. 임시 프레임 번호와 확정 타이밍을 구분한다.
- AI가 먼저 관절 중심·회전축·가동 범위, 연결 유지, 강체 장갑 변형, 스커트·팔다리 간섭, 발 접지와 무기 파지를 확인한다. 명백한 결함은 사용자에게 넘기기 전에 수정한다. 작동 범위가 정해지지 않았거나 확인하지 못한 항목은 미검증으로 남긴다.
- 같은 조건의 앞/뒤/좌/우/위/아래 6면과 확대·실제 표시 크기를 확인하고, 사용자에게 정면·측면·사선의 비교 이미지와 필요한 관절·손·무기 확대를 제시한다. 전체 검토 이미지도 함께 접근할 수 있게 한다.
- 포즈 후보는 정지 이미지 또는 포즈별 넘김으로 검수한다. 사용자 확정 전에는 사이 동작을 연결해 완성 애니메이션으로 진행하지 않는다.

## 3. 사용자 검수와 AI 수정

- 사용자는 후보에서 자세, 무게감, 실루엣, 기계적으로 이상한 부분을 짚는다. AI가 지적한 후보·부위와 수정 의도를 정리하고 실제 수정을 담당한다.
- 수정한 후보는 같은 구도로 전후를 제시한다. 영향을 받는 인접 부품, 접지와 파지도 다시 확인한다. 사용자의 직접 편집은 선택 사항이다.
- 실제 사용자 응답으로 확정된 후보와 수정 대기 후보를 구분한다. 침묵, 렌더 성공, AI 자체 검토를 키포즈 확정으로 간주하지 않는다.
- 해당 동작에 필요한 키포즈 묶음이 확정된 뒤 사이 동작 연결로 넘어간다. 이번 제작 방식의 수용은 앞으로 만들 모든 후보에 대한 승인이 아니다.

## 4. AI 사이 동작 연결

- AI가 확정된 키포즈 사이에 타이밍, 유지 구간과 중간 자세를 넣는다. 준비·타격·회수·체중 이동의 목적에 맞게 연결하며 자동 보간 결과도 직접 확인한다.
- 확정된 키포즈와 접촉 조건을 기준으로 유지한다. 연결하려면 키포즈·파지·공격 궤적을 바꿔야 하는 경우, 영향을 설명하고 해당 후보를 다시 검수받는다.
- 중간에만 발생한 관절 이탈·관통·발 미끄러짐은 우선 중간 자세와 연결 경로에서 보정한다. 리그 구조 변경이나 웨이트 보수를 암묵적으로 수행하지 않는다.
- 관절 제약을 지시문에 적거나 보간을 수행했다는 사실만으로 준수를 보증하지 않는다. Constraint/Driver 적용 후 평가된 실제 자세를 확인한다.

## 5. 연결 동작 검수와 출력

- AI가 재생 속도와 느린 재생·프레임 이동으로 중간 자세, 접지·체중 이동, 장갑 간섭, 파지와 수납·인출 시점을 확인한다. 시작·끝 포즈나 극값 표본만으로 전체 동작을 통과 처리하지 않는다.
- 사용자에게 연결된 동작을 제시하고 수정·재검수한다. 키포즈 승인은 정지 자세의 승인이고, 연결 동작 승인은 타이밍과 중간 자세를 포함한 별도 확인이다.
- 검토 이미지, 후보/작업본 해시, 사용자 지적과 수정 내용, 실제 승인 범위, 미검증 항목을 남긴다. 승인된 파일이 바뀌면 영향을 받는 범위를 다시 확인한다.
- 연결 동작 확정 뒤 기존 프레임 목록·FPS·이벤트·렌더·패킹 경로로 전달한다. 최종 게임 크기의 재생과 게임 연동 확인은 제작 단계의 승인과 구분한다.

## 도구 연결과 현재 범위

| 역할 | 기존 도구와 적용 범위 |
| --- | --- |
| 정지 포즈 후보와 이미지 검토 | `model_pipeline.py`의 포즈 연산·`review`, `model_review.py`의 AI 검토·사용자 응답 기록을 재사용한다. |
| 사이 동작 초안·보정 | `motion_blocking.py`, `pose_refinement.py`를 재사용한다. 키포즈 확정 뒤 실행하며, 생성 결과는 검수 대상이다. |
| 저장·출력·미리보기 | `animation_pipeline.py`, `build_motion_preview.py`와 기존 Asset Tool 경로를 재사용한다. |

이 문서는 AI와 사용자의 제작 절차다. 현재 도구의 소스 승인 확인만으로 개별 키포즈 묶음과 연결 동작의 승인을 모두 강제하지는 않는다. 후보별 자동 승인 게이트와 관절 제약의 전 프레임 자동 검증을 구현·검증한 것으로 해석하지 않는다.
