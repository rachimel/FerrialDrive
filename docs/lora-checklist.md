## 판정 방식

- **합격:** 위 기준에서 확인 가능한 명백한 문제가 없다.
- **불합격:** 명백한 구조·접촉·조명 오류가 확인된다. 파일명과 오류 위치·이유를 기록한다.
- **보류:** 가림, 구도, 해상도 등으로 확신하기 어렵다. 불합격으로 단정하지 않는다.
- 이 문서의 보류는 앱의 **미정(new)** 상태에 대응한다.
- 사용자 요청 없이 별도 평가 항목이나 정량 임계값을 추가하지 않는다.
- 2026-10-27 현재 범위 20장에 대한 1차 검토를 수행했다. 결과는 [LoRA 이미지 1차 평가](lora-review-2026-10-27.md)를 참고한다. 제외 1장 / 보류 6장 / 유지 13장이며, 앱의 기존 선별 상태와 원본 파일은 변경하지 않았다. 이후 추가 생성분은 별도 검토 대상이다.
