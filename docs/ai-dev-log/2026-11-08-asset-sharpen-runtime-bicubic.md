- 출처: 현재 대화 “샤프닝은 미리 적용하고, Bicubic은 게임 렌더에서 화면에 보이는 픽셀들에 적용”, “에셋 툴에서도 게임 렌더 처럼 해달라고”.
- 개별 발언·수용·구현의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261108-asset-sharpen-runtime-bicubic:scope]] 위 구절의 원문에서 확인한다. 아래 항목에 공통 적용한다.
- 상태: **사전 본체 샤프닝·공통 GPU Bicubic·도구 필터 메뉴 구현, 자동 84개 통과, 실제 모델 OpenGL 표시 확인**.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 저해상도 프리렌더에 샤프닝과 Bicubic을 적용한다. 최종 지시는 샤프닝을 미리 적용하고 게임의 표시 픽셀에 Bicubic을 적용하는 것이다.
  - 이유·근거: 저해상도 표시 보완을 위한 직접 요청이다.
- **사용자 제안 2 (U2):** 에셋 툴도 게임 렌더와 같은 방식으로 표시한다.
  - 이유·근거: 툴에서 Bicubic을 PNG에 구워 넣는 것으로 해석한 AI의 범위를 직접 정정했다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1/U2: 240×240 프레임을 유지하고 패킹할 때 본체에 샤프닝을 적용한다. 도구·게임 공통 표시기에서 GPU Bicubic으로 화면 픽셀을 보간한다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1), 구현 판단:** 샤프닝 강도 0.35와 제작 패널의 켜기/끄기를 제공한다. 알파를 보존하고 투명도 가중 블러를 사용하며 그림자·원본 프레임은 유지한다.
  - 이유·근거: 투명 가장자리의 숨은 색상과 그림자에 샤프닝이 번지는 것을 막고 반복 패킹의 중복 적용을 방지한다.
- **AI 제안 2 (A2), 구현 판단:** Pico2D 원본을 수정하지 않고 SDL OpenGL 텍스처를 16샘플 Catmull-Rom 셰이더에서 재사용한다. Nearest/Linear/Bicubic 메뉴와 미지원 드라이버의 실제 대체 모드를 표시한다.
  - 이유·근거: SDL 기본 필터는 Bicubic을 제공하지 않는다. CPU에서 이미지를 매 프레임 확대하거나 화면을 읽어오는 경로 없이 공통 표시 동작을 제공한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사전 샤프닝·표시 시 Bicubic·도구/게임 동일 경로는 사용자 지시다. 강도 0.35·셰이더 알고리즘·배치 API의 별도 사용자 승인을 받은 것으로 기록하지 않는다.

## 5. 반영 후 발견한 문제

- **발견한 문제 1 (I1), 범위 오해:** AI가 도구에서 Bicubic을 미리 처리한 PNG를 저장하는 뜻으로 해석했고 사용자가 정정했다. 최종 구현은 표시 시 처리다.
- **발견한 문제 2 (I2), 실제 GPU 검사 중 발견:** SDL 뷰포트와 비정수 표시 배율을 섞으면 SDL의 논리 좌표와 실제 GL 뷰포트가 달라질 수 있었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1: 사용자가 “에셋 툴에서도 게임 렌더 처럼”이라고 범위를 확정했다. 확대 PNG 생성 대신 공통 GPU 표시 경로를 도구에 연결했다.

## 7. AI 해결 제안과 실제 해결 과정

- I2: SDL에 화면 밖 점을 제출해 지연된 뷰포트/클립 상태를 먼저 확정한 뒤 실제 GL 뷰포트에 맞춰 그린다. 배치 종료 시 셰이더·텍스처·블렌딩·뷰포트·클립 상태를 복원한다.
- 구형 `PicoSprite`도 공통 `PicoAssetResource`에 위임한다. 도구/독립 실행부는 캔버스를 열기 전에 OpenGL을 요청하며 다른 드라이버는 Linear로 대체하고 실제 필터를 표시한다.
- 자동 **84개 통과**. 그중 실제 GPU 6개는 1:1 색상·Bicubic 확대 수치·투명 색/인접 프레임 번짐·클리핑 후 SDL 그리기·렌더 타깃 방향·비정수 배율/뷰포트 좌표를 검사했다. 나머지는 샤프닝 알파/해상도·원본/그림자 보존·재패킹 동일성·필터 메뉴와 기존 경로를 포함한다.
- 기존 모델의 8방향 원본 프레임을 별도 폴더에서 재패킹하고 숨긴 실제 OpenGL 창의 도구 화면을 캡처해 Bicubic·강도 0.35·240×240·원본 해시 보존을 확인했다. 검증 출력은 로컬 `output/asset_loader_review/bicubic/`에 두고 Git에서 제외한다.
- Blender 재렌더·최종 외관 승인·Iris 대상 60FPS/수백 기 성능 검증은 이번 확인 범위에 포함하지 않는다.
