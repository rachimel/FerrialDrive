- **사용자 제안 1 (U1):** PRE-PRD의 오래된 내용과 legacy 성격의 설명을 현재 기준으로 정리한다.

## 2. 사용자 제안 중 AI가 수용한 것

- 사용자 제안 1~2를 수용해 현재 규칙·개발 범위·검토안·미정 사항을 중심으로 PRE-PRD를 구성한다. 날짜별 작업 보고·옛 수치·이전 안의 폐기 설명·글꼴 변경 경위는 본문에서 정리한다.
- 저장 장면·8방향 출력·시트 패킹·독립 재생은 현재 제작 경로와 개별 명세로 연결한다. UI 글꼴 역할을 현재 명세에 맞추고 훈련 데모·로제·후속 ADV 구성을 유지한다.
- 후속 캐릭터의 상세 욕구와 관계 설정은 로컬 전용 기록으로 관리한다.
- 프로젝트 작성 지침과 기록 규칙에 기준 문서/변경 기록의 역할을 구분한다. 외부 메모리 파일이나 과거 개발 로그는 재작성하지 않는다.

## 5. 반영 후 발견한 문제

- 기존 문서에는 최소 엔티티 출력 경로와 추가 구현 대상으로 적힌 설명, 날짜별 UI/에셋 작업 보고, 옛 Standby 수치와 폐기안이 함께 있었다. 문서 정리 대상이며 새로운 실행 버그가 아니다.
- 게임 설계에서 아직 정하지 않은 비용·조건·서사 인과관계는 미정으로 유지한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 사용자 제안 1~2에 따라 현재 설계는 PRE-PRD, 변경 경위는 개발 기록, 구현·검증 상세는 개별 명세에서 관리한다. 작업 전 작성되어 있던 현재 전투·UI 기획 내용은 보존한다.

## 7. AI 해결 제안과 실제 해결 과정

- 편집 전 작업본과 대조해 전투 절의 차이가 역사 문구·용어 정리에 한정되는지 확인했다. 탄약·에너지·Overdrive·Break/Break Assault·콤보·필살기의 규칙과 수치를 유지한다.
- 기존 절 번호·문서 링크와 현재 글꼴/프리렌더 경로를 확인했다. 미정 사항은 별도 절에 모으고, 스냅샷과 코드상의 패킹 경로를 대조했다.
- 문서 작업이므로 게임 실행·자동 기능 검사·화면 렌더링은 수행하지 않았다. 과거 검사 결과를 이번 문서 검증 결과로 옮기지 않는다.
