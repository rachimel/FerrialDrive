- **I1, 기존 UV**: 상·하박과 허벅지/종아리가 각20~53개의 UV조각,연결 스커트가93조각이었다. 작은 조각마다 다른 방향의 무늬가 이어졌다.

- **I3, 언랩/패킹**: 팔 끝면의 일직선 정점을 그대로 투영하면 UV삼각형이 눌렸다. 새 조각을0~1 밖에 임시 배치한 상태에서 ORIGINAL_AABB 패킹을 쓰면 여러 타일 범위를 채운 뒤 축소되어 면적 효율이 나빠졌다.
- **I4, 기존 미세 UV**: 재패킹하면서 헬멧/어깨의 작은 자체 겹침/퇴화가 드러났다. 이전 검사 허용오차와 재패킹 결과는 같은 미술 검증이 아니었다.
