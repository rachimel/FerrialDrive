# 레이더 방향 표시를 채운 삼각형으로 변경

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청에 따라 선 화살표를 **속이 채워진 이등변삼각형**으로 바꿨다.
- 적을 향하는 꼭짓점과 방향에 수직인 대칭 밑변을 사용한다. 감지 범위·플레이어 중심·링 반경·색은 유지한다.
- 기존 `arrow_length_pixels`·`arrow_half_width_pixels` 설정을 삼각형 높이·밑변 반폭으로 사용한다.
- 렌더러에 삼각형 채우기를 추가했다. 내부 픽셀은 한 번씩 그려 전환 중 알파가 중첩되지 않게 한다. Pico2D 원본은 수정하지 않았다.
- 사용자 확인 방침에 따라 자동 검사·프로그램 실행·렌더링·실제 창 조작은 수행하지 않았다.
