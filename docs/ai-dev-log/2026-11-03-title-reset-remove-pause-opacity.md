# 타이틀 초기화 제거·일시정지 패널 알파

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 타이틀의 표시 초기화를 없애고 일시정지 패널 알파를 올린다.
- 타이틀의 초기화 버튼을 제거하고 테스트 종료를 둘째 행으로 올렸다. 남은 버튼은 전투 HUD 보기·테스트 종료다. 전투 HUD 하단의 테스트 초기화는 유지한다.
- 일시정지 패널 자체의 배경 채움 알파를 0.45→0.85로 올렸다. `pause.panel_fill_opacity`로 공통 패널 스타일과 분리했다. 배경 화면을 어둡게 하는 알파 0.75와 타이틀·타겟 패널의 알파 0.45는 유지한다.
- 소스·설정·버튼 연결을 읽어 대조했다. 자동 검사·실행·렌더링·조작은 수행하지 않았다.
