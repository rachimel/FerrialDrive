## 5. 반영 후 발견한 문제

- **I2** 선택 패킹 환경에서 CPU 커밋 감소를 확인했지만 180기 반복 실행의 P99는 원본보다 높았다. 최초 동시 실행 중 캡처 원본이 검게 저장되어 대조를 순차 실행했다.
- **I3** 현재 활성 출력의 OpenGL은 RTX 5070 Laptop이었다. Intel 실제 통합 메모리의 새 표본은 얻지 못했다.

## 6. 사용자 해결 제안과 실제 해결 과정
