# 품질 즉시 적용·찌르기 Trail 확대와 PDW 속성 표시 제거

- **기록 ID: FDLOG-20261115-live-quality-thrust**
- 작성·최종 자동 검사 확인: 2026-11-15 02:31:33 KST.
- 개별 요청·구현·실제 렌더 확인의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261115-live-quality-thrust:scope]] 현재 대화의 `찌르기 Trail 많이 크게`·`설정이 재실행말고 바로 적용`·`찌르기 Trail 좀 더 두껍게`·`PDW 밑에`·`이거 없애도 될듯`으로 찾는다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: 찌르기 Trail을 크게 하고 이어 굵기도 늘린다. 구체적인 수치와 이유는 별도로 제시하지 않았다.
- **사용자 제안 2 (U2)**: 바로 적용할 수 있는 설정은 재실행 없이 적용한다. 원본 기준 높음 75%·보통 50%·낮음 25%를 사용한다. 근거는 현재 대화의 적용 방식·품질 정의 요청이다.
- **사용자 제안 3 (U3)**: PDW 아래 화염 표시의 정체를 확인한 뒤 제거를 요청했다. 근거는 화염 아이콘 캡처와 `화염 속성 아이콘이 있었나`·`이거 없애도 될듯` 발언이다. 제거 이유는 추가로 제시하지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 찌르기 표시의 배율·굵기에 반영했다. U2를 품질 프로필·설정 저장/적용 경로에 반영했다. 사용키 표시는 저장 즉시 적용을 유지한다.
- U3에 따라 기본 PDW 샘플의 FIRE 추가 속성을 제거했다. 이는 샘플 표시 제거이며 화염 공격 규칙을 구현하거나 폐기한 사실로 확대하지 않는다.

## 3. AI가 제안한 것

- **구현상 판단 A1**: 끝점을 고정하고 V형 날개와 굵기에 표시 배율 2.5를 적용한다. 후속 굵기 요청에 기준 반폭을 외곽 약 7.38px·코어 약 2.36px로 정했다. 이유는 기존 단일 찌르기 궤적을 유지하면서 시인성을 높이기 위해서다. 명중 판정은 별도다.
- **구현상 판단 A2**: 새 품질을 준비하고 저장이 성공하면 자원 참조를 교체한다. 실패하면 새 자원을 정리하고 기존 자원·설정을 유지한다. 교체 중 위치·콤보·HUD·일시정지 상태를 보존한다. 근거는 사용자 U2와 기존 설정/아틀라스 구조다.
- **구현상 판단 A3**: 25% Oodle 후보를 기존 텍스처 준비 경로로 생성하고 공통 `--add-oodle-scale` 옵션을 추가했다. 원본 입력을 보존하고 품질마다 같은 160클립을 사용한다.
- A1~A3은 별도 사전 제안이 아닌 구현상 판단이다. 제시·반영의 개별 시각은 위 scope 누락 항목으로 추적한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자는 확대 뒤 굵기 증가를 추가 요청했다. 정확한 배율·폭과 A2/A3의 세부 구현 방식에 대한 별도 최종 승인은 아직 없다.

## 5. 반영 후 발견한 문제

- **문제 1 (I1)**: 기존 자동 검사가 찌르기 굵기의 과거 수치를 고정해 실패했다. 표시 변경 요구에 맞게 외곽·코어의 유효한 폭 관계를 검사하도록 정리했다.
- **문제 2 (I2)**: 추가한 품질 교체 검사가 개인 설정의 현재 품질을 읽어 실행 환경에 따라 실패했다. 검사 시작 품질을 명시해 개인 설정과 독립시켰다. 개인 설정 파일은 수정하지 않았다.
- 실제 입력/렌더 경로에서 품질 전환·상태 보존·미준비 프로필 실패 처리를 확인했다. 전체 방향·성능 목표와 사용자 최종 외관 승인은 별도다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 후속 굵기 요청을 기준 폭 증가로 반영했다. I1/I2의 자동 검사 오류에 대한 구체적인 사용자 해결 제안은 별도 제시되지 않았다.
- U3은 FIRE 샘플 표시 제거 요청이며 제품 실행 오류의 해결 제안으로 바꾸어 기록하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- I1의 과거 표현 수치 고정 조건을 정리하고 I2의 검사 시작 품질을 고정했다. **전체 자동 검사 757개 실행·722개 통과·환경 제외 35개·실패 0개**다. 결과: `output/maintenance/live-quality-thrust-checks.log`.
- **실제 렌더/입력 경로 확인**: 로컬 기체·OpenGL에서 설정 버튼 이벤트로 75%→50%→25%→75% 전환, 저장 상태·이전 자원 정리·위치/콤보/게이지/일시정지 보존을 확인했다. 준비하지 않은 프로필은 기존 품질을 유지했다. 별도 설정 파일을 사용했다. 결과: `output/maintenance/live_quality_review/`.
- 보간 GPU 페이로드는 높음 508.69MiB·보통 236.06MiB·낮음 65.96MiB다. 그림자 50%·HUD·바닥은 별도이며 실제 GPU 할당량·FPS 실측으로 확대하지 않는다.
- 찌르기는 동쪽·북쪽의 3/4타 실제 렌더 42개 캡처를 생성하고 대표 프레임의 확대·굵기·단일 궤적을 직접 열어 확인했다. 결과: `output/maintenance/combo_trail_review/thrust_thick/`. PDW 샘플에 추가 속성이 없고 실제 화면에도 화염 아이콘이 없음을 확인했다.
- 현행 UI·훈련장·품질·샘플 안내를 갱신했다. 사용자 직접 창 조작·최종 외관 승인·커밋·업로드는 수행하지 않았다.
