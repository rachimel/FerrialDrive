# 변경 숫자만 이동·방향성 스미어

- 작성일: 2026-11-03, 한국 시간
- 사용자 최신 요청: 변경되는 숫자만 밀어내고, 블러에 손가락 효과 같은 방향성을 준다. 이전 모든 자리 이동 요구를 이 요청으로 대체한다.
- 이전·다음 숫자가 같은 자리는 이동·페이드·블러를 생략한다. `120→240`에서는 백·십의 자리만 움직이고 일의 자리 0은 고정한다. 이전 숫자가 위로 밀리며 점점 투명해지는 동작은 유지한다.
- 과거 자세를 겹치는 블러를 현재 글자를 지정 방향으로 쓸어 늘이는 잔상으로 바꿨다. 끝으로 갈수록 가중치를 낮추고, 셔터 구간 이동량에 따라 길이가 변하도록 했다. 시작·정착 시 잔상은 사라진다.
- `damage_counter.blur_direction=[0,-1]`(위쪽), `blur_length_pixels=28`(최대 길이)을 추가했다. 기존 강도 0.58·셔터 0.085초·샘플 9개·페이드 지수 1.4는 유지한다. 숫자 영역 잘라내기와 DAMAGE·쉼표 고정도 유지한다.
- 코드·설정·현재 명세를 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 `120→240`의 0 고정, 움직이는 자리의 위쪽 스미어·이전 숫자 페이드를 확인한다. 시각적 품질·실제 성능은 사용자 확인 전이다.
