## 5. 반영 후 발견한 문제

- 최초 명세 반영 단계에서는 실행 검증을 하지 않았다. 기존 훈련장 명세에는 Trail·잔상·지면 효과도 2배 가속 대상으로 적혀 있었으며 이번 결정으로 요구사항을 변경했다. 이를 이번 변경으로 발생한 버그로 분류하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- PRE-PRD의 모든 애니메이션 가속 문구와 훈련장·UI 명세를 수정했다. VFX 자체 시간과 공격 동작 추종을 구분하고, 일시정지에서는 VFX도 멈추도록 명시했다.
- 최초 명세 단계와 U2 이후 구현을 구분한다. 과거 구현·검증 기록은 당시 상태로 보존했다.
- `movement_application.py`: 검 효과에 일반 경과 시간과 원본 `AttackStep.real_seconds`를 전달한다. 공격 위상·검끝 추종은 가속된 `start_seconds`·`end_seconds`를 유지하고, 생성 시각·Trail·잔상·접촉 효과의 수명은 실제 시간으로 계산한다. 지면 효과와 Rim 호흡도 일반 경과 시간을 사용한다. 지면 부착 위치는 현재 동작에서 계속 읽는다.
- `preview.py`: CPU 흡수 Trail의 도착 판정·이동, GPU 입자의 생성 주기·갱신 요청, 피해·회복 flash와 표적 소멸에 일반 경과 시간을 전달한다. HUD 전환·스왑·기체 동작은 기존 애니메이션 시간을 유지한다. 기존 정지 분기 이전에 VFX 갱신을 추가하지 않았다.
- `test_overdrive.py`: 실제 Trail 형상의 공격 위상 추종, 같은 실제 시간에 동일한 수명 감소·소멸, 기체 2배와 지면/Rim 일반 시간의 분리, CPU·Compute 입자 갱신 요청·flash·일시정지 회귀 검사를 추가했다. 기존 가속 시간 기대값도 수정했다.
- 프로젝트 전용 Python으로 Overdrive·무지개 팔레트·검 효과·지면 효과·이동 공격·이동 HUD·Standby Rim·UI 보간·HUD 기본·에너지/피격/준비 효과·에너지 채움·피해 숫자의 관련 자동 검사를 실행했다. **203개 중 200개 통과·선택 GPU 검사 3개 건너뜀·실패 0개**다. GPU 입자 시계 검사는 갱신 요청을 확인한 것이며 실제 GPU 렌더링 완료로 확대하지 않는다.
- 문구·상대 링크·필수 기록 항목과 관련 자동 검사를 확인했다. 실제 창 조작·시각적 재생·사용자 외관 승인은 미수행이다. 기존 수정·미추적 파일이 다수이며 대상 코드도 기존 미추적 상태여서 다른 작업을 포함하는 커밋·업로드는 수행하지 않았다.
