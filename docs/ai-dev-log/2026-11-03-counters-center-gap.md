# 카운터들 사이 여백을 화면 중앙에 배치

- 작성일: 2026-11-03, 한국 시간
- 사용자 명칭: 콤보와 데미지 카운터를 함께 '카운터들'이라고 부른다.
- 사용자 요청: 카운터들을 위로 올려 두 표시 사이 여백의 중심이 게임 플레이 화면의 중앙 높이에 오도록 배치한다.
- 기존 고정 시작 y=366을 제거하고 창 높이의 절반을 여백 중심으로 사용한다. 콤보 표시 영역 하단은 중심−간격/2, 데미지 표시 영역 상단은 중심+간격/2로 계산한다. 1280×720·8px 간격에서는 각각 y=356·364이며, 여백 중심은 y=360이다.
- 콤보 상단은 숫자·라벨의 측정 높이에서 역산한다. 자릿수 증가·숫자 축소 시에도 여백 중심을 유지한다. 오른쪽 여백 32px·행 간격 8px·변경 자리 효과는 유지한다.
- 변경 코드·설정·명세를 읽어 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 재시작 후 화면 중앙선과 두 카운터 사이 여백, 오른쪽 정렬을 확인한다.
