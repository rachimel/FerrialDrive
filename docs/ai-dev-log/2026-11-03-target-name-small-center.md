# 적 이름 축소·세로 중심 정렬

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 훈련 표적 A의 글자 크기도 줄이고 TARGET과 세로 정렬한다.
- 적 이름은 Regular를 유지하며 20→18px로 줄였다. TARGET은 Bold 14px를 유지한다.
- 기존 글꼴 기준선 보정을 표시 텍스트 높이 차이의 절반 보정으로 바꿔, 같은 y 앵커의 TARGET·적 이름의 세로 중심을 맞췄다. 타겟 없음도 같은 보정을 사용한다. 좌우 정렬·패널·HP 바는 유지한다.
- 설정과 그리기 코드를 읽어 대조했다. 자동 검사·실행·렌더링·창 조작은 수행하지 않았다. 전투 HUD 시안 마감 결정은 유지한다.
