## 1. 사용자가 제안한 것

- U1: 손을 키우고 손가락을 실제 관절로 구현한다. 프리렌더에서 디테일이 줄더라도 애니메이션 때문에 필요하다고 설명했다. 머리는 투구/방탄모 같은 곡면으로, 다리는 더 길게, 팔은3단계로, 허리는 자연스럽게 만들고 레퍼런스를 더 참고하도록 요청했다. 개선안 설명 후 첫 구현 진행을 허용했다.

## 2. AI가 제안한 것

- A1: 손바닥 폭30% 확대·개별 마디 뼈·편 손/주먹/쥐기 포즈, 곡면 헬멧 외피와 안쪽 센서, 발을 유지한 추가20% 다리 기장, 겹치는 복부 장갑과 회전 프레임을 제안했다. 팔은 상완–전완–손으로 진행한다고 안내했다.
- 엄지는 기저 관절+2마디, 나머지는3마디로 구성한다. 확대 손의 여유를 위해 손목을 약간 바깥으로 벌린다. 구체적인 메시·축·임시 관절 각도·샘플 수는 구현상 판단이다.

## 3. 사용자 제안 중 AI가 수용한 것
