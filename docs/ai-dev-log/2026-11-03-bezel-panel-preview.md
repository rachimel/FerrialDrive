# Bezel 근사색 패널 시연

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: UI 패널을 Bezel 색감으로 렌더링한다.
- 공식 Pantone 자료에서 20-0011 TPM Bezel의 이름·Metallic Shimmers 계열은 확인했으나 공식 화면용 HEX/RGB 값은 확인하지 못했다.
- 시연에는 비공식 참고 자료의 `#39444A` / RGB(57,68,74)를 근사색으로 임시 사용한다. 출처: https://www.paleton.net/color/028.110275.201.176471.962755-20-0011-tpm-bezel/ . Pantone 공식 값이나 본편 최종 팔레트로 표시하지 않는다.
- `colors.panel_surface` 역할을 추가해 UiView.panel의 채움에만 연결했다. 새 역할이 없는 설정은 기존 panel 색으로 돌아간다. 타이틀·타겟·일시정지 패널에 적용하고 버튼·임시 기체가 공유하는 기존 panel 역할은 유지한다.
- 공통 알파 0.45·일시정지 알파 0.85와 전환 알파를 유지한다. 실제 화면색은 배경과 합성된다. 금속광택·재질 셰이더나 전체 색상 테마 변경은 추가하지 않았다.
- PRE-PRD·UI 명세·샘플 안내에 임시 적용값과 최종 색상 확정의 경계를 기록했다. 소스·설정을 읽어 대조했으며 실행·렌더링·시각적 일치 검증은 수행하지 않았다.
