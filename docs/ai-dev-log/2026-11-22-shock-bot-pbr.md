# Shock Bot 파츠 보간·그림자·거리별 최적화

- **기록 ID** `FDLOG-20261122-shock-bot-pbr`
- 작업일 2026-11-22 KST.

## 1. 사용자가 제안한 것

- **U1** Shock Bot에 보간, 그림자, 소형·중형 적에 쓰는 근거리·원거리 최적화를 적용한다. 기존 최적화 규칙으로 다시 패킹할 것을 확인했다. 개별 요청 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261122-shock-bot-pbr:U1]]`. 검색 단서는 `인간형 적도 보간 추가`, `최적화 규칙`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 승인된 Unreal 동작 다섯 개에서 8방향·6파츠·24fps의 PBR 원본을 출력했다. High·Medium·Low에 BC7 색상, 축소 RG8 벡터, 희소 키와 Box 그림자를 적용했다. 본편과 Combat Test는 같은 방향 스트리밍·캐시·배치 코드를 사용한다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 원거리 시트에 세 기종의 포즈와 방향별 그림자를 담을 공간이 필요해 1,024px 너비를 유지하고 64px 행을 추가했다. 본편과 Combat Test의 시트는 각각 4 MiB와 6.5 MiB다. 근거는 시트 슬롯 계산과 GPU 로딩 검사다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **A1** 행 수와 세부 패킹 수치는 구현상 판단이다. 별도 외관 승인 기록은 없다.

## 5. 반영 후 발견한 문제

- **I1** 보통 품질의 60Hz·8방향 대조에서 초안 Hermite 후보는 근접 공격과 격파의 실루엣 오차가 기존 절충 기준을 넘었다. 보행의 일부 시점도 선형 후보보다 크게 달랐다.
- **I2** 기존 소형 적 Break의 배치 픽셀과 Deferred 깊이의 정확 일치 검사 두 건은 기존 커밋 렌더러를 불러와 다시 실행해도 같은 차이가 났다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 기존 규칙에 맞춰 저장 키와 페이지를 재패킹했다. 원거리 시트는 기존 포즈 선택·가림 순서·그림자 배치를 재사용한다. 근거리와 록온은 기종별 32 MiB 캐시를 사용하고 페이지가 준비되는 동안 같은 동작·방향의 원거리 포즈를 표시한다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1** 근접 공격·격파는 기존 키와 선형 벡터 위상을 유지하고 보행·발사·피격은 본 자세 오차 3px, 최대 5칸, 누적 이동 16px로 다시 구성했다. 보통 품질의 1,640개 시점을 대조해 두 보존 동작의 실루엣 IoU가 선형 후보와 일치함을 확인했다. 파츠 아틀라스의 보통 품질 논리 텍스처는 조밀 BC7/RG8 원본 243.5 MiB에서 94.6 MiB로 줄었다. 이 수치는 한 번에 메모리에 올라가는 용량과 별개다.
- 실제 OpenGL에서 본편의 근거리 PBR·Box 그림자와 원거리 배치·그림자를 확인했다. 원거리 한 기는 PBR 페이지를 요청하지 않았다. Combat Test의 근거리 본체·그림자 배치, Deferred 깊이·좌표 버퍼, 근접 공격·원거리 발사·피격·격파의 재생을 확인했다. 직접 조작 사용감은 미검증이다. 원본·패킹·화면과 검증 보고서는 로컬 `output/enemy_humanoid_shock_bot/`에 있다.
