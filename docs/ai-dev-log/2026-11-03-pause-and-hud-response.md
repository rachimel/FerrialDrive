# 일시정지·테스트 표시 분리·HUD 반응 조정

- 작성일: 2026-11-03, 한국 시간
- 사용자 결정: 플레이어·훈련 표적 A의 임시 도형과 이름표는 유닛 테스트에서만 사용한다. `샘플 상태 조작` 안내 문구만 제거하고 하단 테스트 버튼은 유지한다.
- 임시 기체 도형·이름표를 재사용 뷰에서 테스트 실행부로 옮겼다. 하단 테스트 버튼도 실행부에서 그린다. 플레이어 이름은 샘플 데이터로 옮겼다. 타겟 패널은 여전히 전달받은 `TargetInfo.name`을 표시하며 훈련 표적 이름을 고정하지 않는다.
- 전투 Esc는 타이틀 직행 대신 일시정지를 연다. `계속 / 타이틀로 / 테스트 종료`를 추가했다. 메뉴 Esc의 HUD 진입은 유지한다.
- 별도 `PauseState`로 페이드·차단 상태를 관리한다. 일시정지와 열기·닫기 동안 카운터·표시 수명·피해 숫자·HP 감소 효과·조준 갱신을 멈추고, 정지 중 포인터 입력은 일시정지 메뉴에만 연결한다. 복귀 시 누적 정지 시간을 더하지 않는다. 타이틀 복귀는 샘플 값을 유지한다.
- 조절용 시안: 일시정지 페이드 0.16초, 배경 알파 0.75, 중앙 패널 400×320px. 메뉴 폰트는 Cafe24 Ohsquare Air다. 실제 게임의 종료 동작은 연결 시 별도로 정한다.
- 사용자 추가 요청: 카운터 갱신 0.34→0.20초로 단축, 레이더 반경 124→148.8px로 20% 확대, 흰색 크로스헤어의 원·십자 두께 3px. 기존 탄성 이동·방향성 블러는 유지한다.
- 소스·설정·호출 위치를 읽어 대조했다. 자동 검사·프로그램 실행·렌더링·창 조작은 수행하지 않았다. 효과 도중 일시정지·재개, 배경 입력 차단, 타이틀 복귀와 수치 보존, 카운터 속도·레이더 크기·크로스헤어 두께는 사용자 확인 대기다.
