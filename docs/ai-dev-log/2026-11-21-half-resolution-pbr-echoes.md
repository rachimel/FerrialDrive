# PBR 잔상 반해상도와 키포즈 아틀라스 확인

**기록 ID** `FDLOG-20261121-half-resolution-pbr-echoes`

## 1. 사용자가 제안한 것

- **U1** HUD 패널·텍스트를 이미 재사용하는지 확인하고 PBR 잔상 해상도를 50%로 줄인다.
- **U2** 리패킹한 아틀라스에는 키프레임만 담는다.
- 정확한 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-half-resolution-pbr-echoes:U1-U2]]이다. 같은 대화에서 `잔상은 PBR 해상도 약하게 해도 되고`, `이젠 KeyFrame들만 담아`로 찾을 수 있다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 텍스트 아틀라스와 패널 효과 텍스처 캐시가 이미 동작하는 코드를 확인했다. 현재 패널 배치, 동적 효과와 그리기 호출은 프레임마다 처리한다.
- **U2** 작업트리의 플레이어와 적 `r02` 프로필을 사용했다. 품질 3종과 기체 3종의 파츠 키 시각·픽셀 타일·참조를 검증했다.

## 3. AI가 제안한 것

- **A1** 구현상 판단으로 검 잔상만 PBR을 가로·세로 절반의 재사용 타깃에 합성한다. 색·투명도·화면 위치·크기는 기존 계산을 사용하고, 최종 합성은 선형 확대한다. 기존처럼 키와 양방향 벡터로 중간 자세를 만든다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 50% 잔상 해상도와 키프레임 보관은 사용자 요구다. 선형 확대와 타깃 구성은 이번 구현에서 사용한 값이다.

## 5. 반영 후 발견한 문제

- **I1** 반해상도에서 장갑의 가는 선과 무기 끝의 세부가 부드러워진다. 고품질 콤보의 서로 다른 방향과 시각 5개에서 화면 배치가 일치했고 알파 실루엣 교집합/합집합 비율은 94.6~96.3%였다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 잔상 PBR 품질을 낮춰도 된다는 요청에 따라 잔상 전용 합성에 반해상도를 적용했다.
- **U2** 아틀라스 검증에서 플레이어 333→226, 스파이더 80→59, 메카 84→60개 표본을 보관했다. 수치는 방향·공유 모션을 중복 집계하지 않았다. 검사한 9개 카탈로그에서 파츠 이미지 타일은 보관 키에서 참조되며, 정상 교전이 세 기체의 `r02` 카탈로그를 읽는 것도 확인했다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1 ↔ A1** 알파를 보존한 선형 확대로 잔상 위치·크기와 색 처리를 유지했다. 리패킹한 동일 고품질 자료로 잔상 다섯 개를 그린 별도 GPU 계측의 평균 중앙값은 5.07→2.34ms였다.
- **A1** 게임용 Python의 FHD 28기 교전에서 기존·반해상도를 교대해 420프레임을 측정했다. 잔상 구간은 프레임당 3.34→1.95ms, 전체 작업은 25.54→24.50ms였다. 후보 잔상 타깃의 보고된 크기는 36 KiB였다.

## 확인 상태

- 실제 화면 비교, 키·타일 참조 검사와 파츠 회귀 검사 31개를 통과했다. 고품질 2 GiB 교전은 준비 중 약 1,924 MiB에서 커밋 가드로 종료했다. 원시 결과와 비교 이미지는 `output/performance/echo_half_r01/`에 있다.
