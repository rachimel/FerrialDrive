## 1. 사용자가 제안한 것

- 팔과 뒤틀린 기하 정보만 교정하도록 범위를 제한했다.
- 진행 중 작은 프리렌더에서 스커트가 부풀어 보인다고 지적하며 평평한 형상으로 변경하도록 추가 요청했다.

## 2. 사용자 제안 중 AI가 수용한 것

- 새로운 장식 없이 팔의 음영과 비평면 다각형을 교정한다.
- 스커트의 앞뒤 볼륨과 밑단 벌어짐을 줄이고 작은 정면/후면 렌더에서 확인한다.

## 3. AI가 제안한 것

- v074: 비평면 다각형을 명시적으로 분할하고 팔의 날카로운 모서리와 면적 가중 노멀을 적용한다. 기존 평평한 끝면의 음영은 유지한다.
- v075: 스커트 중간 단면을 상단과 밑단 사이의 직선형 단면으로 정리한다. 연결 외피와 전면 겹침판에 같은 변환을 적용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 핵심 변경은 명시 요청이다. 수치·세부 음영·최종 외관은 아직 사용자 승인 전이다.

## 5. 반영 후 발견한 문제

- v075 초기본에서 스커트 장착 삼각형의 변형이 고리의 회전 방향까지 바꿨다. 팔을 벌린 수납 111개 표본 중 앞쪽 수납/기울기 18도인 6개에서 고리 입구와 허벅지 덮개가 교차했다.
- 첫 회전 보정에서 VERTEX_3 부모의 matrix_world를 직접 대입해 렌더 시 고리가 위로 떠올랐다. 해당 중간본의 교차 0건은 올바른 배치의 증거가 아니므로 폐기했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- v074: 15개 메시의 비평면 다각형 분할/팔 노멀을 교정했다. 정점 좌표·본 웨이트·UV 좌표·재질·Shape Key는 488개 메시 모두 v073과 같음을 확인했다.
- v075: 연결 스커트와 좌우 전면 겹침판 3개 메시만 변형했다. 최대 정점 이동 약 0.220 모델 단위. 위쪽 연결은 유지하고 아래쪽 기준 앞 깊이 0.460/뒤 깊이 0.445/반폭 0.930으로 직선 보간했다. 주면은 평면 음영, 작은 모서리는 부드러운 음영을 유지했다.
- 1K 아틀라스와 가슴 링·에너지 경로는 변경하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- 고리의 새 장착 위치는 유지하면서 기존 월드 회전 방향을 복원했다. 최종본의 111개 수납 표본에서 본체 표면 교차가 없어졌다. 기존 로컬 회전축과 에너지 0/0.5/1도 검사했다.
- 장착 부모의 실효 변환을 구해 matrix_basis에 회전 보정을 적용하도록 수정했다. 재로딩·중립 자세·프레임 1에서 양쪽 고리 장착 높이가 모델 좌표 약 2.96/2.97임을 확인하고 수납 검사와 렌더를 다시 실행했다.
- 스커트 확대·전신·320×400 정면/후면 렌더를 생성해 검토한다. 이전 v073/v074 파일은 보존한다. 실제 창 조작·게임 스프라이트 재출력·무기 장착·연속 충돌·전체 전투 모션·최종 미술 승인은 별도다.
