## 5. 반영 후 발견한 문제

- **I1, 기존 문제 해결 대상**: 헬멧8각 면의 일부 UV 코너가 일직선이어서 렌더 삼각형1개가 UV 면적0으로 눌렸다. 기존에는 극미세 면 예외로 남겼다.
- **I2, API 설계 위험**: 메시 로컬 좌표를 직접 바꾸면 부모 계층마다 축이 달라지고 형태 키 일부만 바꾸면 전개 형상이 불일치한다. 연결 본 수정은 미지정 본으로 전파될 수 있다.
- **I3, 검사 구현 문제**: 첫 장치 검사는 quaternion 본을Euler값으로 읽어 실패했다. 실제 장치 오작동으로 간주하지 않고 올바른 회전 채널로 검사했다.
- **I4, 범위 한계**: 형상과 본의 위치 변경은 자동 기구 재설계가 아니다. 제약/드라이버 내부의 고정 수치,UV 밀도,커스텀 법선,인접 장갑 연결은 새 변형마다 검토해야 한다.
