# HUD 필터 마스크 타깃 재사용

- **기록 ID** `FDLOG-20261123-hud-mask-pool`
- 작업일 2026-11-23 KST.

## 1. 사용자가 제안한 것

- **U1** 텍스처 배열과 HUD 마스크 재사용을 진행한다. 정확한 발언 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261123-hud-mask-pool:U1]]`. 검색 단서는 `텍스쳐 배열과 HUD 마스크 재사용`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** HUD 필터의 기존 픽셀 캐시에 같은 크기의 SDL 타깃 재사용을 연결했다.

## 3. AI가 제안한 것

- **구현상 판단** 패널 모양이 달라지면 원래 규칙으로 다시 그리고, LRU에서 밀려난 타깃은 크기가 같은 마스크가 필요할 때 다시 쓴다. 보관 상한은 유휴 타깃 24개·RGBA 기준 2MiB다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 별도 수용 요청은 없었다. 풀의 상한은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** `panel_border`의 모양이 바뀌는 동안 같은 폭과 높이의 작은 타깃을 반복 생성했다. 마스크의 픽셀은 모양에 따라 달라 화면 변경 없이 픽셀 캐시 키를 합칠 수 없었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1, I1** 기존 HUD 배치 제출 뒤 유휴 타깃을 보관한다. 꺼낼 때 이전 색·투명도 modulation을 지우고 기존 생성 코드에서 blend·필터와 픽셀을 다시 설정한다.

## 7. AI 해결 제안과 실제 해결 과정

- 같은 180기 FHD Medium/SMAA 자동 검 상세 계측 240프레임에서 마스크 요청은 양쪽 26.90회/프레임, 타깃 생성은 1.117→0.292회/프레임이었다. 198회 재사용했고 끝에 유휴 타깃 19개·880,688바이트를 보관했다. 1회 전후의 FPS·P99 편차로 프레임 개선을 단정하지 않는다.
- 출력 RGBA와 이전 modulation 초기화를 확인하는 검사 포함 UI 필터 검사 18개가 통과했다. 원시 로그는 `output/performance/hud_mask_reuse_20261123/`에 있다.
