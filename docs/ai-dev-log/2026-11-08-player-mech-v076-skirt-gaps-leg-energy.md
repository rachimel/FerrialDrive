# 기체 v076 — 열린 스커트 경계·조인트 공간·다리 에너지

- 기록 ID: FDLOG-20261108-player-mech-v076-skirt-gaps-leg-energy
- 출처: 현재 대화의 후방 스커트와 다리 위 조인트 충돌 지적, 앞쪽 경계 분리 요청, 선택 답변 “꺾이는 경계에서 판을 나눠 틈 벌리기”, 다리 홈 에너지 요청. 정확한 시각 미확인: [[FDLOG_MISSING_TIME:FDLOG-20261108-player-mech-v076-skirt-gaps-leg-energy:request]] 해당 원문 시각으로 보완한다.

## 1. 사용자가 제안한 것

- 뒤 스커트와 다리 위 조인트의 충돌을 고친다.
- 앞쪽 꺾임을 제거하거나 경계에서 벌린다. 확인 질문에 판을 나누고 틈을 벌리는 방식을 선택했다.
- 다리 홈에 에너지가 들어가도록 요청했다.

## 2. 사용자 제안 중 AI가 수용한 것

- 스커트와 다리 부품의 교차를 직접 검사하고 조인트 공간을 확보한다.
- 전면 중앙과 좌우 꺾임에 실제 열린 세로 틈을 만든다.
- 다리 홈을 정강이의 기존 세로 매입부로 해석한다고 알리고 가는 발광부를 추가한다.

## 3. AI가 제안한 것

- 평판 형상은 유지하되 중간 단면을 조인트 바깥으로 배치한다. 원본 장착 메시를 숨겨 고리의 정점 부모 인덱스를 보존하고, 별도 가시 메시를 절삭한다.
- 상단 연결부 아래에 0.045 모델 단위의 세로 틈 3개를 절삭한다. 겹침판도 좁혀 틈을 덮지 않게 한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 판 분리/틈 방식은 사용자 명시 선택이다. 틈의 수치와 정강이 발광부 배치는 구현 판단이며 최종 외관 승인은 아직 없다.

## 5. 반영 후 발견한 문제

- v075의 스커트 축소로 양쪽 고관절 덮개·외측 보호판·허벅지와 표면 교차가 생겼다. v074 중립 자세에서는 해당 교차가 없었다. 종전 고리 수납 검사는 스커트 자체와 다리의 교차를 검증하지 않았다.
- 첫 세로 절삭 후 전면 겹침판이 외측 틈을 가리는 것을 확대 렌더에서 발견했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 앞뒤/측면 단면의 조인트 여유를 확보하고 중립 자세에서 스커트와 다리의 교차가 없는 것을 확인했다. 둥근 중간 볼륨 대신 직선 단면을 유지했다.
- 스커트 상단 연결을 남기고 중앙/양쪽 꺾임 아래를 실제 절삭했다. 전면 겹침판을 좁혀 열린 틈을 드러냈다.
- 양쪽 정강이 매입 패널에 폭 0.012, 길이 0.205 모델 단위의 에너지 띠를 추가했다. 기존 에너지 재질의 레벨·색·강도를 공유한다.

## 7. AI 해결 제안과 실제 해결 과정

- 원본 스커트는 장착/복구용으로 숨기고 별도 가시 메시를 절삭하여 기존 고리 정점 부모 연결을 유지했다. 새 메시에는 기존 본 웨이트/UV와 Armature를 유지했다.
- 중립 스커트/다리 표면 교차 검사, 고리 수납 111개 표본, 1K 패킹·에너지 제어를 재검사한다. 작은 정면/후면·전신·스커트 확대 렌더로 확인한다.
- 전체 전투 자세·무기 장착·연속 충돌·실제 게임 재출력·최종 미술 승인은 별도다. v075 원본 보존, 에셋 업로드/커밋 없음.
