## 5. 반영 후 발견한 문제

- **I1 — 초기 분할:** 면 중심 분류 초안의 절단면이 닫히지 않아 평면 절단의 새 후보로 교체했다. 옛 `split/` 초안은 최종 후보가 아니다. AI 검사에서 발견했으며 개별 시각은 위 TIME 태그.
- **I2 — 원본 UV 경고:** 원본에도 면적 0 경고가 있다. UV 품질 전체 통과와 표면 보존 통과를 구분한다.
- **I3 — 공용 seed:** 첫 Unreal 리그 저장이 `Skeleton can't be modified`로 실패했다. 정확한 엔진 내부 원인은 확정하지 않는다.
- **I4 — 옆 패널 관통:** 120Hz 검사에서 총 좌우 달리기 패널·허벅지 교차 검출. 각도 확대 뒤에도 잔여 교차가 있었다. 축 안쪽의 상단 돌출부가 열릴 때 허벅지 쪽으로 내려가는 구조를 확인했다. 근거: `native_panel_leg_intersections_v02.json`·`v03.json`.
- **I5 — 실제 재생 검수 제한:** 브라우저 host 연결 불가. Windows 대체 경로의 기존 탭 읽기는 자동 승인 검토가 작업과 무관한 사적 내용 노출 위험으로 거절했다. 기존 탭을 읽지 않는 빈 창 열기도 앱 승인 시간 초과. 실제 정상/느린 재생·슬라이더 조작은 미검증이다.
- 무릎 제기는 U2로 철회된 진단이며 이번 수정의 결함이나 해결 완료 항목으로 보지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U4 ↔ A1: 승인된 분할을 유지해 Unreal 개별 리프트 제작. 원본 외형·UV·재질·스커트 외 형상을 보존한다.
- U2에 따라 무릎 수정은 실행하지 않았다. U3의 재개 지시가 현재 상태다.
- I4의 구체적인 축·수치 보정은 사용자 해결 제안·승인으로 기록하지 않는다. AI가 구현했고 모션 검수는 남아 있다.

## 7. AI 해결 제안과 실제 해결 과정

- I1 ↔ A3: 공통 `freeze_evaluated_meshes`·`partition_mesh_faces`로 후보 제작. 스커트 외 414객체 보존, 독립 형상·이미지 검사 통과, UV 보존 최대 오차 약 `1.21e-7`, 기본 도형 검사 4개 통과. I2는 남는다. 6면 확대·작은 표시 크기의 전후 이미지를 직접 검토한 뒤 U4 승인을 받았다.
- I3: 깨끗한 geometry-only Root seed에서 새 Unreal 리그 작성. 기존 Blender 본·웨이트·Constraint 미사용. 65본·422개 강체, 9개 출력 단위·Head·에너지 마스크 분리 유지. 새 패널 PBR 저장과 새 worker 재로딩 확인.
- I4 ↔ A2: 전면/옆 리프트와 유효 회전 중심을 보정했다. 계층 변경 없이 `translation = offset - rotation(offset)`으로 표현한다. 95도/85도 등은 시험 수치다. 총 두 클립 최종 입력은 `_v03.json`, 검 1타는 최초 독립 리프트 입력이다.
- **자동 확인:** 원본 몸 키 동일. 최종 3종 기존 본 위치·회전은 120Hz 61표본씩 차이 0. 검 1타 검날 6점도 기존 동작과 차이 0cm. 근거: `final_preservation_checks.json`, `body_preservation_checks.json`, `blade_preservation_check.json`.
- **독립 간섭:** 8개 skirt×좌우 허벅지 16쌍, 최종 세 클립의 120Hz 표면 교차 0. 근거: `native_panel_leg_intersections_v04.json`. 체적 포함·최소 여유·전신·표본 사이 연속 충돌 통과와 구분한다.
- **렌더/패킹:** 정면·측면·사선 54프레임을 직접 열어 확인. 잘림 0·참조 대비 합성 RGB/알파 차이 0. 사선 9파츠·9에너지 마스크를 `unreal.import` 패킹하고 `MechBundle.load` 확인. 패킹 324장 RGBA 차이 0. 근거: `final_render_checks.json`, `delivery_checks.json`.
- **검토물:** `output/skirt_panel_lift_20261116/review/index.html`. 정상 GIF 각 6프레임·500ms, 느린 GIF 1500ms. 링크 누락 0·JS 문법 통과·로컬 HTTP 200. I5로 실제 재생 검수는 미완료다. 검 1타 반복 표시는 검토용이며 반복 모션 승인이 아니다.
