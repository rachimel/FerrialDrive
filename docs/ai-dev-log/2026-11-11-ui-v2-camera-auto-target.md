# UI v2 시선 카메라·자동 표적·에너지 마스크·빠른 HP flash

- **기록 ID: ui-v2-camera-auto-target**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-camera-auto-target:scope]] 검색 단서: `패널 모양으로 마스크`, `데드존 비슷`, `월드 좌표랑 가장 가까운`, `새 후보가 1초 유지`, `기존 획득거리 안에서 시험`.

## 1. 사용자가 제안한 것

- **U1**: 에너지 Scanline이 사각형으로 튀어나오는 것을 패널 형상으로 마스킹한다. HP 흰색 효과는 즉시 흰색으로 바꿔 페이드하기보다 빠르게 등장하고 퇴장하게 한다.
- **U2**: 플레이어를 기본 위치로 하는 카메라에 마우스 변위 방향의 오프셋을 둔다. 마우스 월드 좌표 최근접 적을 자동 선택하고 갑자기 나타난 적에는 약 1초 마진을 준다.
- **U3**: 질문에 R 제거·새 후보 연속 1초 유지·중앙 80px 데드존을 선택했다. 범위 선택은 의견을 물은 뒤 기존 획득거리 안에서 시험한다고 최종 답했다.

## 2. AI가 제안한 것

- **A1**: 카메라 변위 20%·최대 120, 80px 데드존 여부와 범위/전환 조건을 질문했다. 응답 시정수 0.15초는 구현상 판단이다.
- **A2**: 공격 범위 밖의 먼 적을 고르는 문제를 줄이기 위해 기존 획득 범위 안의 최근접 선택을 추천했다. 사용자가 기본 330·조준 460 샘플 범위로 시험하는 데 동의했다.
- 구현상 판단으로 HP flash는 등장 0.02초·유지 0초·퇴장 0.04초를 사용한다. 무효 표적은 즉시 해제하고 재획득은 별도로 1초 확인한다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U3를 반영했다. 에너지 패턴·밝은 띠·노이즈는 배경 면과 분리한 사선 채널 마스크를 공유한다. 흰색은 이번 실제 피해 구간에만 빠르게 밝아졌다 사라지고 빨간 Trail은 유지한다.
- `LookAheadCamera`와 `MouseAutoTargeting`을 입력/렌더러 독립 모듈로 만들고 UI v2에 연결했다. 적·플레이어·피해 숫자는 월드 좌표로 보존하고 몸통·록온·레이더는 동일 카메라로 투영한다. HUD는 고정한다.
- R 입력·가이드 문구·순환 이력 연결을 제거했다. 우클릭 범위 확대는 유지한다. 새 후보가 처음 관측된 프레임부터 1초를 확인하며 후보가 바뀌면 대기를 초기화한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 카메라 시안과 80px 데드존, R 제거, 1초 유지 방식, 기존 획득 범위는 질문에 대한 명시 답변이다. 0.15초 응답·HP flash 세부 시간·무효 표적 처리의 별도 최종 승인은 확인 전이다.

## 5. 반영 후 발견한 문제

- 기존 R 테스트가 제거된 입력과 획득 이력을 참조해 실패했다. 새 규칙에 맞춰 테스트를 갱신했다. 기존 수동 선택 모듈 자체와 그 검사는 호환 경로로 보존했다.
- 마스크 진단은 채널 내부의 픽셀 경계 대신 요구 대상인 패널 외곽을 기준으로 확인했다. 실제 패턴 1,505픽셀이 모두 패널 외곽 안에 있었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 질문 답변을 통해 전체 활성 적 대신 획득 범위 필터, 단순 출현 유예 대신 최우선 후보 1초 유지로 범위를 확정했다. 카메라는 데드존 안에서 오프셋이 없도록 했다.

## 7. AI 해결 제안과 실제 해결 과정

- UI **127개**·기존 획득 **7개**, 총 **134개 통과**. 카메라 방향/데드존/상한/역변환/프레임 분할, 월드 최근접·조준 범위·대기 초기화·신규 적 유예·R 무반응·피해 숫자 투영과 HP flash 상승/하강을 검사했다.
- 최종 설정으로 **360프레임**을 실제 SDL 렌더했다. 마우스 변경 30→90·150→210프레임, 임시 적 출현 225→285프레임으로 각 1초를 확인했다. 기본 샘플 적 3기는 유지하고 검증 실행 중에만 임시 D를 추가했다.
- 마스크 전후와 flash 시작/정점/종료 이미지를 열어 검토했다. 출력은 `output/ui_unit_test_v2/camera_auto_target/`다. 실제 창 조작·전투 본편 연결·GPU 성능·사용자 최종 외관 승인·업로드는 미확인/미수행이다.
