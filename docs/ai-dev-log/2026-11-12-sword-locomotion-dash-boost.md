## 1. 사용자가 제안한 것

- **U1:** 검을 든 보행·추진 이동·대시와 이동 전환 모션을 요청했다. 팔 각도·하체 굽힘·상체 기울기로 상태 차이를 표현하며, 뛰기보다 추진력으로 달리는 느낌을 요구했다. 출처는 현재 대화다.
- **U2:** Shift 유지 상태를 대시, Space로 스러스터 출력을 순간적으로 높이는 빠른 가속을 부스트로 명명하고 관련 문서도 바꾸도록 요청했다. 질의 응답으로 Shift 대시는 `양발을 지면에 붙여 스키처럼 미끄러지는 지속 기동`, Space 부스트 규칙은 `기존 규칙 유지`를 선택했다. 시작 WASD 방향 고정·이동 입력이 없으면 조준 방향 사용·입력 해제 후에도 정해진 거리 진행·완료 후 재사용 규칙을 유지한다.
- **U3:** 같은 기체라면 분리 파츠를 활용해 상부·하부를 공통 재사용할 수 있다고 지시했다. 공통 동작을 조합마다 중복 제작하지 않는 원칙으로 반영했다. 구체적으로 무기 간 하체 공통화와 상체 조합을 뜻하는지 질의했으며, 이 기록 시점에는 응답 전이다.
- 발언의 정확한 시각은 위 누락 항목을 따른다. U1~U3은 제작 요구와 명명/재사용 원칙이며 새 초안의 최종 품질 승인으로 확대하지 않는다.

## 2. AI가 제안한 것

- **A1, 구현상 판단:** 기존 Unreal 새 리그·검 파지·표면을 보존하고 별도 `SwordLocomotion_20261112` 경로에 보행/대시/부스트 반복 3개와 대기/이동 간 전환 12개를 작성했다. 12fps, 각 4~12프레임이며 첫 검토는 정면·측면·사선으로 제한했다. 기존 검격 8방향 연결과 별도다.
- **A2, 구현상 판단:** 보행은 교대 스텝과 골반의 좌우 하중 이동, 대시는 양발 고정과 더 낮은 골반·허리 굽힘, 부스트는 더 깊은 굽힘과 팔/검 각도로 구분했다. 검토 격자 이동량·전환 길이는 임시 표현 값이며 게임 속도·부스트 거리의 신규 결정이 아니다.
- **A3, 구현상 판단:** 기존 공통 애니메이션 작성 경로에 최대 32개 일괄 요청을 추가하고 공통 검토 도구에 동작명·반복 횟수·이동 격자 표시를 추가했다. 개별 자산 전용 Python 제작 코드는 만들지 않았다.
- A1~A3은 사용자 요구의 구현 방식이며 사전 제시·별도 수용으로 기록하지 않는다. 입력과 결과는 `automate/workspace/sword_locomotion_20261112/`를 따른다.

## 5. 반영 후 발견한 문제

- **I1, 기존 용어 충돌:** 이전 Space 대시와 Shift 전력 질주가 문서·샘플·발표자료에 남아 있었다. 최신 요구에 따라 현재 기준 문서를 정리했으며 과거 대화 기록은 고치지 않았다.
- **I2, 출력 구조 확인:** 기존 8파츠는 본체·손·무기·수납부 단위이며 상하체가 독립 출력된 상태는 아니었다. U3의 제작 원칙과 기존 구현의 차이이며 재사용 자체의 불가 판정은 아니다.
- **I3, 보간 접지 오차:** 12fps 키의 발 목표는 접지하지만 120Hz FK 보간에서 정지↔부스트 발 높이 오차가 최대 0.281cm다. 검토 오차 허용 범위 0.5cm를 사용했고 게임상 허용 규칙으로 확정하지 않았다.
- PPTX 수정은 대상 XML 7개만 바꿨다. LibreOffice PDF 비교에서 기획서의 비대상 13/19/29쪽에 국소 래스터 차이가 있었지만 추출 텍스트와 원본 XML/미디어 바이트는 같았다. 변경 전후 이미지를 직접 확인했으며 변환기의 원인은 확정하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- 새 원본 15개를 편집 프로젝트로 복사하고 별도 Unreal 프로세스에서 재로딩했다. 모든 본의 평가 위치/회전은 최초 작성 결과와 같으며 기존 Idle·콤보 에셋 8개의 해시를 보존했다. 세 반복의 첫/끝 자세는 일치하고 12개 전환의 끝 자세는 다음 상태 기준과 위치 0.000001cm 이내로 맞는다.
- 파지 최대 위치 오차는 약 0.000104cm, 팔꿈치 최소 내부각은 약 124.85도다. 수치 검사를 외관 승인으로 확대하지 않았다. 보행의 지지 구간은 검토용 루트 이동을 더했을 때 발의 전후 변동이 0.001cm 미만이다. 새 투영 함수와 기존 8카메라 추적 좌표의 차이는 0px다.

- 정면/측면/사선의 시작·중간·끝과 반복 프레임 접촉표를 직접 열어 자세 차이·손 파지·팔 접힘·발과 골반의 움직임을 확인했다. 실시간 창 재생·직접 입력 조작·연속 메시 충돌 검사는 미수행이다. 재생 가능한 3시점 GIF는 `output/motion/sword_locomotion.gif`, 단일 시점은 `sword_locomotion_oblique.gif`다.
