## 1. 사용자가 제안한 것

- **U1**: 고해상도 텍스처를 사용하고 기체 맥락에 맞춰 각 부위를 텍스처링하도록 요청했다. 표면이 밋밋하며 Material Preview 영향인지 물었다.

## 2. 사용자 제안 중 AI가 수용한 것

- v068을 보존한 v069 사본에 적용한다. 현행 문서의 범용 훈련 플랫폼, 회색 장갑/검은 에너지 경로/청색 발광, 장치 역할을 기준으로 삼는다.

## 3. AI가 제안한 것

- **A1, 구현상 판단**: 기존 4K 본체 맵은 유지하고 1K 공유 소재 결 10종을 실제 4K로 생성한다. 도장/금속/고무 마스크에 따른 반사 응답을 구분한다. 잘 관리된 훈련 플랫폼이라는 해석으로 과도한 녹/손상은 추가하지 않는다. 사용자 미술 승인 전이다.
- **A2**: 기존 넓고 고른 검토 조명도 평평한 인상에 영향을 준다고 판단해 동일 조명 비교와 사선광 검토를 분리한다. 요청 시점의 실제 사용자 뷰포트는 관찰하지 않았다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U1 범위의 작업을 수행했다. 구체적인 소재 수치와 완성 외관에 대한 사용자 수용은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

- **I1**: 고해상도 맵 패킹으로 blend가 약 1.26GB가 됐다. 게임용 텍스처 메모리/용량 최적화까지 완료한 결과는 아니다.
- 저장 시 사용자 썸네일 캐시 쓰기 경고가 있었지만 모델 저장·재로딩은 성공했다.
- **I2**: 첫 비교 렌더의 저주파 주기 결이 장갑에서 격자처럼 보였다. 해당 중간 렌더를 최종 결과로 사용하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1에 따라 본체 4K 맵 42장과 정비/마모 도안을 유지하고 색/거칠기/높이 공유 맵 30장을 4096×4096으로 생성·패킹했다. 형상 수정이나 기존 사용자 변경 되돌리기는 하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- A1: 머리/가슴 코팅, 어깨/스커트 거친 무광, 팔/다리/목/장치 방향성 가공 결, 허리 낮은 요철, 발 거친 접촉면을 적용했다. 도장과 고무 금속성을 억제하고 기존 노출 금속을 유지했다. 텍스처는 절차 생성이며 사진 기반 또는 고폴리 베이크가 아니다.
- 저장본 재로딩으로 357개 메시 형상/UV/법선/가중치/변환과 본 보존, 기존 42개 4K 맵 패킹, 신규 30개 활성 4K 맵 패킹, 에너지 제어 0/0.5/1을 확인했다.
- A2: 동일 카메라/조명 비교와 별도 사선광 렌더를 출력해 확인한다. 실제 게임 출력·전투 모션·사용자의 최종 미술 승인은 별도다. AI 에셋은 공개하거나 커밋하지 않는다.
- I2: AI가 불규칙한 다중 크기 난수 결로 교체하고 색 변화 강도를 낮췄다. 부위별 방향성 금속 결은 유지한다.
