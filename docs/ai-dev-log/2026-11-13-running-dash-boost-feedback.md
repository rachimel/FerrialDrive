## 5. 반영 후 발견한 문제

- **I1:** 첫 달리기 초안은 원본 12fps 프레임에 양발 공중 구간이 없어 빠른 걷기로 읽힐 위험이 있었다. 중간 보간에만 생기는 공중 구간으로 충분하다고 판단하지 않았다.
- **I2:** Unreal 네이티브 배치가 DDC 작업 스레드의 `InheritedContext.cpp` 오류로 종료되어 달리기와 일부 출력 장면만 저장됐다. 일부 파일 존재를 전체 완료로 취급하지 않았다. 종료 전에 종속 장면 검사를 시작한 요청도 뒤따라 실패했다.
- **I3:** 수정 달리기의 120Hz FK 보간에서 지지 구간 발 높이가 기준에서 최대 약 4.618cm 벗어났다. 원본 키의 발 목표와 연속 접지는 구분한다. 게임 실시간 발 고정과 연속 메시 충돌은 검증하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1:** 달리기의 발 지지/회수 비율과 골반 위상을 수정해 원본 3·7프레임에 양발 공중 구간을 넣었다. 달리기 관련 전환 6개도 같은 시작 자세로 재작성했다. 현재 달리기 관련 7개는 `r02` 경로를 사용한다.
- **I2:** 저장 완료 여부를 검사하고, 부분 저장된 출력 장면 대신 새 장면 경로로 복구했다. 남은 동작과 정면/측면 장면을 순차 실행했다. 이후 렌더 완료를 확인한 뒤 편집 프로젝트에서 15개를 별도 프로세스로 다시 읽었다. 기존 원본 19개의 해시는 유지됐다.

- **출력:** 선택된 3시점 228프레임은 분리 전 참조와 실루엣 알파·에너지 알파가 일치하고 잘림이 없다. 관련 자동 검사 9개를 통과했다. 검사 시 설치된 Pillow를 먼저 불러와, 묶음 런타임 바이너리와 현재 Python 버전의 충돌을 피했다. 게임 코드나 라이브러리를 변경하지 않았다.
