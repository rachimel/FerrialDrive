# 근거리 적의 깊이·재질 인스턴스 일괄 전송

**기록 ID** `FDLOG-20261121-near-enemy-instance-upload`

2026-11-21 KST 구현·계측 기록. 이전 비교는 [화면 깊이 선행 패스 시험](2026-11-21-near-enemy-screen-depth.md)에 있다.

## 1. 사용자가 제안한 것

- **U1** 여러 그룹에 분산된 업로드를 깊이 선행 패스 전에 묶어 전송한다.
- **U2** 깊이와 재질 패스에 중복된 키포즈 픽셀 보간 결과를 GPU에서 재사용할 수 있는지 질문했다.
- 정확한 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-instance-upload:U1-U2]]이다. 검색 단서는 `Pre-pass 전에 Batch로 upload`와 `키포즈 픽셀 보간도 한번만`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 근거리 적의 화면 사각형·시트 사각형·키 인덱스·보간율·화면 깊이를 모아 선행 패스 전에 한 번 전송했다. 깊이와 재질 패스는 같은 레코드를 읽는다.
- **U2** 보간 샘플 좌표를 GPU에서 기록해 재사용하는 방법은 가능성만 검토했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 세 개의 RGBA32F 텍셀을 인스턴스 레코드로 사용한다. 포즈를 공유하는 추가 배치는 화면 깊이만 기록하고 시트 슬롯에는 처음 배치만 그린다. `deferred_enemy_depth_uniforms`로 기존 uniform 전송을 재현한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U1** 사용자가 선행 패스 전 일괄 전송의 구현을 요청했다. **A1**의 버퍼 형식과 비교 옵션은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 같은 자세라도 깊이와 재질 셰이더는 각자 픽셀 보간을 수행한다. 인스턴스 전송을 합쳐도 이 GPU 계산과 기존 드로우 그룹은 남는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** Intel 통합 GPU에서 FHD·High·SMAA·검 자동 교전 초기 180기, 준비 120프레임과 측정 240프레임을 사용했다. 전체 드로우와 적 GPU 구간을 별도로 uniform→공유 버퍼→공유 버퍼→uniform 순서로 비교했다. 양쪽에 같은 로컬 Hermite 카탈로그를 사용했다.

| 지표 | 그룹별 uniform | 공유 버퍼 |
| --- | ---: | ---: |
| 평균 프레임 작업 시간 | 31.81~32.15 ms | 29.76~30.68 ms |
| 프레임 작업 p95 | 40.86~41.05 ms | 37.41~38.22 ms |
| 적 렌더 CPU 경과 평균 | 9.24~9.31 ms | 8.47~8.84 ms |
| 전체 GPU 드로우 평균 | 9.00~10.27 ms | 9.37~11.76 ms |
| 적 렌더 GPU 구간 평균 | 2.94~3.05 ms | 2.88~3.25 ms |
| 프로세스 커밋 피크 표본 | 1922.1~1923.6 MiB | 1905.2~1917.3 MiB |
| 인스턴스 전송 호출 / 바이트 | 66회 / 2,400바이트 | 1회 / 1,200바이트 |

- 전송 수치는 마지막 프레임의 근거리 25기 기준이다. 양쪽 모두 깊이 11회, 재질 11회, 조명 1회를 제출했다. 버퍼의 논리 할당은 1,200바이트다. CPU 경과 시간에는 GL 제출과 대기를 포함하며, 프로세스 커밋 피크 차이는 전체 프로세스의 변동을 포함한다.
- 적 GPU 구간의 두 회차는 각각 0.32 ms 증가와 0.17 ms 감소를 기록했다. 같은 프로세스의 추가 교대에서는 프레임 평균이 32.62→30.99 ms, 역순 비교 기준으로 31.07→31.78 ms였다. 일괄 전송의 프레임 시간 이득은 반복 조건에 따라 달랐다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1** 가림·반투명 합성·공유 포즈를 기존 uniform 경로와 OpenGL 캡처 픽셀 단위로 대조했다. 작업 트리와 커밋 스냅샷에서 실제 OpenGL 검사 13개를 확인했다. 수동 조작 검증은 수행하지 않았다.
- **U2 ↔ I1** 픽셀 보간을 한 번만 하려면 가림 패스가 키별 샘플 좌표를 기록하고 재질 패스가 읽을 수 있다. 보간 절약량과 중간 버퍼 저장·조회 비용을 이 비교에서는 계측하지 않았다.
