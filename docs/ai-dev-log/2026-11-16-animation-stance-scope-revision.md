## 5. 반영 후 발견한 문제

- **I2 — 조준 도달:** 머리 중앙으로 총을 옮기자 기존 몸통 방향에서 팔 도달 거리를 넘었다. 몸통·어깨로 분담하고 전환의 왼손은 후반에 합류하게 했다.
- **I3 — 발 접지:** 첫 스왑 후보의 중간 프레임에서 발바닥 경계 상자가 지면 아래로 최대 약 2.4cm 내려갔다. 실제 발끝 축과 120Hz 발 목표로 보정했다.
- **I4 — 출력 범위:** 측면·정면 장면에 템플릿의 2프레임 범위가 남았다. 완료 검사에서 누락을 발견하고 해당 출력을 채택하지 않았다. 클립별 전체 길이로 장면을 새로 만들었다.
- **I5 — 횡이동 다리 간섭:** U6 지적 뒤 원본 형상과 Unreal 평가 변환으로 실제 표면 교차를 확인했다. 발 위치 분리로 주요 프레임은 개선됐지만 중간에는 왼발이 반대 무릎 장갑에 닿았다. 공중 통과 호를 추가하고 급격한 통과 대신 넓은 시간 구간으로 완화했다.
