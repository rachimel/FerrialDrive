# 스틸 블루 UI·장면별 버튼 배색

- 작성일: 2026-11-03, 한국 시간
- 사용자는 이펙트용 보색과 구분되는 UI 바탕의 포인트색으로 스틸 블루 `#91AEBB`를 선택하고, 나머지 레이블·패널에도 적용하도록 요청했다.
- 패널 적용 범위를 확인하는 질문에 사용자는 우선 HUD 버튼은 Bezel·메뉴 버튼은 스틸 블루로 비교하도록 지정했다. 타이틀과 일시정지의 메뉴 버튼을 함께 적용한다.
- 일반 글자·제목·적 이름·HIT/DAMAGE 레이블·임시 기체 이름표와 패널 테두리·강조선을 스틸 블루로 맞췄다. 패널 바탕의 Bezel 근사색과 방사형 명암·알파는 유지한다.
- 버튼은 `hud_button*`·`menu_button*` 색 역할로 나눈다. 일반 상태는 각각 `#39444A`·`#91AEBB`, 호버/눌림 시안은 HUD `#48565E`/`#2D353B`, 메뉴 `#A6C0CC`/`#7898A8`다. 메뉴 버튼 위 글자·순번·표식은 읽기 쉬운 짙은 청회색 `#17242B`로 둔다. 비활성 알파·입력·버튼 배치는 유지한다.
- UI 포인트 `ui_accent`를 전투 상태 공용 `accent`와 분리해 HIT 숫자·HP·레이더·누적/이번 피해 숫자의 기존 색은 유지한다. 이펙트 전체 팔레트나 본편 색상값을 확정한 것은 아니다.
- PRE-PRD·현재 UI 명세·체크포인트·샘플 안내에 역할과 시안 값을 기록했다. 소스·설정 대조와 Git 변경 검사만 수행했고 자동 테스트·실행·화면 비교·성능 측정은 수행하지 않았다.
