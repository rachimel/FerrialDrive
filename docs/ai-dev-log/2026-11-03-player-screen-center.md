# 플레이어 화면 중앙 고정

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 플레이어는 항상 화면 가운데에 표시한다.
- 고정 좌표를 제거하고 창 크기에서 플레이어 중심을 계산한다. 1280×720에서는 (640, 360)이다.
- 플레이어 도형·이름에 HUD 전환의 수평 이동량을 적용하지 않는다. 플레이어의 이번 피해 숫자도 같은 중앙 기준을 사용하며 HUD와 함께 밀리지 않는다.
- 타겟의 위치·표시 규칙은 유지한다. 피해 표시 데이터에 소유자를 전달해 플레이어·타겟의 이동 기준을 구분한다.
- 사용자 직접 확인 방침에 따라 자동 검사·실행·렌더링·창 조작은 수행하지 않았다.
