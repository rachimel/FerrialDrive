## 3. AI가 제안한 것

- **A1:** 교환 사본의 무기 제어를 확장해 기존 41개 동작 전체를 진행한다. 기존 교환본의 무기가 허리에 고정돼 손 파지·전환을 표현할 수 없었기 때문이다. 원래 본을 바꾸지 않고 교환 사본의 `FD_Sword`·`FD_Gun`을 원래 무기 객체 키로 반환한다.
- **A2:** 자동 저장 파일을 백업·해시 확인한 뒤 복원 생략으로 저장된 작업을 재개한다. 재실행이 패키지 복원 창에서 대기했고 자동 승인 검토가 복구 데이터 유실 위험으로 두 번 거절했기 때문이다. 직접 승인 전 다른 경로로 생략하지 않았다.
- **구현상 판단:** 기존 3차 숫자 초안과 최신 검 대기 세 후보를 참고하고 현재 소스의 평가 값을 Unreal FK 월드 키로 작성한다. 긴 콤보·전환은 최대 12프레임으로 줄이되 장착 이벤트 표본을 유지한다. 구체적 재타이밍·외관은 사용자 승인값이 아니다.
- 시각·출처: 현재 AI의 범위 확인·백업 안내와 실제 실행. 정확한 발언 시각은 scope에 포함한다.

## 5. 반영 후 발견한 문제

- **I1:** 클립마다 같은 이름의 레벨을 새로 저장해 중복 이름 팝업이 발생했다. 두 번째 Sequence는 저장됐지만 호출이 반환되지 않았다.
- **I2:** 새 교환 Skeleton 저장이 누락돼 재시작 후 참조가 끊겼고 Animation Sequence 생성이 실패했다. 메시의 본 목록과 Skeleton 에셋 저장은 다른 확인 항목이다.
- **I3:** 다음 에디터 틱 전에 제어점 0개를 준비 완료로 간주하면 키 작성이 실패했다.
- **I4:** 빈 Animation Sequence의 기본 30fps에서 12fps로 바로 베이크할 때 호환 오류가 발생했다.
- **I5:** 원래 리그의 변환 드라이버가 베이크된 반환 키에 다시 적용됐다. 최초 최대 위치 오차는 약 0.0527 리그 단위였다.
- **I6:** 검 객체 XYZ Euler의 90도 부근에서 3개 클립에 최대 약 0.1044rad의 회전 오차가 남았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 클립 작성 전 현재 작업 맵을 확인하고 Sequence만 저장한다. 새 Actor에는 현재 레벨 저장을 사용한다. 화면 준비는 맵·폴더 전체를 저장하지 않는다. 결과 유실 뒤 파일·키 상태를 읽고 재개한다.
- I2: 기존 사본을 보존하고 `PlayerMech_Anim41Ready`를 새로 가져와 Skeleton까지 저장했다. 같은 73개 본의 새 사본으로 연결했고 Sequence 키 파일 해시가 유지됐다. Skeleton `.uasset`의 디스크 존재도 확인했다.
- I3: 읽기 전용 조회로 실제 제어점 초기화를 기다린다. 이미 키가 있는 Sequence는 재작성하지 않는다. 재시작 뒤 검 대기의 73개 제어점·7,668개 키를 다시 조회했다.
- I4: 빈 Animation Sequence를 공배수인 60fps를 거쳐 12fps로 초기화하고 출력 구간을 명시했다.
- I5: 반환 사본에서 키와 중복되는 리그 변환 드라이버를 mute했다. 리그 드라이버 정의·원본 파일·rest 본은 보존한다. 무기 객체의 기존 장착 동작은 반환 객체 키로 대체한다.
- I6: 반환 사본의 검·총 객체 루트는 Quaternion 키를 사용한다. 원래 69개 본의 회전 모드는 유지했다. 정상 본 키를 보존하고 객체 키만 고친 새 반환본을 만들었다.
- **자동 확인:** 41클립·405프레임·12fps·클립당 최대 12프레임. 반환 타임라인은 1~445의 구간 마커와 `.clips.json`으로 나뉜다. 저장·재로딩한 본 69개 + 무기 2개의 **28,755개 정수 프레임 위치·회전 표본**에서 최대 위치 오차 **5.1167e-6 리그 단위**, 회전 오차 **4.6163e-6rad**로 통과했다.
- **보존 확인:** 원본 SHA-256·기존 사용자 `RoughTorso` Sequence SHA-256이 시작 값과 일치했다. 반환본의 객체 목록·메시 형상·UV·웨이트·재질 슬롯·부모·rest 본·패킹 이미지 해시도 원본과 일치했다. 재질 노드 전체·모든 드라이버 활성 상태의 동등성을 주장하지 않는다.
- **백업:** `recovery_backup/`의 5개 파일·339,361바이트를 원래 자동 저장 파일과 SHA-256 비교했다. 복원 목록의 `RoughTorso`·교환 Skeleton 두 패키지가 백업에 있다.
- **도구 확인:** MCP 스킬 1개 실행 계약 lint 오류·경고 0개. 기본 도형 소품 샘플은 실제 Blender에서 메시 4개·본 5개의 교환 blend·FBX를 출력했다. 이 샘플의 독립 Unreal 수동 왕복은 미검증이다.
