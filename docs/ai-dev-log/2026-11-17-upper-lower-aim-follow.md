## 5. 반영 후 발견한 문제

- **I1 — 해석 오류:** AI가 최초에 즉시 회전과 45° 차이 유지로 설명했다. 사용자가 정정했으며 이 오류는 구현 전에 교정했다.

- **I3 — Unreal 실행 미완료:** 예전 렌더 프로젝트에 최신 메시가 없는 것을 확인하고 최신 에셋이 있는 편집 프로젝트로 바로잡았다. 해당 프로젝트에 Editor/Editor-Cmd로 실행을 요청했지만 새 동작 에셋·제작 보고·지정 실행 로그가 생성되지 않았다. 마지막 Editor-Cmd 실행의 종료 코드는 0이었다. 종료 코드만으로 성공으로 처리하지 않았다. 원인은 아직 미진단 — [[FDLOG_MISSING_CAUSE:FDLOG-20261117-upper-lower-aim-follow:I3]]. 검색 단서: 로컬 `upper_lower_aim_20261117/r02/`의 실행 확인 기록, `prepare_units.py`, 새 로그 없이 종료 코드 0.
- **I4 — 실시간 연결 조회:** 로컬 Gateway 연결 검사에서 소켓 접근 거부를 확인했다. 기존 프로젝트 MCP의 도구 목록 조회는 응답 없이 대기하여 해당 조회 프로세스만 중단했다. 이를 Unreal 어댑터가 설치되지 않았다는 근거로 삼지 않는다.
