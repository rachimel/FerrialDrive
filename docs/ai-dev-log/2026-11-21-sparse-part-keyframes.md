# PBR 파츠 키포즈와 실시간 합성

**기록 ID** `FDLOG-20261121-sparse-part-keyframes`

## 1. 사용자가 제안한 것

- **U1** 주요 키프레임만 아틀라스에 남기고 사이의 포즈를 60fps 표시 시각에 즉시 렌더링한다. 같은 중간 포즈를 쓰는 적은 합성 결과를 인스턴싱한다. 기존 플레이어의 24fps 표본 속도는 사용자가 정했던 값이다. 정확한 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-sparse-part-keyframes:U1]]이다. 같은 대화에서 `일단 아틀라스에는 주요 KeyFrame들만 보존해`와 `적 같은 경우에는`로 찾을 수 있다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 기존 PBR 캡처를 입력으로 플레이어와 적의 키포즈 아틀라스를 별도로 생성했다. Pico2D의 GPU 파츠 합성으로 중간 자세를 계산하고, 같은 적 자세는 근거리 합성 시트와 원거리 포즈 캐시에서 공유한다.

## 3. AI가 제안한 것

- **A1** 구현상 판단으로 기존 캡처의 본 자세 오차를 픽셀로 환산해 키를 선택했다. 기본 오차 기준은 1.5픽셀, 후보 키 간격은 원래 표본 최대 4칸이다. 유지한 키 사이의 정·역방향 벡터를 각각 합성한다.
- **A2** 원거리 적의 공유 포즈 위상을 초당 60단계로 맞췄다. 포구와 공격 구간은 원본 시간으로 계산하고 표시용 공유 키만 분리했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자는 작업을 계속 진행해 달라고 요청했다. 픽셀 기준과 간격 선택은 이번 구현에서 사용한 값이다.

## 5. 반영 후 발견한 문제

- **I1** 첫 고품질 GPU 대조에서 검 콤보 02의 0.28~0.30초 구간에 검과 팔 실루엣 차이가 보였다. 본 자세의 근사 오차만으로 키를 고르면 가동부의 화면 이동을 충분히 반영하지 못한다.
- **I2** 공유 위상을 처음 60단계로 연결했을 때 28기 교전의 피크 커밋이 1,950→2,777 MiB로 늘었다. 공유 대상이 하나인 자세도 원거리 텍스처로 만들었고 그림자에도 새 위상을 사용했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 키 사이를 GPU에서 합성하라는 사용자 요구에 따라 아틀라스 표본 시각과 프레임 표시 시각을 분리했다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1 ↔ A1** 방향별 파츠 양방향 벡터로 이동량을 검사해 한 구간에 누적 이동이 큰 포즈를 추가로 남겼다. 검 콤보 02는 13개 표본을 모두 보존했다. 대시 루프는 9개 중 3개를 저장한다.
- **I2 ↔ A2** 중복된 원거리 본체 자세만 캐시하며 나머지는 근거리와 같은 GPU 합성 시트에서 처리한다. 지면 그림자는 기존 표본 속도를 사용한다. 원거리 본체는 같은 결과가 네 기 이상 함께 그려질 때 OpenGL 인스턴싱으로 복사한다. 게임용 Python의 실제 창에서 적 6기를 한 번에 제출했고 개별 복사와 픽셀이 일치했다.

## 확인 상태

- 높음·보통·낮음 후보를 생성했다. 고품질에서 플레이어는 333→226개, 메카는 84→60개, 스파이더는 80→59개 키를 저장한다. 키 개수는 방향과 에셋을 공유하는 모션 이름을 중복 집계하지 않았다.
- 고품질 전체 텍스처 페이지의 논리 페이로드는 플레이어 815.0→698.2 MiB, 메카 201.6→158.6 MiB, 스파이더 129.7→97.4 MiB다. 전체 프로세스 RAM·VRAM 실측과 구분한다.
- 회귀 검사에서 가변 시각·포즈 종료·루프·허리 기준점과 기존 아틀라스 호환성을 확인했다. 고품질 GPU 대조는 60Hz 표본 6,240개와 저장한 키 1,852개를 읽었다. 검 콤보 02는 검사한 8방향의 실루엣이 기존과 일치했다. 다른 모션은 근사 오차가 남는다.
- 현지 Intel iGPU의 FHD·고품질·SMAA 28기 교전은 무제한 360프레임에서 기존 34.1 FPS / 피크 커밋 1,950 MiB, 최종 후보 28.4 FPS / 1,913 MiB였다. 2 GiB 프로필에서도 360프레임을 완료했다. 그 실행은 40.4 FPS / 피크 커밋 1,877 MiB였다. 보통 품질 이동 테스트의 표시 실측은 39.3 FPS다. 60 FPS를 충족한 장면으로 기록하지 않는다.
