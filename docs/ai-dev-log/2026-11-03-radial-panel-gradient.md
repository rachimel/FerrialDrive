# 패널 방사형 그라데이션·레이블 간격

- 작성일: 2026-11-03, 한국 시간
- 사용자 피드백: 기존 광택이 알루미늄 판처럼 보인다. 제공한 참고 이미지처럼 광택이 방사형으로 넓고 부드럽게 퍼지도록 변경한다.
- 기울어진 반사 띠·가로 브러시 결 계산을 제거했다. 패널 아래쪽 중심에서 가우시안 감쇠로 퍼지는 정적 그라데이션을 사용한다.
- 시안 값은 `contrast=0.28`, `highlight_center=[0.5,1.15]`, `highlight_radius=[1.25,1.3]`이다. 중심은 패널 경계 밖도 지정할 수 있는 정규화 좌표이며 반경은 폭·높이에 대한 양수 비율이다. `grain_strength`는 제거한다.
- Bezel 근사색·기존 알파·테두리는 유지한다. 기존 최대 8개 텍스처 저장·한 번 복사·종료 시 해제와 선택 계측 경로를 유지한다. 매 프레임 픽셀 계산이나 광택 이동을 추가하지 않았다.
- 추가 요청으로 HIT·DAMAGE 숫자 아래 레이블 간격을 4→3px로 줄였다. HIT 숫자 76px·DAMAGE 숫자 60px·레이블 18px·추가 자간 5px와 오른쪽 정렬·두 카운터 사이 중앙 여백은 유지한다.
- 소스·설정·문서를 대조하고 Git 변경 검사를 수행했다. 자동 테스트·실행·렌더링·성능 측정은 수행하지 않았다. 참고 이미지와의 실제 화면 일치, 각 패널 크기에서의 그라데이션과 텍스트 읽기 쉬움은 사용자 확인 전이다.
