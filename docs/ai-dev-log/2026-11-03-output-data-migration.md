# 보존 데이터 이동과 제거 후보 조사

작성일: 2026-11-03, 한국 시간.

## 요청과 결정

- output에 필수 데이터를 남기지 않는다. 현행 원본·작업 파일을 먼저 옮긴다.
- 필요 없어 보이는 파일은 근거·용량·중복 여부를 정리하고, 제거 여부는 사용자가 결정한다.

## 반영

- 표정 스튜디오의 리깅 원본·생성 입력·저장 프로젝트·레이아웃·내보내기 보관본 43개를 `data/portrait_editor/`로 이동했다.
- 이동 목록과 해시, 수정 전 프로젝트를 `data/migrations/2026-11-03-output-assets/`에 보존했다. 저장 프로젝트의 리깅 참조만 새 위치로 바꿨다.
- 도구 기본 경로와 Blender 생성 경로를 바꿨다. 실행용 캐시·검증 결과는 output에 유지한다.
- 사용자가 재배치한 문서 폴더를 유지하고 내부 링크를 수정했다. 재배치된 공개 PPT 두 개의 Git 제외 예외도 맞췄다.
- [제거 후보](../tool-usage/cleanup_candidates.md)를 작성했다. 후보 파일은 삭제하지 않았다.

## 확인과 한계

- 이동 직후 파일 43개의 해시가 일치했고, 프로젝트의 나머지 편집 값도 보존됐다.
- 기존 자동 검사 14개가 통과했다. 기본 원본으로 CLI MOC3 내보내기도 성공했다.
- 다른 작업 폴더에서 프로젝트 로드, 리깅·모델 텍스처 참조, 문서 23개의 내부 링크를 확인했다. 재배치된 공개 PPT 두 개도 이전 커밋과 바이트가 같았다.
- 실제 창에서의 조작·표시, Blender 재생성과 성능은 이번에 확인하지 않았다.
- 과거 실험·발표 작업본은 사용자 판단 대기다. output 전체 삭제 완료나 공개 샘플 제공 완료로 간주하지 않는다.

현재 저장 기준은 [저장 경로 안내](../tool-usage/storage_layout.md)를 따른다. Git 업로드는 별도 실행 여부로 구분한다.
