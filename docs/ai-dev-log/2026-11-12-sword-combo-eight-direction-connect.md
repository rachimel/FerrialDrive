## 1. 사용자가 제안한 것

- **U1:** 중앙 찌르기·낮은 하체/허리·반대 팔 연동·슬라이딩·후방 베기를 반영한 후보를 게임의 8방향 출력에 연결하도록 요청했다. 출처는 현재 대화이며 정확한 발언 시각은 위 누락 항목을 따른다.
- 연결 대상은 [이전 후보 검토](2026-11-12-sword-combo-thrust-slide-rear.md)의 `thrust_slide_rear_20261112_v02`다. 이 요청은 출력·게임 연결의 승인으로 기록하며 최종 모션 품질 승인으로 확대하지 않는다.

## 2. AI가 제안한 것

- **A1, 구현상 판단:** 검토한 3방향 78프레임을 재사용하고 나머지 5방향 130프레임을 기존 Unreal 카메라·조명·파츠·Energy Mask 경로로 출력한다. 새 묶음을 별도 `data/` 경로에 두고 현재 UI 설정과 궤적 경로를 연결한다.
- **A2, 구현상 판단:** 반복 엔진 시작을 줄이기 위해 기존 MRQ 큐와 완료 검증을 재사용하는 `requests` 일괄 호출을 공통 렌더 모듈에 추가한다. 장면 제작은 기존 `scenes` 일괄 경로를 사용한다. 새 모델 전용 Python 파일은 추가하지 않는다.
- A1~A2의 이유는 기존 검토 결과와 출력 규약을 보존하면서 필요한 방향을 완성하고 반복 실행 비용을 줄이는 것이다. 세부 구현 방식에 대한 별도 사용자 제안·수용으로 기록하지 않는다. 실행 시각·입력·결과는 `automate/workspace/sword_combo_follow_8dir_20261112/`의 보고를 따른다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 UI v2의 새 8방향 묶음 연결에 반영했다. `samples/ui_unit_test_v2/ui_config.json`의 `combo_source`는 `data/catalog/prerender/player_mech_combo_follow_8dir/mech.json`을 사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U1의 게임 연결 요청은 명시적으로 확인했다. A1~A2의 세부 호출 방식이나 새 8방향 모션의 최종 품질에 대한 별도 수용은 확인하지 않았다.

## 5. 반영 후 발견한 문제

- **I1, 기존 연결 공백:** Unreal 수정 후보는 3방향 검토물까지 있었고 UI는 이전 Timing 출력에 연결돼 있었다. 새로운 사용자 요구의 연결 대상이며 이번 작업이 새로 만든 게임 결함은 아니다.
- **I2, 검증 환경:** 기본 `game2d` 환경에는 Pillow가 없어 첫 가져오기 검사 모듈의 import가 실패했다. 보존된 `automate/runtime/image/python/`을 검사 실행 경로에 추가한 뒤 관련 26개 검사를 통과했다. 게임 코드나 시스템 패키지를 수정하지 않았다.
- 확인한 출력·패킹·자동 입력·창 캡처에서 새로운 결함은 발견하지 않았다. 직접 마우스 조작, 연속 메시 간섭·실제 GPU 프레임 시간은 이번 검증 범위가 아니다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1로 새 후보를 검토용에만 두지 않고 게임 출력에 연결하는 범위를 확정했다. 5방향을 추가하고 새 파츠 묶음과 궤적을 현재 게임 연결 경로로 지정했다.
- 실행 중 프로그램은 기존 에셋을 메모리에 유지한다. 새 경로를 읽으려면 프로그램을 다시 열어야 하며 F5는 연계/샘플 상태 초기화다.

## 7. AI 해결 제안과 실제 해결 과정

- I1 ↔ A1: 새 묶음은 8파츠·파츠별 Energy Mask·32클립·208프레임이다. 원본과 파츠 재합성의 실루엣/마스크 알파 차이는 0이고, 원본 및 고정 표시 크기의 잘림은 0건이다. 패킹한 3,328개 색상/마스크 프레임을 원본 crop과 RGBA 전 채널로 대조해 모두 일치했다.
- I1 ↔ A2: 기존 출력·중복 목적지·output 밖 경로 거부를 확인했다. 3·4타 두 클립을 실제 일괄 렌더로 검증한 뒤 나머지 출력을 완료했다. 개별 결과와 일괄 완료 보고를 보존한다.
- `PicoAssetResource`로 새 실제 시트를 로드하고 SDL dummy에서 `SDL_PushEvent`로 좌클릭을 전달했다. 8방향 32타의 방향 고정·입력 1개 예약·연결 자세 대기·Idle 복귀를 확인했다. 실제 OpenGL 창에서도 3타 3프레임을 그려 캡처를 직접 열어 확인했다. 자동 입력과 직접 마우스 조작을 구분한다.
- 새 궤적은 `data/animations/player_mech/basic_combo_follow_20261112/blade_trajectory.json`의 120Hz·261표본이다. 사용 중인 네 동작·8카메라와 일치하며 확정 게임 타격 창을 추가하지 않았다.
- `current_animation.json`의 활성 콤보·출력/검토·궤적·장면 경로를 갱신했다. 원래 편집용 동작 에셋의 보존 해시를 확인했고 이전 출력과 궤적은 보존했다. 커밋·업로드는 수행하지 않았다.
