# UI v2 정사각형 록온·교체 연출·가이드 톤

- **기록 ID: ui-v2-lock-on-motion**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 정확한 개별 발언 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-lock-on-motion:scope]] 검색 단서: `flutter dart의 elasticOut`, `정사각형 기준`, `텍스트 렌더전에`, `반대 강조선 좌표`, `0.25초`.

## 1. 사용자가 제안한 것

- **U1**: 가이드의 조작키는 밝게, 설명은 조금 반투명하게 표시한다.
- **U2**: 록온 획득 시 45° 회전·확대, 회전은 elasticOut·확대는 easeInOutCubicEmphasized를 사용한다. 등장 뒤 캐럿이 지나가며 글자를 표시한다. 퇴장은 글자를 숨긴 뒤 45° 추가 회전·확대·페이드한다. R로 신구 표시를 각각 등장/퇴장시키며 등장 중 취소는 현재 구간을 역재생한다.
- **U3**: 처음에는 반대 강조선 두 개의 다음 변 중점 이동·정지 0.5초를 제시했다. 후속으로 **외곽을 따라 서로의 자리로 이동·정지 0.25초**로 변경했다. 최신 지시를 적용한다.
- **U4**: 기본형은 기존 다이아몬드가 아닌 정사각형이다. 테두리가 이미 등장 완료됐다면 글자 표시 전/도중에 교체해도 정상 퇴장한다.

## 2. AI가 제안한 것

- **A1**: 등장 0.4초·캐럿 0.2초·퇴장 0.25초·강조선 이동 0.4초를 질문으로 제시했다.
- 구현상 판단으로 가이드 키 `#F0FCFF`·설명 불투명도 0.78, 시작 0.25배·퇴장 1.5배를 사용했다. 캐럿은 왼쪽에서 오른쪽으로 이동한다. 세부 외관의 사용자 승인을 추정하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U4를 반영했다. 최종 기준은 정사각형 0°→마름모 45°→정사각형 90°다. 강조선 두 개는 시계 방향으로 외곽을 따라 자리를 교환하고 도착 후 0.25초 정지한다.
- 역재생 판정은 테두리 등장 0.4초까지만 적용하며, 글자 표시 여부로 정상 퇴장을 지연하지 않는다. 획득 규칙·표시 상태·도형 출력은 분리한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자가 A1 시간을 시험하는 데 명시 동의했다. 회전 0→45→90°와 처음 제시한 중점 이동도 답변했으나, 경로는 U3 후속 지시로 교체했다. 질문에 답한 정사각형 기본형과 글자 전 퇴장 정정은 최신 기준이다.

## 5. 반영 후 발견한 문제

- **I1**: 실제 렌더에서 캐럿이 공통 선 함수의 지원하지 않는 두께 인자를 사용해 실패했다. 자동 시간/곡선 검사만으로는 이 오류를 확인하지 못했다.
- 기본 도형과 역재생 판정·경로 변경은 사용자 후속 정정이며 I1과 구분한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U4에 따라 정사각형과 테두리 완료 기준을 적용했다. U3의 후속에 따라 강조선 목표를 반대 강조선 좌표로 바꾸고 정지를 0.25초로 줄였다.

## 7. AI 해결 제안과 실제 해결 과정

- I1은 두께를 지원하는 기존 stroke 경로로 변경하고 실제 SDL 렌더러를 사용하는 캐럿 검사로 보완했다. 시간 상태는 `lock_on.py`, 도형·글자 클리핑은 뷰, 샘플 R 연결은 독립 실행부에서 담당한다.
- UI **111개**·획득 **7개**, 총 **118개 통과**. 최종 설정으로 60fps 시간 간격 **300프레임**을 렌더하고 초기 획득·정상 퇴장·진행 중 역재생·글자 표시 중 정상 퇴장·강조선 교환을 확인했다. 출력은 `output/ui_unit_test_v2/lock_on_motion/`에 둔다.
- Flutter 공식 [elasticOut](https://api.flutter.dev/flutter/animation/ElasticOutCurve-class.html)·[emphasized](https://api.flutter.dev/flutter/animation/Curves/easeInOutCubicEmphasized-constant.html)·[easeInOut](https://api.flutter.dev/flutter/animation/Curves/easeInOut-constant.html)의 수학적 정의를 사용한다. 실제 창 조작·GPU 성능·최종 외관 승인·업로드는 미확인/미수행이다.
