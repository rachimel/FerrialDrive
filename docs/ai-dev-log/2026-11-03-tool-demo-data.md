# 툴 시연 데이터 요구

- 작성일: 2026-11-03, 한국 시간
- 요청: 툴 시연을 위해 간단한 테스트 데이터를 게임과 독립적으로 제공한다.

## 결정과 범위

- 각 툴에 게임 에셋·세이브·실행 상태 없이 사용할 수 있는 최소 샘플을 제공한다.
- 기본 도형·직접 작성한 수치 데이터 등 공개 가능한 샘플을 사용한다. AI 생성 에셋의 공개 제외 원칙은 유지한다.
- 샘플과 참조 파일은 `samples/<tool_name>/`에 두고 실행 환경·조작 방법·기대 결과를 안내한다.
- 실제 툴의 기능 경로를 사용하고 원본 샘플과 작업 결과를 분리한다.

## 현재 상태

- [툴 시연용 테스트 데이터 기준](../tool-usage/tool_demo_data.md), 작업 지침과 문서 목록에 요구사항을 기록했다.
- 현재 툴의 기존 로컬 데이터 의존성을 확인했다. 이번 변경은 문서 정리이며 **샘플 제작·도구 연결·독립 시연은 아직 미구현·미검증**이다.
- 현행 도구, 게임 에셋과 기존 로컬 데이터를 이동·삭제·교체하지 않았다.
