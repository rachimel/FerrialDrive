# 콤보·데미지 오른쪽 정렬과 좁은 행 간격

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 콤보와 데미지를 오른쪽 정렬하고, 콤보 바로 아래에 데미지를 약간의 간격으로 배치한다.
- 숫자+라벨 전체 폭을 측정해 공통 오른쪽 끝에 맞췄다. 자릿수가 늘면 왼쪽으로 확장하며 COMBO와 DAMAGE의 오른쪽 끝은 유지한다.
- `layout.counter_stack`으로 오른쪽 여백 32px, 콤보 시작 y=366, 행 간격 8px를 분리했다. 데미지 y는 실제 콤보 표시 높이 아래에서 자동 계산한다. 기존 개별 `combo_value`·`damage_value` 위치 설정을 이 묶음 설정으로 대체했다.
- 카운터의 변경 자리 밀기·이전 숫자 페이드·위쪽 방향성 블러는 유지한다.
- 변경 코드를 읽고 설정·명세를 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·프로그램 실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 재시작 후 두 줄의 오른쪽 끝, 좁은 행 간격과 자릿수 변경 중 정렬을 확인한다.
