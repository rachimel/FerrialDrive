# UI v2 히트·데미지 카운터 전용 점멸

- **기록 ID: ui-v2-counters-only-blink**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-counters-only-blink:scope]] 검색 단서: `데미지 카운터랑 히트 카운터만`, `투명도 80%`, `그러면 0.06초`.

## 1. 사용자가 제안한 것

- **U1**: 점멸을 데미지·히트 카운터에만 적용하고 최소 불투명도 80%, 보간 0.08초를 요청했다.
- **U2**: 현재 주기와 보간 시간의 제약 설명 후 보간 시간을 0.06초로 정정했다.

## 2. 사용자 제안 중 AI가 수용한 것

- 최신 U2를 반영해 0.12초 주기·전환당 0.06초, 80~100% 왕복을 적용했다. 두 카운터의 숫자와 레이블은 같은 위상을 유지한다.
- MAP·HP 글자·무기/잔탄·COUNTER 메시지·개별 피해 숫자에서 점멸 연결을 제거했다. 카운터 받침판과 다른 HUD 효과는 유지한다.

## 3. AI가 제안한 것

- **A1**: 0.12초 주기에 편도 보간 0.08초를 각각 넣을 수 없음을 설명하고 0.16초 주기 또는 왕복 합계 0.08초를 질문했다. 사용자는 별도로 0.06초를 선택했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1의 두 후보를 그대로 수용한 것은 아니다. 사용자의 U2를 최신 결정으로 반영했다. 시간 비율상 유지 구간 없이 연속 보간한다.

## 5. 반영 후 발견한 문제

- 최초 요청의 편도 0.08초는 반주기 0.06초보다 길어 기존 주기와 양립하지 않았다. U2로 해결했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2로 편도 보간을 0.06초로 지정해 주기 0.12초를 유지했다. 적용 범위는 U1의 두 카운터로 한정했다.

## 7. AI 해결 제안과 실제 해결 과정

- UI 자동 검사 **128개 통과**. 80% 하한·중간값·경계 연속성과 전체 HUD 렌더 경로에서 두 카운터만 점멸을 호출하는 회귀 검사를 포함한다.
- 실제 SDL **50fps·60프레임**에서 패널 탐색/실제 렌더 각각 두 카운터만 점멸을 호출함을 확인했다. 개별 피해 숫자도 표시했으며 별도 점멸은 추가되지 않았다.
- 공통 색상표 GIF의 MAP 글자와 타겟 HP 영역은 일정하고 총 재생 시간은 1,200ms다. 카운터 비교 이미지를 직접 열어 검토했다. 출력은 `output/ui_unit_test_v2/counters_only_blink/`다.
- 실제 창 조작·사용자 최종 외관 승인·업로드는 미수행이다.
