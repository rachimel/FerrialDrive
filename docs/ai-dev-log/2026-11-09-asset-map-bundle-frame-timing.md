# Asset Tool 맵 번들과 프레임 유지 시간

- **기록 ID:** `2026-11-09-asset-map-bundle-frame-timing`
- 대화 범위: 2026-11-09 현재 대화. 개별 발언의 정확한 시각은 제공되지 않음 — [[FDLOG_MISSING_TIME:2026-11-09-asset-map-bundle-frame-timing:scope]]. 검색 단서: `bundle에 type`, `각 프레임을 유지하는 시간`, `맵 export import 기능도 구현해주고`.
- 기록 시각: 2026-11-09 15:18:19 KST. clock 도구의 UTC를 KST로 변환한 현재 기록 시각이며 과거 발언 시각이 아니다.
- 상태: 구현·자동 검사·화면 없는 렌더 확인. 실제 창 조작·게임 이동 연결·사용자 사용감 승인 미수행.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 맵도 번들로 export/import하고 manifest의 타입으로 구분한다. 근거: `bundle에 type 같은거 넣으면 되겠지`, `맵 export import 기능도 구현해주고`.
- **사용자 제안 2 (U2):** 배경·바닥·합성 결과·이동 가능 구역을 도구에서 확인한다. 근거: `배경과, 땅, 배경 바닥 합성 결과, 이동 가능 구력`.
- **사용자 제안 3 (U3):** FPS 대신 각 프레임의 유지 시간을 ms로 지정한다. 근거: `각 프레임을 유지하는 시간`, `ms로 일단 하자`.
- 의도: U1/U2는 맵 요소를 함께 다루고 화면으로 확인하는 기능, U3는 프레임마다 유지 시간을 지정하는 기능이다. 별도의 장기 동기나 우선순위는 추정하지 않는다. 시각·출처는 위 대화 범위 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U1~U3를 수용하여 맵 공통 로더·새 폴더 내보내기·재불러오기·GUI 미리보기와 일반 스프라이트 조립의 `duration_ms` 편집을 구현했다.
- 재사용 모듈은 게임 코드에서 읽을 수 있지만 실제 게임 이동·충돌 연결까지 완료한 것은 아니다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 모든 레이어·이동 영역에 같은 원점과 배율을 사용한다. 이유: 이미지와 실제 이동 구역이 어긋나는 문제를 도구에서 확인하기 위함. 근거: 현재 대화의 동일 좌표 기준 설명. 정확한 발언 시각은 scope 항목 참조.
- **AI 제안 2 (A2):** `duration_ms` 필드로 단위를 명시한다. 이유: 프레임 유지 시간 단위 혼동 방지. 근거: `단위는 밀리초(duration_ms)`라는 제안. 정확한 발언 시각은 scope 항목 참조.
- **구현상 판단:** 맵 v1은 같은 크기의 배경·바닥 이미지와 bottom-left 픽셀 다각형을 사용한다. 합성 PNG를 함께 출력하고 원본 이미지는 보존한다. 다각형은 합집합, 빈 목록은 이동 영역 없음이다. 사전 사용자 확정으로 간주하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1: 사용자가 `ㅇㅇ 그렇게 할 수 있어야하고`로 같은 미리보기 방향을 수용했다. 세부 파일 형식과 다각형 알고리즘 승인으로 확대하지 않는다.
- A2: 사용자가 `ms로 일단 하자`로 ms 단위를 잠정 채택했다. 도구 사용감과 완성 결과의 승인은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

- **I1:** AI의 구현 검토에서 투명한 배경 위에 SDL surface blit을 중첩하면 저장한 PNG의 색상이 중복 감쇠할 위험을 확인했다. RGB와 알파를 함께 계산하는 합성으로 보완했다.
- **I2:** 최초 자동 검사는 임시 폴더 접근 제한으로 실행되지 않았다. 제품 기능 오류로 분류하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U3의 `개별 재생 시간`을 AI가 클립 전체 길이로 이해했으나 사용자가 `각 프레임을 유지하는 시간`으로 정정했다. 최종 구현은 프레임마다 `duration_ms`를 저장하고 전체 길이는 합산한다. 사용자 정정과 AI의 실제 구현을 구분한다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: straight-alpha 합성으로 수정하고 완전 투명·반투명·불투명 픽셀을 검사했다. 맵 저장 후 이동·재불러오기, 원본 보존과 출력 덮어쓰기 거절, 좌표 일치, 가변 프레임 시간 경계와 순서/복제 정합을 확인했다.
- I2: 필요한 실행 권한으로 같은 검사를 다시 실행했다.
- 자동 검사: 관련 10개 검사 모듈 **121개 통과**. 실제 Blender 렌더와 실제 창 조작은 수행하지 않았다.
- 화면 없는 렌더: 맵 레이어 화면·맵 패널·애니메이션 시간 편집 패널의 PNG를 생성해 배치를 확인했다. 산출물은 `output/asset_loader/map_timing_review/`에 있으며 재생성 가능한 로컬 결과다.
- 남은 범위: 맵 이미지 크기는 서로 같아야 한다. 장애물·스폰 편집, Blender 맵 렌더, 게임의 실제 이동 연결은 미구현이다. 3D 렌더/메카 제작의 기존 FPS 설정은 유지하며 프레임 시간 편집은 일반 이미지·시트·본체/그림자 조립에서 제공한다.
- 커밋·업로드 상태는 최종 응답과 Git 기록을 기준으로 확인한다. 이 기록 자체를 업로드 완료의 근거로 사용하지 않는다.
