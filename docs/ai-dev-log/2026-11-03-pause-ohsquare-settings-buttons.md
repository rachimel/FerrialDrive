# 일시정지 제목 Ohsquare·설정 버튼

- 작성일: 2026-11-03, 한국 시간
- 사용자 확인: 타이틀과 일시정지 모두 설정 버튼을 둔다. 일시정지 제목은 Cafe24 Ohsquare 일반형을 받아 적용한다.
- 로컬에는 Ohsquare Air만 있었다. 공식 목록에서 일반형과 Air를 확인하고 공식 CDN의 Cafe24Ohsquare-v2.0.zip을 받았다. 일반형 OTF와 동봉 License-Ohsquare.pdf를 각각 data/fonts·docs/licenses에 두고 원본 ZIP은 output/font-downloads에 보관한다. 기존 Git 제외 규칙을 유지한다.
- 일시정지 제목 전용 pause_heading 역할에 일반형 26px를 연결했다. 타이틀·나머지 메뉴 글꼴은 Air를 유지한다. 일반형과 Air는 별도 글꼴이며 Bold라는 별도 파일을 추가한 것은 아니다.
- 타이틀은 전투 HUD 보기·설정·테스트 종료 순으로 배치한다. 일시정지는 계속·설정·타이틀로·테스트 종료 순이다. 네 버튼이 들어가도록 패널을 400×388px로 늘리고 화면 중앙에 유지한다.
- 설정 항목·기능은 아직 정하지 않았다. 이번에는 설정 버튼을 비활성으로 배치한다고 설명했으며 JSON의 enabled=false를 읽도록 연결했다. 비활성 클릭은 소비하고 설정 동작은 실행하지 않는다. 설정 화면이나 임의의 옵션은 추가하지 않았다.
- 공식 ZIP의 파일 목록·추출된 폰트/라이선스 존재와 소스·설정을 읽어 확인했다. 자동 검사·프로그램 실행·렌더링·조작은 수행하지 않았다. 제목 굵기·버튼 배치·비활성 입력은 사용자 확인 대기다.
