# 근거리 적 키포즈 FP16 좌표 비교

**기록 ID** `FDLOG-20261121-near-enemy-keypose-fp16`

2026-11-21 KST 구현·계측 기록. 비교 경로는 [FP32 좌표 재사용 시험](2026-11-21-near-enemy-keypose-sample-cache.md)의 두 모드와 FP16 좌표 재사용이다.

## 1. 사용자가 제안한 것

- **U1** 양쪽 키포즈 샘플 좌표를 FP16으로 저장하고, 같은 적 180기 조건에서 기존 두 번 보간 및 FP32 재사용과 GPU 시간·프레임·메모리·픽셀 오차를 비교한다.
- 정확한 요청 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-keypose-fp16:U1]]이다. 검색 단서는 `양쪽 키 좌표를 FP16으로 저장하면`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `deferred_enemy_depth_cached_samples_fp16`을 추가했다. 두 번 보간과 FP32는 각각 `deferred_enemy_depth`, `deferred_enemy_depth_cached_samples`를 사용했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 두 키의 절대 텍셀 좌표를 `packHalf2x16`으로 각각 32비트에 압축해 파츠 픽셀당 8바이트를 GPU 버퍼에 기록한다. 깊이 판정과 재질 패스가 같은 양자화 좌표를 사용한다. 키 사이의 위치 계산과 PBR 산술은 기존 정밀도를 사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U1** FP16 저장 비교와 픽셀 오차 계측을 요청했다. 좌표 인코딩과 비교 캡처 방식은 실험 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** FP16 좌표 버퍼가 20.50→10.25 MiB로 감소했다. 적 렌더 GPU 구간은 FP32보다 회차별 0.65 ms와 0.77 ms 짧았다. 전체 프레임 타임은 FP32보다 두 회차 모두 길었고, 두 번 보간과의 차이는 회차에 따라 방향이 달랐다.
- **I2** FP16은 근거리 본체 RGB 평균 오차가 0.124/255였다. 채널 오차가 8을 넘은 픽셀 8개 중 최대는 59/255였다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** Intel 통합 GPU, FHD·High·SMAA·검 자동 교전, 초기 180기를 사용했다. 독립 실행마다 준비 120프레임, 측정 240프레임을 사용했다. 전체 드로우와 적 GPU 구간을 별도로 두 번 보간→FP32→FP16→FP16→FP32→두 번 보간 순서로 측정했다.

| 지표 | 두 번 보간 | FP32 캐시 | FP16 캐시 |
| --- | ---: | ---: | ---: |
| 평균 프레임 작업 시간 | 28.97~34.49 ms | 30.93~32.20 ms | 31.15~34.08 ms |
| 전체 GPU 드로우 평균 | 8.94~12.73 ms | 10.65~12.26 ms | 11.24~14.06 ms |
| 적 렌더 GPU 구간 평균 | 3.91~4.02 ms | 3.93~4.47 ms | 3.28~3.70 ms |
| 프로세스 커밋 피크 표본 | 1907~1917 MiB | 2029~2072 MiB | 1996~2010 MiB |
| Deferred·Box 논리 GPU 할당 | 18.63 MiB | 39.13 MiB | 28.88 MiB |
| 좌표 버퍼 | 0 MiB | 20.50 MiB | 10.25 MiB |

- 두 캐시 모드는 마지막 프레임의 근거리 타일 25개 전체에서 좌표를 재사용했다. 프레임 시간은 표시까지의 경과 시간이며, OpenGL GPU 구간은 제출 사이의 대기를 포함할 수 있다. 메모리는 버퍼 논리 할당과 전체 프로세스의 표본을 분리했다.
- 근거리 본체의 동일 상태 캡처 3장에 대해 배경을 제외한 합집합 132,050픽셀을 비교했다. 평균과 최대는 8비트 RGB 채널 단위다.

| 비교 | 평균 절대 채널 오차 | 변경 픽셀 | 채널 오차 > 1인 픽셀 | 채널 오차 > 8인 픽셀 | 최대 채널 오차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 두 번 보간 ↔ FP32 | 0.000061 | 18 | 0 | 0 | 1 |
| 두 번 보간 ↔ FP16 | 0.1241 | 26,847 | 2,257 | 8 | 59 |
| FP32 ↔ FP16 | 0.1241 | 26,845 | 2,257 | 8 | 59 |

## 7. AI 해결 제안과 실제 해결 과정

- **A1 ↔ I1** 세 경로를 벤치마크 모드로 유지했다.
