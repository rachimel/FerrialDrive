# 실제 메뉴·전투 HUD 테스트 구현

- 작성일: 2026-11-03, 한국 시간
- 요청: 공통 실행기에 연결할 실제 UI 테스트를 만든다.

## 사용자 확정

- 누적 데미지는 **플레이어가 적에게 입힌 피해 합계만 HUD 오른쪽**에 표시한다.
- 플레이어·적이 이번에 받은 피해는 **각 기체 근처에 빨간 숫자**로 표시한다. 이번 피해와 누적 피해 인디케이터를 분리한다.
- 메뉴↔HUD 전환 완료까지 **Esc·버튼 클릭을 소비**하고 완료 후 다시 받는다. 전환 시작 시 버튼 누름 상태도 초기화한다.

## 구현

- `tests/ui_test.py`: 메뉴·전투 HUD, 가짜 상태, Esc·버튼 동작과 `TestProgram` 어댑터. GUI 창에 드롭하거나 파일을 직접 실행한다. 공통 실행기는 수정하지 않았다.
- `samples/ui_unit_test/hud_sample.json`: 게임과 독립된 샘플 상태. `ui_config.json`에 레이아웃·문구·색·폰트 역할·피해량·애니메이션 값을 분리했다.
- `ferrial_drive/ui/state.py`: HP·타겟·콤보·누적 가한 피해·정규화 레이더 좌표의 표시 규격. 게임 엔티티·테스트 도구를 참조하지 않는다.
- `transition.py`: SmoothStep 화면 이동·투명도 값. 입력 정책은 테스트 쪽에서 적용한다.
- `damage.py`: 이번 피해 숫자의 별도 수명·상승·투명도. HP·누적 값은 바꾸지 않는다.
- `view.py`: 게이지·타겟 없음·레이더·원+십자 크로스헤어·플레이어/표적 도형·누적 가한 피해·이번 피해 숫자를 표시한다.
- 비활성 버튼도 클릭을 소비하되 동작은 실행하지 않는다. 표시와 판정에 같은 이동 좌표를 사용한다.
- 렌더러의 일부 폰트 로드 실패 시 이미 준비한 폰트를 정리하도록 보완했다.

## 샘플 동작

- 적 피해 +120, 플레이어 피해 +75, 타겟 유무, 표시 초기화 버튼을 둔다. 샘플 HP의 잔여량까지만 차감한다.
- 적에게 적용한 양만 오른쪽 합계에 더한다. 콤보는 유효한 적 피해 버튼 적용 횟수다. 실제 게임의 피해·콤보 판정이 아니다.
- 타겟을 없애면 해당 피해 버튼을 비활성화하고 이번 피해 숫자를 지운다. 복원하면 이전 타겟 HP를 사용한다.
- 최초 장면은 메뉴, 1280×720이다. 레이더는 플레이어 중심·고정 방향 도트이며 크로스헤어는 중앙 고정이다. 실제 게임의 좌표 변환과 연결 호환성은 후속 검증 대상이다.

## 확인 상태

사용자가 직접 테스트하는 방침을 유지해 **이번 변경 후 자동 검사·프로그램 실행·이미지 렌더링·실제 창 조작은 수행하지 않았다.** 사용자 확인 순서는 [샘플 안내](../../samples/ui_unit_test/README.md)에 기록했다. 과거 자동 검사 결과는 이번 구현의 검증 결과가 아니다.
