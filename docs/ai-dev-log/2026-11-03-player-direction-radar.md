# 플레이어 주변 적 방향 레이더

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 발드 시리즈 요소를 참고해 플레이어를 둘러싸며, 일정 거리 안의 적 방향을 가리키는 레이더로 변경한다.

## 구현

- 별도 레이더 패널·RADAR/N 글자·축·위치 점·작은 플레이어 마커를 제거했다.
- 화면 중앙 플레이어 위치를 공유하는 반경 110px의 옅은 링과 바깥 방향 화살표를 표시한다. HUD 전환의 이동량은 적용하지 않는다.
- 중앙 고정 크로스헤어도 같은 플레이어 중심을 사용하도록 좌표를 통일했다.
- 플레이어 상대 벡터의 길이로 감지 범위를 판정하고, 방향을 정규화해 링 둘레에 화살표를 배치한다. 거리와 관계없이 방향 표시는 링 위에 고정한다.
- 적만 표시한다. 아군·범위 밖·거리 0은 제외한다. 샘플에 범위 밖 적을 추가하고 첫 표적의 방향을 현재 배치와 맞췄다.
- `ui_config.json`의 `radar`에서 감지 거리·화면 반경·화살표 크기·링 투명도를 조절한다. 현재 감지 거리 1.0은 샘플 상대 좌표 단위이며 실제 게임 거리 결정이 아니다.

## 확인 상태

사용자가 직접 확인하는 방침에 따라 자동 검사·프로그램 실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기를 완전히 닫고 다시 열어 `tests/ui_test.py`를 드롭해 확인한다.
