# UI v2 대화창 중앙 펼침·TV 종료 시안

- **기록 ID: ui-v2-dialogue-popup**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-dialogue-popup:scope]] 검색 단서: `중앙에서 패널 테두리가 세로로`, `다 커지면`, `TV 꺼지는 효과`, `1차로 구현`, `열리는 시간 0.2초 닫힘 0.1초`.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: 통신 대화창 팝업에서 중앙을 기준으로 테두리를 세로 방향으로 목표 크기까지 키우고, 완전히 커진 다음 텍스트를 표시한다. 표시 순서는 직접 요구다.
- **사용자 제안 2 (U2)**: 닫기는 TV가 꺼지듯 빠르게 사라지는 효과로 1차 구현한다. TV 종료는 사용자가 제시한 연출 기준이며 최종 승인 요청이 아니다.
- **사용자 제안 3 (U3)**: 후속으로 열림 0.2초·닫힘 0.1초를 직접 지정했다. 정확한 시간을 우선 적용한다.

## 2. AI가 제안한 것

- **AI 제안 1 (A1)**: 전체 폭의 중앙 가로선→상하 펼침→글자, 닫기는 세로 압축→가로선 축소→중앙점 소멸로 해석해 먼저 보고했다. 사용자 요구를 구체화한 구현상 판단이다.
- **AI 제안 2 (A2)**: 펼침 0.28초·글자 표시 0.1초, 닫힘 0.08/0.06/0.04초를 시안 값으로 잡았다. 짧은 개폐를 확인할 수 있도록 D·최초 표시·F5에 연결한다.
- U3 이후 A2의 시간은 사용하지 않는다. 열림 전체 0.2초에 맞춰 완성 즉시 글자를 표시하고, 닫힘은 0.05/0.03/0.02초로 나눴다. 세부 배분은 AI 구현상 판단이다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U2를 구현했다. 면과 분리 테두리 10개 조각을 최종 형상의 중앙 기준으로 변형하고, 글자는 최종 위치에서 완성 이후에만 표시한다. 기존 헤더 `조작 가이드`는 유지한다.
- 입력·시간 상태는 `DialoguePanelMotion`, 표시값은 `DialoguePanelVisual`, 실제 도형과 텍스트 출력은 뷰에 나눴다. 닫힘이 끝나기 전에는 표시 데이터를 보존한다. 중간 D 입력은 현재 높이에서 반대 방향으로 전환한다.
- U3의 열림/닫힘 총시간을 반영했다. 60fps 누적 시간의 소수점 오차 때문에 완료가 한 프레임 늦어지지 않도록 완료 판정에 작은 허용 오차를 뒀다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1의 세부 단계와 종료 빛 두께에 대한 별도 명시 승인은 확인 전이다. A2의 기존 시간은 U3으로 교체했다. 사용자 지정 총시간을 AI 제안 수용으로 기록하지 않는다.

## 5. 반영 후 발견한 문제

- 이번 자동 검사와 실제 SDL 렌더에서는 추가 실패를 확인하지 않았다. 최종 사용감·GPU 성능은 검사 범위가 아니다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 순서대로 목표 높이에 도달하기 전에는 헤더와 본문을 숨긴다. U2에 따라 닫기 시작 시 글자를 숨기고 가로선과 중앙점으로 종료한다. U3의 지정대로 열림 0.2초·닫힘 0.1초를 적용했다. 별도 오류 수정 제안은 이번 요청에 해당하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- 현재 배율·clip을 사용하는 기존 패널 조회에도 같은 개폐 표시값을 공급해 밝은 띠 경로가 실제 펼쳐진 범위를 따르게 했다. 완전히 열린 형상은 기존 도형 그대로 사용한다. 전체 UI 장식과 함께 개폐 시간은 일시정지 중에도 갱신한다.
- UI 자동 **102개**·획득 **7개**, 총 **109개 통과**. 텍스트 지연·닫힘 단계·빠른 반전·큰 시간 간격·잘못된 시간·중앙 기준 형상·분리 조각·닫힘 뒤 데이터 제거를 검사했다. 지정 총시간의 60fps/단일 시간 갱신 일치도 검사했다.
- 열기/닫기 두 순환을 60fps 시간 간격의 **180프레임**으로 렌더했다. 단계별 이미지를 열어 중앙 펼침→문구→가로선 압축→축소 순서를 검토했다. 최종 닫힘 데이터 제거, 캐시 상한 유지(도형 32·그레인 8·네온 5·패턴 2)를 확인했다. GIF와 단계별 이미지는 `output/ui_unit_test_v2/dialogue_popup/`에 둔다.
- 실제 창 직접 조작·Runner 드롭·GPU 성능·사용자 최종 외관 승인·업로드는 미검증/미수행이다.
