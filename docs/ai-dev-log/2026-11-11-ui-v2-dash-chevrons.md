# UI v2 대시 아이콘·윈도우 하단 정렬

- **기록 ID: ui-v2-dash-chevrons**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-dash-chevrons:scope]] 검색 단서: `대시 아이콘`, `윈도우 하단`, `겹친 꺾쇠`, `현재 가로 위치 유지`.

## 1. 사용자가 제안한 것

- **U1**: 대시 아이콘을 다시 만들고 윈도우 하단에 정렬한다. 질문에 겹친 꺾쇠 형태와 현재 가로 위치 유지를 선택했다.

## 2. AI가 제안한 것

- **A1**: 모양 후보와 가로 위치를 질문하고, 아이콘/SPACE 묶음을 글자 영역 아래 기준 12px 여백으로 배치한다고 제시했다. 세부 크기·간격·두께는 구현상 판단이다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 반영했다. 오른쪽을 향한 꺾쇠 2개를 키 안내 위에 두고, 기존 논리 가로 위치 870px를 유지한다. HUD 배율을 역산해 창 하단 기준으로 배치한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자가 모양과 현재 가로 위치를 명시 선택했다. 12px 기준은 해당 위치 질문에 포함해 제시했다. 세부 외관의 최종 승인은 확인 전이다.

## 5. 반영 후 발견한 문제

- 이번 검사에서는 추가 실패를 확인하지 않았다. 글자 영역과 실제 잉크 경계는 폰트 여백 때문에 다르며 실제 잉크 아래 여백은 15px다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 오류 해결이 아닌 표현·정렬 변경 요청이다. 별도 오류 해결 제안은 해당하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- 대시 출력을 `dash_indicator`로 분리하고 기존 폴리곤 필터로 꺾쇠를 그린다. 배치·크기 값은 설정으로 분리한다. 준비/비활성 불투명도는 유지한다.
- 기존 자동 **122개 통과**. 실제 SDL에서 높이 720/900 각각 전투·대시 단독 준비/비활성, 총 **6상태**를 렌더하고 주요 이미지를 검토했다. 잉크 좌우 범위 825~873px·아래 여백 15px가 두 높이에서 같았다.
- 출력은 `output/ui_unit_test_v2/dash_chevrons/`다. 실제 창 조작·최종 외관 승인·업로드는 미확인/미수행이다.
