# 1,000기 독립 교전의 플레이어 HP 10만

**기록 ID** `FDLOG-20261122-combat-1000-player-hp`

2026-11-22 KST 작성. 현재 대화와 1,000기 Unit Test 실행을 근거로 기록한다.

## 1. 사용자가 제안한 것

- **U1** 1,000기 독립 교전에서 성능 시험에 사용한 플레이어 HP 10만을 적용한다.
- **U2** 기존 기본 HP의 1,000기 프리셋을 제거한다.
- **U3** 하드웨어 벤치마크의 1,000기 프리셋에도 같은 HP를 적용한다. 요청들의 정확한 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261122-combat-1000-player-hp:U1-U3]]로 남긴다. 검색 단서는 `HP 10만 모드 적용가능`, `기존 1000기 프리셋은 제거`, `hardware_benchmark`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1–U2** 일반·3배속 Combat Test의 1,000기 항목에 HP 10만을 연결했다. 시작과 F5 재시작 모두 기존 전투 체력으로 적용한다.
- **U3** 하드웨어 벤치마크의 `crowd_1000`을 교체했다. 24m 대형, 직접 조작, 자원 제한 없는 무음 실행 조건을 유지한다.

## 3. AI가 제안한 것

- **A1** 처음에는 기본 HP의 1,000기 항목과 HP 10만 항목을 나누는 안을 제시했다. 같은 대형을 선택하고 체력 조건을 구분하려는 목적이었다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **A1 / U2** 사용자는 기존 기본 HP의 1,000기 항목을 제거하라고 정정했다. 최종 Runner 목록은 1,000기 선택지 하나를 제공한다.

## 5. 반영 후 발견한 문제

- **I1** 기존 하드웨어 벤치마크에는 플레이어 HP를 지정하는 경로가 있었으나, 독립 교전 실행기에는 해당 옵션이 없었다. 기존 1,000기 프리셋은 일반 HP로 시작했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1–U2 / I1** 두 독립 Combat Test에 `1,000기 · 24m · HP 10만 · 무음`을 연결했다. 기존 `crowd_1000` ID를 유지하고 시작 인자를 교체했다.
- 실제 Runner 프로세스로 일반·3배속 1,000기를 각각 120프레임 무음 실행했다. 두 실행 모두 100,000으로 시작해 피해 입력 후 99,925로 감소했고, F5와 같은 재시작 경로에서 100,000으로 회복했다. 일반 버전의 화면에서 HUD의 100,000 표시를 확인했다.
- **U3** Runner의 벤치마크 실행 경로로 실제 FHD 창에서 1,000기 무음 90프레임을 측정했다. 보고서에 `player_health_initial.current`와 `maximum`이 각각 100,000으로 기록됐고, 90프레임 모두 교전 중 상태였다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1** 독립 교전 실행기에 `--player-hp`를 연결했다. `EncounterApplication`이 시작 시 HUD와 플레이어 체력의 공통 값을 지정하고, 재시작에 사용되는 HUD 프리셋에도 같은 값을 저장한다. 해당 인자를 전달한 프로세스에만 적용한다.
- Runner 프리셋 검사 10개와 적 교전 검사 25개를 통과했다. `--player-hp 0`은 인자 오류로 처리한다. 실행 결과와 화면은 `output/performance/combat_1000_hp/`에 있다.
- **U3** 벤치마크가 `EncounterApplication`에 시작 HP를 넘기도록 연결했다. 검증 원자료는 `output/performance/hardware_benchmark_hp_runner/report.json`에 있다.
