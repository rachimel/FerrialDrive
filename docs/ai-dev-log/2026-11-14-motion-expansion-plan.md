## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 총 인출, 총↔검 스왑, 멀티미사일 백웨폰 모델과 전개·수납, 카운터·가드·쓰러짐 모션의 구현 가능성을 질문했다. 모션을 강하게 과장하고 Head 파츠도 분리해야 한다고 덧붙였다.
  - 의도·근거: 필요한 전투 표현의 구현 가능성을 확인하며, 과장된 동작을 명시적으로 요구했다. 총 인출 표현은 발언에 중복되므로 별도 모션 두 종류로 확정하지 않는다.
  - 출처: 현재 대화 `구현 가능?`, `모션을 되게 과장되게`, `Head 파츠도 분리해야됨`. 시각은 scope 태그 참조.
- **사용자 제안 2 (U2):** 쓰러짐을 우선 몸·다리에 적용하고 팔을 교체하는 구조를 검토 요청했다.
  - 직접 밝힌 재사용 이유는 미확인 — [[FDLOG_MISSING_REASON:FDLOG-20261114-motion-expansion-plan:U2]]. 검색 단서: `몸과 다리에만 일단 적용시키고, 팔만 교체`.
  - 출처·시각: 현재 대화, scope 태그 참조. 공통 동작 재사용이 목적이라는 설명은 AI 해석이며 사용자 확정이 아니다.
- **사용자 제안 3 (U3):** 카운터가 백웨폰·서브암과 같은 슬롯 공간 하나를 차지하도록 하려는 안을 제시하고 평가를 요청했다.
  - 직접 밝힌 선택 이유는 미확인 — [[FDLOG_MISSING_REASON:FDLOG-20261114-motion-expansion-plan:U3]]. 검색 단서: `카운터는 백 웨폰과 같은 서브 암 슬롯 공간 하나`.
  - 출처·시각: 현재 대화, scope 태그 참조. 슬롯 수·물리 장비 형상·비용 수치는 확정하지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 제작 가능성 검토 범위와 과장된 동작 목표에 반영했다. Head 분리는 요구로 기록했으며 실제 분리는 미수행이다.
- U2: 검토 대상으로 수용했다. 공통 쓰러짐에 무기별 팔을 맞추는 방식은 가능하지만 지면 접촉·어깨 연결·가림을 확인해야 한다고 평가했다.
- U3: 선택형 스왑 액션이라는 현재 기획과 맞는 후보로 평가했다. 설계 확정이나 PRE-PRD 규칙 변경으로 취급하지 않는다.
- 수용 출처·시각: 현재 AI 답변, scope 태그 참조. 모두 상담 범위이며 구현 수용·완료와 구분한다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1, 독립 제안):** 몸·다리 공통 쓰러짐에 같은 몸통 움직임과 시간축을 따르는 무기별 팔 동작을 결합한다. Head는 독립 출력 파츠로 두되 목 기준점과 몸통 움직임을 따라야 한다.
  - 이유·근거: 큰 낙하·회전에서는 기존 직립 팔 이미지를 교체하는 것만으로 연결·접촉·가림을 보존하기 어렵다. 3D 조합과 전체 참조 렌더 대비 재합성 검토가 필요하다.
- **AI 제안 2 (A2, 독립 제안):** 카운터는 공격 장비와 슬롯을 경쟁시키되, 미장착 상태에서도 기본 방어·회피로 대응할 수 있게 한다. 일반 스왑 동작과 장착 시 카운터 판정·성공 보상을 구분한다.
  - 이유·근거: 공격 수단과 타이밍 방어의 선택을 만들 수 있다. 카운터가 생존 필수가 되면 슬롯 선택이 고정된다. 현재 카운터의 제압 보상까지 고려해야 한다.
- **AI 제안 3 (A3, 독립 제안):** 과장은 큰 실루엣·허리와 골반의 체중 이동·빠른 본동작·짧은 강조 정지·늦은 회수로 만든다. 준비 동작을 길게 늘리는 것만으로 과장을 대체하지 않는다.
  - 이유·근거: 실제 표시 크기에서 동작을 읽히게 하면서 조작 반응과 관절·장갑 연결을 유지하기 위한 방향이다.
- 제시 출처·시각: 현재 AI 답변과 검토 정리, scope 태그 참조. 사용자 확정 전 제안이다.
