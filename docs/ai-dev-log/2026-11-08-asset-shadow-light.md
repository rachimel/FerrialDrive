# 에셋 그림자 — 광원 높이·표시 강도

- 기록 ID: **FDLOG-20261108-asset-shadow-light**
- 실제 렌더·표시·기록 기준: **2026-11-08 22:00:57 KST**. 도구 확인 시각이며 원래 발언 시각과 구분한다.
- 출처: 현재 대화 “그림자 강도를 연하게 할 필요가 있구만 아니면 조명을 건들거나”, AI의 그림자 표시 50%/광원 높이 제안, “ㅇㅇ 그렇게 하자 좀 더 위로 올려 광원은”.
- 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261108-asset-shadow-light:scope]] 위 구절의 원문에서 확인한다. 아래 제안·수용·구현 판단에 공통 적용한다.
- 상태: **광원 프리셋·분리 그림자 표시 강도 구현·자동 66개·도형과 실제 기체 대표 프레임 렌더/표시 확인**. 실제 결과의 미술 승인은 사용자 확인 전이다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 그림자를 연하게 하거나 조명을 바꿀 필요가 있다고 판단하고, 후속 응답에서 광원을 더 위로 올리도록 지시했다.
  - 이유·근거: 직전 기체 미리보기의 길고 진한 그림자에 대한 시각적 피드백이다.

## 2. 사용자 제안 중 AI가 수용한 것

- 렌더용 기본 광원을 높여 그림자 길이를 줄이고, 분리 그림자의 표시 강도를 낮춘다. 원본 모델과 PNG를 덮어쓰지 않는다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 그림자 레이어 불투명도를 약 50%로 낮춘다. 길이는 광원 높이로 조절한다.
  - 이유·근거: 레이어의 진하기와 기하학적인 그림자 길이를 별도로 조절할 수 있다.
- **AI 제안 2 (A2), 구현 판단:** 도구 프리셋을 높이 7→12, 광량 700→1400으로 조정한다. 도구의 새 설정은 저장 장면의 기존 광원 대신 렌더 작업본에 적용한다.
  - 이유·근거: 기존 코드는 저장 장면에 조명이 있으면 설정을 무시했다. 거리가 늘어나는 만큼 광량을 보정해 과도한 어두워짐을 줄인다. 정확한 높이/광량은 비교용 구현값이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자는 A1과 광원 높이 조절 제안에 “그렇게 하자”로 답하고 광원을 위로 올리도록 명시했다. 높이 12·광량 1400과 결과 이미지에 대한 별도 미술 승인을 받은 것으로 기록하지 않는다.

## 5. 반영 후 발견한 문제

- **발견한 문제 1 (I1):** 원본 장면에 광원이 있으면 새 프리셋이 적용되지 않는 기존 경로가 있었다.
- **발견한 문제 2 (I2), 구현 위험 처리:** 공유 텍스처에 그림자 알파 설정을 남기면 본체까지 흐려질 수 있다. 그리는 동안만 적용하고 예외에서도 복원해야 한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1이 광원 높이 조절을 직접 지정했다. I1/I2의 구현 방식에 대한 별도 사용자 지시는 없었다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 새 도구 설정은 렌더 작업본의 기존 광원을 숨기고 높은 기준 광원을 만든다. `use_scene_lighting: true`인 기존/명시 설정은 장면 조명을 유지한다. 원본 .blend는 바꾸지 않는다.
- I2: 두 공통 Pico2D 표시 경로에서 그림자 기본 50%와 호출별 `shadow_opacity`를 제공한다. 공유/동일 텍스처의 알파를 그리기 후 복원하고 잘못된 범위는 거절한다.
- 자동 66개 통과: 프리셋·기존 기능·그림자/본체 분리·동일 텍스처 공유·실패 시 알파 복원·잘못된 불투명도를 포함한다.
- 기본 도형과 사용자가 최근 렌더한 실제 기체 각각 240px·대표 1프레임·8방향·2레이어를 실제 Blender로 출력해 총 32장 경계 검사를 통과했다. 원본 모델 해시 보존을 확인했다.
- 같은 기체의 정면 그림자 가로 범위를 촬영 배율로 정규화해 약 4.15→2.79, 약 33% 감소를 확인했다. 이는 해당 방향/대표 프레임 비교이며 모든 방향의 길이가 같은 비율로 줄었다는 뜻은 아니다. 새 결과를 Pico2D에서 50% 그림자로 합성·캡처해 확인했다.
- 실제 모델·렌더·미리보기는 로컬 출력에만 보관하고 소스/문서/검사만 커밋한다. 사용자 원본·기존 등록 에셋은 수정하지 않는다.
