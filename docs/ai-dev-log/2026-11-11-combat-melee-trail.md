## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 휘두르기 Trail은 전투에서 생성하고, Trail에 닿으면 Hit 판정을 한다. 우선 에너지 레벨과 연결하지 않는다.
  - 이유·판단 근거: 사용자가 표현의 책임과 명중 기준을 직접 지정했다.
  - 시각·출처: 현재 요청, 위 TIME 누락 참조.
- **사용자 제안 2 (U2):** 타격 구간이 끝나면 Trail과 판정을 함께 제거한다.
  - 판단 근거: AI의 유지 구간 질문에서 사용자가 이 항목을 명시 선택했다. 타격 이후 희미한 잔상에 판정을 남기는 안은 선택하지 않았다.
  - 시각·출처: 현재 질문 응답, 위 TIME 누락 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 전투가 칼날 궤적·폭을 가진 Trail 면을 생성하고, 표시와 명중이 그 면을 공유하도록 바꿨다. 에너지 상태를 읽거나 요구하지 않는다.
- U2: 타격 종료·대시 캔슬·전투 종료 시 Trail과 판정을 제거한다. 타격 구간 중 남은 Trail의 접촉은 유효하다.
- 수용 근거·시각: 현재 진행 보고·코드, 위 TIME 누락 참조.

## 3. AI가 제안한 것

- **AI 제안 1 (A1, 구현상 판단):** 칼날 양 끝의 이전/현재 위치를 폭 8 월드 단위의 다각형으로 연결한다. 최대 1/240초·회전 5도 간격으로 나누고, 대상의 프레임 사이 이동도 검사한다.
  - 이유·판단 근거: 빠른 휘두르기나 대시로 얇은 궤적을 건너뛰는 누락을 줄인다. 표시 FPS에 판정을 종속시키지 않는다.
  - 시각·출처: 현재 구현, 위 TIME 누락 참조. 폭·분할 간격은 임시 설정이다.
- **AI 제안 2 (A2, 구현상 판단):** 타격 구간 안에서 동일 대상은 한 번만 피해를 받고, 칼날/Trail은 벽에서 잘라낸다. 도형용 임시 4단 궤적을 전투 모듈에서 제공한다.
  - 이유·판단 근거: 다수의 Trail 조각이 같은 적에게 피해를 중복 적용하거나 표시와 사거리가 어긋나는 문제를 방지한다.
  - 시각·출처: 기존 공격별 명중 집합과 새 궤적 생성 코드, 위 TIME 누락 참조.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U2의 유지 구간 선택은 명시 수용이다. 임시 궤적·폭·색·분할 설정·최종 시각 품질은 사용자 승인 전이다. 기존 에너지 연출 기획을 영구 폐기한 것으로 해석하지 않는다.

## 5. 반영 후 발견한 문제

- **I1, 기존 구조:** 기존 명중은 전방 부채꼴·거리 검사였고 표시 잔상은 뷰에서 별도로 계산했다. 실제 Trail 접촉이 명중의 근거가 아니었다.
- **I2, 변경 중 검사:** 기존 사거리 검사는 타격 시작 첫 갱신에 정면 먼 적이 바로 맞는다고 기대했다. 새 궤적에서는 칼날이 그곳을 지나간 뒤 맞도록 기대 시점을 바꿨고, 이전 시점의 비명중도 확인했다.
- 빠른 대상이 타격 활성 전에 이미 지나간 경우까지 맞지 않도록 대상 이동 검사 시간을 활성 구간과 맞췄다. 자동 회귀 검사에 포함했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1 ↔ I1: 사용자가 전투 생성·Trail 접촉을 기준으로 지정했다. AI가 부채꼴 전체 판정을 제거하고 공유 Trail 면 기반으로 구현했다.
- U2: 타격 종료와 동시에 표현·판정을 제거하는 선택을 반영했다. 실제 창 조작은 이전 사용자 직접 테스트 방침을 유지했다.

## 7. AI 해결 제안과 실제 해결 과정

- 순수 전투 `geometry.py`·`trails.py`를 추가하고, 시뮬레이션에서 궤적을 생성한다. 기존 `simulation.Vec2` import 경로는 유지한다. 뷰는 전투의 칼날 위치·Trail 다각형을 투영할 뿐 별도 히트박스를 만들지 않는다.
- 벽 차단·타격 종료/캔슬 제거·한 공격 한 대상 1회·프레임 사이 휘두르기/대상 통과·활성 전 통과 비명중·이전 Trail 조각 접촉·30/60/144 FPS 일관성을 포함해 **규칙/Trail 41개·SDL dummy 연결 10개, 총 51개 통과**했다.
- 4단 공격의 중간 프레임을 SDL dummy로 출력하고 직접 열어 베기 면·찌르기 띠·무기·적중 표시를 확인했다. 재생성 이미지 경로는 `output/combat_prototype/trail_review/`다. 실제 창을 열거나 조작하지 않았다.
- 전투 명세·샘플·PRE-PRD·개발 기록을 갱신했다. 실제 사용감·전체 재생·최종 외관과 목표 성능은 검증하지 않았다. 정적 렌더·자동 검사를 사용자 최종 승인으로 확대하지 않는다.
