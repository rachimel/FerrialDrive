# 근거리 적 키포즈 FP16 이동량 비교

**기록 ID** `FDLOG-20261121-near-enemy-keypose-fp16-offsets`

2026-11-21 KST 구현·계측 기록. 비교 대상은 [FP16 절대 좌표 캐시](2026-11-21-near-enemy-keypose-fp16.md)이다.

## 1. 사용자가 제안한 것

- **U1** 원래 픽셀에 대한 양쪽 키 샘플의 이동량을 FP16으로 저장해 정밀도 차이를 확인한다. 동일한 180기에서 GPU·프레임 타임·메모리·픽셀 오차를 절대 좌표와 비교한다.
- 정확한 요청 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-keypose-fp16-offsets:U1]]이다. 검색 단서는 `원래 픽셀에서 얼마나 이동했는지만 FP16으로 저장`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `deferred_enemy_depth_cached_samples_fp16_offsets`을 추가했다. 대조는 기존 `deferred_enemy_depth_cached_samples_fp16`을 사용했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 공통 셰이더에서 두 키의 샘플 좌표에서 원래 파츠 텍셀 좌표를 빼고 GPU 버퍼에 FP16으로 패킹한다. 깊이와 재질 패스는 같은 원래 좌표를 FP32로 더해 복원한다. 두 모드 모두 파츠 픽셀당 8바이트를 사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U1** 이동량 저장과 180기 대조는 사용자 요청이다. 셰이더와 저장 버퍼를 공유하는 구성 및 RGB 캡처 기준은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 두 모드의 좌표 버퍼 논리 할당은 10.25 MiB로 같았다. 이동량 경로의 프레임 평균은 독립 실행에서 0.04 ms와 0.22 ms 길었다. 같은 프로세스의 적 렌더 GPU 구간은 0.22 ms와 0.24 ms 길었다.
- **I2** 절대 좌표의 RGB 채널 평균 오차 0.1241이 이동량에서는 0.00385로 줄었다. 최대 오차는 59에서 2로 줄었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** Intel 통합 GPU, FHD·High·SMAA·자동 검 교전, 초기 180기를 사용했다. 각 실행에서 준비 120프레임과 측정 240프레임을 사용했다. 절대 좌표→이동량→이동량→절대 좌표 순으로 측정했다. 전체 드로우는 독립 실행, 표의 적 GPU 구간은 같은 프로세스에서 모드를 교대한 결과다.

| 지표 | 절대 좌표 FP16 | 이동량 FP16 |
| --- | ---: | ---: |
| 평균 프레임 작업 시간 | 31.08~31.64 ms | 31.12~31.86 ms |
| 전체 GPU 드로우 평균 | 9.06~9.45 ms | 9.01~9.75 ms |
| 적 렌더 GPU 구간 평균 | 3.09~4.02 ms | 3.31~4.26 ms |
| 좌표 버퍼 | 10.25 MiB | 10.25 MiB |
| Deferred·Box 논리 GPU 할당 | 28.88 MiB | 28.88 MiB |
| 프로세스 커밋 피크 표본 | 1999.1~2007.3 MiB | 1992.4~1995.9 MiB |

- 독립 적 GPU 계측 한 회차의 마지막 프레임에서 가용한 타일이 23개여서 같은 프로세스에서 다시 교대했다. 표의 계측은 마지막 프레임에 근거리 타일 25개를 캐시했고, 같은 프로세스의 대체 포즈 수는 5개로 일치했다. GPU 시간은 OpenGL 명령 제출 사이의 대기를 포함할 수 있다. 프로세스 커밋 피크는 전체 프로세스의 표본이다.
- 같은 교전 상태 3장의 근거리 본체 132,050픽셀을 두 번 보간한 합성으로 대조했다. 오차의 단위는 8비트 RGB 채널 값이다.

| RGB 오차 | 절대 좌표 FP16 | 이동량 FP16 |
| --- | ---: | ---: |
| 평균 절대 채널 오차 | 0.1241 | 0.00385 |
| 변경 픽셀 | 26,847 | 1,057 |
| 채널 오차 > 1인 픽셀 | 2,257 | 5 |
| 채널 오차 > 8인 픽셀 | 8 | 0 |
| 최대 채널 오차 | 59 | 2 |
