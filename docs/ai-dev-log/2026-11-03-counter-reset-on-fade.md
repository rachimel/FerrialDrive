# 카운터 페이드 완료 시 초기화

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 카운터가 페이드 아웃되면 초기화한다. 이전의 숨김 뒤 누적 값 보존 규칙을 변경한다.
- 유지 2초·페이드 0.3초가 모두 끝나는 프레임에 HIT·DAMAGE의 샘플 원본 값과 회전 표시 상태를 0으로 맞춘다. HP와 타겟은 유지한다. 다음 유효 적중은 1 HIT·이번 피해량부터 시작한다.
- 페이드 도중 재적중은 기존 합계에 누적하고 수명을 갱신한다. 메뉴에서도 수명이 끝나면 초기화하고, 일시정지 중에는 수명 갱신 자체를 멈춘다.
- `CounterVisibility.update()`가 자연 종료 프레임에만 True를 반환하고 실행부가 초기화를 담당한다. 최초 숨김·명시적 hide·종료 뒤 반복 프레임에서는 종료를 다시 알리지 않는다.
- 소스의 수명 종료 조건·초기화 연결을 읽어 확인했다. 자동 검사·프로그램 실행·렌더링·조작은 수행하지 않았다. 페이드 완료 후 재적중·페이드 도중 재적중·정지와 재개는 사용자 확인 대기다.
