## 1. 사용자가 제안한 것

**사용자 제안 1 (U1)**: 스커트 UV 재검토와 목 구분선을 요청했다. 이후 면·노멀 정리를 명시 수용했다. 스커트 반복 결과가 만족스럽지 않아 재작업을 중단하고, Python 기반 작업 방식의 영향을 질문했다.

**사용자 제안 2 (U2)**: 앞으로의 모델 생성 파이프라인 개선 보고서로 마무리하고 텍스처는 유지하도록 요청했다. “스커트만 제외”의 범위를 확인하자 “스커트 구분선만 제거”라고 지정했다. 이유는 반복 재작업으로도 충분한 외관 개선을 얻지 못했기 때문이다.

## 2. 사용자 제안 중 AI가 수용한 것

U2를 최종 범위로 삼았다. 기존 도장·다른 부위 구분선·공유 재질은 유지하고 스커트 세 메시의 구분선만 해제했다. 스커트 형상/UV/노멀 및 목 구분선 시험 후보는 반영하지 않는다. 보고서를 프로젝트 문서로 작성한다.

## 3. AI가 제안한 것

**AI 제안 1 (A1)**: 단색·무조명 출력으로 색 텍스처와 형상 음영을 분리하고, 실루엣을 유지하는 면·노멀 정리를 함께 시험하자고 제안했다. 근거는 재질 Normal 연결을 해제한 단색 출력에서도 남는 삼각 음영이었다.

**구현상 판단**: 기존 메시를 수치적으로 평탄화하고 앞 장갑 Surface Deform을 재바인딩하는 후보를 만들었다. 충분한 외관 개선을 제시하지 못했으므로 이 접근을 성공한 해결책으로 남기지 않는다.

A1의 면·노멀 정리는 처음에는 명시 수용했다. 이후 사용자가 스커트 재작업 중단으로 범위를 바꿨다. 보고서의 반복 중단 기준·직접 편집 전환 등 세부 개선안은 제안이며 별도 수용이나 구현 완료가 아니다.
