# 게임과 독립된 공통 테스트 실행기

- 작성일: 2026-11-03, 한국 시간
- 범위: 사용자가 정한 공통 실행 인터페이스와 최소 실행 도구

## 최신 결정

- 공통 실행기는 **게임과 독립된 툴**이다.
- 실행기는 창을 띄우고 실행 루프·화면 교체·종료만 관리한다.
- 추가 UI·샘플 데이터·개별 입력·애니메이션은 각 테스트 `.py`와 해당 재사용 모듈에서 구현한다.
- 게임 본편에서 재사용할 모듈이 실행 도구나 테스트에 의존하지 않도록 유지한다.

## 구현

- `Tools/unit_test_runner/`: `TestProgram`의 초기화·입력·갱신·그리기·정리 규약, `SwitchTo`·`Stop` 흐름 요청, Pico2D 실행 루프, 지정 `.py`를 읽는 진입점을 추가했다.
- 실행기는 게임·UI 패키지·샘플을 import하지 않는다. 테스트 경로는 실행할 때 명시한다. 창은 실행 동안 유지하며 화면 교체는 콜백 반환 직후 적용한다.
- `samples/unit_test_runner/basic_flow.py`: 두 화면과 도형·문구·경과 시간·Esc·좌클릭·종료 동작을 샘플 파일에 구현했다. 폰트는 Pico2D 기본 파일을 사용한다.
- `AGENTS.md`, 프로젝트 안내와 도구·샘플 안내에 책임 경계와 실행 명령을 반영했다.

## 검증

- Python 3.11·Pico2D 1.5.1 환경에서 기존 9개와 실행기 11개를 합한 **자동 검사 20개 통과**.
- 화면 교체 시 창 유지, 남은 이벤트 전달, 갱신에서의 교체, 창 닫기, 초기화·이벤트·갱신·그리기·정리 오류 시 창 정리, 교체 대상 초기화 실패, 중복 정리 방지, import 독립성을 확인했다.
- SDL dummy 경로에서 CLI 5프레임 실행을 확인했다.
- 도구와 샘플만 별도 폴더에 복사하고, 원래 프로젝트 밖의 다른 작업 폴더에서 절대 경로로 3프레임 실행했다. 게임 코드·에셋이 없어도 실행됐다.
- 실제 창을 여는 명령은 정상 종료했다. Computer Use로 조작할 창을 확보하지 못해 **실제 좌클릭·Esc 조작과 시각 품질은 미검증**이다. 위 자동·dummy 결과를 실제 창 사용감 확인으로 간주하지 않는다.
