# 백웨폰 아이콘·슬롯 정렬과 사용키 표시 설정

- **기록 ID: FDLOG-20261115-back-weapon-icon-key-hints**
- 작성·결과 확인: 2026-11-15 02:12:24 KST.
- 개별 요청·구현 제시 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261115-back-weapon-icon-key-hints:scope]] 현재 대화의 `백웨폰 아이콘을 좀 더 UI에 맞게`·`사용키 표시`·`아이콘 좀 더 키워. 위치도 재정렬`로 원문을 찾는다.

## 1. 사용자가 제안한 것

- **U1**: 백웨폰 아이콘을 현재 UI에 맞게 바꾸고 테두리를 약하게 한다. 사용키 표시는 사용자 설정에서 끄고 켤 수 있게 한다. 이유·근거: 현재 대화의 UI 일치·표시 선택 요청이다. 세부 수치·도안은 지정하지 않았다.
- **U2**: 이어서 아이콘을 더 키우고 위치도 재정렬한다. 이유는 별도 제시하지 않았으며 앞선 백웨폰 아이콘 작업의 후속 범위로 반영했다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1/U2를 아이콘 도안·테두리·슬롯 크기/정렬·사용자 설정에 반영했다.
- 기존의 다음 스왑 기능 표시와 무기 스왑 최대 왼쪽 마진 바깥 배치를 유지했다. 구현 사실과 최종 외관 승인은 구분한다.

## 3. AI가 제안한 것

- **구현상 판단 A1**: 쌍 발사관과 중앙 장착 프레임을 가는 외곽선·사선 절단면으로 표시한다. 원형 슬롯 96px·도안 배율 1.12·아래 여백 30px, 테두리 1.25px·불투명도 0.28을 시험값으로 사용한다.
- **구현상 판단 A2**: HP·에너지 영역 오른쪽과 무기 스왑 마진 사이의 가운데로 가로 정렬한다. 오른쪽 끝은 스왑/블러 마진보다 최소 16px 왼쪽이다. 도안 확대와 슬롯 배치는 분리한다.
- **구현상 판단 A3**: `사용키 표시 · 켬/끔` 한 항목으로 E·SPACE·필살기 키 안내를 함께 조절한다. 기본 켬, 저장 즉시 적용·다음 실행 유지, 취소/Esc는 미저장이다. 기능 아이콘과 필살기 레벨 표시를 유지한다.
- 이유·근거: 사용자 U1/U2와 기존 공통 슬롯·게임 설정 저장 구조다. 주기적으로 바뀌는 도형 수치는 UI 설정에, 개인 선택은 `interface.show_key_hints`에 보관한다. 품질 변경은 다음 실행에 적용하며 사용키 표시와 독립이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U2는 확대·재정렬의 명시 요청이다. A1/A2의 정확한 수치·도안과 A3의 공통 적용 범위에 대한 별도 최종 외관 승인은 아직 없다.

## 5. 반영 후 발견한 문제

- **I1**: 설정 검사에서 임시 폴더 정리 권한 오류가 발생했다. 제품의 저장 동작 실패와 구분하고 정상 권한의 임시 폴더 환경에서 재검증했다.
- **I2**: 검증용 아이콘 캡처 영역이 창 아래를 4px 넘었다. 제품 표시 영역은 정상이며 캡처 범위만 창 내부로 맞췄다.
- 표시·저장에 추가로 확인된 문제는 없다. 최종 외관/사용감은 사용자 확인 전이다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 구체적인 구현 오류 해결 방식은 별도 제시되지 않았다. U2는 새로운 확대·정렬 요청이며 버그 수정 제안으로 바꾸어 기록하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- 아이콘·테두리·정렬을 고쳤다. 품질 선택을 바꿔도 사용키 선택이 초기화되지 않도록 기존 설정을 보존해 필드만 변경한다. 예전 설정 파일에는 기본 켬을 적용하고 다른 사용자 설정을 보존한다.
- **자동 검사**: UI 137개·게임 설정 10개 실행에서 실패 0개·환경 제외 4개. 이어 전체 755개 실행·720개 통과·환경 제외 35개·실패 0개다. 결과: `output/maintenance/slot-key-hints-checks.log`·`slot-key-hints-full-checks.log`.
- **실제 렌더/입력 경로 확인**: 로컬 기체와 OpenGL에서 설정 버튼에 마우스 이벤트를 공급해 켬→끔 저장→켜기 저장을 확인했다. E·SPACE·필살기 키 안내가 모두 즉시 바뀌고 LV.03은 유지됨을 검사했다. AI가 확대 아이콘·두 UI 영역 사이 배치·약한 테두리·설정 패널·ON/OFF 캡처를 열어 확인했다. 결과: `output/maintenance/slot_settings_review/`.
- 검증은 별도 설정 파일을 사용했다. 사용자 개인 설정은 덮어쓰지 않았다. 현재 명세·샘플 안내를 갱신했으며 직접 창 조작·최종 외관 승인·커밋·업로드는 수행하지 않았다.
