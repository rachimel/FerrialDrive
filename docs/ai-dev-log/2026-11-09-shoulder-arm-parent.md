# 어깨 하부와 상완 연결 수정

현재 상태 정정: 사용자가 기존 비틀린 포즈 보존을 거절하고 중립 자세·무기 전부 수납을 요청했다. 아래 첫 후보 기록은 당시 결과이며 현재 편집 기준은 `data/models/basic_weapons/base_pose.blend`다.

기록일: 2026-11-09. 발언별 시각: [[FDLOG_MISSING_TIME:shoulder-arm-parent:scope]]. 근거: 현재 대화의 “어깨랑 팔이랑 붙여야할거 같아”, “그렇게 모델 수정하자”.

## 1. 사용자가 제안한 것

**U2**: “지금 꼬임 풀고 무기는 다 수납된 상태로”. 기존 비틀린 포즈를 보존한 채 연결만 바꾼 결과를 거절했다. 발언 시각은 위 scope 누락 태그를 따른다.

**U1**: 잘못된 검 자세를 다듬기 전에 어깨와 팔을 연결한다. 앞서 제시한 세 사진은 같은 잘못된 자세의 서로 다른 시점이며 목표 자세가 아니다.

## 2. AI가 제안한 것

**A1**: 어깨 상부 → 하부 → 상완 → 전완 → 손 계층을 구성하고 단순 가동 자세로 확인한다. 메시 병합은 하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

U2를 수용하여 기존 동작의 활성 Action을 해제하고 NLA를 비활성화했다. 본 포즈를 중립으로 초기화하고 검·총 수납 속성을 모두 1로 설정했다.

U1을 수용하여 기존 검 자세를 목표로 삼지 않고 연결 관계만 수정했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

A1에 사용자가 “그렇게 모델 수정하자”라고 명시 수용했다. 후보 외관의 최종 승인은 아직 없다.

## 5. 반영 후 발견한 문제

**I3 — 첫 후보의 범위 오류**: AI가 나쁜 기존 포즈를 보존한 채 연결 수정만 완료하고 기본 레퍼런스로 안내했다. 사용자가 이를 거절했다. 포즈 보존 검사 통과는 중립 자세 완성을 뜻하지 않았다.

**I1 — 수정 전 구조**: ShoulderWingLower는 ShoulderWingUpper의 자식이지만 UpperArm은 Chest에 직접 연결돼 있었다.

**I2 — 기존 진단 정정**: 앞선 sword_draw 영상의 목표 경로는 사용자에게 거절됐다. 해당 경로에서 계산한 도달 오차를 리그의 근본적인 도달 불가능 증거로 사용하지 않는다. 스커트 미할당 정점 진단은 별개다.

## 6. 사용자 해결 제안과 실제 해결 과정

U1에 따라 양쪽 상완의 부모를 어깨 하부로 변경했다. 최신 저장본 combo_poses/animations.blend를 입력으로 사용하고 원본은 보존했다.

## 7. AI 해결 제안과 실제 해결 과정

U2 후속 처리: 사용자가 정리한 `base_pose.blend`의 해시가 첫 후보와 동일함을 확인했다. 임시 후보에서 초기화·저장·재로딩 후 정면/사선/측면 렌더를 확인하고 해당 파일을 갱신했다. 어깨 부모 관계는 유지했다. 1·6·24프레임에서 어깨/상완/전완/손목/손의 포즈 오프셋은 0이고 검·총 수납 속성은 1이다. 기존 스커트 자동 보정 드라이버는 유지했다. 최종 SHA-256은 `e38afa282013db01f42f1ceea7e38eb7ba47e5d4593ff19e6599f2bb149630d2`이며 `base_pose.json`에 기록했다. 증거는 `output/shoulder_repair/neutral_report.json`과 `neutral_front.png`, `neutral_oblique.png`, `neutral_side.png`다. 사용자 외관 확인은 대기 중이다.

기존 DCC-MCP Blender 인스턴스와 원본 리그를 재사용했다. 기존 제작 재사용 검토를 이어가는 작업이며 추가 플러그인·외부 에셋은 사용하지 않았다. 전용 도구에 없는 본 부모 및 포즈 보존 편집은 노출된 Blender scripting 도구로 수행했다.

구현상 판단: 본 끝으로 강제 스냅하지 않고 오프셋 부모 연결을 사용했다. 기존 상완 피봇은 관절 하우징 안에 있으며 Rest 좌표·메시·웨이트는 유지했다. 부모 변경 후 상완 키를 보정해 기존 1~6 프레임 포즈를 보존했다. 기존 나쁜 자세를 개선했다는 의미는 아니다.
