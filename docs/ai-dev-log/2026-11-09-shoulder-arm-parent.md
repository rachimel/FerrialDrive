# 어깨 하부와 상완 연결 수정

기록일: 2026-11-09. 발언별 시각: [[FDLOG_MISSING_TIME:shoulder-arm-parent:scope]]. 근거: 현재 대화의 “어깨랑 팔이랑 붙여야할거 같아”, “그렇게 모델 수정하자”.

## 1. 사용자가 제안한 것

**U1**: 잘못된 검 자세를 다듬기 전에 어깨와 팔을 연결한다. 앞서 제시한 세 사진은 같은 잘못된 자세의 서로 다른 시점이며 목표 자세가 아니다.

## 2. AI가 제안한 것

**A1**: 어깨 상부 → 하부 → 상완 → 전완 → 손 계층을 구성하고 단순 가동 자세로 확인한다. 메시 병합은 하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

U1을 수용하여 기존 검 자세를 목표로 삼지 않고 연결 관계만 수정했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

A1에 사용자가 “그렇게 모델 수정하자”라고 명시 수용했다. 후보 외관의 최종 승인은 아직 없다.

## 5. 반영 후 발견한 문제

**I1 — 수정 전 구조**: ShoulderWingLower는 ShoulderWingUpper의 자식이지만 UpperArm은 Chest에 직접 연결돼 있었다.

**I2 — 기존 진단 정정**: 앞선 sword_draw 영상의 목표 경로는 사용자에게 거절됐다. 해당 경로에서 계산한 도달 오차를 리그의 근본적인 도달 불가능 증거로 사용하지 않는다. 스커트 미할당 정점 진단은 별개다.

## 6. 사용자 해결 제안과 실제 해결 과정

U1에 따라 양쪽 상완의 부모를 어깨 하부로 변경했다. 최신 저장본 combo_poses/animations.blend를 입력으로 사용하고 원본은 보존했다.

## 7. AI 해결 제안과 실제 해결 과정

기존 DCC-MCP Blender 인스턴스와 원본 리그를 재사용했다. 기존 제작 재사용 검토를 이어가는 작업이며 추가 플러그인·외부 에셋은 사용하지 않았다. 전용 도구에 없는 본 부모 및 포즈 보존 편집은 노출된 Blender scripting 도구로 수행했다.
