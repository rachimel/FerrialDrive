# UI v2 전역 패널 효과·가이드 헤더 확대

- **기록 ID: ui-v2-global-panel-effects**. 원래 대화·구현·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-global-panel-effects:scope]] 검색 단서: `나머지 패널들도`, `헤더 폰트 크기`, `local이 아니라 global`, `체력이나 필살기 아이콘, 에너지 레벨`.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: `통신`을 빼고 `조작 가이드`만 남기며 다른 패널에도 투명도·Scanline·밝은 띠 스크롤을 적용한다. 근거는 현재 직접 요청이다.
- **사용자 제안 2 (U2)**: 가이드 헤더 글꼴을 더 키운다. 별도 수치는 제시하지 않았다.
- **사용자 제안 3 (U3)**: 패턴과 밝은 띠를 패널별 local이 아닌 global 효과로 한다.
- **사용자 제안 4 (U4)**: HP·필살기 아이콘·에너지 레벨에서는 Scanline을 제거한다. 근거는 현재 후속 요청이다.

## 2. AI가 제안한 것

- 구현상 판단으로 일반 배경 불투명도 0.55·선 불투명도 0.06, 가이드 헤더 전용 24px를 사용했다. 먼저 제시한 패널별 시간/좌표 방식은 U3 후속에 따라 한 화면 좌표·한 UI 시계로 수정했다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U4를 반영했다. 헤더는 이미 `조작 가이드`였으며 메뉴에 남은 `통신 패널` 문구도 제거했다. 가이드 제목을 `dialogue_heading` 역할로 분리해 18→24px로 확대하고 본문·다른 표적명은 유지했다.
- 무기·로드아웃·에너지 바 빈 배경·카운터 받침판·메뉴/일시정지 패널과 버튼에 효과를 연결했다. HP·필살기 아이콘/단축키/보조 레벨·에너지 레벨은 스캔을 제외하고 투명도만 남겼다.
- 패턴 5px/s·밝은 띠 60px/s는 화면 좌표를 사용하고 패널 면 내부에만 표시한다. 장면과 배율이 달라도 하나의 시계와 같은 화면 Y를 공유한다. UI 장식은 일시정지 중에도 움직이고 게임 시간·피해·흡수 Trail은 멈춘다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 24px·일반 투명도 등 구현 수치와 최종 외관에 대한 명시 승인은 아직 확인하지 않았다. U3·U4는 사용자의 직접 후속 요구다.

## 5. 반영 후 발견한 문제

- **문제 1 (I1)**: 새 검사 블록의 잘못된 위치로 이름 참조 오류가 났다. 검사 코드를 제자리로 옮겼다.
- **문제 2 (I2)**: 화면 밖까지 뻗는 검사 패널에서 전역 UV가 유효 범위를 벗어나 SDL 그리기가 실패했다.
- **문제 3 (I3)**: 사각형 묶음 출력에서 배율 간 전역 위상이 맞지 않았다. 네이티브 내부의 정확한 차이는 미확인이다. [[FDLOG_MISSING_CAUSE:ui-v2-global-panel-effects:I3]] 검색 단서: `SDL_RenderGeometry` 사각형 경로와 개별 삼각형, 축소 viewport, UV 위상.

## 6. 사용자 해결 제안과 실제 해결 과정

- U3에 따라 화면 전체 좌표의 패턴을 패널로 마스킹하고 UI 시계를 공유했다. U4에 따라 자원부 일부는 투명도만 남겼다. I1~I3의 별도 구현 해결안은 사용자가 제시하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I2는 화면 세로 범위로 먼저 자르고, I3는 수평 UV를 펼친 뒤 개별 삼각형으로 출력해 정합 검사를 통과했다. 소프트웨어 SDL에서 배율 1/0.5·이동 viewport·밝은 띠의 같은 화면 행을 픽셀로 비교했다.
- UI 자동 92개·획득 7개, 총 **99개 통과**. 전투 156·일시정지 36·메뉴 36, 총 **228프레임**을 12fps 시간 간격으로 렌더했다. 상단/하단 밝은 띠와 일시정지 이미지를 열어 검토했다. 전투 13초 GIF를 생성했고 패턴 텍스처는 **2개**로 유지됐다.
- 실제 창 사용감·GPU 성능·사용자 외관 승인·업로드는 미확인/미수행이다. 출력은 `output/ui_unit_test_v2/global_panel_effects/`이며 공개하지 않는다.
