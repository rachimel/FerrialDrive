# 원거리 적 Box 투영 그림자

**기록 ID** `FDLOG-20261121-crowd-box-shadows`

## 1. 사용자가 제안한 것

- **U1** 원거리 적 그림자가 너무 작게 보인다. 플레이어와 같은 Box 투영으로 표현한다.
- 정확한 사용자 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-crowd-box-shadows:U1]]이다. 검색 단서는 `플레이어 마냥 Box로 표현할 순 없어`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 소형·중형 적의 기존 리그 Box와 광원에서 각 8방향 그림자를 미리 생성했다. 군집은 이동 대표 자세의 방향별 그림자를 공유한다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 1024×1024 고정 시트의 빈 16칸에 그림자를 저장한다. 전투 중에는 적 하나당 그림자 타일을 한 번 복사한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- Box 표현을 사용자가 요청했다. 방향별 대표 자세와 시트 재사용은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1 · 기존 시트** 180기 동일 상태에서 그림자를 켜면 153개, 원거리만 빼면 28개, 전부 빼면 0개였다. 기존 타원은 적 몸체보다 작고 발밑에 가려지는 경우가 있었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1 ↔ I1** 플레이어가 쓰는 `PartShadowMap`의 Box 투영을 적의 카탈로그에 적용했다. 소형과 중형 모두 기존 타원 영역 밖에 그림자가 드러나는 것을 같은 FHD 교전에서 확인했다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1** 아틀라스 v2에는 본체 240칸과 Box 그림자 16칸을 보관한다. 16개 그림자 모두 알파 픽셀을 확인했다. v1은 기존 타원으로 표시한다.
- GPU 논리 용량 4MiB와 원거리 적 PBR 페이지 요청 회피를 유지했다. OpenGL 적 렌더 검사 10개가 통과했으며, 원거리 한 기의 그림자 표시와 PBR 준비 0회를 확인했다.

## 확인 상태

- 동일 상태 전후 캡처와 Box 적용 후 180기 HUD 교대 계측은 `output/performance/filtered_hud_cached_batch_180_20261121/paired_box/`에 있다. 방향마다 걷기 대표 포즈를 사용하며 공격·피격 중 실시간 Box 보간은 근거리 경로에서 적용한다.
