# 카운터 레이블 크기 정정

- 작성일: 2026-11-03, 한국 시간
- 사용자 의도는 HIT 숫자의 확대가 아니라 HIT·DAMAGE 레이블 확대였다. 이전 숫자 92px 적용은 잘못 해석한 결과다.
- HIT 숫자를 기존 76px로 복원한다. DAMAGE 숫자는 기존 60px를 유지한다.
- HIT·DAMAGE 레이블을 16→20px로 키우고, 추가 자간을 2→3px로 넓힌다. 두 값은 우선 비교할 시안이다.
- 숫자 아래 4px 간격·오른쪽 정렬·카운터 사이 8px 여백의 중앙 높이는 유지한다. 기존 뷰가 글자 높이로 배치를 계산하므로 설정만 변경한다.
- UI 명세·샘플 안내·체크포인트를 현재 값으로 정정하고 이전 로그에 후속 정정을 연결한다.
- 설정·문서를 대조하고 Git 변경 검사를 수행했다. 자동 테스트·실행·화면 확인은 수행하지 않았다.

## 후속 미세 조정

- 같은 날 사용자 요청으로 HIT·DAMAGE 레이블을 20→18px, 추가 자간을 3→5px로 조정했다. HIT 숫자 76px·DAMAGE 숫자 60px와 배치 규칙은 유지한다.
- 현재 기준은 레이블 18px·추가 자간 5px다. 설정·문서 대조와 Git 변경 검사만 수행했으며 실행·화면 확인은 수행하지 않았다.
