## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 편집한 `boost.ogg`에서 슈웅하는 소리를 남기고 취이익 잡음을 제거해, Warframe 가우스의 마하 대시처럼 가볍고 빠른 느낌으로 가공·연결한다. 사용자 레퍼런스는 음색 목표이며 게임 원음을 추출·사용하라는 요청으로 해석하지 않는다.
- **사용자 제안 2 (U2):** 대시 마찰이 중간에 끊기거나 반복하는 느낌 대신 `스르르르륵` 이어져야 한다. 우웅우웅하는 톤은 불필요하다고 정정한다. 이전의 새 대시 파일·용도 보류와 별개로 현재 마찰 표현을 수정하는 요청이다.
- **사용자 제안 3 (U3), 후속 정정:** 부스트는 경쾌하게 시작하고 더 잔향을 남긴다. 현재 대시는 삐그덕삐그덕에 가까우므로 연속적인 스키 마찰에 가깝게 만든다. 이전 연결 검사 통과를 음색 수용으로 취급하지 않는다.
- **사용자 제안 4 (U4), 후속 지정:** 대시에 에너지음 대신 치이이익 하는 연기·증기 느낌의 소리를 원하며, 스키 마찰과 두 개를 합성하라고 요청했다. U3·U4의 개별 시각도 TIME(scope) 보완 대상이다.
- U1 원본의 외부 출처·라이선스는 모름. `[[FDLOG_MISSING_SOURCE:FDLOG-20261115-boost-cleanup-continuous-friction:U1]]` — 사용자 편집 전 원본 페이지·작성자·라이선스 증빙으로 보완한다. 다른 음원의 CC0/Pixabay 표기를 상속하지 않는다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 원본을 보존하고 별도 WAV를 준비한다. Space 부스트 준비 종료에 선택 가공본을 연결한다. 사용자가 제공한 파일 외의 Warframe 게임 음원은 사용하지 않는다.
- U2: 기존 짧은 공기 후보·주기적인 마찰 레이어를 지속 마찰 재료로 교체한다. 시작/종료에만 페이드하고 유지 중 루프를 다시 시작하지 않는다.
- U3·U4: 부스트의 앞부분과 잔향을 분리하고, 대시는 눈 마찰 재료와 고역 증기층을 독립적으로 혼합한다. 콘크리트 쓸림을 더 겹치는 방식은 중단한다.

## 3. AI가 제안한 것

- **구현상 판단 A1:** 원음의 주파수·시간 분석에서 넓은 고역 잡음과 3~4kHz 부근의 중심 이동 대역을 구분했다. 처음 약 0.025~0.385초를 사용하고, 이동 대역과 낮은 공기 본체를 남기며 고역·긴 꼬리·지속 레벨을 줄인다. 새 발진음은 더하지 않는다.
- **구현상 판단 A2:** CC0 실제 마찰 8종에서 짧은 조각을 골라 6초의 원형 overlap-add 재료를 만든다. 대역 제한·조각 음량 보정·원형 RMS 보정을 적용해 짧은 재료의 부풀고 꺼지는 주기를 줄인다. 값은 JSON으로 분리한다.
- 필터 수식은 RBJ/W3C Audio EQ Cookbook을 참고했다. 오프라인 가공은 표준 Python과 기존 Pico2D 디코더를 사용한다. 추가 게임 오디오 라이브러리는 없다.
- **후속 구현상 판단 A3:** 콘크리트 마찰 조각은 끊김 수치가 정상이어도 목표 음색과 다르다는 사용자 평가를 수용해 재료를 교체했다. IgnasD의 CC0 눈 밟기 2종을 28ms 조각·3.5ms 간격으로 겹쳐 스키 마찰 재료를 만들고, 공기 원본의 고역을 별도 증기층으로 만든다. 두 층은 대시 유지 중 각각 한 번만 시작한다.
- **후속 구현상 판단 A4:** 부스트 중심음을 0.30초로 조정하고 저음 비중을 낮췄다. 최종값은 24ms 이후 시작하는 불규칙 감쇠 반사 48개·잔향 혼합 0.55·길이 0.5초이며 전체 길이 약 0.80초로 준비했다. 반사·감쇠 값은 설정으로 분리한다. 특정 게임 음원의 복제를 주장하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 가공과 연결은 U1·U2의 직접 요청 범위로 진행했다. A1·A2의 대역·길이·조각 간격·음량 수치는 구현상 판단이며 사용자의 확정 음색으로 표시하지 않는다.
- 최종 부스트가 레퍼런스와 비슷하게 들리는지, 대시 마찰의 질감이 만족스러운지는 사용자 청취 확인 전이다.

## 5. 반영 후 발견한 문제

- **문제 1 (I1), 사용자 발견:** 기존 대시 마찰이 중간에 끊기며 반복하는 느낌과 우웅우웅 톤을 준다. 짧은 공기음의 시간 변화와 추가 마찰 반복층이 현재 목표와 맞지 않았다. 소스 내용과 재생기 재시작을 구분한다.
- **문제 2 (I2), AI 확인:** 고역을 모두 없애면 중심 슈웅 대역도 손상될 수 있어 단순 전체 저역통과만 적용하지 않았다. 선택한 중심 대역과 낮은 공기 본체를 따로 보존한다.
- **문제 3 (I3), 사용자 발견:** U2를 반영한 콘크리트 마찰도 삐그덕거리는 음색으로 평가했다. 연속성 검사와 원하는 재질감은 다른 검증임을 확인했다. 같은 재료·방식의 반복 조정 대신 U3·U4에 따라 재료와 혼합 구조를 바꿨다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U2: 사용자가 지속적인 마찰과 불필요한 공진 제거를 제시했다. AI는 6초 마찰 질감으로 교체하고 종전 짧은 공기 반복층을 제외했다. 자갈 단발음은 낮은 음량의 별도 사건으로 유지한다.
- U1의 원본 1.263초를 보존하고 약 0.36초 가공본을 연결했다. 잘라낸 꼬리를 임의의 다른 소리로 대체하지 않았다.
- I3 ↔ U3·U4: 사용자는 연속 스키 마찰과 치이익 증기층의 혼합을 제시했다. 원본 CC0 눈 소리를 새로 보존하고 `ski_slide.wav`·`steam_hiss.wav`를 별도 레이어로 연결했다. 부스트는 경쾌한 앞부분과 감쇠 잔향으로 재가공했다.

## 7. AI 해결 제안과 실제 해결 과정

- `ferrial_drive/audio/processing.py`에 중심 대역 부스트 정리와 원형 마찰 조각 합성 공통 기능을 추가했다. `sound-import --processing`과 `sound-effects`가 재사용한다.
- `sound-preview --only mobility`는 실제 믹서에서 부스트 한 번과 13초 마찰 재생을 기록한다. 반복 경계를 두 번 넘겨 확인하는 파일이며 게임의 필수 입력이 아니다.
- 믹서의 마찰 시작은 0.05초, 종료는 0.1초 페이드한다. 재료 내부에는 매 반복 시작·끝 페이드를 넣지 않는다. 일시정지·포커스 상실의 즉시 정지는 유지한다.
