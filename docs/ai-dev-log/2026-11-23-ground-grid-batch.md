# 훈련장 격자선과 미터 눈금 일괄 제출

- 기록 ID `FDLOG-20261123-ground-grid-batch`
- 기록일 2026-11-23 KST

## 1. 사용자가 제안한 것

- **U1** VBO 일괄 업로드 뒤 남은 드로우 호출을 더 줄인다. 요청 시각 `[[FDLOG_MISSING_TIME:FDLOG-20261123-ground-grid-batch:U1]]`. 대화에서 `드로우 콜 더 줄여볼래`로 찾는다.

## 2. 사용자 제안 중 AI가 수용한 것

- 일반 정점 호출을 교전 전체에서 집계했다. 훈련장 격자선과 미터 눈금에 반복된 제출을 묶고, 기존 VBO와 클라이언트 배열을 각각 대조했다.

## 3. AI가 제안한 것

- **A1** VBO 안에서 같은 상태의 호출을 `MultiDraw`로 묶을 수 있는지 조사했다. RTX 5070 Laptop 180기 120프레임에서 같은 모드·텍스처·블렌드·인덱스 규약을 가진 인접 호출은 17회만 줄일 수 있었다.
- **A2** 눈금선의 단색 텍셀과 눈금 글자 텍스처를 하나의 512×512 아틀라스에 놓는다. 기존 선·글자 순서와 색상·클립을 유지하는 조건에서 일반 HUD 정점 배치를 재사용한다. 아틀라스 크기는 구현상 판단이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 드로우 호출 감소 요청을 구현했다. 묶음 대상과 아틀라스 구현은 AI의 선택이며 사용자 직접 조작 검수는 미수행이다.

## 5. 반영 후 발견한 문제

- **I1** FHD 교전은 드로우 수가 줄어도 아틀라스 확보 등 다른 경과 시간의 편차가 남았다. 드로우 호출 감소와 전체 프레임 개선을 별도로 확인한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 직접 OpenGL의 단위 배율·알파 블렌드 조건에서 눈금선과 글자를 기존 순서대로 공통 메시로 제출한다. 같은 180기 자동 교전에서 일반 GL 드로우는 클라이언트 배열 182.42→137.22회, VBO 157.96→112.76회였으며 모두 프레임당 평균이다. 셰이더 전용 패스는 이 호출 수에 포함되지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- 격자선·글자 겹침과 클립을 포함한 세 위치의 단위 검사에서 화면 RGBA가 일치했다. 30기 High·180기 Medium의 10개 시점에서 플레이어·적 깊이 맵 및 사용 중인 그림자 타일도 전부 일치했다. 첫 3개 최종 RGB 캡처가 일치했고 나머지에 일부 픽셀 차이가 남았다.
- **I1** 상세계측의 `world.ground` 평균 포함 경과 시간은 클라이언트 배열에서 1.44→0.97ms, VBO에서 1.56→0.77ms였다. RTX 5070 Laptop FHD 180기에서 같은 자동 입력으로 각각 120프레임을 수집했다.
- 상세계측을 끈 120프레임 반복에서 표시 창의 180기 p50은 기존 20.34–20.65ms, 배치 20.51–22.53ms였다. 숨김 창에서는 180기 37.63–39.04→21.71–30.74ms, 30기 21.45–25.52→25.97–31.69ms였다. 실행 조건과 변동 폭이 달라 전체 프레임 시간 개선을 확정하지 않았다.
- 직접 OpenGL의 기본 눈금 경로에 반영했다. 비단위 배율과 비교 실행 `FDRIVE_GROUND_GRID_SUBMISSION=legacy`는 기존 선·글자 제출을 사용한다. RTX 5070 Laptop의 2GiB 제한 180기 교전은 120프레임을 완료했고 최고 프로세스 커밋은 약 931MiB였다.
- Intel에서 신규 격자 RGBA 검사와 HUD 필터 검사 18개를 확인했다. 전체 렌더링 검사에서 CPU 깊이 정렬·업로드의 13·17파츠 소검사 2건은 실패했고, 변경 전 Git 소스에서도 같은 Intel 실패를 재현했다. Intel 교전 성능과 장시간 직접 조작은 미수행이다.
- 근거는 `output/performance/native-multidraw/`의 `flamegraph-client-grid.svg`, `flamegraph-vbo-grid.svg`, `*-comparison.json`, `*-trace/native-draw-counts.json`, `identity-runs/draw-runs.json`이다.
