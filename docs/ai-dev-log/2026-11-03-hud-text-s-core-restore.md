# HUD 텍스트를 에스코어 드림으로 복원

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: HUD 텍스트를 에스코어 드림으로 되돌린다.
- HUD 제목은 SCDream6, 라벨·설명·타겟/플레이어 이름·버튼·COMBO·DAMAGE는 SCDream4로 복원했다. 글자 크기는 현재 값을 유지한다.
- 메뉴와 공유하던 본문·작은 글자 역할에서 `hud_body`·`hud_small`을 분리했다. 메뉴의 Cafe24 PRO와 숫자의 학교안심 운동장은 유지한다.
- 카운터들의 오른쪽 정렬·8px 간격·여백 중앙 배치·변경 자리 효과와 레이더 거리 표현은 유지한다. 폰트 기준선·폭 측정은 변경한 글꼴을 사용한다.
- 변경 코드·설정을 읽어 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 HUD 글꼴·COMBO/DAMAGE 정렬·버튼 문구 잘림을 확인한다.
