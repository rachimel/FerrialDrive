# 기본 무기 8fps 애니메이션과 출력 연결

기록 ID: 2026-11-09-basic-weapons-animation. 날짜는 사용자 대화의 2026-11-09 KST 기준이다. [[FDLOG_MISSING_TIME:2026-11-09-basic-weapons-animation:scope]] 개별 발언·구현의 정확한 시각은 미확인이다. 검색 단서: “플레이어 애니메이션은 8fps”, “데이터 형식을 툴에 맞춰달라고”.

## 1. 사용자가 제안한 것

U1: 검/총 전환, 지향/조준 전환, 걷기/달리기 전환, 달리기→대시, 검 4콤보, 총 발사와 검/총 idle 제작을 요청했다. 플레이어 전체 애니메이션은 8fps다. 검 한 타에는 8프레임을 사용해도 된다고 했다.

U2: 직접 그린 측면 4콤보를 제공하고 어색한 연결은 자연스럽게 바꾸는 것을 허용했다. 내려베기→가로베기→찌르기→아래로 빼며 베기의 해석을 확인했다.

U3: 전체를 제작하고 기존 툴의 데이터 형식과 내보내기에 맞추라고 요청했다. 데이터 형식을 새로 지정하겠다는 뜻이 아니라고 정정했다.

## 2. 사용자 제안 중 AI가 수용한 것

8fps·검 4타 각 8프레임을 적용했다. 검/총 이동 변형, 한손 지향/양손 조준, 각 타 중단 복귀를 포함한 29개 모션·198프레임을 별도 작업본으로 저장했다. 원본 모델은 보존했다.

## 3. AI가 제안한 것

A1: 기존 툴의 프레임 기반 출력 계약을 유지하고 모션 구간을 타임라인 마커와 JSON으로 제공한다. 제작 데이터는 본/앵커 로컬 행렬과 장착 속성 표본으로 저장한다. 버전별 Python 생성기를 추가하지 않고 공통 animation_pipeline.py로 굽는다.

A2: 출력 설정 불러오기 버튼으로 모델·이름·FPS·구간·카메라 입력을 채운다. 제자리 이동 모션이며 게임의 이동량·판정은 별도로 둔다. 이는 구현상 판단으로 사용자에게 설명했으며 외관 승인을 뜻하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

사용자는 목록을 확인한 뒤 “애니메이션들 다 제작 해줘”라고 요청했다. 최종 모션 외관과 이번 툴 버튼에 대한 사용자의 직접 시연/승인은 아직 없다.

## 5. 반영 후 발견한 문제

I1: 첫 이동 표본에서 골반 로컬 축을 월드 상방으로 취급해 다리 도달 범위를 넘었다. 월드 좌표로 골반 높이를 조정해 다시 제작했다.

I2: 총 수납 전환에서 손 도달 범위 때문에 앵커가 약 0.014 모델 단위 어긋났다. 검 극점은 팔 길이를 늘리지 않고 도달 범위 안으로 조정했다.

I3: 기본 Python에는 Pico2D가 없고 제한 환경의 임시 폴더 접근도 실패했다. 승인된 프로젝트 game2d 환경에서 검사를 다시 실행했다.

## 6. 사용자 해결 제안과 실제 해결 과정

U3에 따라 새 게임용 형식을 강요하지 않고 기존 production.render_config, render_asset_sample, pack_sprites, SpriteBundle 경로를 사용했다. 출력 모션 설정을 기존 패널에서 불러올 수 있도록 했다. 초기 의미 확인 후 추가 형식 선택을 요구하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

I1: 월드 골반 높이와 두 관절 해법으로 제자리 보행/달리기/대시를 만들었다. I2: 총 슬롯 접근 시 몸통을 조금 돌리고 재파지 전에 접근 표본을 추가했다. 최종 부착 이벤트의 손/수납 앵커 위치 오차는 0.0000005 미만, 연결 본 틈은 0이다. 전신 장갑/칼집 연속 충돌을 보증하지 않는다.

29개 전 모션의 본·앵커 행렬과 장착 속성을 저장 후 재로딩했다. 최대 행렬 오차 0.000000954, 원본 해시 유지. 모든 모션의 사선 작업 렌더를 생성하고 콤보/전환 접촉 시트와 이동/찌르기 표본을 확인했다. 8fps 검토 페이지와 모션별 WebP를 제공했다. 총 지향 발사 4프레임을 64px로 실제 8방향 본체/그림자 출력·패킹한 뒤 SpriteBundle로 읽어 8fps를 확인했다. 전체 모션의 최종 8방향 출력 완료와 구분한다.

공통 도구·출력 입력 자동 테스트 14개 통과. 단일 본/상자의 독립 시연도 저장·재로딩 오차 0으로 통과했다. 툴의 실제 창 클릭 검증은 하지 않았다. 전신 장갑·칼집 간섭, 게임 이동과 발 접지 동기화, 공격 타격감/반동 세부 조정, 이펙트, 손 레이어별 최종 출력은 후속 검수 대상이다. 현재 결과는 1차 모션이며 사용자 외관 승인 대기다.
