## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 대략적인 키포즈부터 수치 변화와 전체 실루엣, 자연스러운 관절 굽힘을 함께 검토한다. 기존 원칙에 추가하고 `base_pose.blend`에서 기존 애니메이션 요구사항의 키포즈를 새로 만든다.
  - 이유·의도: 숫자만 변한 자세가 아니라 읽히는 실루엣과 실제 관절 굽힘을 확인하려는 요구다. 근거는 현재 대화의 “전반적인 실루엣과 관절이 자연스럽게 꺾였나”. 발언 시각은 scope의 누락 항목을 따른다.
- **사용자 제안 2 (U2):** 허용각 미정 상태에서 범위도 후보로 제시해 달라는 응답 뒤 “아니 일단 그냥 constraint 없이 / 일단 만들어봐 / 그리고 내가 피드백 할게”로 정정했다.
  - 이유·의도: 우선 제한 없는 자세 후보를 만들고 사용자가 피드백한다는 최신 요청이다. 임시 허용각이나 각도 제한의 선행 확정은 이번 범위에서 제외한다.

## 2. AI가 제안한 것

- **AI 제안 1 (A1):** 기본 리그에 실제 각도 제한이 없음을 확인하고 허용각의 별도 규격 또는 검토용 범위 후보를 질문했다. 근거는 기본 파일의 `Limit Rotation`·IK 허용각 미설정이다. U2의 후속 정정으로 이번 범위에서는 폐기했다.
- **구현상 판단:** 공통 제작·이미지 검토 모듈과 숫자 JSON을 사용하고, 152개 자세를 94개 동작·연결 묶음으로 연결했다. 같은 자세는 여러 동작에서 공유한다. 자세 번호는 타이밍이 아니다. 동작 수·수치·IK 방식이 사용자에게 사전 승인된 설계라는 뜻은 아니다.
- **구현상 판단:** 보행 하체 방향은 확정하지 않고 정면 조준을 유지한 전후좌우 스텝 후보로 표시했다. 총 슬롯 접근 실패는 성공으로 숨기지 않고 미도달 거리를 기록했다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1·U2를 수용해 제작 흐름·기본 무기 사양·메카 제작 규칙에 실루엣과 자연스러운 관절 굽힘 확인을 추가했다. 최신 지시에 따라 각도 Constraint와 임시 허용각은 추가하지 않았다.
- 이전 검 대기 후보를 승인된 자세로 재사용하지 않고 사용자가 지정한 현재 기본 파일의 해시에서 새 후보를 만들었다. 원본과 기존 후보를 보존했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1의 허용각 후보 검토는 처음 응답 후 U2로 철회됐다. 현재 수용 범위는 제한 없이 키포즈를 만들고 피드백한다는 요청이다.
- 이번 152개 키포즈·동작별 수치·외형·연결 방식에 대한 사용자 승인은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

- **I1:** 기준 파일의 총 파지 앵커가 오른손 손바닥에서 크게 벗어났다. 새 후보 제작 과정에서 AI가 확인했다. 부모 본은 오른손이며 앵커의 배치·방향 보정이 필요했다. 원본의 문제가 언제 생겼는지는 이번 작업에서 조사하지 않았다.
- **I2:** 총의 반대편 슬롯 손잡이 접촉은 기본 비율과 현재 장착 배치에서 자연스러운 자세로 해결하지 못했다. 몸통을 과도하게 돌려 수치상 도달하는 자세는 최종 해법으로 채택하지 않았다.
- **I4:** 일부 사격·근접 자세에서 전완/손과 가슴 장갑 표면 교차를 확인했다. 팔꿈치 위치만 바꾼 첫 시도는 양손 조준을 해결하지 못했다. 손 위치도 조정한 비교 뒤 한손 사격과 일부 근접 25개 자세를 보정했다. 양손 조준과 슬롯 접근의 간섭은 아직 남아 있으며 원본 비율·리그·무기 형상을 바꾸지 않고 초안의 수정 대기 항목으로 남긴다.
- **I3:** 전체 자세를 한 구도에 맞추면 무기를 높이 드는 극값 때문에 평상시 자세가 작고 화면 아래에 표시됐다. AI가 실제 이미지에서 확인하고 정지 자세별 고정 구도로 다시 렌더했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2에 따라 각도 제한의 선행 구성 대신 초안 제작과 사용자 피드백 흐름을 적용했다. 아직 받지 않은 자세 피드백이나 승인을 작성하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 새 후보에서만 총 파지 앵커를 손바닥에 맞췄다. 원본, 무기 형상, 오른손 파지 부모와 반대쪽 수납 대응은 유지했다.
- I2: `gun_slot_contact`는 슬롯 접근 후보이며 손잡이 접촉 미해결로 명시했다. 목표 손목 위치까지 약 0.3656 월드 단위의 미도달 거리가 남는다. 실제 미터 크기는 프로젝트에서 확정하지 않았으므로 미터로 환산하지 않는다. 장착부·팔 비율이나 승인된 형상을 임의로 바꾸지 않았다.
- I3: 기존 `model_review.py`에 선택적 Workbench·베벨 제외·자세별 구도 설정을 추가했다. 전체 형상을 사용하며 각 자세의 6면·사선과 확대/표시 크기 조건은 고정한다. 기본 Cycles 경로는 유지한다. 게임 시트와 연결 동작용 구도 변경은 아니다.
- 공통 제작·갤러리·독립 구조 검사와 게임 에셋이 필요 없는 기본 도형 시연을 제공했다. 연결 동작·연속 인출·전체 장갑 간섭·게임 반응은 별도 검증이다.
