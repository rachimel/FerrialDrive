- 상태: 사용자 명시 승인 / 파일 이동·경로 수정 완료 / 자동 검사 완료 / 화면·DCC 재로딩 미검증 / 커밋·업로드 미수행.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 중구난방인 `data/`를 정리한다. 이유는 사용자가 직접 밝힌 폴더 배치의 혼란이다.
- **사용자 제안 2 (U2):** AI의 분류안에 `ㅇㅇ 그렇게 해줘 이동과 참조 경로는 수정해줘`로 승인하고 이동·참조 수정의 실행을 요청했다. 제안·수용 시각은 scope의 누락 항목을 따른다.

## 2. AI가 제안한 것

- **AI 제안 1 (A1):** 제작 원본은 `source/`, 실행 데이터는 `runtime/`, 참고 자료는 `references/`, 실험·보관 자료는 `experiments/`로 묶고 `fonts/`·`settings/`를 유지한다. 이유는 원본·실행·실험 자료가 같은 깊이에 섞인 상태를 해소하기 위해서다. 출처는 U2 직전의 AI 분류표이며 정확한 발언 시각은 scope에 포함한다.
- **구현상 판단:** 현재 게임이 읽는 압축 아틀라스는 `runtime/textures/`, 투영 좌표는 `runtime/animations/`, 기존 이관 기록은 `experiments/migrations/`로 분류했다. 날짜별 후보와 카탈로그의 교차 참조는 보존했으며 삭제하지 않았다. 세부 배치는 [데이터 배치](../../data/README.md)를 따른다. 이 세부 경로 각각에 별도 사용자 승인을 받았다고 주장하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1·U2를 수용하여 15개 경로를 이동하고 코드·현재 문서·설정·제작 요청의 참조를 수정했다. 기존 사용자 변경을 되돌리지 않았고 에셋을 삭제하지 않았다.
- 과거 개발 로그와 보관 이관 스크립트는 당시 경로를 유지한다. 현행 실행 경로의 근거로 사용하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1은 U2의 명시 응답으로 수용되었다. 이 승인은 분류·이동·참조 수정의 범위이며 게임 외관이나 동작 품질 승인이 아니다.

## 5. 반영 후 발견한 문제

- **I1:** 실제 이동 전 백업 하위 경로 생성에서 접근 오류가 발생했다. AI가 준비 단계에서 확인했으며 실제 데이터 이동은 시작하지 않은 상태였다.
- **I2:** 최초 경로 수정 후 추가 검사에서 아틀라스의 `sources`처럼 파일 경로를 사전의 키에 저장한 항목이 남아 있는 것을 AI가 확인했다. 경로 수정 대상에 값뿐 아니라 해당 키도 포함해야 했다.
- **I3:** 확장 자동 검사에서 Python 3.11용 보조 numpy/Pillow가 Python 3.13 가상환경보다 먼저 import되는 환경 충돌을 확인했다. 최초 확장 실행은 69개 중 오류 7개·건너뜀 1개였으며 성공으로 처리하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2의 이동·참조 동시 수정 요구를 실제 작업 범위로 유지했다. I1~I3 확인 이후 사용자의 별도 해결 제안은 이번 대화에 없었다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1:** 원문 백업을 짧은 식별 파일명으로 보관하도록 변경한 뒤 준비를 완료했다. 이동은 절대 경로와 `data/` 범위·링크 유무를 검사한 Native PowerShell `Move-Item`으로 수행했다.
- **I2:** 경로를 저장한 사전 키와 관련 메타데이터 해시를 추가 갱신했다. 경로 수정 전후 메타데이터와 이동 기록을 로컬 자동화 작업본에 보존했다. 원래부터 일치하지 않던 해시를 임의로 정상화하지 않고, 기존 입력 해시와 일치하는 연결만 이동 결과에 맞춰 갱신했다.
- **I3:** 패키지를 설치하거나 제품 코드를 변경하지 않고 기존 Python 3.13 가상환경의 호환 numpy/Pillow를 먼저 import하여 검사했다. 재실행은 69개 실행·실패 0·오류 0·건너뜀 1이었다.
- **파일 보존:** 이동 전 33,036개 파일의 전체 SHA-256을 수집했다. 이동 후 참조·해시를 수정한 메타데이터를 구분하고, 나머지 파일의 크기·해시와 모든 원본 파일의 존재를 대조하여 실패 0을 확인했다. 약 7.424GB의 원본 데이터가 대상이었다.
- **참조:** 이동 전 존재한 JSON 파일 참조 64,230개가 이동 후 같은 대상으로 연결되는지 대조하여 실패 0을 확인했다.
- **실제 로더:** 에셋 카탈로그 22개·정의 169개, 보간 카탈로그 13개, 현재 고·중·저 품질별 376개 동작의 아틀라스 페이지·입력 경로·입력 해시 검사를 완료했다.
- **공개 제외:** 새 `source/`·`runtime/`·`references/`·`experiments/`의 에셋은 기존 `/data/*` 제외 규칙을 유지한다. `data/README.md`만 안내 문서로 추적할 수 있도록 예외를 추가했다.
- **미검증:** 실제 게임 창 조작·시각적 반응·성능, Blender·Unreal에서의 재로딩 및 파일 내부의 외부 경로 표시. 자동 검사 결과를 이 범위의 검증이나 사용자 외관 승인으로 확대하지 않는다.
