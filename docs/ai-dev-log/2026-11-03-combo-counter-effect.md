# 콤보에 동일한 카운터 효과 적용

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 현재 누적 피해 카운터의 효과를 콤보에도 적용한다.
- 숫자 표시를 공통 `UiView.number_counter`로 정리했다. 변경 자리만 위쪽 밀기·이전 숫자 페이드·위쪽 방향성 블러를 적용하고, COMBO·DAMAGE 라벨과 같은 숫자 자리는 고정한다.
- 기존 콤보 폰트 76px·색·위치·COMBO 기준선 정렬을 유지한다. 피해 숫자에는 기존 쉼표 형식을, 콤보에는 쉼표 없는 정수를 사용한다. `combo_max_width=312`를 추가해 긴 값에서도 라벨 공간을 확보한다.
- 콤보와 피해는 `damage_counter`의 효과 설정을 공유하고 독립된 `RollingCounter`로 진행한다. 실제 샘플 수치와 구분하며, 연속 입력은 각 최신 값으로 병합한다. 초기화·값 감소는 즉시 반영한다.
- 변경 코드와 차이를 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 적 피해로 두 효과 동시 진행, 플레이어 피해·타겟 전환에서 재생 없음, 초기화 시 두 잔상 제거를 확인한다.
