# 레이더 원 안의 화살표 숨김·HUD 범위 평가

- 작성일: 2026-11-03, 한국 시간
- 사용자 확인: 화살표를 숨길 범위는 감지 거리 전체가 아니라 화면의 플레이어 중심 200px 원 안이다.
- `RadarContact`에 필수 화면 픽셀 좌표 `screen_x/screen_y`를 추가했다. 감지용 상대 좌표 x/y는 거리별 크기·알파와 감지 범위 판정에 유지하고, 화면 좌표는 링 내부 숨김과 화살표 방향에 사용한다.
- 화면 거리 200px 이하에서 숨긴다. 아군·감지 범위 밖·영벡터 제외도 유지한다. 필수 화면 좌표를 공급하는 호출부는 현재 테스트의 JSON 로더 한 곳이며 샘플 전체에 값을 넣었다.
- 샘플의 근거리 적 화면 좌표를 훈련 표적 (756,342)와 맞춰 화살표를 숨긴다. 중거리·감지 한계 적은 원 밖이므로 2개의 화살표가 남는 구성이다.
- 타겟은 고정 샘플 표시·숨김과 가짜 HP 갱신만 지원한다. 조준 기반 선택·전환·적중 판정은 구현되지 않았다. HUD 표시·반응의 기본 구성과 실제 전투 연결 완료를 구분한다.
- 소스·호출부·샘플과 문서를 읽어 대조했다. 자동 검사·실행·화면 조작은 수행하지 않았다. 원 내부·경계·외부에서의 화살표, 먼 적 크기·알파, 실제 게임 좌표 연결은 사용자 확인 대기다.
