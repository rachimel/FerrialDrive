# 기본 무기 동작 초안과 HTML 미리보기

기록일: 2026-11-09. 개별 발언 시각은 [[FDLOG_MISSING_TIME:animation-blocking-preview:scope]]. 근거는 현재 대화의 “preview html”, “다른 각도에서도”, “손가락이 앞쪽”, “살짝만 숙여”다.

## 1. 사용자가 제안한 것

**U1**: 중립 모델을 기준으로 모든 동작에 과장된 팔·어깨·허리 움직임, 스텝과 체중 이동을 적용하고 HTML 미리보기를 만든다. 이완 자세는 완만한 곡선 또는 일직선이며 중간 프레임의 관절 비틀림도 확인한다.

**U2**: 검의 손·하박을 확대하고 다른 각도에서도 확인한다. 검은 파지 위치를 맞추고, 총은 앞으로 뻗는다. 총을 잡는 손은 손가락이 앞을 향하고 손바닥 면이 세워진 형태다. 머리와 총의 거리를 유지하며 허리는 약하게만 숙인다.

## 2. AI가 제안한 것

**A1**: 기존 프레임 기반 출력 도구를 유지하고 35개 동작 초안을 사선·측면 렌더와 네 방향 손 확대 이미지로 검토한다. 12fps 재생, 프레임 이동, 느린 재생, 4타 연속 재생을 제공한다.

## 3. 사용자 제안 중 AI가 수용한 것

U1·U2를 작업본에 적용했다. 기준 `base_pose.blend`는 읽기 전용으로 사용한다. 파지 수정 중 사용자의 설명을 “손가락 아래”로 잘못 해석했으나 “손가락 앞”으로 정정했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

HTML 미리보기 제작은 U1의 명시 요청이다. 개별 수치와 전체 동작 외관의 최종 승인은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

**I1**: 첫 검 초안은 손잡이가 손가락 길이 방향에 놓였고 파지 중심도 손목에 가까웠다. 전역 축 기반 하박 굽힘이 몸통 회전 시 부자연스러운 움직임을 만들었다.

**I2**: 첫 조준 초안은 총이 뒤에 있었고 허리 기울기가 과했다. 양손 파지의 도달 범위도 맞지 않았다.

**I3**: 기존 분할 스커트의 무가중치 정점 125개가 골반 이동을 따르지 않았다. 작업본에서 기존 연결 스커트의 가장 가까운 정점 가중치를 전달했다. 기준 모델은 변경하지 않았다.

**미완성 범위**: 무기 전환의 정확한 손 접촉·연속 발도 경로, 찌르기의 칼끝 방향과 세부 공격 궤적, 전 프레임의 장갑 충돌은 승인되지 않았다. 현재 결과는 동작 폭과 타이밍을 검토하는 초안이며 완료된 게임 애니메이션이 아니다.

## 6. 사용자 해결 제안과 실제 해결 과정

U2에 따라 검 대기·내려베기·찌르기·총 조준을 정면/측면/반대 사선/손바닥 쪽에서 확대 출력했다. 총 손가락은 전방, 손바닥 면은 세로로 맞췄다. 조준 허리는 구현상 임시값 5도로 낮추고 팔로 총을 전방에 배치했다.

## 7. AI 해결 제안과 실제 해결 과정

기존 DCC-MCP Blender 연결, 중립 리그, `animation_pipeline.py`의 bake·재로딩·클립/이벤트/export_configs 출력을 재사용했다. 기존 제작 재사용 검토의 연속 작업이며 새 외부 에셋·플러그인은 없다. 원본 제작 JSON에서 손가락 파지 수치만 가져오고 거절된 팔 포즈는 재사용하지 않았다.

공통 모듈 `motion_blocking.py`는 JSON 핵심 자세와 보행 매개변수를 평가하고 `build_motion_preview.py`는 PNG를 WebP 아틀라스와 로컬 HTML로 묶는다. 자산 설정은 `Tools/blender_pipeline/workspace/basic_weapons/animation_blocking/config.json`이다.

- 소스: `data/models/basic_weapons/base_pose.blend`, SHA-256 `e38afa282013db01f42f1ceea7e38eb7ba47e5d4593ff19e6599f2bb149630d2`.
- 동작 작업본: `data/models/basic_weapons/animation_blocking/animations.blend`.
- 총 35개 클립, 736개 표본, 12fps. 동작마다 필요한 길이를 사용했다.
- 미리보기: `output/animation_preview/preview.html`. 외부 서버 없이 같은 폴더의 아틀라스를 읽는다.
- 손/하박 확대: `output/animation_preview/hand_review/`.
- 자동 확인: 저장·재로딩 포즈 오차, 부착 상태 이산 전환, 유한 행렬, 클립/이벤트 프레임 범위, 이미지 누락과 HTML 스크립트 구문을 확인한다. 각 확인의 실제 결과는 작업 출력 보고서에 둔다.
- 시각 확인: 대표 이동 자세와 주요 파지 자세를 직접 확인했다. 전체 동작을 사용자가 승인한 것으로 기록하지 않는다. 실제 브라우저 조작 및 게임 실행은 별도 미검증이다.
