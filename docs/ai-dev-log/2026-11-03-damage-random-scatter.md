# 이번 피해 숫자를 피격 위치 주변에 무작위 배치

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 데미지 숫자를 위로 올려 사라지게 하지 말고, 공격 받은 쪽에 무작위로 뿌려 본다.
- HIT·DAMAGE 카운터들이 아닌 기체 근처의 이번 피해 숫자를 변경했다. 적 피해는 적 기준, 플레이어 피해는 플레이어 기준으로 생성한다.
- 피격 시 x·y 오프셋을 한 번 추출해 표시 위치를 정한다. 이후에는 위치를 유지하며 기존 1.15초 SmoothStep 페이드로 사라진다. 위쪽 이동량과 머리 위 고정 오프셋 설정은 제거했다.
- 분산 범위는 x ±64px·y ±44px의 시안이며 `animation.damage_scatter_x_pixels`·`damage_scatter_y_pixels`에서 조절한다. UI 전용 난수 인스턴스를 사용해 전역 난수 상태와 분리했다.
- HIT·DAMAGE 카운터들의 적중 출현·탄성 이동·페이드·블러·합계 계산과 HP 계산은 유지한다.
- 코드·설정·문서를 읽어 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 적·플레이어 피해 버튼으로 각 피격 기체 주변의 무작위 생성, 표시 중 위치 고정·페이드, 연속 피격 시 배치를 확인한다.
