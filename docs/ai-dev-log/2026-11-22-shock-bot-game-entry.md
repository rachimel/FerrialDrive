# Shock Bot 교전과 본편 진입점

**기록 ID** `FDLOG-20261122-shock-bot-game-entry` · 2026-11-22 KST · 본 대화와 Unreal·Pico2D 실행 결과.

## 1. 사용자가 제안한 것

- **U1** 준비한 인간형 적을 먼저 연결하고 게임의 `main`을 시작한다. 검색 단서는 `일단 인간형 적 만들어 둔거 연결하자`다.
- **U2** 플레이어와 전고를 맞춘 `form_04_player_size`의 외형을 승인하고 Unreal 프리렌더와 교전 연결을 진행한다. 검색 단서는 `승인하고 연결`이다. 발언의 정확한 KST 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261122-shock-bot-game-entry:U1-U2]]로 남긴다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1–U2** 승인한 `.blend`의 해시를 고정하고 형상·UV·재질을 Unreal로 인계했다. 새 리그와 동작을 작성한 뒤 2D 시트로 패킹하고 기존 인간형 전투 상태에 연결했다.
- **U1** `main.py`에서 FDrive 실행부를 사용한다. `game/`이 본편 시작 상태와 첫 교전 데이터를 소유한다.

## 3. AI가 제안한 것

- **A1** 초기 본편은 기존 타이틀과 전투·HUD를 재사용하고 `START → NEW GAME`에서 Shock Bot 한 기로 시작한다. 타이틀 복귀와 재시작을 앞단에서 확인하기 위한 구현 범위다. 근거는 독립 교전에서 검증한 인간형 AI와 PRE-PRD의 초기 전투 목표다.
- **A2** 기존 PBR 소형·중형 옆에서 인간형 한 종의 8방향 본체 시트를 함께 읽도록 했다. 발사 효과는 Unreal의 전완 발사구 위치를 투영한다. 배율은 플레이어의 전고와 카메라를 기준으로 맞췄다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U2** `form_04_player_size` 후보와 Unreal 출력 및 전투 연결 단계의 진행을 승인했다. 보정된 게임 화면과 조작감은 사용자 검토 대상이다.

## 5. 반영 후 발견한 문제

- **I1** Unreal이 원본 FBX 슬롯의 공백과 `|`를 보존해 최초 재질 이름 대응이 실패했다. 명령줄 모드의 골격 편집에는 Slate가 필요했고, 기존 시드의 Skeleton은 다른 리그에서 사용 중이었다.
- **I2** 정면·측면 프레임 검수에서 초기 근접과 사격 팔이 후방을 향했고 격파 자세의 발이 지면을 통과했다. 실제 전투 렌더에서는 기존 록온 표시가 새 기체의 다리에 걸렸다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U2** 사용자가 선택한 크기 조정 후보의 형상·재질을 기준으로 이관과 프리렌더를 진행했다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1** 원본 슬롯 이름과 유효한 Unreal 에셋 이름을 따로 지정했다. 발광색을 sRGB 텍스처로 베이크했다. Unreal 편집기에서 고립된 단일 Root 시드를 새로 가져왔고 52개 형상, 8개 재질, 새 Skeleton과 AnimSequence를 저장했다.
- **I2** 팔 회전 부호를 고쳤다. Unreal 저장 좌표에서 근접 방호판 81.0cm, 사격 포구 60.55cm의 전방 이동을 확인했다. 이동·격파의 렌더 표본별 최소 발 정점을 지면에 맞췄다. 록온 표시는 스프라이트 범위에서 몸통 높이를 구한다.
- 최종 로컬 런타임은 `data/runtime/catalog/prerender/enemy_humanoid_shock_bot_r02/`에 있다. 이동·근접·사격·피격·격파 5종의 8방향, 12fps, 40클립 320프레임을 확인했다. 본체 시트의 RGBA8 크기는 약 62.8MiB다. 개별 프레임의 알파·잘림과 여러 방향의 자세를 확인했다. 작성 입력과 렌더 증거는 각각 `automate/workspace/enemy_humanoid_shock_bot/`, `output/enemy_humanoid_shock_bot/`에 있다.
- 본편은 `main.py`의 타이틀에서 시작하고 첫 교전의 플레이어 체력과 적 배치를 별도 데이터로 읽는다. 사격·피격, 일시정지, 타이틀 복귀, 재시작과 Combat Test의 세 기종 표시를 지정 입력으로 검사했다. 기존 타이틀·HUD·전투 자동 검사 73개가 통과했다. 세이브·로드·Survival과 사용자의 직접 조작 확인은 후속 범위다.
