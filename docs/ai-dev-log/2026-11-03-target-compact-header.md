# 타겟 패널을 한 줄 제목과 얇은 HP 바로 압축

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: TARGET은 왼쪽, 적 이름은 오른쪽 정렬하고 HP 숫자는 숨긴다. HP 바를 더 얇게 하고 전체를 컴팩트하게 만든다.
- TARGET과 적 이름을 같은 줄·기준선에 배치했다. 오른쪽 이름은 최대 300px에서 말줄임하며, 타겟 없음도 같은 위치에 오른쪽 정렬한다.
- 타겟 HP 숫자 그리기와 사용하지 않는 `target_value` 폰트·좌표 설정을 제거했다. 내부 HP·피해 계산은 유지하고 비율만 바에 전달한다.
- 패널 높이 120→64px, HP 바 두께 10→4px, 좌우 패딩 24→16px로 줄였다. 패널 폭 464px과 중앙 배치·색·알파는 유지한다.
- 변경 코드·설정·명세를 읽어 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 같은 줄의 양쪽 정렬, HP 숫자 숨김, 피해 시 바 감소, 타겟 없음 표시를 확인한다.
