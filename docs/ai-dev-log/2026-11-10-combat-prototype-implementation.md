## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 합의한 도형 기체·적 한 기·일반 적의 별도 경고 표시 없는 전투를 직접 구현한다.
  - 이유·판단 근거: 앞선 구조 검토와 “ㅇㅋ 일단 그렇게 구현해줘”라는 명시 구현 요청. 에셋에 시간을 오래 쓰지 않겠다는 이유는 앞선 구조 검토 U1에서 직접 제시했다.
  - 시각·출처: 현재 대화, 위 TIME 누락 참조.
- **사용자 제안 2 (U2):** 실제 테스트는 사용자가 직접 수행한다.
  - 판단 근거: AI가 실제 창 조작을 확인하던 중 “일단 테스트는 내가할게”라고 역할을 지정했다. 별도 선택 동기는 추정하지 않는다.
  - 시각·출처: 현재 후속 발언, 위 TIME 누락 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 재사용 전투 규칙·화면 표현·입력 연결·독립 실행부와 공개 도형 샘플을 구현했다.
- U2: 추가 직접 조작·테스트를 중단하고 시작 대기 상태의 실행 창을 유지했다. 이후 작업은 안내·상태 기록·변경 범위 확인으로 제한했다.
- 수용 근거·시각: 현재 진행 보고, 위 TIME 누락 참조.

## 3. AI가 제안한 것

- **AI 제안 1 (A1, 구현상 판단):** 120Hz 고정 갱신, 플레이어 중심 카메라, 실제 피해를 기존 HUD 표시 규격에 연결한다. 속도·거리·시간·피해량은 설정에 분리한다.
  - 이유·판단 근거: 표시 FPS와 판정을 분리하고 에셋 교체·본편 재사용 범위를 유지하기 위함이다.
  - 시각·출처: 현재 코드와 진행 보고, 위 TIME 누락 참조. 수치를 사용자 확정 밸런스로 취급하지 않는다.
- **AI 제안 2 (A2, 구현상 판단):** 검 4단 연계·전 구간 대시 캔슬·초기 대시 공격, 45발 총·자동 재장전, 적 우회·승패/재시작을 첫 실행에 연결한다.
  - 이유·판단 근거: 현행 기본 무기·이동 요구와 합의한 적 한 기 교전 범위를 작은 도형 훈련장에서 확인하기 위함이다.
  - 시각·출처: 현재 구현, 위 TIME 누락 참조.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U1은 앞선 검토안을 바탕으로 직접 구현을 명시 요청한 근거다.
- 이번 임시 수치·개별 알고리즘·실제 조작감·시각 품질의 사용자 승인은 아직 없다. U2를 검증 통과나 최종 품질 승인으로 해석하지 않는다.

## 5. 반영 후 발견한 문제

- **I1:** 자동 검사에서 적이 장애물 모서리 근처에 멈췄다. 도착 허용 오차 때문에 다음 경로 계산의 확장 사각형 안에 시작점이 들어간 것이 원인이다. AI가 검사 실패와 위치·경로를 확인했다.
- **I2:** 첫 실제 창 확인 권한 요청이 시간 초과됐고 백그라운드 실행 창이 다시 조회되지 않았다. 그 창이 없어진 정확한 원인은 확정하지 않았다. 이후 표시 프레임 제한 실행은 정상 종료로 확인했다.
- **I3:** 실제 창의 AI 키 입력 후 화면 변화는 확인하지 못했다. 입력 도구 호출을 성공한 게임 조작으로 기록하지 않는다. 사용자 직접 테스트 요청으로 추가 검증을 중단했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2 ↔ I3: 사용자가 테스트를 맡겠다고 했다. AI는 추가 조작을 중단하고 실행 안내와 확인 범위를 정리했다. 사용자의 테스트 결과는 아직 받지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 우회 모서리 여유와 도착 허용 오차를 조정하고 가시성 검사 여유를 실제 기체 반경과 맞췄다. 장애물 우회 후 플레이어를 공격하는 회귀 검사가 통과했다.
- I2: 별도 실행 세션으로 창 수명을 유지하고 시작 화면·HUD 배치를 확인했다. 프레임 제한 종료와 원인 미확정의 첫 종료를 구분했다.
- 전투 규칙 22개·Pico2D/SDL dummy 연결 6개, 기존 UI 55개를 실행해 통과했다. SDL dummy 3프레임 실행과 선택 계측 저장을 확인했다. Runner의 소스 검사에서 `standalone`으로 판별했다.
- 사용자의 직접 테스트 요청 이후 추가 검사는 수행하지 않았다. 전투 조작감·가독성·최종 품질·목표 성능·사용자 승인은 미검증이다.
- 현재 실행·범위는 [전투 명세](../unit-tests/combat_prototype.md), 조작은 [공개 샘플](../../samples/combat_prototype/README.md)을 따른다. 기존 사용자 변경을 되돌리지 않았고 AI 에셋은 생성하거나 추가하지 않았다.
