# UI v2 공통 점멸 타이밍·GIF 색상표 수정

- **기록 ID: ui-v2-synchronized-blink**. 대화·구현·검증·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-synchronized-blink:scope]] 검색 단서: `다 합치고`, `주기 더 짧게하고`, `타겟 HP 바`, `GIF 미리보기가 이상한걸로`.

## 1. 사용자가 제안한 것

- **U1**: 점멸을 합치고 주기를 더 짧게 하며 같은 주기로 반복하도록 요청했다.
- **U2**: 타겟 HP 바가 점멸하는 이유를 물었다. 후속 질문에서 제공된 GIF 미리보기가 이상한 것으로 정정했다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 공통 타이밍으로 반영했다. 대상별 seed/위상을 제거하고 기존 선택 글자들이 같은 밝기로 교대하게 했다. 대상 범위를 전체 UI 글자로 확대하지 않는다.
- U2의 타겟 HP 바를 원본 PNG와 GIF에서 각각 비교했다. 타겟 HP 바의 게임 코드에는 점멸을 추가하거나 제거하지 않았다.

## 3. AI가 제안한 것

- **A1**: 100% 밝기 0.15초 → 50% 밝기 0.15초, 총 0.3초 반복을 더 짧은 시험값으로 제시하고 구현했다.
- **A2**: 프레임마다 달라지는 GIF 색상표 대신 공통 색상표와 고정 양자화를 사용했다. GIF 시간 단위에 맞춰 프레임 시간을 10/20/20ms로 배분해 재생 시간을 보존했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 공통 타이밍과 더 짧은 반복은 사용자 요청이다. 0.3초 세부 수치·최종 외관은 사용자 확인 전 시험값이다. GIF 변환 방식은 AI의 진단과 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1**: 직전 GIF의 타겟 HP 바 영역은 60프레임 중 59프레임에서 색이 달랐지만, 원본 PNG 120프레임의 같은 영역은 일정했다. 미리보기 변환의 색상표 변화로 게임에 없는 깜빡임이 생겼다.
- AI는 처음에 HP 바와 글자의 밝기 연결 가능성을 언급했으나 코드 확인으로 직접 연결되지 않았음을 정정했다. 제품 버그를 확인한 것으로 기록하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2의 후속 정정으로 실제 게임이 아닌 GIF 미리보기를 진단 대상으로 확정했다. HP flash 등장/퇴장과 빨간 Trail은 그대로 유지한다.

## 7. AI 해결 제안과 실제 해결 과정

- UI 자동 검사 **127개 통과**. 0.3초 반복·50% 하한과 기존 효과를 검사했다.
- 실제 SDL **126프레임**에서 프레임별 모든 글자 점멸 호출의 밝기가 동일하며 18프레임마다 같은 패턴이 반복됨을 확인했다.
- 공통 색상표 GIF로 I1을 해결했다. 원본/디코딩한 GIF에서 타겟 HP 바 영역의 픽셀 변화가 모두 0이고 GIF 총 재생 시간은 2,100ms였다. 밝음/감광 비교 이미지를 직접 열어 확인했다.
- 출력은 `output/ui_unit_test_v2/synchronized_blink/`다. 실제 창 조작·최종 사용자 외관 승인·업로드는 미수행이다.
