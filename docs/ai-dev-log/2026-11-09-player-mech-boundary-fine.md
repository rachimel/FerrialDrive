# 플레이어 메카 구분선 대비와 적용 범위 조정

**기록 ID: player-mech-boundary-fine.** 2026-11-09 KST의 현재 대화와 당일 실행 결과다. 개별 발언 시각은 미확인이다. [[FDLOG_MISSING_TIME:player-mech-boundary-fine:scope]] 현재 대화 원문 시각으로 보완한다.

## 1. 사용자가 제안한 것

**사용자 제안 1 (U1)**: 가슴·스커트·어깨 선이 잘 안 보인다며 더 진하게 하고, 투구와 ‘무름 장갑’에도 추가해 보도록 요청했다. AI는 해당 표현을 무릎 장갑으로 이해한다고 밝혀 적용했다. 출처: “지금은 잘 안 보이는 듯 헬멧에도 구분선 한번 넣어봐”. 이유는 선의 낮은 가시성이다.

**사용자 제안 2 (U2)**: 이후 선을 가늘게 하고 스커트는 앞·뒤 돌출부에만 남기도록 범위를 수정했다. 출처: “스커트는 구분선은 앞이랑 뒤의 돌출부에만 넣자”. 세부 스타일 선택의 별도 이유는 미제시다. [[FDLOG_MISSING_REASON:player-mech-boundary-fine:U2]] 해당 발언 전후 설명으로 보완한다.

## 2. 사용자 제안 중 AI가 수용한 것

U1의 짙은 색과 투구/무릎 추가를 유지하면서 U2를 최종 기준으로 삼았다. 스커트 옆면과 전체 골반 외곽은 해제하고, 지정 장갑의 앞/뒤 방향·외측 위치 범위에만 마스크를 생성한다. 얼굴 안쪽·목 띠·팬 유리에는 추가하지 않는다.

## 3. AI가 제안한 것

**AI 제안 1 (A1)**: 재생성 시 기존 경계 UV/속성을 명시적으로 갱신하고 부위별 선 폭을 구분한다. 구현상 판단이다. 최종 선 폭 0.0045, 투구 0.003, 무릎 0.004와 강도 0.97은 사용자 지정 수치가 아니다. 공유 재질·무광·원래 UV/리그를 보존한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

범위와 선폭 축소는 사용자 지시다. 구현 수치와 이번 최종 외관에 대한 별도 수용은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

적용 대상을 줄일 때 기존 적용 속성이 남으면 빠진 골반 외곽에도 새 마스크가 잘못 표시될 수 있었다. 또한 같은 출력 경로를 반복 갱신할 때 기존 이미지 데이터가 중복/구버전으로 남지 않도록 갱신 경로를 보완했다. 구현 중 확인한 재생성 경계이며 사용자에게 새 문제 발생으로 보고한 것은 아니다.

## 6. 사용자 해결 제안과 실제 해결 과정

U2에 따라 스커트의 전체 외곽 적용을 해제하고 앞/뒤 돌출 장갑으로 제한했다. 짙은 색은 유지하고 선 폭을 줄였다.

## 7. AI 해결 제안과 실제 해결 과정

공통 경계 마스크 연산에 명시 갱신, 부위별 선 폭, 면 방향/위치 필터, 기존 대상 해제를 추가했다. 같은 경로의 이미지 데이터도 갱신한다. 최종 대상은 26개 메시이며 마스크는 기존 1K 한 장을 교체했다. 기존 UV_Paint/UV_Panel·형상·리그·재질 공유·무광·발광·팬 유리는 보존했다.

정면·사선·후면 1024px/240px 렌더를 확인했다. 독립 샘플에서 경계 UV 중복 방지, 기존 UV 보존, 개별 선 폭, 면 방향/위치 선택, 대상 해제, 이미지 중복 방지와 갱신 내용, 저장·재로딩을 검사했다. 새 경계 UV 범위/면적 검사도 통과했다.

원본 반영 후 별도 Blender에서 형태/리그/기존 UV·재질 슬롯, 노멀/발광/유리·무광 설정, 적용/해제 속성, 125개 이미지의 내용·상대 경로를 확인했다. 릴리스·레지스트리·기본 제작 해시를 동기화했다. 모델/텍스처는 로컬 제외 대상이다. 최신 실행 근거·렌더·복구 모델과 마스크는 `output/player_mech_boundary_fine/`에 있다. 전체 모션/성능과 사용자 최종 외관 승인은 이번 검사에 포함하지 않는다.
