# 기체 v073 — 중앙 링·직선 경로·하체 아틀라스

- 기록 ID: FDLOG-20261108-player-mech-v073-center-ring-atlas
- 출처: 현재 대화의 가슴 주석 이미지, 머리 링 참고 이미지와 “젖꼭지들 없애고”, “곧은 Path”, “다리랑, 스커트, 허리를 개별 아틀라스”, “가슴 단차 사이에 패널 경계”. 개별 발언 시각 미확인: [[FDLOG_MISSING_TIME:FDLOG-20261108-player-mech-v073-center-ring-atlas:request]] 현재 대화의 해당 원문 시각으로 보완한다.

## 1. 사용자가 제안한 것

- 양쪽 가슴 접속 장식을 없애고 중앙 돌출부에 참고 이미지와 같은 원형 링을 배치한다.
- 에너지 경로는 복잡한 회로 분기 대신 뒤 리액터로 이어지는 곧은 경로로 한다.
- 다리·스커트·허리를 개별 아틀라스로 분리하고 가슴 단차에 패널 경계를 넣는다.

## 2. 사용자 제안 중 AI가 수용한 것

- 기존 1K 제한을 유지하며 요청한 부위와 경로를 v073 사본에 반영한다. 접속 패널에 붙은 짧은 배관도 함께 숨긴다.

## 3. AI가 제안한 것

- 구현 판단: 중앙 링에서 좌우로 이어지는 얇은 리본형 경로가 흉갑 표면을 따라 뒤쪽 기존 고정 전력 버스에 연결되게 한다.
- 다리는 기존 독립 UV를 보존하고 새 재질 세트로 분리한다. 스커트와 허리는 재전개한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 핵심 변경은 사용자 명시 요청이다. 경로의 세부 배치와 최종 외관은 아직 사용자 승인 전이다.

## 5. 반영 후 발견한 문제

- 다리 전체 재패킹 시 다수의 작은 아일랜드 여백 때문에 선형 밀도가 기존의 약 0.54배로 줄었다. 이 중간 UV는 최종본에 적용하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 양쪽 가슴 패널/배관은 숨기고 해당 Boolean을 꺼 원래 흉갑 면을 복원했다. 중앙에 캡·금속 테두리·얇은 청색 링을 추가했다.
- 가슴의 분기 에너지 마스크를 제거하고 표면을 감싸는 연속 경로로 대체했다. 주석의 수평·수직 단차 위치에는 도장 경계를 넣었다.
- 다리/스커트/허리 세트를 별도 1K 이미지로 연결했다. 기존 가슴/팔의 전용 UV도 유지한다.

## 7. AI 해결 제안과 실제 해결 과정

- 다리는 원래 UV 배치로 복원해 텍셀 밀도를 보존했다. 스커트 약 2.54배, 허리 약 3.25배 선형 밀도이며 가슴 포함 4개 세트의 UV 겹침/퇴화 검사를 통과했다.
- v072와 비교해 기존 메시 480개의 좌표·면·본 웨이트·Shape Key를 보존했고 8개 메시를 추가했다. 123개 이미지가 최대 1K로 패킹되어 있다.
- v072 고리 축 성분 보존과 에너지 레벨 0/0.5/1을 검사했다. 팔을 25도 벌린 111개 회전/기울기 표본에서 본체 표면 교차 없음. 전투 모션·무기 장착·소켓 내부 접촉·실제 창 조작은 미검증이다.
- 정면·후면·전신 렌더로 외관을 검토한다. v072 원본 보존, 에셋 커밋/업로드 없음.
