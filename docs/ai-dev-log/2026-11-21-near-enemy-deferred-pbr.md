# 근거리 적 Deferred PBR과 Box 마스크 시험

**기록 ID** `FDLOG-20261121-near-enemy-deferred-pbr`

2026-11-21 19:28 KST까지의 구현과 비교를 기록한다.

## 1. 사용자가 제안한 것

- **U1** 근거리 적의 표면을 먼저 모으고 조명을 한 번 실행한다. Box 바닥 그림자도 한 패스로 묶고 같은 적 180기에서 프레임·GPU·메모리를 비교한다.
- **U2** 적 카탈로그가 키포즈 중심이며 중간 자세를 렌더 중에 보간한다는 점을 성능 원인으로 제기했다.
- 정확한 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-deferred-pbr:U1-U2]]이다. 검색 단서는 `근거리 적만 대상으로 Deferred PBR 테스트`와 `KeyFrame만 저장하고 보간`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `--variant deferred_enemies`에 두 기종 공통 표면 시트·조명과 Box 마스크를 연결했다. 기본 교전은 기존 경로를 사용한다.
- **U2** 두 경로 모두 표면 기록에서 같은 키포즈 보간을 수행함을 확인했다. 별도 대조에서 기체 본체 인스턴스의 보간율만 0으로 고정했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 시트에 기체별 슬롯을 유지해 기존 앞뒤 합성과 SMAA 확대를 재사용한다. G-buffer 첨부 4개에 표면을 모으고 공통 PBR 조명으로 한 번 해석한다. 반투명 파츠 여러 개가 같은 픽셀에 기여하면 해당 픽셀의 기존 합성을 표면 기록 단계에서 유지한다.
- **A2 · 구현상 판단** 근거리 Box의 투영 꼭짓점을 모아 반해상도 바닥 마스크에 한 번 제출하고 한 번 합성한다. 기체끼리 겹치는 Box는 마스크 안에서 합친다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 표면 후 조명 1회와 공통 Box 그림자 시험은 사용자 요청이다. 시트 슬롯 구조·마스크 배율·반투명 합성 처리 방식은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 표면 제출은 마지막 측정 프레임에서 기존 본체 배치와 같은 12회였다. 기체별 슬롯을 사용하는 시험이므로 다른 기체 뒤에 가려지는 픽셀을 거르지 않는다. 추가 렌더 타깃과 조명 패스가 프레임 개선으로 이어지지 않았다.
- **I2** 전후 화면에서 기체의 배치는 유지됐으며, 표면 정밀도와 그림자 경계에는 픽셀 차이가 있었다. 반해상도 Box 마스크는 겹침과 가장자리의 표현이 기존 포즈별 그림자와 다르다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** FHD·고품질·SMAA·Intel iGPU·180기 자동 검 교전을 준비 120프레임·측정 240프레임, Deferred→기존→기존→Deferred 순서로 실행했다. 두 경로 모두 같은 군집 공유 아틀라스를 사용했다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1 ↔ I1** 기존 경로를 기본으로 유지한다. 별도 적 렌더 GPU 구간은 평균 2.14→2.41ms, p95 3.55→4.72ms였다. GL 시간 질의에는 CPU 제출 간격이 포함될 수 있다. Deferred의 신규 표면·조명·마스크·포즈 테이블 논리 할당은 16.86MiB였다.
- **A2 ↔ I2** 마지막 프레임에서 근거리 PBR 본체 28기, 원거리 공유 시트 125기, Deferred 조명 1회, 근거리 Box 마스크 기록 1회를 확인했다. 마스크 화면 합성은 별도 복사 1회다.
