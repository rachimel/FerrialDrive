## 7. AI 해결 제안과 실제 해결 과정

- `ui/text_style.py`: 단일 문자열의 알파 채널을 슬라이스로 복사하고, 행별 RGB를 한 번 계산해 알파와 결합한다. 여러 글리프의 겹침 최대값·커닝·자간·획 축소 계산은 유지한다.
- `ui/pico_renderer.py`: 작업 폴더를 반영한 절대 경로로 정규화 결과를 캐시하며 종료 시 비운다. 기존 이미지 GPU 캐시 8개·Pico2D 원본·렌더링 방식·해상도·전투 규칙은 유지한다.
- I1은 기대 키를 현행 계약에 맞췄다. UI 기본·도형 필터·무기 카드·HUD 배치 관련 **43개 통과, 4개 제외**. 경로 재조회 방지·작업 폴더별 동일 상대 경로 분리·종료 정리를 검사했다. 전체 자동 검사는 미수행이다.
- 수정 전 소스 사본과 실제 SDL surface의 크기·RGBA를 영어/숫자/한글, 자간 0/5, 획 축소 0/0.55, 그라데이션 1/0.18/0의 **48가지**에서 비교해 모두 일치했다. 전투 캡처도 확인했으며 전체 모션 직접 조작 검수·사용자 승인을 뜻하지 않는다.
- 문자열 `45`·그라데이션 0.18 반복 생성: `TimingRecorder.benchmark()`로 20회×5묶음, 묶음당 예열 5회. 평균 **1.6841 → 0.1335ms**. 전체 프레임 개선율과 구분한다.
