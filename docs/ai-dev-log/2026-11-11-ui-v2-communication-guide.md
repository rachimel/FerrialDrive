# UI v2 통신 조작 가이드·Scanline 속도 조정

- **기록 ID: ui-v2-communication-guide**. 원래 대화·구현·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-communication-guide:scope]] 검색 단서: `밝은 띠는 좀 더 느리게`, `기본 scanline은 5px`, `조작 가이드를 대화창에 표시`, `기존의 조작 가이드`, `본문도 위로`.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: 밝은 띠를 느리게 하고 기본 Scanline은 5px로 조정한다. 현재 속도 문맥에서 5px/s로 반영했다. 별도 이유는 제시하지 않았다.
- **사용자 제안 2 (U2)**: 조작 가이드를 통신 패널에 표시하고 기존 조작 가이드는 제거한다. 사용자가 `기존의 대화창은 삭제`를 바로 `기존의 조작 가이드`로 정정했으므로 통신 패널은 유지한다.
- **사용자 제안 3 (U3)**: 헤더를 위로 올리고 이어서 본문도 위로 올린다. 근거는 현재 연속 후속 요청이다.
- **사용자 제안 4 (U4)**: 대화창 전체를 조금 더 위로 올리고 헤더에서 `통신`을 빼 `조작 가이드`만 남긴다. 근거는 현재 후속 발언이다.

## 2. AI가 제안한 것

- 구현상 판단으로 밝은 띠를 60px/s로 낮추고, 안내 4줄을 `small` 역할·20px 간격으로 넣었다. 헤더·본문은 위 여백 16px에서 8px로 함께 올렸다. 별도 수치/외관 승인은 확인 전이다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U3을 반영했다. 기본 선 5px/s·밝은 띠 60px/s이며 폭·밝기는 유지했다. 샘플 통신 문구를 조작 가이드로 교체하고 F1 안내 상태·입력·별도 그리기를 제거했다. 메뉴 안내도 통신 패널을 가리키도록 맞췄다.
- U4 후속은 패널을 8px 올린 (360,20)으로 맞추고 헤더를 `조작 가이드`로 줄였다. 패널 내부 배치와 크기는 유지했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 수정본 외관과 AI가 고른 60px/s·8px 여백에 대한 명시 수용은 아직 확인하지 않았다.

## 5. 반영 후 발견한 문제

- 새 실행 오류나 자동 검사 실패는 발견하지 않았다. 사용자의 대화창/조작 가이드 정정은 삭제 대상의 명시적 범위 수정으로 반영했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2 정정에 따라 통신 패널을 삭제하지 않고 기존 별도 조작 가이드만 제거했다. U3 후속에 따라 헤더와 본문을 함께 올렸다.

## 7. AI 해결 제안과 실제 해결 과정

- 자동 검사 **95개 통과**. 실제 글꼴 측정에서 안내 최대 폭 384px/가용 폭 504px와 마지막 줄의 패널 내부 표시를 확인했다. 기본 전투·F1 후·메뉴를 렌더하고 F1 전후 PNG가 같은 것을 확인했다. 기본·메뉴 이미지를 열어 읽기와 상단 여백을 검토했다.
- 직접 창 조작·최종 외관 승인·업로드는 미수행이다. 출력은 `output/ui_unit_test_v2/communication_guide/`이며 공개하지 않는다.
- U4 후속은 기본 화면 재렌더와 이미지 열기로 위치·헤더·상단 잘림을 확인했다. 이 작은 위치/문구 변경에 자동 검사 전체를 다시 실행하지 않았다.
