- **U1·U2** 기존 직접 조작 보고서에 대화창 경로의 시간을 기록하고, SDL과 직접 OpenGL 사이의 호출별 경계를 검토한다.

## 3. AI가 제안한 것

- **A1, 구현상 판단** `rich_text`를 측정해 본문 배치와 글자 측정을 텍스트 시간에 더한다. 같은 호출 경로의 자체 시간은 대화창 아래 첫 분류에 한 번만 더한다.
- **A2, 검토 후보** `EnemyGlSheet.frame`처럼 연속 OpenGL 구간에서 제출 경계와 상태 소유권을 공유한다. 아틀라스 업로드·그림자·본체 합성 사이에 SDL 렌더 명령·대상·클립 전환이 끼는지 확인한 뒤, 연속인 구간부터 합친다.
