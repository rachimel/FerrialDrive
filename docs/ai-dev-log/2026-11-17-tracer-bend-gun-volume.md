## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** Bullet Trail이 직선 대신 군대 예광탄처럼 가다가 꺾이는 느낌을 원했다. 시각적 목표를 직접 제시했다.
- **사용자 제안 2 (U2):** 총 발사음을 많이 올린다. 구체적 배율과 추가 이유는 제시하지 않았다.
- **사용자 제안 3 (U3):** 롤백 요청 뒤 발사음을 더 크게 조정해 달라고 했다. 출처: `발사음은 더 크게 ㄱㄴ?`.
- 발언 출처·시각은 scope를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 탄두의 명중 위치와 분리한 잔광 굽힘으로 연결했다. U2는 발사 사건 레이어만 증폭했다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 실제 탄환 방향 전환과 잔광만 휘는 표현을 선택지로 구분했다. 판정 변경 범위를 확인하기 위한 질문이다. 출처는 현재 세션 선택 질문이다.
- **구현상 판단:** 4구간 연속 UV 띠, 기본 길이에서 최대 옆 변위 8px·시간 변화 1.5Hz, 발사별 고정 위상을 사용했다. 탄두·꼬리 끝과 탄도는 유지한다. 여러 탄환의 제출은 1회다.
- **구현상 판단:** 발사음 레이어 배율을 0.85→1.7로 설정했다. 전체 음량 0.4에서 채널 배율 0.34→0.68이며 신호 진폭 기준 약 +6dB다. 원본 PCM과 다른 사건 음량은 그대로다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1 질문에 사용자는 `잔광만 휘어짐`을 선택했다. 실제 탄도 변경은 요청 범위에서 제외했다.
- 구체적 굽힘 수치·증폭 배율·최종 외관과 청취감은 AI의 구현상 판단이며 별도 사용자 수용 전이다.

## 5. 반영 후 발견한 문제

- **I1:** 사용자가 `이런 느낌은 아니었음. 다시 롤백`으로 굽힘 표현을 거절했다. 정확히 원하는 예광탄 형태는 아직 재확인하지 않았다.
- 이번 반영에서 수정이 필요한 실행 오류는 관측하지 않았다. 짧은 Combat 실행을 성능 개선이나 목표 FPS 달성의 증거로 사용하지 않는다.
- 발사음 증폭은 여러 효과가 겹친 전투 전체 믹싱·실제 장치 청취까지 검증한 결과가 아니다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1에 대한 사용자 요청으로 이번 굽힘 변경만 역적용했다. 기존 직선 Trail을 복구하고 발사음 증가는 유지했다.
- U3에 따라 발사음 레이어를 1.7→2.5로 추가 증폭했다. 전체 음량 0.4에서 실제 채널 음량은 1.0이며 직전 대비 약 +3.3dB다. 2.5는 AI의 구현상 판단이다. 기존 직선 Trail 복구 뒤 관련 7개 검사가 통과했다.
- U1 확인 응답에 따라 판정 모듈은 수정하지 않고 `PicoGunEffects`와 표현 설정을 수정했다. U2는 로컬 선택 bank의 `gun_fire` 레이어만 변경했다.

## 7. AI 해결 제안과 실제 해결 과정

- `weapons.effects.bend_pixels`·`bend_frequency_hz`로 조절하며, 길이 배율·초기 비행 거리에 비례해 굽힘도 조절한다. `bend_pixels=0`이면 직선이다. 매 프레임 난수 생성·텍스처 생성은 추가하지 않았다.
