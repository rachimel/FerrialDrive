# 본편 시작 스플래시

2026-11-24 KST 본편 제작 대화와 같은 날의 로컬 실행 결과.

## 사용자가 제안한 것

**U1** 검은 배경에 한국공대 로고를 먼저 표시하고 +를 페이드인하면서 45도 회전한다. 제작자 이름 Rachimel은 SUITE Bold로 표시한다. 공통 로딩은 스플래시에서 수행한다.

**U2** 같은 날 후속 대화에서 학교 로고 해상도 개선, 중앙에서 왼쪽으로 이동, 화면 중앙의 ×와 이름 동시 등장, 이름 굵기 감소, 빠른 × 전환을 요청했다.

**U3** 같은 날 이어서 이름도 중앙에서 오른쪽으로 페이드인하며 0.5초 동안 이동하고, × 중앙 고정과 대기 단축, 이미지 AA 적용을 요청했다.

**U4** 시작 시 타이틀과 빠른 공통 자원만 준비하고, 오른쪽 이름 여백을 늘리며 이동 완료 0.1초 뒤 페이드아웃하도록 요청했다.

## 사용자 제안 중 AI가 수용한 것

**U1** 본편 로딩 화면에 적용했다.

**U2** 공식 벡터의 한·영문 가로형을 1472×312로 출력했다. 구현상 선택은 SUITE Regular, 이동 0.70초, 회전 0.28초다.

**U3** 양쪽 이동은 0.50초, 첫 로고 최소 표시는 0.15초, 종료 유지는 0.22초로 조정했다. 로고 알파를 표시 크기로 Lanczos 축소해 텍스처로 재사용한다. 두 렌더러의 960×540 캡처에서 로고 시작점과 최종 × 중심을 1픽셀 오차 이내로 확인했고 본편 타이틀 2프레임까지 실행했다. 캡처는 `output/splash_review/r3/`에 있다.

**U4** 타이틀 UI·글꼴·HUD 아이콘 목록을 준비하고 동일 HUD를 교전에서 재사용한다. 플레이어 메시·적·전투 효과와 효과음 준비는 교전 진입 시 수행한다. 이름 오른쪽 끝과 로고 왼쪽 끝의 중앙 기준 거리를 맞췄다. 이동 후 0.10초 유지하고 0.22초간 페이드아웃한다. 실제 에셋 무음 단일 실행에서 앱 enter부터 첫 타이틀 프레임까지 1.09초, 새 게임 요청부터 첫 교전 프레임까지 2.97초였다. 프로세스 시작과 창 생성은 측정에서 제외했다. 기본 오디오 설정으로도 타이틀 실행을 확인했다. 캡처는 `output/splash_review/r4/`에 있다.

## AI 해결 제안과 실제 해결 과정

본편의 기존 HUD·메시·효과·교전 초기화 단계를 재사용했다. 실제 에셋과 무음 옵션으로 타이틀 2프레임 실행을 확인했다. 두 렌더러의 시작·중간·완료 화면은 `output/splash_review/`에 저장했다. 사용자 직접 재생 검수는 남아 있다. 로고 출처는 [한국공학대학교 공식 로고](https://www.tukorea.ac.kr/sites/tukorea/images/common/logo_w.png)다.

후속 수정에서는 [공식 시그니처 벡터](https://www.tukorea.ac.kr/sites/tukorea/files/UI/signature.ai)를 사용했다. 두 렌더러에서 첫 프레임의 로고 수평 중앙과 마지막 프레임의 중앙 기호를 확인했다. 실제 에셋으로 타이틀 2프레임까지 재실행했다. 재생 캡처는 `output/splash_review/r2/`에 있다.

후속 사용자 요청에 따라 첫 로고는 중앙에서 시작하고 최종 조합 전체의 양쪽 바깥 여백을 맞춘다. × 위치는 실제 로고와 글리프의 표시 폭으로 계산한다. 960×540·1920×1080·800×600·1280×540에서 두 렌더러 모두 내부 여백이 같고 바깥 여백 차이는 최대 1px였다. 본편 무음 타이틀 2프레임 실행을 확인했다. 캡처는 `output/splash_review/r8/`에 있다.
