# 플레이어 파츠·SMAA의 반복 GL 상태 조회

**기록 ID** `FDLOG-20261122-player-part-gl-state`

2026-11-22 KST 작성. RTX 5070 Laptop GPU, FHD, 중간 PBR, Bicubic·SMAA 1×, 적 600기·12m 간격, 자동 SMG·무음. 공격 도형 최적화까지 적용된 `5719689`의 동작이 기준이다.

## 1. 사용자가 제안한 것

- **U1** 플레이어 파츠와 업스케일의 `glGet*` 약 98회를 패스별로 확인한다. 패스 안의 중복을 줄일 수 있으면 적용하고 600기 픽셀·CPU·GPU 시간을 대조한다. 요청의 정확한 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261122-player-part-gl-state:U1]]이다. 검색 단서는 `플레이어 파츠랑 업스케일에서 나오는 glGet 98회`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 플레이어 깊이·본체 파츠 두 패스와 Bicubic·SMAA 네 패스를 분리해 계측했다. 같은 시뮬레이션 프레임과 준비된 리소스로 전후 전체 화면을 번갈아 그렸다.

## 3. AI가 제안한 것

- **A1** 파츠의 바깥 GL 패스가 유닛 0을 저장하고 복원하는 경우 아틀라스 도우미의 중복 조회를 생략한다. 중첩된 배치와 별도 텍스처 유닛은 각 시점의 원상 복구를 수행한다.
- **A2** 공격 도형의 속성 스택을 공통 패스에서 재사용한다. 파츠·확대 패스에서 블렌드와 가위 영역을 한 묶음으로 저장하고 각 SDL 타깃 전환 전에 복원한다. [OpenGL 4.6 호환 명세 21.6절 및 가위 영역 상태 표](https://registry.khronos.org/OpenGL/specs/gl/glspec46.compatibility.pdf)

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 이어서 분해·적용·비교하는 목표는 사용자 요청이다. 상태 저장 그룹과 전후 대조 방식은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 파츠 패스에서 공통 상태 저장과 아틀라스 유닛 0 복구가 같은 바인딩을 각각 조회했다. 나머지 아틀라스의 수는 보간에 사용하는 방향 수에 따라 달랐다.
- **I2** GPU 타임스탬프 평균은 일부 구간의 긴 꼬리에 영향을 받았다. 드라이버에 명령을 보내는 사이의 GPU 유휴도 포함하는 값이므로 패스별 짝 차이와 중앙값도 함께 기록했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 앞선 공격 최적화 이후 남은 호출을 다시 집계하고 중복 저장을 제거했다. 호출 수는 90쌍에서 아래와 같이 줄었다.

| 패스 | 전 평균 `glGet*`/프레임 | 후 평균 |
| --- | ---: | ---: |
| 플레이어 파츠 깊이 출력 | 25.47 | 17.47 |
| 플레이어 파츠 본체 색상 | 25.47 | 17.47 |
| Bicubic 색상 확대 | 11 | 4 |
| SMAA 경계 검출 | 11 | 4 |
| SMAA 가중치 계산 | 13 | 6 |
| SMAA 최종 혼합 | 12 | 5 |
| 파츠·업스케일 합계 | 97.93 | 53.93 |
| 전체 그리기 | 355.90 | 311.90 |

파츠는 공통 상태 22회·아틀라스 약 26.93회·그림자 깊이 샘플 바인딩 2회였다. 공통 상태 14회와 중복 유닛 0 조회 2회를 없앴다. 업스케일은 공통 상태 44회와 보조 텍스처 3회였다. 업스케일 네 패스 각각 공통 상태 조회 7회를 없앴다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1** 파츠 패스가 직접 열릴 때만 내부 아틀라스 유닛 0의 조회·복구를 생략했다. 블렌드·클립만 GL 속성 스택에 맡기고 타깃, 셰이더, 뷰포트와 텍스처를 복구하는 경계는 유지했다.
- **I2** API 추적을 끈 CPU 120쌍, GPU 타임스탬프 120쌍을 따로 실행했다. 이전과 변경 경로의 렌더 순서를 교대했다. CPU는 마지막 강제 완료 대기를 제외한 제출 경과 시간이다. 첫 실행과 반복 실행 각각의 FHD RGBA 12쌍이 모두 픽셀 일치했다.

| 측정 | 첫 실행 전 → 후 | 반복 실행 전 → 후 |
| --- | ---: | ---: |
| 파츠 CPU 평균 | 0.799 → 0.776ms | 1.977 → 1.788ms |
| 업스케일 CPU 평균 | 0.336 → 0.283ms | 1.243 → 0.900ms |
| 전체 그리기 CPU 평균 | 18.465 → 18.764ms | 38.779 → 38.874ms |
| 파츠 GPU 타임스탬프 중앙값 | 0.219 → 0.104ms | 0.220 → 0.103ms |
| 업스케일 GPU 타임스탬프 중앙값 | 0.0328 → 0.0326ms | 0.0332 → 0.0331ms |
| 전체 그리기 GPU 타임스탬프 평균 | 11.688 → 11.861ms | 20.530 → 19.824ms |

파츠·업스케일 GPU 구간의 짝별 시간 차이 중앙값은 두 실행 모두 절대값 0.001ms 이하였다. 파츠 GPU 구간의 폭과 전체 프레임 변동을 감안하면 두 실행에서 직접 확인된 개선은 상태 조회 횟수와 해당 CPU 구간에 한정된다. 기본 자동 검사는 1,090개 통과·89개 선택 실행 제외다. 별도로 Bicubic 단독·SMAA의 클립과 확대 픽셀, 적 합성 시트, 도형 상태 복원, 아틀라스 상태를 대조한 검사 23개가 통과했다. UHD 630 실기는 미측정이다.
