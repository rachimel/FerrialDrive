# 근거리 적 GL 상태 공통화

- **기록 ID** `FDLOG-20261123-enemy-gl-shared-state`
- 작업일 2026-11-23 KST.

## 1. 사용자가 제안한 것

- **U1** 중형과 대형에도 근거리 적의 GL 합성 방식을 적용하고 렌더링 상태를 중앙에서 관리한다. 대형은 현재 인간형일 가능성이 높다고 보완했다. 정확한 요청 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261123-enemy-gl-shared-state:U1]]` 검색 단서는 `렌더링 상태는 중앙에서 관리`다.
- **U2** 모든 그래픽스 작업에 적용하는 가이드라인을 만들고 `AGENTS.md`에 참조를 의무화한다. 정확한 요청 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261123-enemy-gl-shared-state:U2]]` 검색 단서는 `무조건 지킬 가이드라인`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 소형·중형·인간형에 같은 렌더링 조건을 적용한다. 상태 관리 범위는 한 교전의 근거리 PBR 시트다. 최종 합성의 순서를 유지한다.
- **U2** [그래픽스 작업 가이드라인](../graphics_guidelines.md)을 작성하고 `AGENTS.md`에서 설계·수정·검토 전에 읽고 적용하도록 명시했다. 문서 커밋은 `887161d`다.

## 3. AI가 제안한 것

- **구현상 판단** `EnemyUpscaleScratch`가 `EnemyGlSheet`를 한 개 소유한다. 네이티브 확대 입력, 필터와 SMAA 중간 타깃을 공유한다. 프로그램·뷰포트·FBO·블렌드·텍스처 바인딩은 시트의 SDL 경계 사이에서 추적한다. 출력 타깃과 발 위치 순 제출은 기종별로 유지한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 구체적 자원 수명과 검증 코스는 U1 구현에서 정했다.

## 5. 반영 후 발견한 문제

- **I1** 기본 반경 16m의 자동 검 코스는 변경 후 공통 경로를 소형만 실행했다. 이 코스만으로 중형·인간형의 확대를 평가할 수 없었다.
- **I2** 전체 GPU·런타임 검사 46개 중 소형 Break 배치와 지연 PBR 깊이 캐시의 픽셀 검사 2개가 실패했다. 이전 렌더 모듈을 같은 작업 트리에 불러 실행해 두 실패가 동일하게 재현됨을 확인했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1, I1** 기본 코스와 별도로 양쪽 반경을 60m로 맞췄다. RTX 5070 Laptop에서 180기·간격 15m·자동 검 60Hz·FHD Medium/SMAA·예열 120·계측 240프레임 조건이다. 제품의 반경과 적 행동은 기존 설정을 사용한다.

## 7. AI 해결 제안과 실제 해결 과정

- 16m 정순·역순 중앙값은 46.22→46.92 FPS, 프레임 작업 P99 32.99→28.76ms였다. 60m FPS는 38.22→40.68, 역순에서 39.37→40.85였다. P99는 각각 59.76→29.66ms, 32.77→32.33ms였다. 첫 변경 전의 긴 프레임 때문에 꼬리 개선량의 반복성은 낮다.
- 60m 상세 실행에서 `world.enemies`의 계측상 자체 CPU 경과는 7.443→6.672ms/프레임, GPU `enemy_render` 평균은 1.015→0.986ms였다. 검증 실행에서 변경 후 GL 구간의 기종별 호출은 소형 230회, 중형 161회, 인간형 222회였다. 호출은 예열을 포함한다.
- 별도 함수·패스 계측 240프레임에서 양쪽 모두 파츠 시트 686개와 SMAA 시트 446개를 제출했다. `glGetIntegerv`는 적 시트에서 119.25→53.40회/프레임, 전체 378.20→312.35회/프레임이었다. 적 시트의 GL 조회 구간 CPU 경과는 1.037→0.629ms/프레임이었다.
- CPU 포함 경과는 `EnemyPartBatch.prepare` 4.212→3.078, `_paint_groups` 2.291→2.183, `PartPainter.paint` 1.975→1.881, `_table` 0.114→0.108, `PartSheetUpscaler.draw` 0.904→0.171ms/프레임이다. 가장 큰 감소는 업스케일 단계 사이의 SDL·GL 상태 처리에 있었다.
- GPU timestamp 평균은 시트당 파츠 0.27113→0.27243, Bicubic 0.00782→0.00616, SMAA edge 0.00552→0.00642, weights 0.01067→0.01160, blend 0.00560→0.00648ms다.
- 소형·중형·인간형을 같은 상태 관리자에서 그린 뒤 0.9×·1.4×·1.85×, 배열과 SDL 중간 타깃 양쪽에서 SDL 대조 RGB와 후속 SDL 그리기가 일치했다. 예외 시 FBO·프로그램·활성 텍스처·뷰포트·블렌드·scissor 복원과 출력 타깃 해제를 확인했다. 180기 전체 화면은 변경 전 두 차례의 대조군 중 하나와 RGB 해시 35/35가 일치했다. 변경 전 두 실행 사이에서는 3개 샘플이 달랐다.
- **I2** 기존 경로에서도 소형 Break는 허용치 4 대비 최대 채널 차이 20, 지연 PBR 캐시는 5채널에서 최대 차이 1이었다. 두 검사의 기준과 경로는 이번 작업 범위 밖이다.
- 원시 자료는 `output/performance/enemy_shared_gl_20261123/`에 있다. Intel 실기와 직접 조작은 미검증이다.
