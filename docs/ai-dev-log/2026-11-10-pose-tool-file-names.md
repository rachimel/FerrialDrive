## 2. AI가 제안한 것

**A1**: 새 편집 작업본도 선택한 입력 파일명을 유지한다. 별도 작업 폴더는 그대로 사용한다. 이유는 선택 파일을 파일명으로 구분하면서 원본을 보존하기 위해서다. 샘플 이름 `sample_pose.blend`는 구현상 판단이다.
