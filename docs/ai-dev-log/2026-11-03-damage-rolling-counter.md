# DAMAGE 가로 배치와 회전 카운터

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 누적 피해를 콤보처럼 숫자 옆에 DAMAGE로 배치하고, 값 변경에 물리 카운터 같은 회전과 모션 블러를 추가한다.

## 반영

- 상단의 `누적 가한 피해` 제목을 없애고 **큰 학교안심 운동장 숫자 + 작은 Cafe24 PRO DAMAGE**로 기준선을 맞췄다. 숫자는 고정 폭 자리를 사용하며, 전체 폭 안에 라벨이 들어오도록 긴 숫자만 축소한다.
- `ui/counter.py`에 `RollingCounter`와 `CounterVisual`을 분리했다. 실제 합계는 기존 샘플 상태에 즉시 반영하며, 표시 상태만 별도로 진행한다. 회전 중 입력은 최신 합계 하나로 병합하고, 초기화·값 감소는 즉시 반영한다.
- 변경되는 자리의 이전 숫자는 위로 나가고 새 숫자는 아래에서 들어온다. 각도의 사인·코사인으로 위치·세로 압축·명암을 바꾸는 2D 원근 근사다. 렌더러의 글자 확대·축소와 텍스처 잘라내기로 숫자 영역을 벗어나는 부분을 감춘다. 콤보 숫자는 이번 회전 적용 대상이 아니다.
- 블러는 셔터 구간의 과거 자세를 재계산해 겹쳐 그리는 잔상 근사다. 기본 회전 0.34초·셔터 0.045초·5개 샘플·잔상 알파 0.28은 조절용 시안이며 설정 파일에 분리했다. 동일한 시점에서는 프레임 수에 상관없이 같은 샘플 자세를 사용한다.
- 메뉴에서도 표시 시간은 진행한다. 피해 0·타겟 전환·플레이어 피해는 같은 누적 값을 다시 회전시키지 않는다. 초기화하면 표시와 잔상도 즉시 초기화한다.

## 확인 상태

- 코드와 변경 차이를 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·프로그램 실행·렌더링·실제 창 조작은 수행하지 않았다.
- 실행기 완전 재시작 후 `tests/ui_test.py`를 드롭해 DAMAGE 기준선, 바뀌는 자리만 회전하는지, 연속 클릭의 최신 합계 반영, 회전 중 초기화·메뉴 왕복을 확인한다. 회전의 물리적 인상·블러 품질·실제 성능은 사용자 확인 전이다.
