## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 앞선 계측에서 HUD가 가장 큰 CPU 구간으로 나온 뒤, HUD 내부의 심한 병목을 더 좁혀 계측하도록 요청했다. 이유·의도는 실제 최적화 대상을 확인하는 것이다. 출처는 현재 대화의 위 사용자 발언이며 발언 시각은 scope 태그 대상이다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 수용하여 무기 UI·보조 슬롯·자원부·미니맵·스캔라인·필름 노이즈·사전 순회를 나눠 계측했다. 수용 근거는 현재 대화의 계측 시작 보고와 아래 실행 결과다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 패널 범위 수집용 사전 순회와 실제 표시 시간을 구분하고, 무거운 구성 요소의 표시 생략 대조를 반복한다. 이유는 중첩된 호출별 시간을 단순 합산하거나 사전 순회를 이중 표시로 잘못 해석하지 않기 위해서다. 근거는 현재 대화의 실행 계획과 현행 `prepare_panel_effects` 경로다. 개별 제시 시각은 scope 태그 대상이다.
- **AI 제안 2 (A2):** 결과 확인 후 원형 보조 슬롯의 정점·인덱스 재사용과 개별 도형 제출 묶기를 우선 검토한다. 이유는 두 슬롯이 도형 제출 호출의 약 69%를 차지하고, 슬롯 생략으로 약 4.87ms가 줄었기 때문이다. 위 결과 확인 시점의 AI 분석이며 최적화 구현은 하지 않았다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 계측은 U1로 요청받았다. 세부 비교 조건 및 A2의 최적화 구현·외관 변경에 대한 별도 사용자 수용은 확인하지 않았다.

## 5. 반영 후 발견한 문제

- **I1:** 제품 변경 전 조사다. 새 수정으로 인한 회귀가 아니다.
- 기본 CPU 프레임 평균은 15.255ms였다. 무기 UI 생략 시 9.102ms, 보조 슬롯 두 개 생략 시 10.386ms, 보조 슬롯 원 테두리만 생략 시 13.340ms였다.
- 무기 UI의 평균 절감량 6.153ms 중 보조 슬롯 전체의 절감량은 4.869ms였다. 부모·자식 대조는 겹치므로 합산하지 않는다.
- 상세 계측의 HUD `SDL_RenderGeometry` 호출은 평균 약 745회/프레임, 두 보조 슬롯은 약 515회/프레임(69.2%)이었다. 이 수치는 모든 그리기 API나 GPU 점유 비율을 뜻하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U1: 현재 훈련장의 실제 에셋과 UI를 사용해 1920×1080·high 품질·레벨 3 오른쪽 연속 공격을 고정했다. 각 회차 60프레임 예열 후 240프레임을 측정하고, 120프레임마다 초기화했다. 화면 제한·VSync를 끄고 갱신은 고정 60Hz로 유지했다.
- 제품 소스와 사용자 설정을 변경하지 않았다. 표시에 관한 생략은 계측 프로세스 안에서만 적용했고, 지형·기체·검 Trail·잔상은 유지했다.

## 7. AI 해결 제안과 실제 해결 과정

- I1 ↔ A1: 기본/무기 UI 생략/보조 슬롯 생략/원 테두리 생략/필름 노이즈 생략/스캔라인 생략/자원부 생략/미니맵 생략/사전 순회 생략/HUD 전체 생략의 10조건을 각 3회 측정했다. 별도 상세 구간·도형 제출 집계 3회를 더해 총 33회가 정상 완료됐다.
- 기본 대비 평균 절감량: 무기 UI 6.153ms, 보조 슬롯 4.869ms, 원 테두리 1.915ms, 자원부 1.769ms, 스캔라인 1.455ms, 필름 노이즈 1.130ms, 사전 순회 1.052ms, 미니맵 0.351ms였다. 여러 구성 요소와 효과의 범위가 겹치므로 합산하지 않는다.
- 상세 표시 구간은 무기 UI 6.268ms, 보조 슬롯 4.670ms, 원 테두리 1.905ms, 자원부 1.784ms, 레이더 0.826ms, 안내 패널 0.557ms, 미니맵 0.259ms였다. 사전 순회 전체는 1.411ms였다. 상세 계측에는 약 1.3ms/프레임의 추가 비용이 있어 절감량 판단은 표시 생략 대조를 우선한다.
- 보조 슬롯은 원을 48개 점으로 만들고, 두꺼운 테두리를 선분별 사각형·삼각형으로 나눠 개별 제출한다. 내부 면·필름 노이즈·스캔라인도 같은 다각형 위에서 따로 처리한다. 정적 도형의 반복 구성과 제출 횟수가 첫 검토 대상이다.
- 사전 순회 생략은 기본 장면에서 미리 수집한 패널 범위를 고정한 진단이다. 동적 배치·일시정지·장비 전환까지 지원하는 캐시 구현으로 확대하지 않는다.
- I1 ↔ A2: 최적화 우선순위를 제시했으며 외관·분할 수·렌더링 코드 변경은 하지 않았다. 실제 개선량과 시각 품질은 구현 후 별도 검증 대상이다.
