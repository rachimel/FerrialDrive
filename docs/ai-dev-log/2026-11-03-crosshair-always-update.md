# 크로스헤어 위치 상시 갱신

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 크로스헤어는 항상 갱신한다.
- 포인터 좌표 반영에서 일시정지 차단 조건을 제거했다. 메뉴·전투·장면 전환·일시정지 열기/닫기 중에도 창 안의 유효한 포인터 좌표를 반영한다. 창 밖에서는 마지막 유효 위치를 유지한다.
- 일시정지 중 피해 숫자·카운터·HP 감소 효과·공격 방향 갱신과 배경 버튼 차단은 유지한다. 크로스헤어의 그리기 순서·표시 장면은 변경하지 않았다.
- 입력 처리 순서와 문서를 읽어 확인했다. 자동 검사·실행·화면 조작은 수행하지 않았다.
