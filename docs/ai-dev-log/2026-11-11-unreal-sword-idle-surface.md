## 3. AI가 제안한 것

- **AI 구현상 판단 1 (A1)**: 12fps·1초 Idle에 포즈 키 0/3/6/9/12와 완만한 보간을 사용했다. 12는 중복 끝점이며 출력은 0~11이다. 발·루트는 고정하고 상체/팔/검에 작은 대기 움직임을 부여했다. 큰 관절 가동보다 짧은 동작의 루프·파지를 먼저 확인하려는 판단이다.
- **AI 구현상 판단 2 (A2)**: Blender의 복잡한 노드를 FBX가 그대로 옮긴다고 가정하지 않고 새 UV0에 최종 PBR/에너지/코팅을 베이크했다. 기존 UV와 원본 이미지를 함께 보존했다. Unreal에서 표면을 재현할 수 있는 공통 이관 경로가 목적이다.
- **AI 구현상 판단 3 (A3)**: 그림자 기준 렌더는 전체 품질을 끄는 대신 별도 장면에서 메시의 그림자 투사만 끈다. 면광원의 지면 밝기 차이를 그림자로 오인하지 않기 위한 판단이다.

## 5. 반영 후 발견한 문제

- **문제 1 (I1, 기존 인계 결함)**: 실제 초기 형상 가져오기 요청은 `import_materials=true`, `import_textures=false`였다. 이전 결과에 재질 생성 기록이 있었지만 원래 형상 폴더의 저장 파일은 형상 417개뿐이었다. 원래 Blender 이미지 116개의 외부 경로도 모두 끊겨 있었으며 패킹된 원본 데이터는 남아 있었다. 복잡한 표면 노드를 FBX 자동 변환으로 복원할 수 없었다.
- **문제 2 (I2, 새 표면 후보 결함)**: Unreal 재질에 Skeletal Mesh 사용 설정이 없어 실제 렌더가 기본 회색 재질로 대체됐다. 에너지 출력도 영향을 받았다.
- **문제 3 (I3, 조명 인계 결함)**: 모델 루트 배율 0.52를 제거한 형상에 원래 월드 광원을 그대로 비교할 수 없었다. 정규화한 광원은 모델에서 1300cm 이상 떨어졌지만 기본 감쇠 반경은 1000cm여서 직접광이 닿지 않았다. 이 원인과 위치를 바꾸려는 사용자 선택을 구분한다.
- **문제 4 (I4, 검사 결함)**: 엔진 압축 후 애니메이션을 프레임 인덱스로 읽으면 요청의 12fps와 다른 샘플링 때문에 루프 오류로 오인했다.
- **문제 5 (I5, 그림자 기준 결함)**: `r.ShadowQuality=0` 기준은 면광원의 그림자 외 지면 밝기도 바꿔 캔버스 전반에 낮은 알파를 남겼다.
- **문제 6 (I6, 작업 프로세스 종료)**: 대량 표면 가져오기 프로세스가 저장 후 종료 오류를 냈다. 저장 기록만으로 성공 처리하지 않도록 종료 코드 검사도 추가했다. 저장된 파일은 이후 별도 프로세스의 실제 로딩·렌더로 확인했다.

## 6. 사용자 해결 제안과 실제 해결 과정
