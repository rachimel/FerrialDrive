# 3·4타 검 Trail 중복과 접힘 보정

## 1. 사용자가 제안한 것

- **U1**: 3타와 4타에서 Trail이 이상하게 표시된다고 보고했다. 특정 방향·프레임·원인은 지정하지 않았다. 의도는 해당 표시 문제의 확인과 보정이다.
- **후속 U2**: `그림자 검사 불일치도 확인해서 고쳐줘`라고 요청했다. 이유·근거는 이전 결과 보고에서 남긴 I4다. 개별 발언 시각은 scope 누락 범위에 포함한다.

## 2. 사용자 제안 중 AI가 수용한 것

- 실제 기체의 3타 찌르기와 4타 베기를 연속 프레임으로 재현하고 표시 경로를 수정했다. 명중 면·타격 유효 시간·기존 모션과 파지는 변경하지 않았다.
- 후속 U2를 수용해 I4의 검사와 현재 그림자 출력 경로를 다시 비교했다.

## 3. AI가 제안한 것

- **구현상 판단 A1**: 찌르기는 동일 타격의 최신 궤적 한 개만 그린다. 두 날개에 텍스처를 따로 반복하지 않고 끝점을 공유한다. 다음 타격 시작 후 0.08초 동안 표시를 지운다.
- **구현상 판단 A2**: 투영된 칼날이 접히거나 면의 방향이 뒤집히는 구간에서 표시 띠를 분리한다. 좁게 투영되는 면과 이동 길이가 매우 짧은 조각을 제외한다. 표시 분리로 실제 판정을 축소하지 않는다.
- 이유·근거: 아래 I1~I3의 실제 캡처와 표시 면 계산이다. 개별 제시 시각은 scope 누락 범위에 포함한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1/A2의 구체적 방식·수치와 최종 외관은 사용자 확인 전이다. 구현·렌더 확인으로 사용자 수용을 추정하지 않는다.

## 5. 반영 후 발견한 문제

- **I1**: 찌르기의 시간 구간마다 V를 반복해 두세 개의 화살표로 갈라졌다. 각 날개 텍스처가 끝에서 투명해져 접합도 약했다.
- **I2**: 3타 잔여 V가 4타 초반까지 남았다. 4타는 투영된 검의 길이·진행 면이 바뀌는 구간을 한 띠로 연결해 가느다란 조각과 접힘이 생겼다.
- **I3**: AI의 첫 보정에서 폭을 진행 곡선의 수직 방향으로 강제 유지하자 4타 일부가 빛 덩어리처럼 뭉쳤다. 해당 접근은 채택하지 않았다.
- **I4**: 범위를 넓힌 자동 검사에서 `test_attack_body_shadow_and_non_interpolated_frame_share_accelerated_time`이 실패했다. 현재 그림자 경로는 보간을 꺼도 별도 `shadow_blend`를 사용하지만 검사는 원본 리소스의 그림자/몸체 두 번 호출을 기대한다. 이번 Trail 변경 파일과 분리된 검사 불일치이며 수정하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1 외에 구체적인 해결 방식은 아직 제시되지 않았다. 사용자의 원인 진단이나 A1/A2 수용을 만들어 기록하지 않는다.
- I4는 후속 U2에 따라 확인 범위에 포함했다. 사용자는 검사 구현 방법이나 그림자 표현 변경을 지정하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1/I2: 최신 V 단일 표시·날개 꼭짓점/텍스처 연결·연계 소멸을 적용했다. 새 베기 면이 표시상 제외된 프레임에도 원본 타격 시작 시각으로 찌르기를 소멸시킨다.
- I2/I3: 폭 강제 보정을 걷어내고 칼날의 기존 투영 면을 유지했다. 접힘·방향 반전·너무 짧은 구간을 나눠 각 띠의 텍스처를 따로 연결했다.
- **자동 검사**: 검 효과 16개·Trail 표현 5개·연속성/중복 회귀 4개, 총 25개 통과. 더 넓힌 `test_sword*.py` 81개 실행에서는 80개 통과·I4 하나 실패했다. 후속 25개 통과와 혼동하지 않는다. 원본 검사 출력은 `output/maintenance/combo-trail-checks.log`다.
- **실제 렌더**: 동/북 방향 전체 구간의 수정 전후 캡처 42장씩, 최종 8방향 표본 72장을 생성했다. AI가 8방향의 3·4타 대표 프레임을 열어 중복 V 제거·전환 잔여 감소·표시 띠의 분리 상태를 확인했다. 결과는 `output/maintenance/combo_trail_review/before_full/`·`final_8dir/`다. 기존 1·2타를 포함한 레벨 비교도 657프레임 재렌더해 확인했다.
- 당시 남은 확인: 사용자 직접 조작·최종 외관 평가, I4의 그림자 검사 불일치. 커밋·업로드는 수행하지 않았다.
