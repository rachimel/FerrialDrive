# 누적 피해 카운터 밀어 올리기·페이드·블러 강화

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 다음 숫자가 이전 숫자를 위로 밀어내고, 위 숫자는 점점 투명해지도록 변경한다. 모션 블러를 강화하고 자릿수가 그대로인 갱신에도 적용한다.
- 이전 세로 압축 회전을 한 글자 높이 간격의 위쪽 이동으로 바꿨다. 새 숫자는 아래에서 들어오며 이전 숫자의 알파는 진행률에 따라 0으로 줄어든다. 감쇠 지수는 설정의 `outgoing_fade_power=1.4`로 분리했다.
- 개별 숫자가 같은 자리도 움직인다. 예를 들어 `120→240`은 세 자리 전부, 일의 자리 0까지 효과를 적용한다. 합계 자체가 같으면 재생하지 않고, DAMAGE·쉼표는 고정한다.
- 블러 시안은 셔터 0.045→0.085초, 샘플 5→9개, 잔상 강도 0.28→0.58로 올렸다. 이동 시간은 0.34초다. 원본 합계·연속 입력 병합·초기화 동작은 유지한다.
- 변경 내용을 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 `120→240`의 모든 자리 이동, 위 숫자 페이드와 블러 강도를 확인한다. 화면 품질·실제 성능은 미검증이다.
