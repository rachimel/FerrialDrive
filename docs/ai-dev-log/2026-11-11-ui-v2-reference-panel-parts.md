# UI v2 레퍼런스 패널·테두리 분리

- **기록 ID: ui-v2-reference-panel-parts**. 원래 대화·구현·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-reference-panel-parts:scope]] 검색 단서: `이런 느낌으로 대화창, 미니맵 패널`, `저거 등장효과 만들거라서`, `곡선 형태로 줄어드는건 없애자`.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: 첨부한 패널 레퍼런스처럼 대화창·미니맵의 테두리와 면을 재구성한다. 외형 목표는 첨부 이미지이며 별도 이유는 제시하지 않았다.
- **사용자 제안 2 (U2)**: 이후 등장 효과를 만들 수 있도록 테두리를 따로 분리한다. 이유는 현재 발언에 명시했다.
- **사용자 제안 3 (U3)**: 테두리가 가늘어질 때 곡선 형태로 줄어드는 표현을 제거한다. 근거는 현재 후속 요청이다.

## 2. AI가 제안한 것

- 별도로 수용을 요청한 디자인 후보는 없다. 구현상 판단으로 레퍼런스를 짧은 꺾임·가로선·사선 끝 조각으로 나누고, 면의 강조 꼭짓점을 짧게 잘랐다. 레퍼런스에서 읽은 구성 요소이며 최종 외관 승인은 확인 전이다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U3을 반영했다. 대화창·미니맵에만 새 분절 프레임을 연결하고 기존 크기/배치·문구·필터를 유지했다. 공통 두께 변화는 곡선 보간을 제거하고 직선으로 바꿨다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 이번 수정본 외관에 대한 명시 수용은 아직 확인하지 않았다. U2는 사용자의 직접 구조 요청이며 AI 제안의 수용으로 재분류하지 않는다.

## 5. 반영 후 발견한 문제

- 이번 변경에서 새 실행 오류나 검사 실패는 발견하지 않았다. 이전 곡선 두께 변경 요청은 사용자 외형 선택으로 기록하며 버그로 분류하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U3에 따라 곡선 보간과 곡선 분할 설정을 제거하고 3px 최대 두께 구간 이후 직선으로 줄이게 했다.

## 7. AI 해결 제안과 실제 해결 과정

- `panels.py`에서 패널 면과 꺾임/가로선/끝 조각 10개를 별도 형상으로 반환한다. `panel_surface()`·`panel_border()`와 조각별 표시값을 분리했다. 등장 효과의 시간·순서·재생은 구현하지 않았다.
- UI 자동 83개·획득 7개, 총 **90개 통과**. 면·테두리·좌상단 조각의 독립 표시와 기본/상단 표적/대화창 없음, 총 **6개 상태를 렌더**하고 주요 이미지를 열어 확인했다.
- 실제 창 조작·수정본 외관 승인·업로드는 미수행이다. 출력은 `output/ui_unit_test_v2/reference_panel/`이며 공개 대상에 포함하지 않는다.
