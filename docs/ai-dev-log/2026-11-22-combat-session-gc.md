## 1. 사용자가 제안한 것

- U1 · 2026-11-22 KST 대화 `[[FDLOG_MISSING_TIME:FDLOG-20261122-combat-session-gc:U1]]`.
- 전투 중에는 자동 GC를 끄고, 전투 리소스와 참조를 놓은 뒤 로딩 화면에서 한 번만 전체 수집하라고 했다. 같은 180기로 프레임 P99와 재진입 메모리를 비교하고 별도 커밋하도록 요청했다.

## 3. AI가 제안한 것

- A1 · 2026-11-22 KST 작업 대화. 본편의 ‘타이틀로’에서 현재 전투를 닫고 같은 캔버스 안에서 새 타이틀을 열어, 실제로 장면 참조를 놓을 수 있도록 했다.
- 종료 전후 Windows Private Bytes와 앱 약한 참조를 측정했다. 프레임 통계와 GC 콜백은 별도 구간을 실행했다.

## 5. 반영 후 발견한 문제

- I1. 기존 본편 ‘타이틀로’는 같은 앱 안에서 HUD의 장면만 바꿔 이전 전투가 계속 참조됐다. 기존 180기 재진입 검사에서도 종료 직후 전투 객체가 매회 1개 남았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1, I1. 전투가 활성화되면 자동 순환 GC를 끈다. 정상 종료 시 `exit()`로 리소스를 닫고 앱과 프레임 루프의 참조를 놓는다. 로딩 화면을 SDL에 표시한 다음 `gc.collect(2)`를 호출하고 원래 자동 GC 설정을 복원한다.
- F5와 전투 테스트 타이틀의 기존 교전 재개는 세션을 유지한다. 본편 ‘타이틀로’는 세션을 닫는다. 타이틀만 열었다 닫는 경우엔 명시적 전체 수집을 호출하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- A1, I1. 기존 180기·15m·HP 100,000·FHD Medium·SMAA 검 입력을 사용했다. 60Hz 고정 업데이트, 무음, VSync 끔, 프레임 제한 없이 같은 캔버스에서 앱을 다시 만들었다. 각 진입은 120프레임 준비 후 720프레임 측정했다. 전후 게임 상태 해시가 일치했다.
- 1차 3회 기준 전체 프레임 P99 31.85 → 32.00 ms, 평균 48.89 → 45.94 FPS. 회차별 P99는 기존 36.02 / 30.49 / 31.47 ms, 변경 31.85 / 31.48 / 32.28 ms.
- 1차 구간 P99는 `benchmark_program`의 `app.update` 4.32 → 4.39 ms, `app.draw + SDL_RenderFlush` 27.58 → 28.36 ms, `PicoCanvas.present` 0.66 → 0.29 ms였다. GPU 패스 시간은 수집하지 않았다.
- 순서를 뒤집은 2회에서 전체 프레임 P99 33.59 → 32.32 ms, 평균 43.50 → 45.50 FPS. 회차별 P99는 기존 32.68 / 34.05 ms, 변경 31.12 / 33.11 ms.
- 1차 Private Bytes, 1회차부터 순서대로 기록.
  - 진입 직후 기존 1,688.08 / 1,957.31 / 1,821.73 MiB, 변경 1,688.34 / 1,820.65 / 1,775.32 MiB.
  - 종료 로딩 직전 변경 2,054.14 / 2,082.51 / 2,069.12 MiB.
  - 다음 진입 전 기존 1,819.29 / 1,869.87 / 1,868.96 MiB, 변경 1,723.54 / 1,805.73 / 1,826.13 MiB.
  - 변경 후 전체 GC 경과 238.26 / 283.87 / 305.83 ms.
- 역순 Private Bytes, 1회차부터 순서대로 기록.
  - 진입 직후 기존 1,627.73 / 1,888.20 MiB, 변경 1,693.23 / 1,809.83 MiB.
  - 종료 로딩 직전 변경 2,051.58 / 2,081.75 MiB.
  - 다음 진입 전 기존 1,979.97 / 2,023.62 MiB, 변경 1,729.48 / 1,808.98 MiB.
  - 변경 후 전체 GC 경과 242.35 / 278.44 ms.
- 약한 참조 검사에서 각 종료 직후 남은 전투 객체는 기존 1개, 변경 0개였다. 변경한 각 회차에서 로딩 표시 → 전체 수집 1회 순서를 확인했다. 첫 진입을 제외한 3개 재진입에서 Private Bytes가 46.41~136.66 MiB 낮았다.
- 별도 480프레임 계측에서 기존 전투 프레임 중 자동 GC 29회, 최장 2.99 ms를 측정했다. 변경 후 전투 프레임 중 자동 GC는 0회였다. 일반 계측에서 100 ms 초과는 기존 2회, 변경 0회였다. 기존 186.26/202.55 ms 프레임은 별도 콜백 계측에서 원인을 확인하지 못했다.
- 자동 검사 53건 실행 중 52건 통과, 1건 건너뜀. 본편 SDL 더미 실행에서 일시정지 메뉴의 ‘타이틀로’ 버튼과 같은 창 재진입, F10 종료를 실제 핸들러에 연결해 순서와 상태를 확인했다. 하드웨어 Combat 벤치마크는 180기 공개 도형으로 2프레임 실행을 완료했다. 직접 조작과 장시간 플레이는 확인 범위에 포함하지 않았다.
