## 1. 사용자가 제안한 것

- **U1** 이번 대화에서 현재 최적화를 커밋하고 기존 테스트에 연결한 뒤 남은 병목을 찾아 달라고 했다. 전장 900~1,000기, 현재 카메라, 근거리·록온 보간 유지, 원거리 동일 에셋의 프레임 공유와 무음 실행이 앞선 요청의 조건이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 일반·3배속 Combat과 하드웨어 벤치마크가 같은 적 배치를 사용하도록 하고, 검 이동 단독 진입점도 실제 파츠 경로에서 확인했다.

## 3. AI가 제안한 것

- **구현상 판단** 21:27 KST 벤치마크에서 같은 교전의 전장 이름표·HP와 플레이어 HUD를 따로 생략했다. 21:32 KST에는 함수 호출을 별도로 기록했다. 계측 오버헤드가 붙는 실행은 FPS 대조에서 제외했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 근거리 파츠 묶음 제출은 앞선 대화에서 수용됐다. 24m 프리셋과 진단 조건의 선택은 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 작업 트리의 공통 PBR·텍스트 렌더러에 미커밋 의존성이 있었다. 기존 벤치마크만 적 배치를 바꿀 수 있었고, 일부 검사는 예전 에너지 전달 방식과 글자 캐시 키에 의존했다.
- **I2** Intel Graphics, FHD, 중간 품질, PBR, 1,000기·12m·SMG의 전체 표시 기준은 회차별 16.35·19.60 FPS였다. 프레임 작업 시간 p95는 93.75·78.36ms로 60 FPS 예산 16.67ms를 넘었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1 ↔ I1** 로컬 커밋에 들어갈 소스와 공개 샘플 설정을 분리해 검증했다. 기체 배치는 교전 생성 시 한 번 정하며 F5에서도 같은 수와 위치를 복원한다. 기존 사운드 실험과 제작 도구 변경은 별도로 보존했다.

## 7. AI 해결 제안과 실제 해결 과정

- **연결 검증** 분리한 소스와 기존 로컬 에셋으로 일반 Combat 900기·3배속 Combat 1,000기를 각 12프레임 실행했다. 마지막 프레임에서 두 테스트 모두 근거리 12기 묶음·원거리 40기 공유·근거리 그림자 1회 제출을 확인했다. 검 이동은 PBR로 6프레임 실행했다. 벤치마크의 별도 12프레임 대조에서는 전장 이름표 생략 시 텍스트 제출이 135건에서 장면 상태 표시 1건으로 줄었고 근거리 묶음은 12기를 유지했다.
- **자동 검사** 렌더러 `4d6bf14`와 테스트 연결 `e2e410a`의 소스는 전체 1,116개 실행, 61개 생략, 실패·오류 0건이다. 같은 소스의 실제 OpenGL 검사 25개가 통과했다. 별도 개발 변경이 있는 작업 트리는 전체 1,141개 실행, 70개 생략, 실패·오류 0건이다. 작업 트리의 파츠 합성까지 포함한 실제 OpenGL 검사 27개도 통과했다. 모든 실행의 오디오 출력을 껐다. 원자료는 `output/performance/crowd_commit_review/`에 있다.
