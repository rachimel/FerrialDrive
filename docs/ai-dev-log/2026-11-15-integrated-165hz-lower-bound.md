# 내장 그래픽 FHD 165FPS 하한 목표와 저사양 후보

- **기록 ID:** `FDLOG-20261115-integrated-165hz-lower-bound`
- 대화·작성 날짜: 2026-11-15 KST. 개별 발언 시각은 미수집이다. `[[FDLOG_MISSING_TIME:FDLOG-20261115-integrated-165hz-lower-bound:scope]]` 검색 단서: `FHD 165Hz 하한 목표`, `Celerlon`, `N5105급 4코어`, `2016년도 표준 최저 사양`.
- 근거: 현재 대화, PRE-PRD·성능 목표 문서, Intel/Microsoft/게임 공식 자료. 성능 수치는 앞선 계측 결과를 참조하며 이번에 다시 실행하지 않았다.
- **상태:** 개발 목표 문서 반영. N5105·RAM 4GB의 공식 최소 사양 채택은 검토 중이다. 게임 코드·FPS 제한 변경, 기기별 테스트·새로운 성능 보장은 없다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 하한 개발 목표를 내장 그래픽의 FHD 165Hz로 지정했다. 목표 지정 자체가 사용자 발언의 근거이며 별도의 동기는 제공되지 않았다. 출처·시각은 scope 참조.
- **사용자 제안 2 (U2):** Celeron·내장 그래픽·RAM 4GB를 하한으로 잡을 수 있는지 질문하고, 후속 확인에서 N5105급 4코어를 후보로 지정했다. 가능성 평가 요청이며 최소 사양 채택 지시와 구분한다. 출처·시각은 scope 참조.
- **사용자 제안 3 (U3):** 2016년의 표준 최소 사양을 질문했다. 프로젝트의 최소 사양을 2016년 게임 기준으로 확정한 발언은 아니다. 출처·시각은 scope 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 내장 그래픽 FHD 165FPS, 프레임당 약 6.06ms의 개발 목표로 PRE-PRD·성능 목표·렌더링 안내에 반영했다. 모니터의 출력 주사율과 실제 게임 FPS 달성을 구분했다.
- U2를 구체적인 저사양 검토 후보로 남겼다. RAM 8GB 검증 기준을 4GB의 확정 최소 사양으로 교체하지 않았다. U3은 당시 출시 게임의 공식 사양으로 비교 설명했다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** N5105·RAM 4GB는 저사양 검증 후보로 두고 실제 FHD 165FPS 하한 채택은 부하 테스트 후 결정한다. 이유는 앞선 상위 측정 장비의 1기 공격 표본도 CPU 측 평균 17.77ms로 6.06ms 예산을 넘었고, 수백 기·N5105·4GB의 실측이 없기 때문이다. 약 2.93배의 시간 차이를 다른 CPU의 성능 배수로 환산하지 않았다.
- **AI 제안 2 (A2):** 2016년 게임별 최소 사양은 참고 자료로만 사용하고, 그 사양을 165FPS 또는 N5105 내장 그래픽과 동급으로 간주하지 않는다. 이유는 게임별 CPU·GPU·RAM 조건과 FPS·품질·전투 규모가 다르기 때문이다.
- 제안 근거는 현재 대화의 설명과 아래 공식 자료이며 개별 시각은 scope 참조.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 내장 그래픽 FHD 165Hz 개발 목표는 U1로 명시 지정됐다. N5105급은 U2에서 검토 모델로 확인했다.
- N5105·RAM 4GB가 목표 성능을 충족한다는 사용자 승인이나 AI 실측은 없다. A1의 공식 최소 사양 채택 보류와 A2의 비교 해석에 대한 별도 사용자 결정은 아직 없다.

## 5. 반영 후 발견한 문제

- **I1:** 현재 실행 루프의 기본 60FPS 제한과 새 개발 목표 165FPS는 다르다. 문서의 목표 변경을 코드에서 165FPS를 구현한 것으로 보고하지 않는다.
- **I2:** N5105·4GB는 성능·메모리·공유 GPU·드라이버 조합을 확인하지 않았다. Windows 11의 설치 최소 RAM 4GB는 이 게임에 4GB가 남는다는 뜻이 아니다.
- **I3:** 이전 사양표의 60Hz 하한·165Hz 산정 보류 표기는 새 U1과 충돌해 현행 목표 표에서 수정했다. 과거 계측·당시 검토 로그는 보존했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1·I3 ↔ U1: PRE-PRD의 그래픽·메모리 검증 대상·표시 FPS 절을 일치시키고, Live2D 24FPS는 게임 표시 주기와 별도라는 규칙을 유지했다. QHD의 하한 기기·목표 FPS는 미정으로 남겼다.
- I2 ↔ U2: 후보는 N5105급 4코어·내장 GPU·RAM 4GB로 구체화했으나 실제 최소 사양은 미정이다. 기본 시나리오 1GiB·큰 시나리오 2GiB, 기본 품질 50%는 유지했다.
