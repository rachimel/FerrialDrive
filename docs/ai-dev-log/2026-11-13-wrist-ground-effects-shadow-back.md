## 7. AI 해결 제안과 실제 해결 과정

- I1: Unreal 12모션의 실제 120Hz 572표본에서 검 19부품×오른팔 15부품의 삼각형 표면 교차가 0이었다. 파지 위치 오차 최대 약 0.000105cm다. 체적 포함·최소 여유·전체 전투 모션의 무간섭이나 사용자 외관 승인을 뜻하지 않는다. 원본 `.blend`를 수정하지 않았다.
- 96방향 클립/448프레임을 새 후보에 렌더하고 그림자·벡터 변환과 보간·압축을 완료했다. 기존 대기/달리기 32클립을 유지해 이동 128클립으로 연결했다. 다른 초기 제작 프로젝트의 오래된 달리기를 최신 훈련장에 덮지 않았다.
- I2: 현재/다음 그림자를 각자의 크기·기준점으로 공통 출력 사각형에 배치하고 별도 텍스처로 샘플링한다. SW·NE 전환의 튀는 그림자가 연속 캡처에서 사라졌다. 서로 다른 크기/기준점의 두 그림자가 보간 0/0.5/1에서도 같은 화면 위치에 유지되는 실제 GPU 회귀 검사를 추가했다.
- I3: Trail은 활성 상태에서 매 프레임 실제 노즐을 따라간다. 연기는 부드러운 전체 알파 영역을 별도로 잘라 경계를 완화했다. 마찰/흙은 discard와 coverage fade, 연기/Trail은 알파를 사용한다. CPU 발생·수명 목록과 GPU 표현이며 GPU 시뮬레이션/Instancing/overdraw 최적화 측정 완료는 아니다.
- 최종 계열 OpenGL 재현은 8방향·일반/대시 4타·정지까지 820프레임이다. 일반 1·2타는 발생 없음, 일반 3·4타는 `attack`, 대시 네 타격은 `dash_attack`을 trace와 이미지로 확인했다. 최대 96개/상한 128개, 종료 시 0개다. 실제 키보드 조작·사용자 사용감 승인은 별도다.
- 관련 자동 검사와 숨긴 실제 OpenGL 검사 **61개 최종 통과**. 실제 부스트 중 공격에서도 부스트 표현을 유지하는 규칙, 노즐 분사 위치와 부스트 Trail 강화, 3프레임 마찰 소멸을 포함한다. 부스트 도중 공격 재입력의 실제 화면 검증은 별도로 수행하지 않았다.
- 백웨폰 56프레임은 모두 잘림이 없고, 8개 파츠 재합성과 통짜 기준의 알파/RGB 차이가 0이었다. 6면/8방향 이미지를 직접 확인했다. 출력은 검 대기 자세 기준이며 실제 백웨폰 장착·스왑·다른 자세 합성은 미연결이다.
- 금속 프로필은 불꽃/연기로 분기하지만 실제 금속 지형이 없어 지형 판별·실제 금속 화면 검증은 미수행이다. 주변기기 발열 확인 때 멈춘 후처리는 사용자의 계속 진행 지시에 따라 완료했다. 충전 발열의 원인은 확정하지 않았다.
