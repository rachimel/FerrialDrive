# 적 확대 시트 통합과 교전 병목

**기록 ID** `FDLOG-20261121-enemy-upscale-sheet`

**범위** 2026-11-21 KST. 게임용 Python, FHD, Intel iGPU에서 측정했다.

## 1. 사용자가 제안한 것

- **U1** 적마다 반복하던 확대 렌더 패스를 통합한다.
- **U2** CPU 제출에 국한하지 않고 전반적인 병목을 찾아 공격적으로 줄일 순서를 결정한다.
- 정확한 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-enemy-upscale-sheet:U1-U2]]이다. 같은 대화에서 `확대 렌더 패스 통합하고`, `전반적인 Bottleneck`으로 찾을 수 있다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 적 본체를 기종별 네이티브 시트에 합성한 후 영역별 Bicubic과 SMAA의 에지·가중치·블렌드 단계를 시트로 확대했다. 최종 화면의 앞뒤 순서는 기존 배치를 그대로 따른다.
- **U2** 기본 교전과 적 180기 부하에서 본체·그림자, 플레이어 PBR과 잔상, HUD, 월드 효과, 아틀라스 적재, 군집 갱신, GPU 패스, 프레임 지연, 메모리 가드를 검토했다.

## 3. AI가 제안한 것

- **A1** 기종별 확대 결과만 보존하고 네이티브 타깃·SMAA 임시 타깃·셰이더는 교전 뷰에서 순차 공유한다. 시트 크기는 사용 영역에 따라 확보한다.
- **A2** 동일 자동 입력에서 네 프레임마다 기존·통합 경로를 ABBA 순서로 교대해 시스템 속도 변화의 영향을 줄인다.
- **A3** 28기에서는 HUD의 정적 패널·텍스트와 플레이어 PBR 잔상을 다음 대상으로 검토한다. 밀집 교전에서는 화면상 크기에 따른 적 렌더 비용과 군집 갱신을 별도로 줄인다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 확대 통합과 전반 병목 진단을 사용자가 요청했다. 공용 임시 타깃, 교대 계측, 다음 순서는 구현상 판단과 진단 결론이다.

## 5. 반영 후 발견한 문제

- **I1** Bicubic 단독 확대의 시트 후보는 개별 확대 화면과 일부 픽셀 차이가 반복됐다. 확대 배율과 렌더 상태를 바꿔도 같은 차이가 남았다.
- **I2** 고품질 2 GiB 프로필은 통합과 개별 확대 모두 준비 중 가드에서 정지했다. 중단 직전 샘플은 각각 약 1,926 MiB와 1,924 MiB였다.
- **I3** 전체 FPS는 독립 실행과 긴 회차 교대에서 편차가 컸다. 30.9→43.8 FPS는 단일 독립 실행의 결과다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1·U2** 확대 통합을 적용하고 FPS 원인을 렌더 및 갱신 구간별로 대조했다. 프레임 목표 16.67ms를 넘기는 측정값을 후속 순서에 사용했다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1 ↔ A1** SMAA 확대를 통합하고 AA 끔 설정은 개별 Bicubic 경로를 사용한다. 스파이더·메카가 겹친 화면을 1.2×와 1.85×에서 대조했다. 임시 시트 공유에도 기존의 가림과 필터를 픽셀 검사로 확인했다.
- **I2 ↔ A1** 임시 타깃을 공유하고 시트 할당 영역을 줄였다. 고품질 가드 동작은 유지됐다. 보통 품질 2 GiB는 220프레임을 완료했고 42.7 FPS였다.
- **I3 ↔ A2** 최종 프레임 교대 360개에서 기존→통합 평균 24.50→23.33ms, p95 32.68→30.75ms였다. 렌더 제출은 평균 22.21→21.01ms였다. 독립 경로의 적 렌더 타깃 전환은 약 32.1→12.3회/프레임이었다.
- **A3** 통합 후 28기에서 프레임 작업 22.8ms, GPU draw 8.9ms, HUD 7.1ms, 플레이어 표면 5.0ms, 적 렌더 3.8ms, 갱신 1.8ms였다. 플레이어 잔상 구간은 2.9ms이며 표면 계측과 중첩된다. 별도 GPU 패스 계측의 시트 확대는 평균 약 0.17ms/프레임이었다.
- **A3** 180기에서 작업 40.4ms, GPU draw 12.2ms, 적 렌더 10.6ms, HUD 9.0ms, 갱신 7.0ms였다. 그중 군집 이동은 게임용 Python 경로에서 3.7ms였다. 아틀라스 파일 읽기는 실행 중 최대 50.8ms가 기록됐다. 파일 계측에는 준비 구간도 포함되므로 이 수치를 프레임 p95에 직접 귀속하지 않는다.

## 확인 상태

- 기존 품질을 유지한 자동 픽셀 검사와 고품질·보통 품질 네이티브 벤치마크를 수행했다. 60 FPS 목표는 미달이다.
- 재현용 진단과 원시 보고서는 `output/performance/enemy_sheet_upscale_r01/` 아래 `final_paired`, `wide`, `stress180`, `gpu_passes`, `final_capped_medium`에 있다.
