# 적 이동·공격 선적재와 록온 HUD 표시

**기록 ID** `FDLOG-20261120-enemy-preload-hud`

## 1. 사용자가 제안한 것

- **U1** 이동·공격처럼 사용할 적 모션은 교전 로딩 때 준비한다. 여러 적의 첫 재생 시점에 로딩이 겹치는 일을 줄이려는 요청이다.
- **U2** 적 이름은 디버그 표시이므로 평상시에는 생략한다. 적 정보는 기존 록온 HUD로 충분하다고 판단했다. 두 제안의 개별 발언 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261120-enemy-preload-hud:U1-U2]]이다. 검색 단서는 `로딩 시간에서 미리 캐싱`과 `록온 했을 때만`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1·U2** 2026-11-20 KST에 적 리소스 초기화와 전장 이름표 기본값을 별도 기능으로 검증하고 커밋했다.

## 3. AI가 제안한 것

- **A1** 기종별 기존 GPU 예산 48MiB 중 최대 36MiB를 선적재에 사용한다. 중간 품질에서 두 모션 8방향 전체가 소형 약 48MiB, 중형 약 57MiB였고 전투 중 피격·Break를 올릴 공간도 필요하다. 선적재 후보에는 설정의 공격별 대체 모션도 포함한다.
- **A2** 전장 이름·공격 단계·체력 막대·Break 글자는 벤치마크의 `debug_enemy_labels`에서 다시 켤 수 있도록 한다. 기존 표시로 비용을 대조하기 위한 선택이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자는 로딩 중 적 모션 준비와 록온 HUD 사용을 직접 요청했다. 36MiB 선적재 상한, 방향 순서와 진단 옵션은 구현 과정에서 AI가 정했다.

## 5. 반영 후 발견한 문제

- **I1** 정면·후면·좌우 순으로 계속 이동과 공격을 번갈아 올린 첫 구현은 1,000기 교전의 91~150번째 프레임에 대체 포즈가 1,149회였다. 기존 방식의 같은 구간은 206회였다.
- **I2** 이름표를 끈 시험에서 전장 텍스트 제출은 줄었지만 최초 교차 측정의 전체 FPS는 오르지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1 ↔ I1** 요청에 따라 실제 이동·공격 방향 JSON과 코팅을 로딩 단계에서 읽고, 기종별로 텍스처를 공유했다. 소형·중형 모두 낮음·중간·높음 품질에서 이동·공격 메타데이터 각 8방향을 확인했다.
- **U2 ↔ I2** 일반 교전은 각 적의 디버그 표시를 생략한다. 기존 HUD 위젯에 록온이 없을 때 이름 제출 0건, S1 록온 시 해당 이름 1건을 확인했고 피격 후 선택 대상의 체력 갱신도 검사했다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1 ↔ I1** 정면·후면의 이동과 공격을 먼저 준비하고 나머지는 이동을 우선했다. 중간 품질에서 소형은 이동 8·공격 4방향에 35.99MiB, 중형은 이동 8·공격 3방향에 35.82MiB였다. 예산 밖 방향은 기존 전투 스트리밍으로 준비한다. 커밋은 2026-11-20 23:28:51 KST `71a8438`이다.
- **초기 재생 대조** FHD·중간 PBR·1,000기·12m 간격·SMG 무음 자동 교전에서 같은 입력으로 150프레임을 기록했다. 기체 한 기가 한 프레임에 다른 포즈를 쓸 때마다 1회로 셌다. 최초 30프레임은 2,165회에서 136회, 전체 150프레임은 3,684회에서 703회로 줄었다. 91~150번째 프레임은 206회에서 297회였다. 해당 실행의 전체 장면 로딩은 0.876초에서 1.008초로 늘었다.
- **A2 ↔ I2** 두 조건 모두 마지막 프레임의 표시 후보는 306기, 파츠로 그린 기체는 285기였다. 이때 기본 화면과 진단 화면의 전장 텍스트 제출은 각각 1건과 306건이었다. 기본 화면의 1건은 교전 상태 안내다. 작업 폴더의 준비 0프레임·측정 90프레임 대조에서 평균 FPS는 기본 14.59·14.60, 디버그 표시 16.14·18.26이었다. 커밋은 2026-11-20 23:34:01 KST `e270a09`다.
- **커밋 기준 교차 대조** FHD·중간 PBR·1,000기·12m 조건에서 준비 30·측정 90프레임으로 표시 순서를 뒤집어 다시 측정했다. 기본 화면은 29.15·25.32 FPS, 전장 디버그 표시를 켜면 22.89·25.60 FPS였다. CPU 렌더 제출은 기본 20.58·22.80ms, 디버그 표시 28.52·23.90ms였다. 전체 FPS의 일관된 상승과 60 FPS 달성은 확인되지 않았다.
- **검증** 커밋 기준 전체 무음 자동 검사 1,119개 중 63개 생략, 실패 0개였다. 별도 실제 GPU를 포함한 교전·묶음 검사 29개, 작업 폴더의 교전·HUD 검사 51개가 통과했다. 직접 조작감과 육안 평가는 이번 검사 범위 밖이다.
