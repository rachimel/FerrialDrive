## 결정

- 현행 흐름은 **JANIMA로 레퍼런스 이미지 생성 → GPT로 디테일 보정**이다. 사용자가 결과를 확인·채택한다.
- 별도 LoRA 학습·데이터 선별 자료는 과거 기록으로 보관한다.
- 로제 프롬프트, 외부 Anima-Style-Lab 앱과 현행 JANIMA 워크플로우, Blender·Live2D 도구는 유지한다.
