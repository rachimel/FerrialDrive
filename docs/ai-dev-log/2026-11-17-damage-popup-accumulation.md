# 순간 피해 숫자의 대상별 0.1초 합산

- **기록 ID:** `FDLOG-20261117-damage-popup-accumulation`
- 대화 범위: 2026-11-17 KST 현재 세션. 개별 요청·선택 응답의 정확한 시각은 제공되지 않았다. `[[FDLOG_MISSING_TIME:FDLOG-20261117-damage-popup-accumulation:scope]]` — 검색 단서: `데미지 인디케이터에서 순간 데미지 accumulation해서 한 번만`, `0.1초 단위` 선택 응답.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 데미지 인디케이터에서 순간 피해를 누적해 한 번만 표시하도록 요청했다. 내용·목적은 현재 세션의 위 원문을 따른다. 정확한 발언 시각은 scope 누락 항목을 따른다.
- **사용자 선택 (U2):** `0.1초 단위`를 선택했다. 첫 피해부터 0.1초간 모아 합계 하나를 표시하고, 연속 공격은 다음 구간으로 나누며 HP·HIT는 즉시 반영하는 선택지다.

## 2. AI가 제안한 것

- **AI 제안 1 (A1):** 대상별 합산 구간으로 0.1초·같은 프레임·0.2초의 세 선택지를 제시했다. 연사 중 표시 개수와 지연의 균형을 위해 0.1초를 권했다. 제시 근거는 현재 세션 선택 UI이며 정확한 시각은 scope 누락 항목을 따른다.
- **구현상 판단 (A2):** 첫 피해의 위치·방향·마감을 고정하고 합계가 확정된 뒤 자릿수 크기·겹침 회피 배치를 계산한다. 계속 맞아도 표시가 무기한 미뤄지지 않게 하고 표시 중인 숫자는 변경하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1/U2를 수용했다. `DamageNumbers`에 대상별 대기 묶음을 추가하고 현재 UI v2 설정을 `damage_popup.accumulation_seconds=0.1`로 연결했다. 재사용 모듈의 기본값 0은 기존 개별 즉시 표시를 보존한다.
- 피해·HIT/DAMAGE·피격 반응·흡수 경로는 명중마다 즉시 처리한다. 숫자 생성만 합산 마감까지 기다린다. 다른 적·플레이어는 owner별로 분리한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1의 0.1초 단위를 U2에서 명시 수용했다. A2의 세부 배치와 표시 체감에 대한 최종 사용자 승인은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

- I1: 기존 검사 일부가 명중 직후 숫자가 존재한다고 전제했다. HP·HIT의 즉시 반영 검사는 유지하고 숫자 검사는 합산 0.1초 뒤 확인하도록 갱신했다.
- I2: UI v2는 Overdrive에서 `delta_seconds`를 애니메이션 속도로 가속했다. 그대로 사용하면 합산 0.1초도 실제 0.05초가 된다. AI가 현재 호출 코드를 확인해 발견했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1/U2대로 대상별 0.1초 합산을 구현했다. 같은 적의 직격 25+폭발 13은 38 한 개, 다른 적의 13은 별도 13으로 표시한다. 미표시 대기는 일시정지·메뉴에서 멈추고 초기화·owner 삭제 시 제거한다.

## 7. AI 해결 제안과 실제 해결 과정

- I2 해결: `DamageNumbers.update`의 표시 애니메이션 시간과 `accumulation_delta_seconds`를 분리했다. UI v2가 합산에는 `wall_seconds`를 공급해 Overdrive 중에도 실제 0.1초를 유지한다. 기존 등장/퇴장 재생 속도는 보존한다. 마감을 넘긴 프레임의 경과분만 새 팝업 애니메이션에 반영하고 이미 수명이 끝난 묶음은 띄우지 않는다.
- 관련 자동 검사 **185개 통과**: `test_ui_damage_popups`, `test_ranged_movement`, `test_movement_hud_integration`, `test_overdrive`, `test_ui_v2`, `test_ui_v2_hit_feedback`, `test_camera_impact`, `test_combat_application`, `test_enemy_encounter`. 대상 분리·고정 마감·합계 자릿수·첫 위치·프레임률·표시 수명·일시정지·초기화·Overdrive 실제 초·즉시 HP/HIT/흡수를 확인했다.
- OpenGL 도형 교전: 같은 대상에 25+13, 다른 대상에 13을 공급했다. HP 180→142·HIT 3·총 피해 51은 즉시 반영하고 0.1초 합산 후 팝업은 S1=38·S2=13 두 개였다. `output/damage_accumulation_20261117/report.json`과 `combined_damage.png`를 저장하고 AI가 이미지를 직접 열어 표시를 확인했다. 실제 플레이 사용감과 사용자 외관 승인은 별도다.
