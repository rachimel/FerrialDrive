# 부스트 분사음·공격 발 디딤과 레이더 축소 조정

- 근거: 현재 대화의 요청·선택 응답과 이번 코드·설정·출력·검사 결과.

## 1. 사용자가 제안한 것

- **U1:** 앞서 제공한 게임 부스트 레퍼런스 6개를 참고해 더 찰진 부스트음을 만든다. 이전 지시인 과도한 유사성 제한을 유지한다.
- **U2:** 레이더의 기본 반경을 약간 줄이고 대시 0.75배·부스트 0.7배를 시험한다. 확인 질문에 `레이더 크기 — 카메라 줌은 유지`와 `260px로 적용`을 명시 선택했다. 일반 이동 배율은 긍정적으로 평가했다.
- **U3:** 일반 공격에 발 스텝 소리를 시험 연결한다. 별도 동기·정확한 접지 시각은 직접 지정하지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 게임 원본 PCM은 합성에 사용하지 않고 보존된 CC0 원본에서 새 부스트음을 제작·연결했다. 기존 선택 부스트 WAV·원본은 보존하고 로컬 bank의 교체 전 사본도 남겼다.
- U2: 정지 반경 260px, 일반 이동 90%·대시 75%·부스트 70%다. 화면 반경은 각각 260/234/195/182px다. 0.2초 전환과 대시·부스트 불투명 표시를 유지했다. 카메라는 1/1/0.9/0.85배 그대로다.
- U3: 일반 검 공격 1~4타에 타격당 한 번의 발 디딤을 연결했다. 정확한 접지 검증 완료로 확대하지 않는다.

## 3. AI가 제안한 것

- **A1:** 레이더 260px를 제시하고 새 배율이 레이더인지 카메라인지 물었다. 현재 설정의 대상과 감소량을 확정하기 위한 질문이다.
- **구현상 판단 A2:** CC0 공기 녹음과 기계 충격·클릭을 대역·길이·포락선별로 조립했다. 0.38초 본체와 0.5초 감쇠 잔향, 최종 0.88초다. 짧은 발진·공기 분사·종료 감쇠를 분리해 조정할 수 있게 했다. source.json에 보존된 원본 표기와 해시를 따르며 제작 입력은 `whoosh/whoosh2_0.wav`, `mechanical/lightclunk2.wav`, `mechanical/typewriter.wav`뿐이다.
- **구현상 판단 A3:** 기존 발걸음 두 층을 gain 0.65로 재사용한다. 원본 모션 진행률의 임시 위상 [0.18, 0.18, 0.2, 0.18]에서 한 번 발생시킨다. 활주·부스트 공격에서는 해당 접지 사건을 소모해 나중에 뒤늦게 발 소리가 나오지 않게 한다. 타격 구간 데이터에 당시 boost 상태를 보존한다.
- **구현상 판단 A4:** 기존 `sound-effects`에 `layered_burst` 공통 가공과 `--only` 선택 생성을 추가했다. 청취 도구는 단발·연속 부스트·발 디딤과 4타의 음량 확인을 지원한다. 런타임에 추가 오디오 패키지를 요구하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1은 위 사용자 선택 응답으로 명시 수용됐다. U1/U3의 구현은 직접 요청 범위다. A2/A3의 음색·음량·타이밍에 대한 사용자 청취 수용은 아직 없다.

## 5. 반영 후 발견한 문제

- **I1:** 코드 검토에서 현재 4타 휘두르기음은 진행률 0부터 시작함을 확인했다. 청취용 고정 간격 예시에서 모든 타수의 발 소리를 먼저 놓으면 실제 순서와 다르므로 4타는 휘두르기 뒤 발 소리로 조정했다. 청취 예시는 실제 모션 접지 검증을 대신하지 않는다.
- **I2:** 부스트가 프레임 안에서 끝나면 마지막 controller 상태만으로 발 소리를 허용할 수 있다. 타격 구간에 boost 상태를 기록해 그 구간의 접지 여부를 유지했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2 선택 응답으로 레이더/카메라 대상의 모호함을 해결했다. 이후 카메라 수치를 임의로 변경하지 않았다. 추가 반영 후 오류에 대한 별도 사용자 해결 제안은 현재 대화에서 제시되지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- 새 `boost_impulse.wav`를 공통·demo 폴더에 생성하고 공통 bank와 로컬 사용자 bank를 연결했다. 종전 `user_boost.wav`·원본·처리 설정은 유지했다. 레퍼런스 변환본은 `output/audio/boost_reference_design/reference/`의 분석 출력이며 제작/게임 입력이 아니다.
- **자동 검사:** 최종 전체 828개 실행·782개 통과·46개 환경 제외·실패 0개. UTF-8과 프로젝트 내부 임시 폴더 환경이다. 타격당 중복 방지·여러 타격 통과·활주/부스트 제외·boost 종료 구간 보존·가공 진폭/꼬리·레이더 목표 값을 포함한다.
- **실제 믹서 기록:** 부스트 단발 1회·0.28초 간격 4회, 공격 4타와 발 소리 4회 기록 모두 클리핑·레이어 누락 0개다. 단발 진폭 최대 8335, 연속 8439, 공격 예시 14859/32767이다. 음색·원작과의 청감상 유사성 평가나 법적 판단으로 확대하지 않는다.
- **실제 게임 연결:** 숨긴 OpenGL 창에서 로컬 기체+오디오를 연결했다. 부스트 사건 1회에 새 WAV 1회, 일반 공격 6회에 발 디딤 6회가 기록됐고 레이어 누락 0개다. 정지·일반 이동·대시·부스트·복귀·초기화의 trace와 레이더 캡처를 확인했다. AI는 정지·대시·부스트 화면을 직접 열어 검토했다.
- **청취 결과:** `output/audio/boost_reference_design/mixer/boost.wav`, `boost_repeated.wav`, `attack_preview/attack_steps.wav`, `before_after.wav`(종전→새 부스트), 입력 해시·설정·연결 보고서 `design_report.json`이다. 음원·원본·로컬 bank 사본·시연 생성물의 Git 제외를 확인했다.
- 현재 명세·샘플 안내를 갱신했다. 실제 스피커 청취·접지 프레임 정밀 동기화·사용자 음색 수용·커밋·업로드는 미수행이다. 기존 다수의 미커밋 변경은 혼합하지 않았다.
