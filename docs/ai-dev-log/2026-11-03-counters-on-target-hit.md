# 적중 시 HIT·DAMAGE 표시

- 작성일: 2026-11-03, 한국 시간
- 사용자 확정: 카운터들은 내 공격이 적에게 적중할 때 모두 표시한다. DAMAGE는 내가 입힌 피해다. 이전 출현 조건 확인 대기를 이 결정으로 해소했다.
- 공통 `CounterVisibility`를 추가해 값·숫자 이동과 표시 수명을 분리했다. 최초·초기화 시 숨기고, 샘플의 적 피해가 양수로 적용될 때만 두 카운터를 함께 켠다. 플레이어 피격·타겟 전환·메뉴 진입·무효 공격은 표시 수명을 갱신하지 않는다.
- 마지막 적중 후 2초 유지·0.3초 SmoothStep 페이드는 AI가 둔 조절용 시안이며 확정 전투 규칙이 아니다. `counter_visibility`에서 조절하며 추가 적중으로 시간을 갱신한다. 숨김은 HIT·누적 가한 피해를 초기화하지 않는다. 메뉴에서도 표시 시간은 흐른다.
- `UiView.combat`에 공통 `counters_opacity`를 전달해 숫자·라벨·방향성 블러 전체에 장면 알파와 함께 적용한다. 기본값은 0이며, 본편 연결부는 실제 유효 적중에서 `show()`를 호출한다.
- 변경 코드와 연결을 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 최초 숨김·적중 시 출현·피격만으로 출현 없음·시간 경과 페이드·재적중 갱신·초기화 숨김을 확인한다.
