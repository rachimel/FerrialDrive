# Unreal 프리렌더·툴 2D 조립 구현

- 기록 ID: FDLOG-20261110-unreal-prerender-parts
- 상태 확인: 2026-11-10 23:26 KST. 개별 발언의 정확한 시각은 미확인 — [[FDLOG_MISSING_TIME:FDLOG-20261110-unreal-prerender-parts:scope]] 현재 대화의 `그렇게 구현하고, 파이프라인 문서 수정해줘` 발언에서 보완한다.

## 1. 사용자가 제안한 것

- U1: Unreal 프리렌더와 툴 파츠 조립 분리 안을 구현하고 문서를 갱신하도록 요청했다. 출처: 현재 대화. 이전 `.blend` 반환 선택 뒤 다시 검토한 안을 최종 구현 대상으로 수용했다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 현행 경로로 채택했다. Blender 모델링 → Unreal 새 리깅·애니메이션·프리렌더 → PNG 파츠+JSON → 기존 툴 2D 조립·패킹 → Pico2D다. 모델 원본은 보존하며 기존 Blender 리그는 재사용하지 않는다.

## 3. AI가 제안한 것

- A1(구현상 판단): 새 조립기를 만들지 않고 기존 MechBundle·Asset Tool 작업본/출력을 재사용했다. 새 `unreal.import`는 RGBA 프레임을 기존 시트 v1·메카 v2로 패킹한다.
- A2(구현상 판단): 기존 뷰포트 캡처 문제를 피해 별도 Unreal 5.8 프로세스에서 기본 Movie Render Queue와 Actor Layer stencil 출력을 사용했다. 설치된 기본 Cube와 자체 단색 재질로 독립 시연했다. 외부 에셋/유료 플러그인을 추가하지 않았다. 기존 DCC 재사용 계약을 검증했고 공식 기본 기능을 선택했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 앞선 AI의 Unreal 프리렌더·툴 2D 조립 제안은 U1로 수용됐다. 세부 API·노출/후처리 설정은 AI 구현 판단이다. 사용자의 새 리그·최종 외관·모션 품질 승인은 별개다.

## 5. 반영 후 발견한 문제

- I1: 화면 없는 실행은 펜 입력 플러그인에서 충돌했다. 비동기 MRQ가 끝나기 전에 시작 스크립트가 종료되는 문제도 있었다.
- I2: 저장 전 맵에 생성한 카메라 바인딩으로 빈 PNG가 출력됐다. 파일 존재/렌더 콜백만으로 시각 검증 완료를 주장하지 않았다.
- I3: 자동 노출/후처리를 유지하면 참조와 재합성 색상에 최대 28/255 차이가 있었다. 알파는 같았다.
- I4: 패킹에 필요한 Pillow가 기존 Python에 없었고 pip 설치가 응답하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 책임 분리를 유지했다. 3D 파지·부착·가림은 Unreal, 툴은 2D 조립이다. `.blend` 왕복/Blender 렌더는 호환용으로 보존하고 현행 안내에서 필수 단계를 제거했다. 실제 메카의 출력 단위 분리·그림자 패스·동작 품질은 미완료로 표시했다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 일반 Unreal 렌더 프로세스와 keep-python-alive를 사용했다. 기존 사용자 에디터를 종료하지 않았다. 새 폴더·기존 큐/출력 덮어쓰기 거부·제한 시간·완료 상태 확인을 추가했다.
- I2: 맵을 먼저 저장한 뒤 카메라를 바인딩했다. 이미지를 직접 열어 본체·무기 표시를 확인했다. `unreal.import`는 전체 본체가 투명하면 입력을 거부한다. 출력 경로를 프로젝트 output 아래로 고정했다.
- I3: 파츠 정합 프리셋에서 자동 노출·블룸·모션블러·다중 픽셀 후처리를 비활성화했다. 실제 Unreal 렌더의 본체/무기 2레이어 × 2정지 프레임을 패킹·재합성한 RGBA 최대 차이는 두 프레임 모두 [0,0,0,0]이었다. 기존 plan.create/export도 통과했다. GUI 직접 조작과 실제 메카/그림자 전용 패스는 미검증이다.
- I4: 공식 PyPI wheel의 게시된 SHA-256을 대조하고 Pillow 13.0.0을 automate/runtime/image/python에 설치했다. 원본 wheel·버전·해시·라이선스를 로컬에 보존하고 일반 환경을 변경하지 않았다. 응답 없는 이번 작업의 설치 프로세스만 종료했다.
- 자동 검사 4개 통과: 프레임 좌표·원본 보존, 누락 파츠/외부 경로/빈 본체 거부. 근거: 로컬 `output/unreal_prerender_demo/validated_verification.json`, `validated_recomposed.png`, `validated_tool_export/mech.json`. 시연은 [샘플](../../samples/unreal_pipeline/README.md), 계약은 [파이프라인](../ai-asset-pipeline/unreal_pipeline.md)을 따른다. 커밋·업로드는 수행하지 않았다.
