# UI v2 맵·통신 반투명 Scanline

- **기록 ID: ui-v2-transparent-scanlines**. 원래 대화·구현·정리: 2026-11-11 KST, 현재 대화.
- 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:ui-v2-transparent-scanlines:scope]] 검색 단서: `맵은 테두리 빼거나`, `맵과 통신 패널에 투명도`, `Scanline 효과 한번 적용`.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1)**: 맵은 테두리를 빼거나 통신 패널과 다른 효과로 구분한다. 이유는 통신 패널과 다른 표현이 낫다는 현재 발언이다.
- **사용자 제안 2 (U2)**: 맵·통신 패널에 투명도와 Scanline을 시험 적용한다. 근거는 현재 직접 요청이다.

## 2. AI가 제안한 것

- 별도로 수용을 요청한 후보는 없다. 구현상 판단으로 맵 테두리를 빼고 배경 불투명도 0.42/0.6, 고정 가로 패턴 4px 간격·1px 두께, 선 불투명도 0.07/0.08을 시험 적용했다. 배경에 효과를 두고 글자·지형·표식은 위에 그린다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1~U2를 반영했다. 면·테두리의 독립 구조를 유지하면서 배경 Scanline 그리기를 별도로 추가했다. 패턴 형상은 면의 사선·절단 외곽 안으로 자르고 기존 필터·텍스처 캐시를 재사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 시험 수치와 수정본 외관에 대한 명시 수용은 아직 확인하지 않았다.

## 5. 반영 후 발견한 문제

- 이번 변경에서 새 실행 오류나 검사 실패는 발견하지 않았다. 맵 테두리 제거는 사용자의 외형 변경 요청이며 이전 구현의 버그로 분류하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- 별도 문제 해결 제안은 없었다. U1에서 허용한 테두리 제거를 선택해 맵과 통신 패널을 구분했다.

## 7. AI 해결 제안과 실제 해결 과정

- UI 자동 85개·표적 획득 7개, 총 **92개 통과**. 줄무늬의 사선 면 내부 제한·잘못된 간격/두께·맵 테두리 미표시·표시 순서를 확인했다.
- SDL dummy에서 기본 전투·상단 표적·Scanline 끄기·격자 배경의 투명도 비교, 총 **4개 상태를 렌더**했다. 기본 화면과 격자 비교 이미지를 직접 열어 패널 뒤가 비치고 줄무늬가 면을 벗어나지 않는 것을 확인했다.
- 고정 Scanline이며 이동 애니메이션·등장 효과는 미연결이다. 실제 창 조작·사용자 외관 승인·업로드는 미수행이다. 출력은 `output/ui_unit_test_v2/scanline/`이며 공개하지 않는다.
