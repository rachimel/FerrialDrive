# 2020년 보급형 PC 구성의 하한 검증 기준 채택

- **기록 ID:** `FDLOG-20261115-2020-entry-pc-baseline`
- 대화·작성 날짜: 2026-11-15 KST. 개별 발언 시각은 미수집이다. `[[FDLOG_MISSING_TIME:FDLOG-20261115-2020-entry-pc-baseline:scope]]` 검색 단서: `2020년 보급형 PC 사양`, `ㅇㅇ 이정도로 하자`.
- 근거: 현재 대화의 사용자 질문·AI 구성 제안·사용자 수용. 현행 PRE-PRD와 성능 목표 문서.
- **상태:** 하한 검증 장비 지정·문서 반영. 해당 기기의 실제 실행·165FPS 달성·최종 출시 최소 사양 실측은 미검증이다. 실행 코드·설정·에셋은 변경하지 않았다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 2020년 보급형 PC 사양을 질문했다. 이유는 앞선 하한 장비 검토의 연속이며 구체적인 추가 동기는 제공되지 않았다. 출처·시각은 scope 참조.
- **사용자 제안 2 (U2):** AI가 제시한 i3-10100·UHD 630·DDR4 RAM 8GB·SSD 256GB 구성에 `ㅇㅇ 이정도로 하자`고 응답했다. 기존 FHD 165Hz·내장 그래픽 목표를 취소하거나 낮춘 발언은 없다. 출처·시각은 scope 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U2를 하한 검증 장비 선택으로 반영했다. FHD 165FPS·6.06ms, 기본 시나리오 1GiB·큰 시나리오 2GiB, 기본 50% 품질은 유지했다.
- N5105·RAM 4GB 검토는 이전 기록에 보존하고 현행 기준으로 반복하지 않는다. 사용자 수용을 실제 기기 성능 검증으로 확대하지 않는다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 2020년 사무·가정용 보급형의 대표 기준으로 Core i3-10100(4코어/8스레드)·UHD 630·DDR4 RAM 8GB·SSD 256GB를 제시했다. 시장 전체의 통일된 최저 사양이나 판매 비중 통계는 아니라고 구분했다.
- 근거는 [Intel i3-10100 명세](https://www.intel.com/content/www/us/en/products/sku/199283/intel-core-i310100-processor-6m-cache-up-to-4-30-ghz/specifications.html)와 [2020년 Lenovo 제품 자료](https://psref.lenovo.com/syspool/Sys/PDF/datasheet/ideacentre_3_07IMB05_datasheet_EN.pdf)다. 이번 문서 수정에서 외부 자료를 새로 조회하거나 기기를 벤치마크하지 않았다. 제안 시각은 scope 참조.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1의 구성을 U2로 명시 수용했다. 수용 범위는 개발·최적화의 하한 검증 기준이며 해당 구성에서 이미 FHD 165FPS가 나온다는 뜻은 아니다.
- 메모리 채널·속도, SSD 인터페이스·성능, 메인보드·출력 단자, 정확한 동시 표시량과 QHD 목표 FPS는 별도 확정 전이다.

## 5. 반영 후 발견한 문제

- **I1:** 현재 기준 문서에는 CPU·내장 GPU 세부 모델 미정과 N5105·4GB 후보 표기가 남아 새 선택과 일치하지 않았다.
- 새 제품 코드 변경이나 새로운 성능 회귀는 이번 작업에서 발견·검증하지 않았다. 기존 성능 미달과 기본 60FPS 실행 제한은 앞선 기록을 따른다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U2: PRE-PRD의 그래픽·메모리 검증 장비·목표 FPS 절과 성능 목표표를 같은 구성으로 맞췄다. N5105 검토 이력은 원기록에 유지했다.
- SSD 256GB는 기준 장비의 드라이브 용량으로 기록했으며 게임 설치 여유 공간 요구량으로 사용하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1 ↔ A1: 기존 AI 비교 후보와 사용자가 수용한 하한 장비를 구분했다. 성능 목표 문서의 CPU/GPU/RAM/SSD 선정 이유와 미검증 범위를 갱신했다.
- 확인은 문서 간 구성·목표·미검증 표시의 일관성과 차이 검사로 한정했다. 실행 코드 변경이 없어 자동 기능 검사·GPU 검사·실제 성능 계측은 새로 실행하지 않았다.
- 기존의 다수 미커밋 변경을 보존했으며 이번 문서 변경과 섞어 커밋하지 않았다.
