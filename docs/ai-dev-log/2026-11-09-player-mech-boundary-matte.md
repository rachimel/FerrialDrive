# 플레이어 메카 경계 구분선과 광택 조정

**기록 ID: player-mech-boundary-matte.** 2026-11-09 KST의 현재 대화와 당일 실행 결과다. 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:player-mech-boundary-matte:scope]] 현재 대화 원문 시각으로 보완한다.

## 1. 사용자가 제안한 것

**사용자 제안 1 (U1)**: 가슴·스커트·어깨의 돌출부와 경계를 강조하는 구분선 텍스처를 요청했다. 의도는 기존 입체 구조의 구분 강화다. 출처: “돌출부나 그런 경계면을 강조하는 그런 구분선 텍스쳐”.

**사용자 제안 2 (U2)**: 작업 도중 광택을 낮추도록 요청했다. 출처: “광택 좀 줄이자”. 별도 선택 이유는 미제시다. [[FDLOG_MISSING_REASON:player-mech-boundary-matte:U2]] 해당 발언 전후 설명으로 보완한다.

## 2. 사용자 제안 중 AI가 수용한 것

U1·U2를 반영한다. 새 숫자/임의 패널을 늘리지 않고 실제 메시 경계·급격한 꺾임을 사용한다. 공유 외장 재질은 유지하며 지정한 가슴·스커트·어깨 외장에만 구분선을 표시한다. 팬 유리의 투명도는 유지한다.

## 3. AI가 제안한 것

**AI 제안 1 (A1)**: 실제 경계와 면 법선 차이에서 1K 마스크를 생성하고 전용 UV/적용 속성으로 합성한다. 구현상 판단이다. 같은 외장 재질을 쓰는 투구와 목 아래 띠에 선이 생기는 것을 방지하기 위해 메시별 적용 속성을 사용한다. 선 폭 0.006, 경계각 32도, 도장 거칠기 0.60~0.80과 반사 강도 0.28은 사용자 지정 값이 아닌 구현/렌더 검토 값이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

구분선 추가와 광택 감소는 사용자 요청이다. 이번 결과에 대한 별도 최종 외관 수용은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

새 경계 UV 검사에서 어깨의 미세 삼각형 하나가 거의 면적 0으로 투영됐다. 조사 시 해당 형상의 3D 면적이 약 1.7e-11이며 기존 UV_Paint도 검사 임계값보다 작았다. 이를 새 경계 UV의 통과로 취급하지 않고 최소 텍셀 면적을 확보한 뒤 재검사했다. 기존 형상과 UV_Paint는 수정하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

사용자는 후보 작업 중 U2로 광택 감소를 추가 지시했다. 도장과 모서리 마찰면의 거칠기를 높이고 반사 강도를 낮췄다. 유리는 선택 대상에서 제외했다.

## 7. AI 해결 제안과 실제 해결 과정

공통 `generate_boundary_texture`·`apply_boundary_texture`·`set_surface_finish` 연산을 추가했다. 지정 외장 11개에만 UV_Boundary와 적용 속성을 만들고 경계 마스크 한 장을 추가했다. 재질 자체는 공유하며 노멀·발광 연결은 바꾸지 않는다.

1024px/240px 정면·사선·후면을 렌더해 선 밀도와 반사를 확인했다. 독립 기본 도형 샘플에서 기존 UV/형상 보존, 재질 공유 대상 중 선택 적용, 반복 적용 시 노드 중복 방지, 노멀/발광 보존, 무광 조정과 유리 속성 보존, 저장·재로딩을 확인했다. 기존 회귀 검사 15개, 새 경계 UV 범위/면적 검사와 이미지 패킹 검사를 수행했다.

원본 반영 후 별도 Blender에서 기존 형상·리그·UV/재질 슬롯·노멀·발광 보존, 11개 적용 대상/비대상 속성, 공유 재질, 도장 거칠기와 유리 투과, 125개 이미지 내용/상대 경로를 확인했다. 새 마스크를 포함한 텍스처는 textures 바로 아래에 있다. 릴리스·레지스트리·기본 제작 해시를 동기화했다. 실행 근거·검토 렌더·수정 전 복구 사본은 `output/player_mech_boundaries/`에 있다. 모델/에셋은 Git 제외 대상이며 전체 모션·게임 성능과 최종 사용자 외관 승인은 이번 검증에 포함하지 않는다.
