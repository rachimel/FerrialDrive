## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 1920×1080에서 HUD가 너무 작으므로 확대를 시험한다. 기체는 현재 크기로 유지한다. 이유는 사용자가 밝힌 HUD 가독성이다. 시각·출처는 scope를 따른다.
- **사용자 제안 2 (U2):** 일시정지창과 타이틀의 어긋난 위치를 중앙에 맞춘다. 시각·출처는 scope를 따른다.
- **사용자 제안 3 (U3):** 카메라 이동 중 모션 블러를 시험한다. 추가로 언리얼 같은 모션 블러를 요청했다. 적용 범위 질문에서 `기체·적 등 월드에만 적용하고 HUD는 선명하게 유지`를 선택했다. 의도는 카메라 이동 표현 추가이며 강도는 미지정이다. 시각·출처는 scope를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1~U3을 수용해 일반 HUD 배율·타이틀/일시정지 좌표·월드 그리기 필터를 수정했다. 1920×1080과 기체 배율 `128/202`는 유지했다. 미니맵·무장 별도 배율은 0.9를 유지했다. 수용 시각은 scope의 미확인 범위를 따른다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 일반 HUD 배율을 0.81에서 1.0으로 올려 약 23% 확대한다. 사용자의 작은 HUD 지적에 대한 제안이다. 시각·출처는 scope를 따른다.
- **구현상 판단 (A2):** 기존 좌우 타이틀 구성을 한 묶음으로 옮기고, 일시정지 패널 중심을 `(960, 540)`으로 맞춘다. 표시와 입력에 같은 설정 좌표를 사용한다. 기존 1280×720 좌표 잔존이 확인 근거다.
- **구현상 판단 (A3):** 카메라의 프레임 이동량/초와 기존 OpenGL 방향성 필터를 재사용한다. 약한 시험값으로 최초 시험은 셔터 0.012초·최대 10 화면 px·최대 세기 0.35·17샘플이었다. 이후 사용자의 언리얼 같은 느낌 요청에 따라 `amount=0.75 / target_fps=60`의 0.0125초·최대 24px·33샘플로 조정하고 원본 별도 혼합을 제거했다. 노출 길이만 속도에 비례시키며 번짐에 속도별 투명도를 다시 곱하지 않는다. 카메라 정지·일시정지·장면 전환 때 필터를 생략한다. 배경은 단색이며 기체·적 그리기만 필터 안에 둔다. HUD·피해 숫자·록온·흡수 효과는 필터 밖이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1은 `그러면 1.0으로 올려보자`로 잠정 시험을 명시 수용했다. U3의 월드만 적용하는 범위도 질문 응답으로 명시했다. A2의 세부 좌표와 A3의 강도 수치는 구현상 판단이며 사용자 최종 외관·체감 승인과 구분한다. 발언 시각은 scope를 따른다.

## 5. 반영 후 발견한 문제

- **I1:** 기존 자동 검사의 단순 Mock 뷰가 새 필터의 컨텍스트 진입을 지원하지 않았다. 해당 뷰를 MagicMock으로 바꿔 검사 계약을 맞췄다.
- **I2:** 실제 OpenGL 실행에서 필터 범위를 튜플로 전달한 오류를 확인했다. 기존 필터가 요구하는 `Rect`로 수정했다. 자동 검사만으로 실제 렌더 경로 검증을 대신할 수 없음을 구분한다.
- **I3:** 임시 파일 검사에 접근 권한 오류가 있어 같은 검사를 승인된 일반 권한으로 다시 실행했다. 캡처 비교는 새 이미지 라이브러리를 설치하지 않고 SDL의 RGBA 화면 버퍼로 확인했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2에 따라 타이틀의 로고·설명·메뉴·버튼을 함께 이동하고 일시정지 제목·버튼도 패널과 함께 이동했다. 버튼 중심의 합성 클릭으로 활성/비활성 입력 결과를 확인했다. U3의 선택에 따라 HUD 전체를 월드 블러에서 제외했다.

- I1~I2를 수정하고 `test_ui_v2*.py` 116개 중 113개 통과·선택 실행 3개 건너뜀을 확인했다. 카메라 속도·초기화·시간 0·블러 길이 제한·정지/비활성 생략·기체/적과 HUD 필터 구간 분리를 포함한다.
