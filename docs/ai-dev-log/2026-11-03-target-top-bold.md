# 타겟 패널 상단 이동·Bold·6px 바

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 타겟 패널을 상단으로 올리고 TARGET·적 이름의 굵기를 높인다. 이어서 HP 바 두께를 6px로 지정했다.
- 패널 y=88→24로 올리고 제목·이름·바도 함께 64px 위로 이동했다. 상단 중앙·패널 464×64px·양쪽 정렬은 유지한다.
- TARGET 16px·적 이름 20px는 별도 폰트 역할로 분리해 SCDream4→SCDream6(Bold)로 변경했다. 새 역할의 실제 ascent를 사용해 기준선을 맞추며, 다른 HUD 라벨·기체 표시는 기존 굵기를 유지한다.
- 타겟 HP 바 두께는 4→6px로 변경했다. HP 숫자 숨김·피해 비율·긴 이름 말줄임은 유지한다.
- 변경 내용을 읽어 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다. 실행기 완전 재시작 후 상단 위치·굵기·6px 바를 확인한다.
