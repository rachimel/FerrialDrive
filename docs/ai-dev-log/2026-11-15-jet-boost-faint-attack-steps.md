# 제트 엔진 기반 부스트와 희미한 공격 발 디딤

- 근거: 현재 사용자 요청·정정, 원본 출처 페이지·가공 설정·자동 검사·실제 믹서/게임 기록.

## 1. 사용자가 제안한 것

- **U1:** 기존 부스트음에 컴프레서가 과하게 들어간 듯하다고 평가하고 다른 제트 엔진 가속음의 가공을 요청했다. 사용자 청감 평가이며 실제 컴프레서 사용이 확인된 것으로 바꾸지 않는다.
- **U2:** 일반 공격 발 스텝을 더 희미하게 넣는다. 정확한 배율은 별도 지정하지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: 재료를 제트 엔진 시험 녹음으로 교체했다. 한 층의 녹음과 연속 가속 재생률, 가벼운 대역 정리·감쇠·짧은 잔향만 사용한다. 컴프레서·포화·기계 충격/클릭층은 사용하지 않는다.
- U2: 공통 발걸음 대비 공격 gain을 0.65→0.3으로 낮췄다. 달리기 발소리·기존 1타당 1회·대시/부스트 제외 정책은 유지한다.

## 3. AI가 제안한 것

- **구현상 판단 A1:** qubodup의 [Jet Turbine Noise.flac](https://freesound.org/people/qubodup/sounds/205581/) CC0 페이지와 공개 HQ MP3 표현을 사용했다. 로그인 다운로드용 FLAC을 받은 것으로 표시하지 않는다. 원본 페이지·MP3·SHA-256을 `data/audio/sources/jet_turbine/`에 보존했다. m_cel의 [Jet Engine](https://freesound.org/people/m_cel/sounds/534856/) HQ MP3도 비교용으로 보존했으나 최종 제작에는 사용하지 않았다.
- **구현상 판단 A2:** 선택 녹음의 4.8~5.48초를 0.58초로 옮기며 재생률 가중치 0.82→1.28을 연속 적용했다. 표본 위치에 속도 적분을 사용해 경계에서 피치가 뛰지 않게 했다. 본체 0.62초·약한 잔향 0.22초·전체 0.84초·최대 진폭 0.62다. 특정 게임 원본 PCM은 사용하지 않았다.
- **구현상 판단 A3:** 공격 발 디딤은 바닥을 짚는 느낌만 남기기 위한 시험 gain 0.3이다. 이는 이전 0.65 설정의 약 46% 진폭이며 사용자 청취 수용 전이다.
- **구현상 판단 A4:** `sound-sources --only`와 출처 명세의 공개 다운로드 URL·MP3 저장을 지원한다. `sound-effects --only boost_jet`가 기존 공통 가공기를 재사용하며 게임은 준비된 WAV만 적재한다. 사용자가 직접 올린 게임 레퍼런스 6개는 계속 분석용으로만 둔다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 원본 교체와 발 스텝 감소는 U1/U2의 직접 요청이다. A1/A2/A3의 최종 음색·배율·사용감에 대한 후속 사용자 승인은 아직 없다.

## 5. 반영 후 발견한 문제

- **I1:** U1은 이전 후보의 청감상 문제 제기다. 이전 layered_burst 후보에는 컴프레서·tanh 포화가 없었으며 레이어 합성과 포락선·정규화를 사용했다. 거친 질감의 정확한 청감 원인은 미확인 — [[FDLOG_MISSING_CAUSE:FDLOG-20261115-jet-boost-faint-attack-steps:I1]]. 검색 단서: 사용자 U1과 보존한 이전 후보/새 후보의 스피커 비교.
- **I2:** 기존 UI v2 명세 한 곳에 레이더 144px가 남아 있어 현재 260px·90/75/70%와 맞췄다. 과거 개발 로그의 수치는 이력으로 보존한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U1: 사용자가 다른 제트 녹음을 가공하는 해결 방향을 제시했다. AI는 충격/클릭층을 더 조정하는 대신 원본과 조립 방식을 바꿨다.
- U2는 gain 0.3으로 반영했다. 타이밍·달리기 음량을 함께 바꾸지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- `boost_jet.wav`를 공통·공개 도형 시연 경로에 준비하고 공통/로컬 bank의 부스트 선택을 바꿨다. 종전 user_boost·boost_impulse WAV와 원본·설정은 보존했다.
- **자동 검사:** 최종 전체 829개 실행·783개 통과·46개 환경 제외·실패 0개. 마지막 변경의 관련 검사 81개도 별도 통과했다. 연속 가속 재생률의 상승과 길이 보존, 발 디딤 gain 0.3 등을 확인했다. UTF-8·프로젝트 내부 임시 폴더 환경이다.
- **실제 믹서:** 새 부스트 단발/0.28초 간격 4회에서 클리핑·레이어 누락 0개. 최대 진폭은 단발 6983·연속 8336/32767이다. 공격 4타+발 소리 4회의 gain 0.3 청취본도 클리핑·누락 0개이며 최대 진폭 12319/32767이다.
- **게임 연결:** 숨긴 OpenGL 창에서 실제 기체·오디오를 연결했다. boost 사건 1회에 boost_jet 1회, 공격 6회에 발 디딤 6회를 확인했고 레이어 누락은 0개였다. 결과는 `output/verification/radar_zoom_20261115/jet_boost_audio/`와 `jet_attack_steps_audio/`다.
- **청취 자료:** `output/audio/jet_boost_design/mixer/boost.wav`, `boost_repeated.wav`, `attack_preview/attack_steps.wav`, `before_after.wav`(충격층 후보→제트 후보), 출처/설정/연결 기록 `design_report.json`이다.
- **유지 상태:** 레이더 기본 260px·일반 90%·대시 75%·부스트 70%, 카메라 1/1/0.9/0.85배를 유지했다. 이전 통과 검사를 현재 추가 검증으로 중복 계산하지 않는다.
