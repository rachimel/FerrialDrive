# 툴 내부 작업 폴더

작성일: 2026-11-03, 한국 시간.

## 요청

사용자가 output 삭제를 알리고, 작업본을 툴 내부 폴더에 생성하도록 변경을 요청했다.

## 반영

- 표정 스튜디오의 기본 작업 폴더를 `Tools/portrait_editor/workspace/`로 변경했다. 저장 프로젝트·레이아웃·영역 작업의 기본 위치다.
- 기존 프로젝트와 레이아웃 2개를 옮겼다. 프로젝트의 리깅 상대 경로만 바꾸고 다른 편집 값은 유지했다.
- 이동 기록과 수정 전 프로젝트는 `data/migrations/2026-11-03-tool-workspace/`에 보존했다.
- `Tools/*/workspace/`를 Git에서 제외하고 개발 지침과 현행 경로 안내를 수정했다.
- 원본·텍스처와 내보내기 폴더는 data에 유지한다. 재생성 가능한 실행 캐시·검증 결과는 output에 생성된다.
- 제거 후보 목록은 삭제 전 조사 기록으로 표시했다. 이번 작업에서 추가로 삭제하지 않았다.

## 확인

- 기존 자동 검사 14개 통과.
- 다른 작업 폴더에서 새 기본 프로젝트를 불러오고 리깅 원본·텍스처 14개의 참조를 확인했다.
- 이동 파일의 해시와 프로젝트의 나머지 편집 값 보존을 확인했다.
- 실제 창 조작은 이번에 확인하지 않았다. 업로드 여부는 별도 실행으로 구분한다.

현재 경로는 [저장 경로 안내](../tool-usage/storage_layout.md)를 따른다.
