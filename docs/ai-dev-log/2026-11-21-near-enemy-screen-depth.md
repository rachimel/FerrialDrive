# 근거리 적의 화면 깊이 선행 패스 시험

**기록 ID** `FDLOG-20261121-near-enemy-screen-depth`

2026-11-21 KST 구현·계측 기록. 비교 기준은 [근거리 적 Deferred PBR](2026-11-21-near-enemy-deferred-pbr.md)이다.

## 1. 사용자가 제안한 것

- **U1** 근거리 적에 화면 좌표를 공유하는 Z-buffer를 사용한다. 선행 패스에서 가림을 확정하고 가려진 픽셀의 재질 조회를 생략해, 동일한 180기 교전에서 기존 Deferred와 프레임·GPU·메모리를 비교한다.
- 정확한 요청 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-screen-depth:U1]]이다. 대화에서 `근거리 적만 화면 좌표 공유하는 Z-buffer`로 찾을 수 있다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** Hardware Benchmark에 `deferred_enemy_depth` 대조 조건을 추가했다. 기존 `deferred_enemies`와 동일한 고정 입력을 사용했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 기존 발밑 Y 정렬을 기체의 화면 깊이 순위로 사용했다. 깊이만 기록하는 패스에는 색상 알파·모션 벡터·로컬 깊이를 사용했다. 불투명한 파츠가 기록한 깊이를 시트에 매핑해, 가려진 픽셀은 포즈 보간과 재질 조회 전에 버렸다. 렌더 영역은 후보 본체가 차지하는 화면 사각형으로 제한했다.
- **A2 · 구현상 판단** 기존 조명·시트 합성 순서와 Box 그림자 경로를 재사용했다. 반투명 가장자리에는 깊이를 쓰지 않으며, Bicubic·SMAA가 적용되는 확대 포즈와 여러 위치에서 재사용되는 포즈 타일은 기존 표면 기록을 사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U1** 화면 깊이를 먼저 기록하고 재질 조회를 생략하는 대조 시험은 사용자 요청이다. **A1–A2**의 구체적인 정렬·범위·필터 처리 방식은 실험 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 마지막 측정 프레임에서 근거리 Deferred 25기 모두가 깊이 검사를 사용했다. 기존 표면 제출 11회에 깊이 제출 11회가 추가됐다. 두 GPU 대조 모두 적 렌더 구간이 길어졌다.
- **I2** 겹치지 않는 픽셀도 선행 패스에서 알파를 구하기 위해 모션 보간을 수행한다. 가려진 재질 조회를 줄이는 이득에는 화면 안 불투명 가림량이 영향을 준다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** Intel 통합 GPU, FHD·High·SMAA·검 자동 교전, 초기 180기를 사용했다. 각 독립 프로세스에서 준비 120프레임과 측정 240프레임을 실행했다. 전체 드로우는 시트→깊이→깊이→시트, 적 GPU 구간은 별도로 같은 교대 순서로 쟀다. 광원·아틀라스는 로컬 작업본의 Hermite 카탈로그를 양쪽에 사용했다.

| 지표 | 기존 시트 Deferred | 화면 깊이 선행 패스 |
| --- | ---: | ---: |
| 프레임 작업 평균 | 29.20~29.69 ms | 29.58~34.80 ms |
| 프레임 작업 p95 | 34.46~35.42 ms | 35.88~50.70 ms |
| 전체 드로우 GPU 평균 | 9.11~11.67 ms | 12.32~13.14 ms |
| 적 렌더 GPU 구간 평균 | 1.94~2.15 ms | 3.03~3.49 ms |
| 프로세스 커밋 피크 표본 | 1899.8~1901.5 MiB | 1911.3~1916.0 MiB |
| Deferred·Box 논리 GPU 할당 | 16.875 MiB | 18.625 MiB |

- 프레임 작업 시간은 표시까지의 경과 시간이며, OpenGL GPU 구간은 제출 사이의 대기를 포함할 수 있다. 원거리 공유 아틀라스로 그린 적은 각 실행의 마지막 프레임에서 128기였다. 별도 적 GPU 대조의 증가량은 회차별 1.33 ms와 1.09 ms였다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1 ↔ I1** 깊이 텍스처는 후보 화면 사각형으로 제한해 실측 할당을 1.75 MiB로 줄였다. 성능 결과를 근거로 벤치마크에서 선택하는 실험으로 유지했다.
- **A2 ↔ I2** 실제 OpenGL 교전 렌더 검사 13개를 작업 트리와 커밋 스냅샷에서 각각 통과했다. 겹침 검사는 뒤쪽 스프라이트의 가려진 픽셀이 빠지고 최종 합성이 기존 Deferred와 픽셀 단위로 일치함을 확인한다. 직접 조작 검증은 수행하지 않았다.
