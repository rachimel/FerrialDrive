# UI 글꼴·패널·콤보 표시 조정

- 작성일: 2026-11-03, 한국 시간
- 사용자 화면 피드백을 반영한 외형 수정이다.

## 사용자 결정과 반영

- 메뉴·HUD·피해 숫자를 모두 **에스코어 드림**으로 통일하고 기존 굵기 제한을 해제했다. 대체 글꼴은 사용자가 추후 선택한다.
- 기존 공식 배포 ZIP에서 Medium·Bold 원본 파일을 추가했다. 이번 피해·누적 피해·콤보 숫자를 Bold로 표시한다. 기존 폰트와 이용 조건은 삭제하지 않았다.
- `TARGET / HP`를 **TARGET**으로 줄였다. 패널 배경 알파는 0.94에서 0.45로 낮췄다. 테두리는 원래 알파가 1이므로 이를 유지하고 색을 `#52727C`로 올려 더 선명하게 했다.
- 상단 브랜드·UI 테스트 표시·구분선과 하단 조작 안내를 제거했다. Esc와 전환 중 입력 소비 동작은 유지했다.
- 콤보·누적 피해의 패널을 제거했다. 콤보는 **64px 숫자 + 14px COMBO**를 가로로 배치하고 실제 글자 폭과 폰트 기준선으로 정렬한다. 누적 피해 숫자는 54px, 이번 피해 숫자는 32px로 키웠다.
- 외형 값은 `samples/ui_unit_test/ui_config.json`에 둔다. 재사용 뷰와 글자 측정 함수를 수정했으며 샘플 피해·합계 계산은 변경하지 않았다.

## 확인 상태

자동 검사·프로그램 실행·이미지 렌더링·실제 창 조작은 수행하지 않았다. 사용자 직접 확인 방침을 유지한다. 공유 모듈 변경을 반영하려면 실행기 창을 완전히 닫고 다시 열어야 한다.
