# 에너지 게이지 경계의 사각 빛띠 진단

- **기록 ID:** `FDLOG-20261116-energy-boundary-diagnosis`
- 확인·작성: 2026-11-16 15:00 KST 이후. 근거는 현재 대화의 첨부 화면·확인 요청과 현행 렌더 코드, 숨긴 OpenGL 분리 렌더다.
- 개별 발언 시각 미확인 — [[FDLOG_MISSING_TIME:FDLOG-20261116-energy-boundary-diagnosis:scope]]. 검색 단서: `블렌딩 되지 않고 네모나게`, `일단 확인해줘`.
- **상태:** 알파 감쇠 텍스처 적용·관련 검사·OpenGL 전후/레벨별/훈련장 시연 확인 완료. 사용자 최종 외관 승인 전. 커밋·업로드 없음.
- 후속 반영·확인: 2026-11-16 15:09 KST 이후. 사용자가 같은 채팅에서 `그러면 그렇게 수정해줘`로 A1 구현을 요청했다. 개별 발언 시각은 위 scope 누락에 포함한다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** HUD에서 사각 경계가 보이는 첨부 화면을 제시하고 원인 확인을 요청했다. 의도는 화면의 합성 결함을 확인하는 것이다.
- **사용자 제안 2 (U2):** 원인 보고 후 A1 방식으로 수정하도록 요청했다. 근거 출처는 후속 `그렇게 수정해줘` 발언이며 의도는 확인된 빛띠 경계 문제의 수정이다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 코드 변경 없는 조사로 수용했다. 기존 HUD 텍스처·도형·입자 경로를 읽고 각 요소를 분리 렌더했다.
- 후속 U2는 빛띠 마스크 생성·렌더 경로와 해당 호출부의 수정으로 수용했다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 에너지 끝 빛띠의 가장자리 알파를 연속 감쇠시키고 결과 텍스처를 재사용한다. 현행 고정 투명도 띠의 경계를 없애면서 캐시 사용을 유지하려는 제안이다. 제시 시각은 위 확인·작성 시점이며 출처는 현재 대화의 조사 결과 보고다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U2로 A1의 구현 방향을 명시 수용했다. 구현 후 최종 외관 승인은 별도다.

## 5. 반영 후 발견한 문제

- **문제 1 (I1):** 기존 에너지 경계 표현의 빛띠가 번짐처럼 연속 감쇠하지 않고 직선 경계에서 갑자기 끝난다. 이번 조사는 결함 발생 시점이나 무기·아이콘 텍스처 분리와의 인과관계를 입증하지 않는다.
- 초기 AI 설명의 HP 바 위치 추정은 정정한다. 실제 조사한 효과는 HP 아래 에너지 게이지의 경계다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1은 원인 확인 요청이며 U2에서 A1 방식의 실제 수정을 요청했다.

## 7. AI 해결 제안과 실제 해결 과정

- `ui_v2/view.py`의 `energy_boundary()`는 레벨 1에서 폭 18/9/1px 띠를 서로 다른 고정 투명도로 겹친다. `stroke()`는 넓은 띠를 사각형으로 만들며, `ui/pico_renderer.py`의 `filled_triangle()`이 픽셀 단위로 채운다. 가장자리의 연속 알파 감쇠와 면적 기반 안티앨리어싱은 없다.
- **확인 V1:** 실제 OpenGL에서 바탕만/빛띠만 추가/입자만 추가/둘 다 추가한 4개 경우를 분리 렌더했다. 빛띠만 추가한 경우 사각 끝과 계단 경계가 나타났고, 입자는 둥글고 부드럽게 합성됐다.
- **확인 V2:** 공용 원형 입자 아틀라스의 바깥 테두리 알파 최댓값은 0이다. 해당 분리 렌더에서는 입자 텍스처 경계가 사각형으로 드러나지 않았다.
- 비교 이미지: `output/hud_boundary_diagnosis/comparison.png`. 왼쪽부터 바탕/빛띠/입자/결합이며 기본 도형과 현행 렌더러를 사용했다. 첨부 화면 전체·모든 레벨·직접 조작의 검증을 뜻하지 않는다.
- U2 반영: `PicoV2Renderer.soft_line()`이 선분과의 거리에 따라 알파가 0까지 연속 감소하는 둥근 마스크를 만든다. 4배 표본·선형 축소로 사선/끝을 완화하고 기존 3층의 폭·색·맥동·레벨 배율을 유지한다. 1px 코어에는 축소 필터용 가장자리 여유가 포함된다.
- 마스크는 길이·폭을 키로 64개까지 보관하며 이동·회전·색·투명도는 정점에서 처리한다. 닫을 때 해제한다. 패널 범위 수집 경로는 그리지 않는 호출로 연결했다.
- **확인 V3:** 관련 UI 자동 검사 140개 중 137개 통과·선택 GPU 검사 3개 제외. 별도 실제 OpenGL 회귀 검사 2개는 연속 감쇠·둥근 끝·회전/투명도 캐시 재사용·자원 해제를 확인해 모두 통과했다.
- **확인 V4:** `before_after.png`와 `levels_after.png`를 직접 열어 고정 투명도 띠의 끝/계단 경계가 완화된 것과 레벨 1/2/3·Overdrive 출력을 확인했다. 120회 이동·투명도 변경 후 캐시는 8개로 유지됐다. 위치는 앞서 기록한 진단 출력 폴더다.
- **확인 V5:** 공개 도형 훈련장 OpenGL 100프레임을 실행해 에너지 증가·입자·HUD 연결을 확인했다. `integrated_after.png`, `integrated_report.json`에 저장했다. 실제 기체·물리 입력·장시간 성능·사용자 외관 승인은 미검증이다.
- 기존 미커밋 HUD 배치 처리(`hud_batch.py` 포함)에 의존하므로 이번 기능만 불완전하게 커밋하거나 다른 변경을 함께 커밋하지 않았다. 제품 소스·검사·기록은 작업본에 반영돼 있다.
