# 훈련장 UI·Standby 림·몸 주변 검풍

- **기록 ID: FDLOG-20261115-ui-standby-body-wind**
- 작성·렌더 확인: 2026-11-15 00:12 KST 이후. 대화 범위는 2026-11-14~15의 UI·검 효과 요청이다.
- 개별 발언·수용·구현의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261115-ui-standby-body-wind:scope]] 현재 대화의 `자간 10px`, `일단 30도로`, `등 뒤에도 공격이 왜 들어가는지`를 원문에서 확인한다.

## 1. 사용자가 제안한 것

- **사용자 제안 U1**: DPI-aware FHD 화면에서 배치를 다시 조정한다. 통합 보조 슬롯은 HP 바와 무기 패널 사이·스왑 최대 왼쪽 마진 바깥에 두고 다음 스왑 기능을 표시한다. Space는 필살기 레벨을 가리지 않게 더 왼쪽으로 둔다. 이유·근거: 현재 대화의 배치 요청과 가림 지적.
- **사용자 제안 U2**: 패널은 텍스처, 글자·스캔라인은 실시간 표시한다. IMPACT 등은 약간 얇게·최종 자간 10px, 잔탄은 더 크게·밝은 부분에 미세 그라데이션을 사용한다. HIT·DAMAGE는 오른쪽 등장/퇴장·레이블 자간 확산·새 자릿수 오른쪽 등장을 요청했다. 외관 요청 외의 별도 이유는 제시되지 않았다.
- **사용자 제안 U3**: 파란 Trail에 자연스럽게 섞이는 V자 결을 넣고 알파를 높인다. 잔상은 0/4/8개, 소멸할수록 명도도 낮춘다. 흰색에 가까운 Trail은 피한다. 의도·근거: `투명도가 아니라`, `모션 블러`, `산데비스탄 효과`.
- **사용자 제안 U4**: 기체·검에 강한 빨간 림과 호흡을 넣는다. 적용 구간은 게이지 완충 후 OVERDRIVE가 등장한 Standby다. 에너지 마스크 밝기는 출력본이 없어 사용자가 보류했다.
- **사용자 제안 U5**: 빡빡한 검 판정을 몸 주변까지 채우고 검풍으로 설명한다. 등 뒤 반대축에서 좌우 30°씩 비우는 안을 우선 시험한다. 15°는 효과가 부족할 때의 후보다. 검풍은 발사체·퍼지는 면이 아니라 몸 옆·뒤에도 공격이 닿는 이유를 보여주는 궤적이다. 이유·근거: 현재 대화의 판정 불편과 검풍 역할 정정.
- 머리 분리·록온 응시·몸과 ±1방향 여유는 별도 검토 범위다. 이 작업에서 구현 완료로 확정하지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1~U5를 표시 모듈·설정·검 판정에 반영했다. 구현 사실과 사용자의 최종 외관 승인은 구분한다.
- 에너지 마스크 밝기는 명시 보류를 유지했다. 별도 발동 입력/새 Standby 상태는 추가하지 않았다.

## 3. AI가 제안한 것

- **구현상 판단 A1**: 글꼴 원본 대신 글리프 텍스처의 자간·0.55px 획 축소를 사용한다. 잔탄은 54px·아래쪽 코어 밝기 93%다. 패널 면·테두리·그레인은 재사용하고 상태 채움은 실시간 표시한다. 사용자에게 사전 승인받은 수치가 아니다.
- **구현상 판단 A2**: 카운터 등장 0.24초·유지 2.5초·퇴장 0.28초·레이블 자간 0→5px다. 기존 숫자 변경 블러는 유지한다.
- **구현상 판단 A3**: 림은 2D 알파 외곽 기반으로 OpenGL 아틀라스·보간 경로에 적용한다. 호흡 1.8초·강도 65~100%, 정지 중 동결이다. 실제 3D 법선 광원과 구분한다.
- **구현상 판단 A4**: 몸 주변 300°를 삼각형으로 나눠 검사하고 검날과 타격 ID를 공유한다. 반경 96px·중심 `[0,-80]px`·표시 띠 폭 18px는 시험값이다. 전체 볼록 외곽으로 후방 틈을 메우지 않는다. 고속 이동은 각 삼각형의 이동 경로를 검사한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 후방 반대축 좌우 30°씩 제외하는 해석은 사용자가 `일단 30도로`라고 확정한 시험값이다.
- A1~A4의 세부 수치·알고리즘·최종 외관은 별도 사용자 승인 전이다. 구현·검사·침묵으로 수용을 추정하지 않는다.

## 5. 반영 후 발견한 문제

- **I1**: Space가 필살기 레벨을 가린다고 사용자가 지적했다.
- **I2**: 방향성 Trail을 투명도 변화/작은 화살표로 해석한 표현이 V자 혼합 의도와 달랐다.
- **I3**: 몸 주변 검풍의 초기 부채꼴 채움이 퍼지는 추가 효과처럼 보였다. 사용자는 몸 뒤 판정을 설명하는 역할이 더 크다고 정정했다.
- **I4**: 실제 훈련장 출력본에는 에너지 마스크가 없었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1: 더 왼쪽으로 요청해 x=420으로 반영했다.
- I2: V자 결의 자연스러운 블렌딩·높은 알파·0/4/8 잔상·명도 소멸을 명확히 해 해당 값과 표현을 반영했다.
- I3: 역할 정정에 따라 방사형 채움을 없애고 고정 반경에서 기체 옆·뒤를 감는 짧은 띠로 표시했다. 후방 좌우 30° 시험 판정은 유지했다. 최종 외관 확인 전이다.
- I4: `아직 없음. 이건 보류.`라는 명시 응답에 따라 마스크 제어를 보류했다.
