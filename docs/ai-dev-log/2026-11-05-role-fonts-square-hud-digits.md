# 역할별 폰트 변경·HIT/누적 피해 숫자 수정본

- 기록 ID: `FDLOG-20261105-role-fonts-square-hud-digits`
- 기록 기준 시각: 2026-11-05 02:32:14 KST(작업 중 시계 확인).
- 출처: 현재 대화의 “탄약 표시기는 가물치 고딕”, “일시정지 같은 헤더는 SUITE”, “네모네모하게 수정된 폰트 사본”, “0의 사선은 제거”.
- 개별 사용자 요청·수용 발언의 정확한 시각은 모른다. [[FDLOG_MISSING_TIME:FDLOG-20261105-role-fonts-square-hud-digits:scope]] 보완 시 위 검색 구절과 후속 “데미지 인디케이터도”, “전투 HUD나 이런쪽에서도” 발언 및 AI 적용 범위 안내 시각을 확인한다. 아래 U1~U2/A1~A2에 공통 적용한다.
- 상태: 폰트 사본 생성·설정·문서 반영, 자동 검사·SDL dummy 렌더링 확인. 실제 창 조작·사용자 시각 승인·커밋·업로드와 구분한다.
- 현재 범위: 후속 U2에 따라 개별 피해 숫자와 전투 HUD 텍스트도 Ferrial HUD Square로 비교 적용한다. 아래 A1의 개별 피해 원본 유지·전투 헤더 SUITE는 초기 적용 기록이며 후속 결정과 구분한다.

## 1. 사용자가 제안한 것

- U1: 탄약에 가물치 고딕, 무기 이름에 더 높은 굵기의 Paperlogy, 일시정지 등 헤더에 SUITE를 적용한다. 학교안심 운동장을 더 각지게 수정한 사본을 HIT·누적 피해에 사용하고 0의 사선을 제거한다.
  - 이유·의도·근거: 사용자는 앞선 발언에서 UI와 일관된 테마를 위한 폰트를 구했다고 설명했고, 이번 발언에서 역할과 원하는 형상을 직접 지정했다. 숫자를 각지게 만들고 0 사선을 없애는 시각적 요구를 기준으로 한다.
- U2: 개별 데미지 인디케이터도 Ferrial HUD Square로 바꾸고, 친구 제안으로 전투 HUD 등에도 같은 폰트를 시험한다. 전투 HUD 제목·표적 패널·무장 카드가 보이는 스크린샷을 함께 제공했다.
  - 이유·의도·근거: 데미지 인디케이터 적용은 사용자 직접 요청이며 전투 텍스트 확장은 친구와의 폰트 비교 제안으로 설명했다. 친구 제안을 최종 시안 승인으로 해석하지 않는다.

## 2. AI가 제안한 것

- A1: 구현상 판단으로 Paperlogy Bold·SUITE Bold를 선택하고, 타이틀/소제목/전투 제목/일시정지/TARGET을 헤더 역할로 적용했다. 숫자 0~9만 수정해 원본의 그 외 글리프와 메트릭을 보존한다.
  - 이유·근거: 사용자가 굵기 수치나 헤더 역할 목록을 별도로 지정하지 않아 기존 역할 설정에 맞춰 적용했다. HIT/누적 피해의 요청 범위에 한정해 사본을 연결하고 개별 피해 숫자는 원본을 유지한다.
- 수정본 이름은 `Ferrial HUD Square`로 분리하고 원본 OFL과 저작권 고지를 승계한다. `Tools/font_variant/`에 기준 원본 해시를 확인하는 재생성·검사 경로를 추가했다. fontTools는 제작 시에만 필요하다.
- A2: U2의 “전투 HUD 등”을 전투 제목·TARGET·표적명·HUD 본문/작은 이름표·HIT/DAMAGE 레이블로 구체화해 비교 적용했다. 메뉴/일시정지 SUITE, 탄약 가물치, 무기 Paperlogy, 로드아웃 번호 에스코어 역할은 유지한다.
  - 이유·근거: 기존 전투 전용 폰트 역할로 범위를 나누면 설정만으로 비교할 수 있다. 수정본의 한글·영문은 원본 윤곽임을 함께 기록하고 폰트 바이너리를 추가 수정하지 않는다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 수용해 UI 설정과 역할 문서에 반영했다. 학교안심 운동장 원본을 덮어쓰지 않고 별도 OTF·이름·라이선스·변경 기록을 생성했다.
- 현재 UI가 참조하는 선택 폰트 원본과 이용 조건만 Git 제외 규칙의 지정 경로에 포함했다. 사용자가 추가한 다른 굵기·폰트·웹폰트·개인 자료는 제외 상태를 유지한다.
- U2를 수용해 `damage_number`와 A2의 전투 전용 역할을 수정본에 연결했다. 배치·크기·색·피해 팝업의 수명/간격·전투 동작은 변경하지 않는다.

## 4. AI 제안 중 사용자가 수용한 것

- U1의 제작·적용은 명시 요청이다. A1의 구체적인 Bold 선택·헤더별 적용과 결과 형상의 사용자 확인은 아직 받지 않았다. 구현 보고나 검사 통과를 시각 승인으로 간주하지 않는다.
- U2는 비교 적용 요청이며 A2의 세부 적용 범위와 가독성에 대한 사용자 확인은 아직 받지 않았다.

## 5. 반영 후 발견한 문제

- 실제 창 조작 후 문제는 확인하지 않았다. 생성본 렌더에서 숫자 윤곽·0의 빈 공간을 확인했다.
- U2는 새 비교 요구이며 이전 폰트 적용의 기능 버그 보고가 아니다. 실제 창 사용감은 여전히 미확인이다.
- 기존 무장 자동 검사는 탄약 폰트 파일명을 SCDream5로 고정하고 있었다. 이 값은 변경 전 규칙이므로 U1에 맞춰 기대값을 갱신했다. 배치·스왑·카운터 동작 코드는 변경하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 별도 사본 요구에 따라 원본 OTF의 해시를 고정해 보존하고, 숫자 모서리 변경·0 사선 제거를 사본에만 적용했다. 탄약/무기/헤더는 사용자 제공 폰트 원본을 참조한다.
- U2의 후속 요청에 따라 개별 피해도 사본을 사용한다. 메뉴/일시정지 헤더는 기존 SUITE를 유지하고 전투 텍스트는 비교용 범위를 기록한다.

## 7. AI 해결 제안과 실제 해결 과정

- ASCII 숫자 10개만 변경하고 그 외 12,604개 윤곽·문자 매핑·글자 폭/사이드베어링·원본 저작권 고지가 유지되는지 생성 도구로 확인했다. 수정본의 기본 0은 두 윤곽(외곽/내부 공간)으로 구성한다.
- UI 자동 검사 50개 통과. 실제 Pico2D(SDL dummy)에서 탄약 0/45/999, HIT 101, 누적 DAMAGE 102,030과 일시정지를 렌더링하고 화면을 확인했다. 가물치 무료고딕 48px의 `999`는 SDL_ttf 기준 폭 69px다.
- 로컬 비교 이미지: `output/font-preview/font_comparison.png`, HUD/일시정지: 같은 폴더의 `hud-999.png`·`pause.png`. 검사·캡처 도우미는 재생성 가능한 로컬 출력 영역에만 둔다.
- PRE-PRD·UI 명세·샘플 안내·폰트 안내를 갱신한다. 기존 다른 문서 변경은 보존한다. 실제 창 입력·사용자 시각 승인은 확인 전이며 커밋·업로드는 수행하지 않았다.
- U2 후속 확인: UI 자동 검사 50개를 다시 통과했다. 실제 Pico2D(SDL dummy)로 전투 제목·작은 TARGET/한글 이름·긴 표적명 말줄임·120/1000/10000 피해·HIT/DAMAGE 레이블을 렌더링하고 확인했다. `output/font-preview/hud-square-text.png`와 `hud-square-long-name.png`, `pause-square-text.png`에 비교 화면을 남겼다. 최종 사용자 가독성 평가는 확인 전이다.
