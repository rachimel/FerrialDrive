# 레이더·크로스헤어 포인트색 통일

- 작성일: 2026-11-04, 한국 시간
- 사용자 요청으로 레이더 링·화살표와 크로스헤어 원·십자를 UI 포인트색인 스틸 블루 `#91AEBB`로 맞춘다.
- 레이더는 HP/HIT 공용 `accent`·적 HP 공용 `enemy` 대신 UI 전용 `ui_accent`를 사용한다. 크로스헤어는 기존 전용 역할 `colors.crosshair`를 유지하고 값만 변경한다. HP·HIT/DAMAGE·피해 숫자 색은 유지한다.
- 화살표 기준 밑변 60px·높이 20px·최소 자체 알파 0.3, 링 반지름 200px·두께 2px·알파 0.28, 크로스헤어 크기·두께·항상 갱신되는 입력은 유지한다.
- 현재 명세·샘플 안내·체크포인트·PRE-PRD의 적용 범위를 맞췄다. 소스·설정 대조와 Git 변경 검사를 수행했으며 자동 테스트·UI 실행·렌더링은 수행하지 않았다.
