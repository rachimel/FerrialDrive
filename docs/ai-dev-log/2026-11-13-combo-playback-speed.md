# UI v2 콤보 재생 시간 단축

- **기록 ID:** `FDLOG-20261113-combo-playback-speed`
- 기록·검증 기준: 2026-11-13 00:20 KST 이후. 발언별 정확한 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261113-combo-playback-speed:scope]]. 현재 대화의 `더 줄여볼까?`, `20%`, `ㅇㅇ ㄱㄱ`를 검색한다.
- 상태: 구현·자동 검사 완료. 실제 창 사용감과 사용자 외관 승인은 미확인이다.

## 1. 사용자가 제안한 것

- **U1:** 현재 UI 테스트 콤보 시간을 확인한 뒤 더 짧은 재생을 시험한다. 출처는 현재 대화이며 개별 시각은 scope 범위다.

## 2. AI가 제안한 것

- **A1:** 전체 재생 시간을 20% 단축한다. 1~3타 각각 0.50→0.40초, 4타 약 0.67→0.53초, 연속 약 2.17→1.73초다. 빠른 연계를 시험하되 준비·타격·후속 동작의 가독성을 확인하려는 시안이다. 출처·시각은 scope 범위다.
- **A2 — 구현상 판단:** 원본·보간 데이터는 유지하고 실행부의 콤보 시계에만 설정 배속 1.25를 곱한다. 기존 파츠 재생에도 같은 경로를 사용하며 Idle 속도는 유지한다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1을 A1의 수치로 구현했다. `v2.player_asset.combo_playback_speed=1.25`이며 설정 누락 시 기본 배속은 1이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1은 사용자의 `ㅇㅇ ㄱㄱ`로 시험 적용을 수용했다. 최종 타격감·외관 승인과 구분한다.

## 5. 반영 후 발견한 문제

- 첫 검사에서 임시 폴더 접근 제한으로 메타데이터 검사 1개가 실행 오류를 냈다. 동일 검사를 권한 확장으로 재실행해 통과했다. 재생 시간 계산 오류는 발견하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1/A1에 따라 배속을 설정하고 기존 보간 전달·일시정지 검사의 기대 시간을 갱신했다. 별도 후속 해결 제안은 이번 범위에 해당하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- 재생·방향·보간 연결 검사 12개 통과. 실제 GPU 선택 검사 3개는 실행하지 않았다.
- 현재 로컬 보간 카탈로그의 32개 콤보를 읽어 실행부에 연결하고, 8방향 각각 종료 직전·종료 경계·다음 입력 대기·4타 뒤 Idle 복귀를 확인했다. 타수별 0.40·0.40·0.40·0.533333초이며 Idle의 0.1초 갱신은 그대로다. 결과는 `output/combo_speed/timing_check.json`이다.
- 실제 창·타격감·새 GPU 렌더링은 확인하지 않았다. 설정 적용은 재실행 후 확인한다.
- 변경 기반인 플레이어 에셋/보간 연결과 관련 모듈·검사가 기존 미커밋 작업이다. 그 작업을 함께 포함하지 않고는 이번 변경만 독립 실행 가능한 커밋으로 만들 수 없어 작업본에 남겼다. 업로드하지 않았다.
