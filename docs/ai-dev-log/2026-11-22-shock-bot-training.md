# 전체 훈련장 Shock Bot 아틀라스 연결

- **기록 ID** `FDLOG-20261122-shock-bot-training`
- 작업일 2026-11-22 KST.

## 1. 사용자가 제안한 것

- **U1** 새 인간형 적 아틀라스를 모든 훈련장에 반영해 달라고 요청했다. 정확한 요청 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261122-shock-bot-training:U1]]`. 검색 단서는 `모든 훈련장에 새로운 인간형 적 아틀라스`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 본편·이동·파츠 합성·Combat Test 및 하드웨어 벤치마크의 일반 훈련 경로에서 이미 패킹한 Shock Bot `r03`을 사용한다.

## 3. AI가 제안한 것

- **구현상 판단** 적 배치가 없던 실제 에셋 이동·파츠 합성 훈련장과 Movement 벤치마크는 본편의 Shock Bot 1기 배치를 공유한다. 공개 도형 시연과 플레이어 아틀라스 전용 벤치마크는 기존 실행 경로를 사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 별도 제안의 수용에 해당하는 사항은 없다. 실행 경로 선택은 U1의 구현상 판단이다.

## 5. 반영 후 발견한 문제

- 자동 실행에서 추가 문제는 발견되지 않았다. Movement 벤치마크의 일반 실행은 이전의 적 없는 실행과 교전 부하가 다르다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 이동과 파츠 독립 테스트의 공통 실행부 및 일반 Movement 계측을 본편 훈련 교전에 연결했다. 본편, Combat Test 및 Combat 계측은 기존 혼합·전용 `r03` 카탈로그를 각각 유지했다.

## 7. AI 해결 제안과 실제 해결 과정

- 실제 GPU로 이동·UI, 독립 파츠 합성, Combat Test, Movement·Combat 벤치마크와 도형 이동 시연을 실행했다. 벤치마크 두 장면에서 같은 `r03` 인간형 품질 카탈로그가 선택됐다. 이동·파츠 합성 보고서는 인간형 본체와 그림자를 각각 1회 제출했다.
- 본편에서 새 게임을 시작하고 Break 후반을 주입했다. 살아 있는 Shock Bot이 `knockdown`을 재생했으며 9m에서 PBR 본체·그림자, 23m에서 군집 본체·그림자를 각각 1회 제출했다. 적 교전 자동 검사 31개가 통과했다. 직접 조작과 전체 Break 재생의 시각 검수는 미실시다.
