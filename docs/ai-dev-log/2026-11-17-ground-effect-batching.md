## 2. 사용자 제안 중 AI가 수용한 것

- U1을 수용해 `PicoGroundEffects` 기본 경로를 배치로 연결했다. 입자 생성·수명·재질·에너지색·앞뒤 가림 규칙·게임 수치는 바꾸지 않았다. Pico2D 라이브러리 원본·원본 PNG·명세 파일을 수정하지 않았다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1, 구현상 판단):** 파티클별 28개 float를 재사용 CPU 버퍼에 기록하고 RGBA32F 데이터 텍스처로 한 번 업로드한 뒤 인스턴싱한다. Python→네이티브 uniform·좌표·개별 쿼드 호출을 줄이기 위함이다. 처음에는 입력 순서대로 같은 텍스처가 연속된 구간만 합쳤다. 근거: 코드와 진행 보고. 시각은 scope 참조.
- **AI 제안 2 (A2, 구현상 판단):** 원본 시트를 로딩 중 공통 RGBA 아틀라스로 복사해 서로 다른 이미지도 순서를 유지한 채 같은 드로우로 처리한다. 기본 실행에서는 대조용 개별 텍스처를 불러오지 않는다. 앞·뒤 레이어는 별도 제출한다. 근거: 첫 대조의 잔여 제출 수와 진행 보고. 시각은 scope 참조.
- **AI 제안 3 (A3, 구현상 판단):** 개별/배치 조건·`--auto-dash`·지면 효과 제출 통계를 기존 벤치마크에 연결한다. 각 조건 시작의 지면 입자 난수 상태를 복원해 같은 부하를 재현한다. 근거: 현재 소스와 실행 결과. 시각은 scope 참조.

## 5. 반영 후 발견한 문제

- **I1:** 첫 연속 텍스처 배치에서 평균 입자 제출 124.77개가 드로우 60.98회로만 줄었다. 발생 순서에 다른 텍스처가 끼어 있어 추가 병합이 막혔다. 지면 효과 자체는 두 회차에서 5.01→2.65ms, 4.62→2.23ms로 줄었으나 전체 프레임 작업 시간은 개선되지 않았다. 세션 전체 FPS 개선으로 확대하지 않았다. AI가 `ground_batch_comparison/report.json`으로 확인했다.
- **I2:** 실제 전체 화면을 연속 draw하면 HUD 등에도 차이가 생겨 지면 효과만의 픽셀 비교 근거로 쓰기 어려웠다. 고정된 카메라와 지면 효과만 렌더링하는 비교로 분리했다. AI가 이미지·픽셀 비교로 확인했다.
- **I3:** 최종 실제 에셋의 지면 효과만 비교하면 1920×1080 중 52픽셀·77채널이 달랐다. 대부분 채널 차이 1이며 최대 45인 한 픽셀은 컷아웃 경계의 임계값 차이로 추정한다(AI 해석). 원인의 개별 GPU 연산까지 확정하지 않았다. `[[FDLOG_MISSING_CAUSE:FDLOG-20261117-ground-effect-batching:I3]]` 검색 단서: `ground_only_comparison.json`, 좌표 `(638, 534)`, 개별/배치 셰이더의 좌표·아틀라스 샘플 정밀도. 완전한 bit 일치로 보고하지 않는다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: A2로 텍스처를 공통 아틀라스에 조립했다. 현재 실제 시트는 1254×1254 세 장이며 결과는 1254×3762다. 원본을 재저장하지 않고 RAM에서 복사해 GPU에 올린다. 기본 실행은 합쳐진 GPU 텍스처만 보유한다. 비교의 개별 텍스처는 해당 경로 첫 사용 때만 추가한다.
- 최종 대조: Combat·low·SMG·오른쪽 대시·상세 계측·CPU 50%·8개 affinity·2GiB 상한. 조건별 준비 60/측정 240프레임, 2회 역순 교차. 각 조건 평균 입자 제출 수는 동일한 **124.7708개**, 개별 **124.7708회 → 배치 2회**다. 업로드 약 13,974bytes/프레임, 측정 중 CPU 버퍼 재할당 0, GPU 기능 위반 0.
- 지면 효과 포함 wall 시간은 1회차 **5.699→1.839ms**, 2회차 **4.850→1.558ms**, 두 회차 평균 약 **67.8% 감소**다. 전체 work 평균은 각각 29.749→27.788ms, 23.782→20.707ms다. 상세 계측·제한·실행 간 변동을 포함하므로 일반 플레이의 FPS 개선율이나 60FPS 달성으로 환산하지 않는다. 근거: `output/performance/ground_batch_atlas_comparison/report.json`과 `report.md`.
- I2: 동일한 132입자를 고정 카메라로 지면 효과만 앞뒤 순서대로 렌더링해 PNG·수치를 저장하고 실제 화면도 열어 확인했다. I3의 작은 차이는 남아 있으며 완전한 픽셀 동일성을 주장하지 않는다. 근거: `ground_only_individual.png`, `ground_only_batched.png`, `ground_only_comparison.json`.
- 관련 검사 **18개 통과**: 새 배치 7개(실제 GPU 5개 포함), 기존 프레임/계측 4개, 보고서·자동 입력 7개. 공개 패턴의 회전·반전·앞뒤 공간 분할·스케일·clip·render target 픽셀 비교는 최대 채널 차이 2 이내다. 동일·혼합 텍스처의 단일 제출·버퍼 재사용·GL 상태 복원·실패 후 재사용을 확인했다. 실제 게임 에셋 비교의 I3와 구분한다.
- 공통 셰이더 본문·데이터 배치 모듈을 분리하고 기존 개별 경로는 대조용으로 보존했다. `docs/rendering.md`와 벤치마크 사용법에 동작·범위·해석을 반영했다. HUD 최적화는 이번 변경 범위에 포함하지 않았다.
