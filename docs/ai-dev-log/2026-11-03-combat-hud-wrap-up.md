# 전투 HUD 시안 마감·메뉴 후속 작업

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: TARGET 글자를 조금 줄이고, 적 HP 바 위의 훈련 표적 A 이름 굵기를 한 단계 더 낮춘다.
- TARGET은 Bold를 유지하며 16→14px로 줄이고 적 이름은 20px를 유지하며 SCDream5(Medium)→SCDream4(Regular)로 바꿨다. 기존 기준선 맞춤 계산을 사용한다.
- 사용자가 이번 조정으로 전투 HUD를 완료하기로 했다. 완료 범위는 표시·반응 UI 시안이며 실제 전투·타겟팅 연결 완료와 구분한다.
- 후속 작업은 메뉴다. 현재 테스트 메뉴와 Cafe24 Ohsquare Air 시안을 바탕으로 구체적인 화면 구성·동작을 정해야 하며 새 메뉴 구성은 아직 확정하지 않았다.
- 설정과 Regular 폰트 파일 존재를 읽어 확인했다. 마지막 폰트 조정의 자동 검사·실행·렌더링·조작은 수행하지 않았다. 사용자 마감 결정과 미검증 항목을 구분해 기록한다.
