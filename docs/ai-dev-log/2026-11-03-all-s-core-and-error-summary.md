# UI 전체 에스코어 드림 통일·실행 오류 가독성 수정

- 작성일: 2026-11-03, 한국 시간
- 사용자 실행 화면에서 config.py의 폰트 검증 실패를 확인했다. 파일 목록과 설정을 대조한 결과 메뉴가 참조하는 Cafe24 OTF가 현재 data/fonts에 없었다.
- 이후 사용자가 전부 에스코어 드림으로 바꾸도록 지시했다. 메뉴·HUD·HIT/피해/순번 숫자·이번 피해까지 기존 SCDream4·5·6 파일만 참조하게 변경했다. Cafe24 대체 경로를 넣는 중간 조치는 제거했다. 폰트 파일 복원·다운로드·기존 파일 삭제는 하지 않았다.
- 메뉴 큰 제목·TARGET·주요 숫자는 Bold, 전투 제목·적 이름·메뉴 소제목·순번은 Medium, 나머지 본문은 Regular다. 기존 크기·배치·효과는 유지하며 기준선과 오른쪽 정렬은 새 폰트 측정을 따른다.
- Runner는 자식 traceback의 마지막 몇 줄을 그대로 앞세우지 않고 실제 예외를 첫 줄에, 짧은 소스 위치를 다음 줄에 표시한다. 전체 오류 출력은 세션에 보관한다. 글자 폭을 측정해 줄바꿈하고 최대 6줄·내용 높이의 패널로 표시하며 초과분은 말줄임한다. 줄바꿈은 오류·창 크기가 바뀔 때만 재계산한다.
- 없는 폰트 오류는 긴 절대 경로 대신 폰트 역할과 파일명을 표시한다. 오류 요약·줄바꿈 회귀 검사 항목은 준비했으나 실행하지 않았다.
- 파일 경로를 읽어 존재 여부를 대조했다. 사용자 직접 테스트 방침에 따라 자동 검사·프로그램 실행·렌더링·실제 창 조작은 수행하지 않았다. Runner 오류 UI 코드가 바뀌므로 최초에는 Runner를 완전히 재시작한다.
