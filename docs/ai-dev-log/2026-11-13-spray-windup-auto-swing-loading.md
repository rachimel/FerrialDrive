## 1. 사용자가 제안한 것

- **U1:** Trail 옆 연기는 발에, 세 번째 **둥근 회색 연기 텍스처**는 노즐의 스프레이 형태로 배치한다. 등 분사는 부스트에만 더 크게 표시한다. 발 연기/암석은 바닥 텍스처 색과 합성하며 대시의 발/스러스터 연기를 모두 늘린다. 디테일 축소 후 `약간 디테일 살려`로 정정했고 원형 연기는 시간에 따라 커지도록 요청했다.
- **U2:** 좌클릭을 유지하면 자동 스윙한다.
- **U3:** 부스트 250m/s와 초반 가속감을 제안했다. 확인 질문에서 **시작 최고 250m/s→일반/대시 이동 속도로 감속**을 선택했다. 고정 30m 거리에서 곡선 적분 거리로 바뀌는 점을 설명한 뒤 선택한 기준이다.
- **U4:** 등 스러스터의 수직 준비와 선딜을 제안했다. **0.08초 수직 준비→수평 분사**를 명시 선택했다. Trail은 수평 정렬 후 출발 시 켜고 등/다리의 각도를 맞춘다. 부스트 다리 Trail은 더 길게 하며 길이·강도 모두 선형 보간한다.
- **U5:** 반대 방향 이동 시 노즐 가까운 부분은 앞, 먼 꼬리는 뒤라고 구체화한 뒤 `노즐 앞에만`으로 범위를 좁혔다. 등 노즐 경계를 흐리게 보정하고 분사 종료 후 일정 시간 남는 잔상·Fade out·시간에 따른 Trail 크기 축소를 요청했다.
- **U6:** 로고 PNG 기반 로딩 화면을 요청했다. 이후 이미 로고가 있으며 파일을 덮어썼다고 알려줬다. 현재 선택은 사용자가 덮어쓴 파일이다.
- **U7:** 사각형 줄무늬 그림자 이미지를 제공하고 이후 그림자가 보이지 않는다고 제보했다.
- **U8:** Trail과 함께 작은 원형 에너지 입자를 분사축 양옆으로 흩뿌리도록 요청했다.
- 위 제안·정정의 이유/의도는 해당 발언과 시각적 불일치 제보에 근거하며 개별 시각은 scope 참조.

## 2. 사용자 제안 중 AI가 수용한 것

- U1·U8: 발 연기/암석과 노즐의 원형 연기/에너지 입자를 분리했다. 바닥의 실제 반복 좌표 주변 9개 RGB를 읽어 발 효과 색에 합성한다. 원형 연기는 커지고 에너지 입자는 양쪽으로 퍼지며 작아진다.
- U2: 입력 장치와 독립된 전투 제어에 자동 반복을 연결했다. 마우스 해제·일시정지·포커스 상실·메뉴 진입에서 누름 상태를 해제한다. 자동 예약과 클릭 예약을 구분하고 부스트 준비/추진 중에는 자동 공격 재시작을 기다린다.
- U3·U4: 준비 중 일반 이동을 이어가고 0.08초 뒤 추진한다. 250m/s에서 0.2초 동안 현재 목표 30/100/0m/s로 SmoothStep 감속한다. 방향은 요청 시 고정한다. 등 분사는 실제 추진 중에만 발생하며 종료 후 잔상은 별도 수명으로 남긴다.
- U5: 반대 이동의 노즐 주변 12px만 앞에, 먼 꼬리와 발 효과/잔상은 뒤에 둔다. 경계와 노즐 접점을 완만하게 처리했다. 길이와 강도는 별도의 시간 선형 보간이며 잔상은 유지 후 선형 Fade out·길이/폭 축소를 사용한다.
- U6·U7: 사용자 로고와 단계별 진행 막대, 묶음/페이지 사이 화면 갱신을 연결했다. 로딩 이후 그림자 업로드 오류도 복구했다.

## 3. AI가 제안한 것

- **A1:** 선딜 0.08초와 수직 준비→수평 출발을 제시했다. 빠른 이동 입력의 흐름을 유지하면서 기구의 준비 동작을 보여주는 목적이다. U4에서 명시 선택됐다.
- **구현상 판단 A2:** Trail 길이/강도 보간 0.06초, 종료 후 유지 0.12초·Fade out 0.22초, 크기 감소 비율 0.65, 역방향 앞 영역 12px를 설정 JSON에 분리했다. 이 세부 수치는 사용자 최종 선택과 구분한다.
- **구현상 판단 A3:** 등 분사 크기 1.9배·부스트 다리 길이 계수 1.4, 바닥색 합성 0.8, 효과 최대 160개를 사용한다. 에너지 입자는 두 번째 발생마다 양쪽으로 생성해 예산을 제한한다. 실제 GPU overdraw/프레임 시간 최적화를 입증한 수치가 아니다.
- 구현 확인 시각은 위 기록 시각이며 개별 제시 시각은 scope 참조.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U3에서 시작 최고 250m/s 후 이동 목표로 감속하는 방식을, U4에서 0.08초 준비 뒤 수평 분사하는 방식을 명시 선택했다.
- 원형 연기·공간에 따른 앞뒤 분리·기존 로고 사용은 후속 사용자 정정을 기준으로 반영했다.
- 세부 강도·유지/소멸 시간·최종 외관/사용감의 별도 승인을 추정하지 않는다.

## 5. 반영 후 발견한 문제

- **I1:** 기존 로고 조회 범위가 부족해 불필요한 임시 로고를 생성했다. 사용자가 기존 파일을 덮어쓴 뒤 그 파일을 사용한다. 현재 `data/images/ui/logo.png`와 `data/images/textures/logo.png`의 해시는 동일하다.
- **I2:** 로딩 화면의 SDL 텍스트/이미지 업로드가 남긴 OpenGL 입력 행 간격을 R8 그림자 업로드가 그대로 사용해 줄무늬/소실이 생겼다. 사용자 이미지와 같은 증상을 로딩 후 실제 창에서 재현했다.
- **I3:** 초기 전후 정렬은 효과 전체를 한 레이어에 두어 반대 방향 이동에서 어색했다. 사용자 공간 기준 정정에 따라 노즐 시작부만 앞에 분리했다.
- **I4:** 부스트 종료 때 다리의 활성 Trail이 새 대시 Trail로 대체돼 긴 잔상이 남지 않았다. 등 Trail 유지와 별도로 다리 부스트 Trail 복사본을 월드 위치에 남기도록 수정했다.
- **I5:** 새 에너지 입자 검사에서 기본 발생 간격 0.04초와 `매 두 번째 발생`을 고려하지 않아 첫 발생만 검사했다. 입력 시간을 0.08초로 고쳐 실제 두 번째 발생을 검증했다. 초기 실패를 구현 통과로 기록하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1↔U6: 새 생성 대신 사용자가 덮어쓴 로고로 연결했다. 원본은 추가 편집하지 않았다.
- I2↔U7: 제공 이미지와 안 보인다는 제보로 위치 보간 문제가 아닌 업로드 손상을 조사했다.
- I3↔U5: 발생 시각 기준이 아닌 **노즐과의 공간 거리**임을 확인하고 이후 `노즐 앞에만`을 반영했다.
- I4↔U5: 종료 시 즉시 삭제/감쇠하던 처리를 유지→Fade out 잔상으로 바꾸고 크기 축소를 추가했다.

## 7. AI 해결 제안과 실제 해결 과정

- I2: R8 업로드 때 `UNPACK_ALIGNMENT=1`, `ROW_LENGTH/SKIP_ROWS/SKIP_PIXELS=0`을 설정하고 호출 전 상태를 복구한다. 잘못된 행 간격을 미리 넣은 GPU 회귀 검사에서 정확한 알파 위치와 상태 복구를 확인했다. 로딩을 거친 새 창의 실제 그림자도 정상으로 복구됐다.
- 부스트 진입 3모션×8방향 **24클립/112프레임**을 새 Unreal 후보에 출력하고 그림자·벡터·3단계 압축 아틀라스를 갱신했다. 나머지 이동 104클립과 공격 32클립을 유지한다. 기존 모델 형상/재질과 스러스터 외 제어값은 보존했다. 준비 수직 성분 최소 약 0.9999999999998, 정렬 후 수직 성분 최대 약 3.68e-7이다. 동작 전체/중간 이미지와 잘림 없는 112프레임을 확인했다. 12fps 벡터 보간을 매 화면의 새 3D 포즈 재렌더로 취급하지 않는다.
- 부착 좌표는 실제 Unreal 120Hz 자료를 사용한다. 각도 정정은 등 Trail을 다리와 같은 분사 방향으로 맞추고 실제 노즐 위치는 보존한다.
- 관련 **85개 자동/실제 OpenGL 검사 통과**. 공간별 가림, 원형 연기 성장, Trail 크기 축소·선형 보간·잔상 유지/Fade out, 마우스 해제/포커스 상실, 속도 곡선의 프레임률 독립성, 부스트 준비 이동, 에너지 입자의 양방향 비산을 포함한다.
- 최종 지정 입력 **OpenGL 1,200프레임**, 최대 효과 **160개**, 충분한 정지 뒤 **0개**를 확인했다. 자동 스윙 1→2→3→4의 두 주기를 trace에서 확인했다. 실제 키보드/마우스 사용감 승인과 구분한다.
- 같은 최종 실행에서 로딩 준비 완료까지 약 **5.34초**, 그리기 CPU 호출 평균 약 **13.02ms**였다. 보고용 PNG 캡처·단일 환경의 관측값이며 GPU 프레임 시간/성능 보장이나 로딩 단축 완료를 뜻하지 않는다.
- 로딩 화면은 메인 스레드에서 페이지별 갱신하며 병렬 로딩은 아니다. 닫기 요청은 로딩 취소 예외로 자원을 정리한다. 현재 로고 해시: `91f4c8a4fd09102622f7c98ff8d12a3ebebe3e2028ade9702a1a70b9ebca8174`.
- 현재 바닥은 흙이며 금속 지형 판별은 미연결이다. 백웨폰 장착/스왑 시스템과 다른 자세 합성의 기존 미연결 상태를 바꾸지 않았다. 생성물/사용자 에셋은 Git 제외 경로에 유지하고 혼재된 기존 변경을 묶어 커밋하지 않았다.
