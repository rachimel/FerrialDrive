# UI 폰트 시안·배치·레이더 거리 표현

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 숫자에 학교안심 운동장, 일반 문구에 Cafe24 PRO를 적용해 레이아웃을 조정하고, 적이 멀수록 삼각형을 작고 흐리게 표시한다.

## 반영

- 로컬 OTF 원본을 참조한다. HP·콤보·이번 피해·누적 피해·메뉴 순번은 학교안심 운동장, 본문·버튼은 Cafe24 PRO Slim Fit, 제목은 Slim Max다. 버튼 문구에 포함된 숫자는 Cafe24 PRO를 유지한다. 세부 역할·크기는 실제 화면에서 조정할 시안이다.
- 타겟 HP를 이름과 다른 숫자 폰트 역할로 분리했다. 콤보의 숫자와 COMBO는 기존 글자 폭·기준선 정렬을 유지한다.
- 타겟 패널을 464×120px로 넓혔다. 플레이어 패널은 좌하단 324×132px, 콤보·누적 피해는 오른쪽, 샘플 버튼은 y=640의 하단 행에 배치했다.
- 레이더는 거리/감지 거리의 비율로 삼각형 높이·폭과 알파를 선형 감소시킨다. 꼭짓점은 기존 반경 110px의 링 위에 유지한다. 근거리 기준 높이·밑변은 20px이고, 감지 한계에서 크기 45%·알파 25%가 된다. 최소값은 설정으로 분리한 초안값이며 장면 전환 알파와 곱한다.
- 샘플에 근거리·중거리·감지 한계의 적 3개를 제공한다. 범위 밖 적·아군 제외와 영벡터 생략은 유지한다.
- 새 폰트·기존 사용자 제공 라이선스 PDF는 Git에 추가하거나 업로드하지 않았다. 기존 폰트 제외 규칙을 유지했으므로 새 설정을 다른 환경에서 실행하려면 같은 로컬 폰트가 필요하다. 학교안심 운동장의 이용 조건 파일은 로컬 폴더에 없다.

## 확인 상태

- 변경 파일을 읽고 차이를 검토했다. 사용자 직접 테스트 방침에 따라 자동 검사·프로그램 실행·이미지 렌더링·실제 창 조작은 수행하지 않았다.
- 실행기 창을 완전히 닫고 다시 열어 `tests/ui_test.py`를 드롭한다. 글자 잘림·콤보 기준선·패널 여백과 세 거리의 삼각형 크기·알파 차이를 사용자가 확인한다.
