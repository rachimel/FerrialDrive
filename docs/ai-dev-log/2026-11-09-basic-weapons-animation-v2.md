# 기본 무기 애니메이션 2차

날짜는 현재 대화의 2026-11-09 KST 기준이다. [[FDLOG_MISSING_TIME:2026-11-09-basic-weapons-animation-v2:scope]] 개별 발언·구현 시각 미확인. 검색 단서: “뒤로 걷는 느낌”, “모션의 무게를 지탱해주는 주축”, “총도 힘 빼고”, “애니메이션 2차로 깎아봐”.

## 1. 사용자가 제안한 것

U1: 기존 다리 움직임은 괜찮지만 뒤로 걷는 인상이 있어 전진·후진·좌우 이동을 나누자고 했다. 팔과 허리가 전반적으로 움직이지 않고, 검 공격에 지지 발과 내딛기/빼기 스텝이 부족하다고 지적했다.

U2: 과장된 전환을 위해 수납 위치 반대손으로 무기를 사용하자고 했다. 검 대기는 쥔 팔을 벌려 뒤틀림을 풀고, 빈손의 힘을 빼며, 허리를 약간 굽혀 공격 준비를 하도록 요청했다.

U3: 총은 평소 힘을 빼고 사격할 때만 지지했다가 다시 이완한다. 양손 조준 때는 힘을 준다. 위 기준으로 2차 제작을 요청했다.

## 2. 사용자 제안 중 AI가 수용한 것

검/총 각각 4방향 걷기·달리기로 분리했다. 총 41개 모션·323프레임, 8fps다. 검 왼손·총 오른손으로 바꿔 반대쪽 허리에서 인출한다. 원본/1차는 보존했다. 검 대기와 빈손, 이동의 팔 흔들림/몸통 회전, 공격 스텝, 총 이완→지향 사격→이완과 양손 조준 유지에 반영했다.

## 3. AI가 제안한 것

A1: 발 접지/회수 위상을 먼저 고치고 발·골반을 기준으로 상체를 연결한다. 3/4타는 10프레임으로 늘리고 1/2타는 8프레임을 유지한다. 중단 복귀에서 두 발이 동시에 뜨지 않도록 순차 회수한다.

A2: 새 후보의 명시적 관절 포즈에 간섭하는 기존 운반/측면 회피 제약만 멈춘다. 부모 변경과 제약 mute를 공통 제작 데이터 setup_operations로 재현한다. 장비 형상·원본 리그는 수정하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

사용자는 앞선 수정 기준을 확인하고 2차 제작을 요청했다. 구현 세부 수치와 결과 외관은 아직 승인 전이다.

## 5. 반영 후 발견한 문제

I1: 1차는 뒤로 움직이는 발을 들어 올리는 위상으로 구성되어 전진이 후진처럼 읽혔다.

I2: 허리 회전 시 Equipment_Carry_Pose_v051/Equipment_Lateral_Clearance_v051이 상완을 다시 회전시켜 두 관절 해법이 목표에 닿지 못했다.

I3: 반대손 인출에서 슬롯은 허리를 따라 움직이므로 고정 월드 목표를 사용하면 어긋났다. 빈팔도 몸통 기준으로 움직여야 했다.

I4: 처음 출력 검사에서 그림자의 프레임 경계 잘림을 검출했다. 기존 고정 카메라 범위로 무조건 패킹하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

U1에 따라 보행의 지지 발이 이동 반대 방향으로 밀리고 회수 발이 이동 방향으로 돌아오도록 위상을 수정했다. 방향별 클립을 분리하고 기존 보폭/굽힘을 바탕으로 팔과 허리 회전을 추가했다. U2·U3에 따라 반대손 인출과 이완/긴장 상태를 구분했다.

## 7. AI 해결 제안과 실제 해결 과정

I2는 지정 제약 mute 연산으로 해결했다. 다른 제약은 보존하며 없는 이름은 실패 처리한다. 단일 리그 검증과 저장/재로딩 시 setup 유지 및 원본 해시 보존 테스트를 추가했다. Blender 테스트 14개 통과.

I3는 평가된 슬롯 좌표를 따르고 몸통을 크게 돌려 해결했다. 인출 전 접근 표본도 추가했다. 모든 표본의 저장/재로딩 최대 행렬 오차 0.000000835, 연결 본 틈 0, 4개 부착 이벤트 위치 오차 0.0000005 미만이다. 검 왼손·총 오른손 연결을 확인했다. 전신 충돌이나 칼집 완전 인출 경로를 보증하는 검사는 아니다.

I4는 모든 모션에 공통 정사영 범위 7.2와 카메라 목표 [0,0,1.25]를 적용했다. 전환 4표본을 64px로 실제 8방향 본체/그림자 렌더·경계 검사·패킹 후 SpriteBundle로 읽었고 모두 8fps다. 전체 최종 8방향 출력은 미실시다. 재생성 설정의 render_settings에도 반영했다.

41개 모션의 사선 작업 렌더를 생성하고 대기/이동 표본, 콤보·사격·전환 접촉 시트를 확인했다. 4방향 걷기 8종의 지지 방향/높이·회수 발 높이도 확인했다. 검토 페이지는 output/basic_weapons/animations_v2/preview.html, 현재 작업본은 data/models/basic_weapons/animations_v2/animations.blend다. 게임 이동과 접지의 동기화, 칼집/검날/장갑의 전체 연속 간섭, 손 접촉·무게감 세부 조정, 사용자 외관 승인은 남아 있다.
