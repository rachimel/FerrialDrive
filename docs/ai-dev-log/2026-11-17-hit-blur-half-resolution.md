# 탄약 1배·HIT 블러 반해상도

- **기록 ID:** `FDLOG-20261117-hit-blur-half-resolution`
- 작업·확인 날짜: 2026-11-17 KST. 현재 세션 개별 발언 시각은 제공되지 않았다. [[FDLOG_MISSING_TIME:FDLOG-20261117-hit-blur-half-resolution:scope]] 검색 단서: `탄약숫자 텍스쳐는 원본`, `HIT시 숫자`, `3배 해상도 말고 1배율`.
- 상태: 구현·관련 자동 검사·실제 OpenGL 시연·중간 프레임 확인. 사용자 외관 승인·커밋·업로드는 별도다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 탄약 숫자를 원본으로 돌리고 HIT 숫자 모션블러에 반해상도 텍스처를 사용하도록 요청했다.
- **사용자 정정 1 (U2):** 원본을 3배 해상도로 설명한 AI에게 1배율이라고 정정했다. 탄약 생성은 54px 표시 기준 54px로 확정한다. 근거: 현재 세션의 위 검색 문구.

## 2. 사용자 제안 중 AI가 수용한 것

- U1·U2를 적용했다. HIT의 변하는 숫자만 절반 크기 렌더 타깃으로 그린 뒤 화면 크기로 합성한다. 탄약의 그라데이션과 표시 크기는 유지한다.

## 3. AI가 제안한 것

- **구현상 판단:** 공통 `directional_blur`에 선택적 해상도 배율을 추가하고 HIT 설정에서만 0.5를 전달한다. 다른 블러의 기본값은 1이다.
- 전체·절반 크기 타깃을 최대 2개 재사용해 HIT·DAMAGE 사이에서 매번 파괴·생성하지 않는다. 원래 화면 좌표·블러 벡터와 실제 축소 텍스처의 비율을 함께 환산한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 해상도 변경은 사용자 요구 U1·U2다. 타깃 캐시 구조와 좌표 환산은 AI 구현 판단이다. 최종 외관 승인을 추정하지 않는다.

## 5. 반영 후 발견한 문제

- 이번 검사·시연에서 숫자의 위치·크기 회귀를 발견하지 못했다. 반해상도 HIT 블러는 약간 더 부드럽다.
- 카운터 단독 RTX 5070 Laptop 단기 측정에서는 속도 향상이 뚜렷하지 않았다. 블러 원본 타깃 픽셀 수가 1/4로 줄었다는 사실을 전체 성능 향상으로 확대하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2에 따라 탄약 본문 생성 배율을 0.5→1로 조정했다. 선행 반해상도 탄약 결과는 [이전 기록](2026-11-17-hud-palette-ammo-resolution.md)의 당시 결과로 보존한다.

## 7. AI 해결 제안과 실제 해결 과정

- 수정: `ui_v2/pico_renderer.py`, `ui_v2/view.py`, `ui_v2/panel_probe.py`, `samples/ui_unit_test_v2/ui_config.json`. `counters.combo.blur_resolution_scale=0.5`로 HIT만 선택한다. 팔레트 캐시는 유지한다.
- 정지 HIT 숫자·레이블은 기존 텍스처 경로로 표시한다. DAMAGE·카메라·무장 블러는 1배가 기본이다. 반해상도는 글리프 원본을 바꾸는 기능이 아니라 모션블러 캡처 타깃의 배율이다.
- HUD 테마·카운터 동작·UI V2·VFX 관련 검사 82개 통과. HIT 움직임·정지와 DAMAGE 경로의 적용 범위를 확인하는 검사 1개를 추가했다. 전체 자동 검사는 수행하지 않았다.
- 실제 Pico2D/OpenGL에서 1920×1080·960×540 타깃 재사용을 확인했다. 0.9배 UI 확대/축소·평행이동을 포함한 전후 렌더 상태 동일성을 실행 중 검사했다. 움직임 30/90/150ms와 정지 180ms를 캡처하고 90/180ms 이미지를 직접 열어 비교했다.
- 진단 출력: `output/performance/gun_od_probe_20261117/counter_rt.py`, `counter_rt.json`, `counter_rt_*.png`. 첫 진단 스크립트에서 글꼴 역할 이름을 잘못 지정한 실행은 실패했으며 `combo_number`로 고친 뒤 실행 완료했다.
- 샘플 하나당 120프레임·예열 30프레임의 카운터 단독 측정이다. 기본 도형 환경이며 실제 전투 전체 성능·사용자 조작감·다른 GPU 개선율을 확정하지 않는다.
- 후속 실제 에셋 사격·Overdrive·반복 사격 각 120프레임이 정상 종료했다. `ammo1_hit_half.json`과 PNG에 결과를 분리했고 일반 사격의 전체 화면도 직접 열어 확인했다. 자동 입력의 단기 렌더 검증이며 사용자 직접 조작 검증은 아니다.
