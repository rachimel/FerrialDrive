# 현재 UI 폰트 배포 갱신

- 작성일: 2026-11-03, 한국 시간
- 사용자 요청: 변경된 폰트도 업데이트하고 push한다. 이전 UI push에서 남겨 둔 깍두기 도면체 4개 파일 삭제를 이번 변경에 포함한다.
- 현재 UI에서 쓰지만 Git 제외 상태였던 Cafe24 Ohsquare Air·일반형·학교안심 운동장 OTF 3개를 포함한다. `.gitignore`는 지정 OTF·이용 조건만 허용하며, 사용하지 않는 TTF·ZIP·다른 로컬 에셋은 계속 제외한다.
- Cafe24 2종의 공식 패키지 OTF·라이선스 PDF와 현재 파일의 바이트 일치를 확인했다. PDF의 OFL 1.1·재배포 안내를 텍스트로 확인했고 원본 PDF는 유지한다.
- 학교안심 운동장은 [KERIS 공식 안내](https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202312110000000000016)의 OFL·임베딩·재배포 허용과 원본 메타데이터의 KERIS 저작권을 확인했다. 사용자 제공 OTF를 수정·교체하지 않는다.
- 새로 포함하는 3종의 `LICENSE.txt`에 원본 폰트의 저작권 고지와 [SIL OFL 1.1 전문](https://openfontlicense.org/documents/OFL.txt)의 라이선스 본문을 함께 보관한다. 저작권자·예약 글꼴명을 템플릿 자리표시자로 남기거나 임의로 추가하지 않는다.
- 현재 설정의 서로 다른 폰트 6개 경로가 모두 존재하고, 추가할 바이너리의 SHA-256을 Git 대상과 대조했다. 폰트 역할·크기·배치·색·애니메이션은 변경하지 않는다.
- 폰트 안내·프로젝트 실행 안내·UI 명세·체크포인트의 수동 다운로드 및 제외 상태를 현재 배포 범위에 맞췄다. 패키지·파일·설정·Git 범위 검사는 수행했으며 자동 UI 테스트·프로그램 실행·렌더링은 수행하지 않았다.
