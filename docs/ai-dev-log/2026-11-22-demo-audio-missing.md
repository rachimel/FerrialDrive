# 공개 도형 데모의 미준비 음원 처리

- **기록 ID** `FDLOG-20261122-demo-audio-missing`
- 작업일 2026-11-22 KST.

## 1. 사용자가 제안한 것

- **U1** 데모에서 음원 파일이 빠졌으면 경고 없이 무음으로 실행하고, 실제 에셋 실행의 누락 경고를 유지해 달라고 요청했다. 클린 체크아웃 재검증과 별도 커밋도 요청했다. 정확한 발언 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261122-demo-audio-missing:U1]]`. 검색 단서는 `데모에서 음원 파일 없을 땐 경고도`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `MovementApplication`과 교전·본편 파생 경로가 공개 도형 데모일 때 효과음 파일 누락 경고를 생략한다.

## 3. AI가 제안한 것

- **구현상 판단** 효과음 로더에는 옵션을 전달하고 실제 에셋 실행과 다른 직접 호출은 기본 경고를 사용한다. 데모에서 로더 상태와 장치 실패 경고는 계속 확인할 수 있다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 별도 구현 제안에 대한 수용 요청은 없었다.

## 5. 반영 후 발견한 문제

- 변경 전에는 음원 폴더가 없는 클린 사본에서 데모 시작 때 `RuntimeWarning`이 출력됐다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 디코딩·장치 오류와 실제 에셋 모드의 파일 누락은 기존 경고 경로를 사용한다. 공개 도형 모드에서는 파일 누락에도 기존과 같이 오디오 없이 실행한다.

## 7. AI 해결 제안과 실제 해결 과정

- 로컬 음원·게임 에셋이 없는 Git 사본에 수정 후보를 적용했다. 런타임 경고를 오류로 처리하는 옵션으로 이동 데모와 도형 벤치마크가 각각 48프레임을 완료했고 음원 자동 검사 33건이 통과했다.
- 실제 에셋을 읽는 교전에서도 음원 폴더만 비어 있는 조건으로 8프레임을 실행했다. 효과음 누락 경고가 출력됐다.
