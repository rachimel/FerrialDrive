# UI v2 사선 스타일과 외관 피드백

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 기존 패널 디자인을 버리고 v2 도안의 날렵함, 붙어 있는 에너지 바와 레벨, HIT의 약한 원근감을 살린다. 밋밋한 초기 구현과 도안의 의도 차이를 이유로 제시했다. 시각은 scope 태그를 따른다.
- **사용자 제안 2 (U2):** 필살기 문양을 마름모 안에 배치하고 HIT 각도를 DAMAGE와 맞춘다. 받침선을 굵게, HP 채움 끝을 사선으로, 플레이어 HP 높이를 에너지 바 수준으로 줄인다. LOCK ON 겹침 해소·록온 다이아몬드 축소/두께 증가·표적 HP 두께 축소·COUNTER와 메뉴 글자 회전 제거·레이더 확대도 요청했다. 증상과 이유는 해당 사용자 피드백이다. 시각은 scope 태그를 따른다.
- **사용자 제안 3 (U3):** 전체 UI를 약간 줄이는 의견을 전달했고, 후속 선택에서 레이더를 제외한 전투 HUD 약 10% 축소를 선택했다. 메뉴 UI는 나중에 바꿀 여지를 남겼다. 시각은 scope 태그를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1~U3을 수용했다. 기존 v2와 별도로 전투 규칙을 구현하지 않고, v2 표시·설정·샘플과 관련 문서를 수정했다.
- 사용자 수정본 외관 승인과 요청의 구현을 구분한다. 실제 조작은 이번에도 수행하지 않았다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 전체 크기 의견을 이번에 반영할지 질문하며 레이더를 키우고 나머지 전투 HUD를 약 10% 줄이는 범위를 제시했다. 의견의 적용 시점을 확인하기 위한 질문이다. 시각은 scope 태그를 따른다.
- **구현상 판단 (A2):** 에너지/레벨의 공통 외곽, 글자 평면 투영, 도형별 앵커를 유지하는 축소를 사용했다. 흡수 Trail은 실제 시작점과 축소된 도착점을 연결한다. 사용자의 세부 구현 승인으로 취급하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1에 사용자가 **“이번에 약 10% 축소”**를 선택했다. 범위에 대한 명시 응답이며 수정 이미지의 최종 승인은 아니다. 시각은 scope 태그를 따른다.
- A2의 실제 외형·수치와 수정본은 확인 대기다.

## 5. 반영 후 발견한 문제

- **I1:** U1 반영본에 대해 사용자가 마름모 테두리 누락·서로 다른 카운터 각도·얇은 받침선·직사각형 HP 채움·록온 글자 겹침·게이지 두께·불필요한 글자 회전을 지적했다. 사전 사용자 승인으로 기록하지 않는다.
- **I2:** AI가 90% 축소 이미지를 열어 도형의 공유 경계에 틈과 앵커 이동을 발견했다. 정수 행 채움과 SDL viewport의 배율 처리가 원인이었다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U2: 필살기 문양을 테두리 안으로 줄이고, HIT/DAMAGE 투영 각도를 통일했다. 받침선 3px·록온 외곽 2px·표적 HP 6px·플레이어 HP/에너지 높이 26px로 조정했다. 이 수치는 90% 축소 전 논리 픽셀이다.
- LOCK ON은 외곽과 간격을 두고, COUNTER/메뉴 글자는 수평으로 바꿨다. 레이더는 128→160px, 전투 HUD는 메뉴·기체·레이더를 제외하고 0.9배로 표시한다. 새 메뉴 디자인은 미정이다.
- HP 감소 구간도 바와 같은 사선 끝을 유지하는 이미지와 자원 0 이미지를 열어 확인했다. 수정본 사용자 검수는 남아 있다.

## 7. AI 해결 제안과 실제 해결 과정

- I2는 v2 도형에 SDL 삼각형 채움을 사용하고 viewport 배율을 보상해 해결했다. Pico2D 원본과 v1 렌더러는 수정하지 않았다. 축소 후 아이콘/에너지 바로 향하는 흡수 좌표를 별도로 계산했다.
- v2 자동 검사 12개·기존 UI 포함 67개 통과. 화면 없는 실제 Pico2D/SDL에서 8개 상태를 렌더링하고 배율/viewport/clip 복원·기존 금속 패널 미생성·자원 해제를 확인했다. 전투·HP 감소·자원 0·흡수·타이틀·일시정지 PNG를 열어 확인했다.
- 실제 창 키·클릭·Runner 드롭·전체 재생 사용감·최종 외관 승인·커밋은 기록 작성 시점에 미확인이다. PNG는 재생성 가능한 `output/ui_unit_test_v2/` 출력이며 커밋하지 않는다.
