# 본편 프레젠테이션 타이틀

## 사용자가 제안한 것

**U1** 2026-11-24 KST 본편 대화에서 타이틀 전 Light 프로젝트 문구, 진회색 배경, 현행 메카의 흰 실루엣, 진입·대기·호버 입자와 중앙에서 퍼지는 흰 띠를 요청했다. 버전 최종 지정은 `VER. PRE_DEMO`다.

**U2** 같은 대화에서 Atlas를 크레딧으로 옮기고 MP3 원본을 공유하지 않도록 요청했다. 사용자가 알려준 제작자는 Prismatic Tone이다.

## 사용자 제안 중 AI가 수용한 것

U1·U2를 본편에 반영했다.

## AI가 제안한 것

구현상 판단으로 현재 플레이어 카탈로그의 몸체를 비스듬히 투영하고 외곽과 일부 면 경계를 흰색 투명 이미지로 미리 생성한다. 재생성 명령은 프로젝트 루트에서 `python -m automate.title_silhouette`이다.

## AI가 제안한 것 중 사용자가 수용한 것

타이틀 외관과 호버 강도는 사용자 검수 대기.

## 반영 후 발견한 문제

게임 에셋을 제외한 체크아웃에서는 로컬 실루엣 이미지가 없어 입자 배경만 표시한다.

## 사용자 해결 제안과 실제 해결 과정

버전 표기는 사용자 최종 정정에 맞춰 괄호 설명과 끝 마침표를 제외했다.

## AI 해결 제안과 실제 해결 과정

실제 두 렌더러로 프로젝트 문구, 대기·호버·크레딧을 캡처했다. 활성 버튼 포인터 입력에 따른 파동·입자 가속, 크레딧 클릭·Esc 복귀, 전투 메시 미로딩을 검사했다. 출력은 `output/title_pre_demo/`다. 음악 원본은 Git 제외 경로 `data/source/audio/sources/bgm/credit/Atlas.mp3`에 로컬 보관하며 게임에는 출처 문구를 표시한다.

같은 날 후속 요청에 따라 타이틀의 메카 투영을 제거하고 하단에서 상승하는 입자, 가장자리 비네팅, 로고·메뉴 뒤에서 오른쪽으로 투명해지는 어두운 바를 적용했다. 두 렌더러의 960×540 캡처에서 왼쪽부터 중앙까지 배경 R값 7·15·27·34와 모서리 감광을 확인했다. 캡처는 `output/title_pre_demo/r2/`에 있다.

후속 사용자 요청으로 스크롤 그리드를 실제 타이틀에 적용했다. 일부 셀이 격자와 함께 이동하며 밝아진 뒤 중심으로 수축한다. 두 렌더러에서 확인했고 캡처는 `output/title_grid_live/`에 있다. 본편 재생성 시 스플래시와 정리 화면을 생략하고 타이틀 전환을 시작한다. 언어 설정 기본값은 English이며 한국어 선택·저장 후 타이틀·일시정지·설정 메뉴에 적용한다. 별도 임시 설정으로 실게임 루프의 최초 실행, 언어 저장, 교전, 일시정지, 타이틀 재생성까지 확인했다. 스토리 대사 번역은 이번 적용 범위 밖이다.
