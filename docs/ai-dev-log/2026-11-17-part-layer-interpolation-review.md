## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 각 파츠를 따로 렌더하고 보간하는 편이 더 이득일 것 같다고 제안했다.
  - 이유·의도: 이득을 예상한다고 밝혔으나 비용·화질·재사용 중 우선 기준은 명시하지 않았다. 구체적 판단 근거는 미확인이다. `[[FDLOG_MISSING_REASON:FDLOG-20261117-part-layer-interpolation-review:U1]]` 검색 단서: 해당 제안의 후속 설명.
  - 시각·출처: 위 대화 범위와 사용자 발언.
- **사용자 후속 확인 (U2):** `ㅇㅇ 그러면 프리렌더할 때 파츠를 따로 보간해야겠네.`
  - U1의 파츠별 렌더·보간 방향을 이어가기로 확인했다. 별도 성능 이득이나 구체적인 가림 알고리즘까지 승인한 것으로 확대하지 않는다.
  - 시각·출처: 위 대화 범위의 사용자 후속 발언. 정확한 시각은 scope 누락 항목을 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 비교할 가치가 있는 구조 후보로 수용했다. 제작 비용·재사용·보간 품질의 이득 가능성과 런타임 비용을 구분한다. 최종 채택이나 실측 이득을 확정하지 않았다.
- U2 이후 파츠별 프리렌더 입력을 만들고 재생 시 파츠마다 보간한 뒤 합성하는 방향을 출력 규약에 반영했다. 프리렌더 출력과 게임 재생 중 보간의 책임을 구분했다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 한 짧은 동작에서 파츠별 색상·양방향 벡터의 보간 후 합성을 전신 보간 및 같은 시각의 Unreal 참조와 비교한다.
  - 이유·판단 근거: 현재 아틀라스 셰이더에는 파츠 간 깊이 합성이 없고, 현행 Stencil Layers 출력은 가려진 표면이 없는 조합 종속 이미지다. 분리만으로 가림 복원·장비 재사용이 해결되지는 않는다.
  - 비교 대상: 가림 전환의 빈틈·겹침·파지, 공통 시간·피봇, 표면 음영·그림자, 저장 용량·렌더 시간·GPU 시간.
  - 시각·출처: 위 대화 범위의 AI 검토. 현재 파일 `ferrial_drive/rendering/pico_motion_atlas.py`, `motion_atlas.py`, `docs/unit-tests/frame_interpolation.md`, `docs/ai-asset-pipeline/unreal_pipeline.md` 및 [Epic MRQ 렌더 패스](https://dev.epicgames.com/documentation/en-us/unreal-engine/cinematic-render-passes-in-unreal-engine).

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 최초 기록 때에는 사용자 응답 전이었다. U2로 파츠별 렌더·보간 방향의 채택을 확인했다. A1의 구체적인 비교 절차·수치·가림 처리 방식까지 사용자가 확정했다고 기록하지 않는다.

## 5. 반영 후 발견한 문제

- 구현 반영은 미수행이다. 가림으로 잘린 파츠·깊이 합성 부재는 기존 구조의 제약이며 이번 제안 반영 후 발생한 문제로 기록하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2에서 파츠별 렌더·보간 방향을 재확인했다. 구체적인 가림 처리 절차는 제시하지 않았으며 실제 구현은 미수행이다.

## 7. AI 해결 제안과 실제 해결 과정

- A1의 비교 방향만 검토했다. 소스·명세·Epic 문서를 읽었으며 게임 코드·에셋·PRE-PRD는 변경하지 않았다. 파츠별 보간의 화질·성능은 미검증이다.
- U2 이후 `docs/ai-asset-pipeline/unreal_pipeline.md`에 제작 방향과 미구현 범위를 반영했다. 문서 반영만 수행했으며 프리렌더·보간 코드와 에셋은 변경하지 않았다.
- 사용자는 이후 이 방향으로 진행하면서 현재 전체 변경을 기능별로 커밋하도록 요청했다. 새 파츠별 보간의 구현 완료와 구분하며, 커밋 범위·전체 검사 결과는 [기능별 커밋 기록](2026-11-17-feature-commit-checkpoint.md)을 따른다.
