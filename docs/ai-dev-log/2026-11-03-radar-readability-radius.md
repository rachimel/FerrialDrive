# 레이더 화살표 가독성·반경 평가 기준

- 작성일: 2026-11-03, 한국 시간
- 사용자 피드백: 레이더 화살표가 작고 잘 보이지 않는다. 가로 폭과 알파를 높이고 자체 알파 하한을 0.3으로 시험한다.
- 밑변 반폭을 10→15px로 바꿔 전체 기준 폭을 20→30px로 넓힌다. 높이 20px·최소 크기 비율 0.45·거리별 선형 감소·채운 삼각형·적 방향 회전은 유지한다. 감지 한계의 계산상 크기는 높이 9px·밑변 폭 13.5px다.
- 설정과 뷰·초기 검증의 누락 시 기본 알파를 모두 0.3으로 맞춘다. 이 하한은 표식 자체에 적용하며 장면 전환 알파를 곱한 결과까지 강제로 0.3 이상으로 만들지는 않는다.
- 반지름은 사용자 이미지의 요구를 따라 플레이어 시선 고정 상태에서 주변의 대략적인 형체와 표식 방향을 안정적으로 인지할 수 있는 최대 실용 범위로 정한다. 이미지의 이전 답변에 등장한 설명을 그대로 확정된 생리학 수치로 사용하지 않는다.
- 현재 200px는 임시 유지한다. 표시 크기·해상도·시청 거리·표식 크기/알파를 고정하고 방향별·단독/혼잡 배경·전투 이펙트 조건을 비교한다. 존재 감지와 방향·형태 인지를 구분하며 최종값·통과 기준·여유 폭은 사용자 평가 뒤 정한다.
- 반경을 키워 고정 샘플이 원 안으로 들어가면 기존 숨김 규칙 때문에 표식이 사라진다. 시험 대상의 화면 위치를 항상 원 밖에 두어 이 현상을 인지 실패와 혼동하지 않는다. 감지 거리와 표시 반지름도 구분한다.
- [주변시 방향 군집화 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC4792514/)에서 표식 간격에 따른 방향 판단 영향을 참고했다. 논문에서 게임용 최대 px나 사용자의 인지 한계를 산출하지 않았다.
- PRE-PRD·현재 UI 명세·샘플 수동 평가 안내·체크포인트를 맞췄다. 소스·설정·Git 변경 검사는 수행했으며 자동 테스트·UI 실행·화면 확인·시선/인지 측정은 수행하지 않았다.
