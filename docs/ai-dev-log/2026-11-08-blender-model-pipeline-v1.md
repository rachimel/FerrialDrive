## 5. 반영 후 발견한 문제

- 초기 초안은 모델별 build(context) Python과 통합 검사였으나 U2에 따라 폐기하고 JSON 공통 연산/독립 검사로 변경했다. 이 초안을 현재 기능으로 설명하지 않는다.
- Blender의 GENERATED 이미지가 type 기반 필터에서 빠져 source 기준으로 수정했다. 독립 검사 CLI의 import 경로 오류도 수정해 별도 프로세스에서 실행을 확인했다.
- 테스트 임시 폴더 접근 제한으로 실행이 실패해 허용된 실행으로 확인한 뒤, 개발용 임시 파일은 프로젝트 output 아래에서만 만들고 정리하도록 개선했다.
- 정리 도중 최종 파일명이 player_mech.blend로 바뀌어 있는 것을 발견했다. 변경 주체는 확인하지 않았으며 파일 내용을 바꾸거나 이름을 되돌리지 않았다. v078과 동일한 SHA-256을 확인하고 참조를 현재 경로로 동기화했다.

## 7. AI 해결 제안과 실제 해결 과정

## 후속 작업: 손 전방 배치·좌우 방향·디자인 규칙

### 1. 사용자 제안

현재 대화에서 사용자는 손이 고리 앞에 오도록 `player_mech.blend` 직접 수정 및 파일 수 유지를 요청했다. 이어 첨부 정면 이미지의 왼쪽 팔을 기준으로 오른쪽 팔의 orientation을 맞추고, 현재 모델 분석에 기반한 Ferrial Drive 디자인·제작 규칙을 별도 문서와 AGENTS/파이프라인에 연결하도록 명시했다. 후속 기체의 동일 외형 강제와 기존 결함의 디자인 원칙화는 금지했다. 기록일은 2026-11-08 KST이며 개별 발언 시각은 별도 확정하지 않았다.

### 2. AI 제안

고리 수납 위치를 유지하며 어깨에서 양팔을 전방 30도 돌리고 메시/관련 본/Shape Key·혼합 웨이트 연결부를 함께 조정했다. 영구 버전 스크립트를 추가하지 않고 임시 후보에서 공통 좌표 보조 함수를 사용했다. 디자인 문서는 관찰·규칙·미검증을 분리하는 구성을 제안했다.

### 3. 사용자 제안 반영

요청한 기존 파일에 반영하고 릴리스 해시·부위 레지스트리·기본 manifest를 동기화했다. 기준 팔은 화면 왼쪽, 모델 R로 명시했다. 디자인 규칙에 실루엣/기능성 디테일, 메시/계층/UV/재질, 리깅/애니메이션, 장착 호환성, 변경 전후 검증을 정리했다.

### 4. 양방향 수용 범위

기존 파일의 직접 수정과 문서화는 사용자 명시 요청이다. 첫 렌더의 비대칭은 사용자가 지적했다. AI의 후속 수정·렌더 확인은 새 최종 외관의 사용자 승인을 뜻하지 않는다. 릴리스 상태는 수정 후 외관 확인 대기로 구분했다.

### 5. 반영 후 발견한 문제

양팔 Rest Pose만 같은 각도로 바꾸자 기존 COPY_ROTATION 장비 회피 제어가 이전 로컬 회전축을 사용해 평가 자세가 비대칭이 됐다. 고리 볼 2개/소켓 2개의 면적 0 삼각형 오류는 수정 전후 동일했다. 전체 형상 검사를 통과로 처리하지 않았다.

### 6. 사용자 해결 제안과 실제 과정

화면 왼쪽 팔에 맞추라는 지시에 따라 모델 R의 제어축을 기준으로 반대쪽 축을 본 로컬 좌표에 맞게 대칭 변환했다. 고리·스커트·가슴의 기존 형상은 보존했다. 모델 폴더의 파일 목록을 비교하고 임시 후보/스크립트/렌더는 정리한다.

### 7. AI 해결 제안과 실제 과정

저장·재로딩·프레임 변경 후 어깨/팔꿈치/손 위치 대칭 오차 0.000001 모델 단위 미만을 확인했다. 정면/후면/사선 확대 및 작은 표시 크기를 검토했다. 고리 -90~+90도 15도 간격 13상태 × 2,658쌍(팔/손 대 고리 및 주 팔 외피 대 가슴/스커트)의 표면 교차 0, 지정 UV·이미지 패킹 통과. 기존 4개 볼/소켓 형상 오류, 완전 포함·연속 충돌·전체 전투 모션·무기 장착 호환성은 해결/검증 완료로 기록하지 않는다. `mech_design_rules.md`를 추가하고 기존 문서의 중복 표면/디테일 지침을 해당 문서 참조로 통합했다.

## 후속 작업: 허리 매입 슬롯·팔 벌림·손가락 복구

### 1. 사용자 제안

2026-11-08 현재 대화에서 사용자는 팔을 정면에서 벌리고 고리를 허리 양옆 중앙에 붙이며 손가락 관절 고장을 고치도록 요청했다. 중간에 작업을 멈춘 뒤 고리를 폐기하고 평소 닫힌 사각 근접 무기 장착 홈으로 교체하도록 변경했다. 세계관 설정에서도 고리를 제거하고 홈에 깊이·형상 디테일을 추가하도록 명시했다. 개별 발언 시각은 별도로 확정하지 않았다.

### 2. AI 제안

앞선 전방 30도 회전을 취소하고 기존 팔에 정면 방향 벌림 22도를 추가했다. 허리 슬롯은 실체 Boolean 홈, 안쪽으로 열리는 두 덮개, 입구 단차/사선 테두리, 내부 받침과 더 깊은 결합 홈으로 구성했다. 장착 무기 전체가 허리 안에 수납된다는 설정은 추가하지 않았다.

### 3. 사용자 제안 반영

고리와 전용 장치 계층 70개 오브젝트 및 관련 제어를 제거했다. 새 MeleeMount.L/R는 Waist 본을 따라가고 cover_open=0으로 저장한다. 세계관·현행 디자인 규칙·장치 제어 문서에서 현재 장착 구조를 슬롯으로 변경했다. 파일 수 유지 요청에 따라 모델은 기존 player_mech.blend에 반영하고 기준 해시/레지스트리/독립 검사 설정을 갱신했다.

### 4. 양방향 수용 범위

고리 폐기, 슬롯의 평상시 닫힘, 깊이 디테일 추가는 사용자 요청이다. 안쪽 개폐 방식·세부 단차·내부 받침은 이를 구현한 AI의 조형 선택이며 새 최종 외관 사용자 승인과 구분한다. 원본 반영은 명시적으로 요청된 범위다.

### 5. 반영 후 발견한 문제

앞선 팔 수정에서 connected 본의 공유 관절점이 중복 변환되어 손가락 본이 늘어났다. 이는 AI의 수정 오류였다. 손의 중립 이미지와 팔 대칭 검사만으로 손가락 애니메이션을 검증할 수 없었다. 초기 슬롯은 덮개가 표면보다 돌출되고 깊이 표현이 부족했으며, 90도 열림에서 경첩 가장자리가 벽과 교차했다.

### 6. 사용자 해결 제안과 실제 과정

사용자의 방향 수정에 맞춰 고리 수납 검토를 폐기했다. 슬롯을 허리 외피 안으로 넣고 개폐 여유와 입구/바닥의 단계별 깊이를 만들었다. 설정의 고리는 현재 구조에서 제외하되 과거 개발 기록은 당시 이력으로 유지했다.

### 7. AI 해결 제안과 실제 과정

보관된 v061 레지스트리의 팔/손 끝점이 변경 전 좌표와 맞는지 확인한 뒤 손가락을 복구했다. 연결을 해제하고 모든 끝점을 배치한 뒤 다시 연결했으며 힌지 기하 축에 맞춰 roll을 복구했다. 프레임 1~65의 연결 관절 틈 0과 힌지 중심의 일정한 오프셋을 검사하고 펼침/주먹/파지를 렌더로 확인했다. 형상·지정 가슴/팔 UV·이미지 패킹 및 덮개 9단계 × 40쌍 표면 교차 검사를 각각 실행해 통과했다. 허리 회전 추종과 저장/재로딩 기본 닫힘도 확인했다. 새 형상에 필요 없는 이전 볼/소켓 오류는 장치 제거와 함께 사라졌다. 실제 무기 결합 치수·잠금/스왑·전체 전투 모션·연속 충돌·완전 포함 판정은 미검증이다. 임시 스크립트/모델/렌더를 정리하고 모델 폴더 파일 목록을 유지한다.
