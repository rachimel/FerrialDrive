# 기본 무기 파지·수납 기본형

기록 ID: **2026-11-09-basic-weapons-blockout**. 출처: 이 대화의 기본 무기 모델 요청과 후속 수납 위치 답변. 개별 발언의 정확한 KST 시각은 확인하지 못했다. [[FDLOG_MISSING_TIME:2026-11-09-basic-weapons-blockout:scope]] 대화에서 “일단 그러면 기본 무기들 모델 해볼래?”와 “일단 허리슬롯인데”를 찾아 보완한다.

## 1. 사용자가 제안한 것

**사용자 제안 1 (U1)** — 플라즈마 소드의 독 슬롯을 없애고 칼집을 추가한다. 사출 버튼/안전장치는 수납 중에만 사용하며 수납 시 도신은 기본 길이로 복귀한다. 칼집에도 에너지 흐름을 표현한다. 출처: 이 대화의 검 설정 변경 설명. 이유를 별도로 밝히지는 않았다. [[FDLOG_MISSING_REASON:2026-11-09-basic-weapons-blockout:U1]] 해당 설명 앞뒤의 사용자 의도를 확인한다.

**사용자 제안 2 (U2)** — 현재 메카 손을 기준으로 기본 무기를 모델링한다. 총의 견착 슬롯은 팔 결합부다. 손+무기를 한 묶음으로 분리하고 방향별 상체 앞뒤 순서를 바꾼다. 수납 무기는 별도 상태에서 손 부착 상태로 전환한다. 의도: 기존 메카와의 파지 정합성 및 레이어 재사용. 출처: “무기 + 손 분리”, 정면/후면 첨부 이미지와 모델 요청.

**사용자 제안 3 (U3)** — 총도 우선 허리 슬롯에 수납한다. 어울리지 않으면 손·팔 수납과 에임 보정기 수납을 검토한다. 출처: 작업 중 수납 위치 질문에 대한 사용자 답변. 형상 확인 후 대안을 판단하는 범위다.

## 2. 사용자 제안 중 AI가 수용한 것

U1~U3를 기본형 제작 기준으로 수용했다. 형상, 정지 파지·수납 앵커까지만 구현했다. 연속 발도·사출·도신 연장·게임 레이어 출력은 이번 구현 완료로 취급하지 않는다.

## 3. AI가 제안한 것

**AI 제안 1 (A1)** — 원본 메카를 보존하고 별도 착용 후보에서 기본형과 손가락 자세를 맞춘다. 판단 근거: 승인 모델 보존과 무기 교체 시 간섭 확인. 출처: 작업 시작 및 파지 검사 진행 설명.

**구현상 판단** — 검 오른손/총 왼손 동시 배치는 비교용이다. 총의 팔 받침과 팔을 피하려고 수납 위치를 허리 뒤쪽으로 옮겼다. 이를 사용자의 전투 로드아웃 결정이나 외관 승인으로 해석하지 않는다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

기본형 제작은 사용자가 명시 요청했다. 이번 결과의 치수·좌우 배치·총의 후방 수납 외관은 아직 확인 대기다. 사용자 침묵을 승인으로 간주하지 않는다.

## 5. 반영 후 발견한 문제

**I1** — 초기 후보에서 손끝/손잡이, 팔 받침/장갑, 칼집/스커트, 수납 검의 가드/칼집 입구 표면 교차가 검출됐다.

**I2** — 기존 제작 연산만으로 본 장착, 검토 포즈, 동일 무기의 수납/파지 전환을 표현할 수 없었다.

## 6. 사용자 해결 제안과 실제 해결 과정

U3에 따라 총의 허리 수납 후보를 우선 제작했다. 손·팔 수납과 에임 보정기 접기는 비교 필요 시 후속 검토하며 이번에는 구현하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

I1: 손잡이 단면/위치, 손가락 포즈, 방아쇠 위치, 팔 받침 폭, 칼집 입구 간격과 허리 수납 위치를 순차 조정했다. 메카 메시·본 길이·원본 파일은 유지했다.

I2: 공통 JSON 연산에 포즈 고정/방향, 본 기준 장착, 앵커 전환과 에너지 제어를 추가했다. 기본 도형으로 부착 추종과 상태 전환을 검사했고 기존 테스트 포함 11개가 통과했다. 에셋마다 Python 파일을 추가하지 않았다.

결과: 무기 단독 모델과 착용 검토 후보 저장/재로딩 성공. 무기 형상 검사와 사본 이미지 패킹 검사 통과. 파지/수납 두 상태의 25,700쌍 지정 표면 교차 0건. 확대/게임 크기 렌더 확인. 허리 연결 어댑터는 의도된 결합부로 간섭 검사에서 제외했다. 전체 모션, 연속 충돌, 최소 간격, UV 제작, 최종 외관 승인, 게임 출력은 미완료다. 에셋은 Git 제외 로컬 경로에 보존한다.
