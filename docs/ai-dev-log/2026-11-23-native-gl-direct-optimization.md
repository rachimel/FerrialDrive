# 직접 OpenGL 제출과 아틀라스 적재 최적화

- 기록 ID `FDLOG-20261123-native-gl-direct-optimization`
- 기록일 2026-11-23 KST

## 1. 사용자가 제안한 것

- **U1** 초기 직접 OpenGL 실행 결과로 전환을 중단하지 않고 직접 제어를 활용해 비용을 줄인다. OpenGL 상태는 프로젝트 코드가 관리한다. 요청 시각 `[[FDLOG_MISSING_TIME:FDLOG-20261123-native-gl-direct-optimization:U1]]`. 대화에서 `직접 제어의 경우에는 더 깎을 여지`로 찾는다.

## 2. 사용자 제안 중 AI가 수용한 것

- 직접 OpenGL 경로를 최적화하고 본편·이동 훈련·전투 테스트·하드웨어 벤치마크의 기본 경로로 연결했다. SDL 창·입력·이미지 해석·오디오는 기존 Pico2D API를 유지한다.

## 3. AI가 제안한 것

- **A1** 전체 교전 프로파일로 반복 타일 제출, 공통 GL 상태 조회, 아틀라스 적재를 조사한다. 180기 Medium 프레임당 바닥 복사 147.1회와 90프레임 동안 `gl_pass.integer` 22,640회가 근거였다. 변경 전 직접 경로 및 SDL을 같은 GPU와 입력에서 비교한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 직접 제어 요구를 구현했다. 배치·아틀라스 구현 세부 사항은 AI의 판단이며 사용자의 직접 조작 및 외관 승인은 확인하지 않았다.

## 5. 반영 후 발견한 문제

- **I1** 기존 그림자 자료는 Intel, 이번 실행은 RTX 5070 Laptop GPU였다. 다른 GPU의 깊이 해시와 최종 픽셀을 직접 비교할 수 없었다.
- **I2** 같은 GPU에서 반복 측정해도 180기 직접 경로에 60FPS 예산 초과 구간이 남았다. 느린 프레임의 시간 대부분은 `draw_submit_ms`에 기록됐다. GPU 경과 시간과 드라이버 대기 시간을 별도 원인으로 확정하지 않았다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1·I2** 상태·자원 관리를 직접 OpenGL 경로에 두었다. 바닥 타일을 1회에 제출한다. 공통 패스는 캔버스 소유의 프로그램·활성 유닛·뷰포트·텍스처 상태를 재사용한다. 아틀라스는 RGBA 임시 저장소 없이 원래 형식으로 한 번 올린다. 같은 90프레임의 공통 GL 정수 조회는 22,640→15,197회, 직접 `_draw`는 30,236→17,087회였다.

## 7. AI 해결 제안과 실제 해결 과정

- **I1** RTX 5070 Laptop의 FHD 동일 입력 96프레임 중 10개 시점을 대조했다. 30기 High와 180기 Medium에서 각각 플레이어 지면·본체 깊이 맵 30장과 사용 중인 적 타일 572개·574개가 이전 직접 경로와 SDL 기준에 모두 일치했다. 기존·개선 직접 경로의 첫 3개 캡처는 픽셀 단위로 일치했다. 나머지 최종 RGB는 일부 픽셀이 달랐고, 개선 경로를 두 번 실행할 때도 비슷한 영역이 달랐다. 직접 경로의 색상·클립·RGBA/R8/BC7 바이트 자동 검사 3개를 통과했다.
- **I2** RTX 5070 Laptop의 상세 계측 없는 교전 자동 입력, 준비 45프레임·측정 90프레임으로 경로당 두 번씩 비교했다. 30기 High p50은 이전 직접 경로 19.68–20.24ms, 개선 직접 경로 17.38–18.90ms, SDL 17.33–18.85ms였다. 180기 Medium은 각각 23.42–31.92ms, 26.24–27.84ms, 20.41–23.50ms였다. 이 조건에서 180기는 SDL보다 느렸다.
- 2GiB 제한을 적용한 기본 렌더러의 180기 Medium 120프레임이 정상 종료했다. 측정 중 Private Bytes 최대 표본은 988MiB였다. Low 1,000기는 별도 제한 없는 6프레임을 확인했다. 본편 기본 창과 dummy 시연 진입도 확인했다. Intel 재측정과 장시간 실전 조작은 미수행이다.
- 로컬 결과는 `output/performance/native-gl-direct/`의 `pair-*`, `parity-*-comparison.json`, `default-2gib/report.json`, `default-2gib/flamegraph.svg`에서 확인한다.
