# FDrive 전체 메모리 2GiB·적과 이펙트 우선 배분

- 기록 ID: **FDLOG-20261108-fdrive-2gib-resource-priority**
- 기록 작성 기준 시각: 2026-11-08 19:20:37 KST에 확인한 도구 시각이다. 사용자 발언 시각과 구분한다.
- 출처: 현재 대화의 “게임 전체 메모리는 2GiB로 관리하는걸 목표”, “파티클과 전투 이펙트, 적에 더 투자하자”와 앞선 내장 그래픽·RAM 8GB·Iris 중간급 기준 및 이미지 공유·씬별 로딩 설명이다.
- 개별 제안·수용의 정확한 발언 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261108-fdrive-2gib-resource-priority:scope]] 위 검색 구절의 원문에서 시각을 확인한다. 사용자 제안 1과 AI 제안 1~2, 수용에 공통 적용한다.
- 상태: **메모리 목표와 자원 우선순위의 문서 반영**. 세부 배분은 검토안이며 구현·성능 검증은 수행하지 않는다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 게임 전체 메모리를 2GiB로 관리하는 것을 목표로 하고 파티클·전투 이펙트·적에 더 투자한다.
  - 이유·근거: 기체·효과·반응형 HUD·스크립트 ADV를 포함한 규모 추산 뒤 전체 목표와 우선순위를 명시했다. 기존 요구에는 같은 이미지의 공유와 씬에서 필요한 자원의 선택적 로딩이 있다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 PRE-PRD 7.6절에 기록한다. 2GiB는 이미지 전용이 아닌 전체 게임 목표로 구분하고 적·파티클·전투 이펙트의 우선순위를 명시한다.
- HUD와 ADV의 기능 요구는 유지한다. 현재 자원·시간 추산과 실측 결과, 확정 목표와 미정 항목을 구분한다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1), 세부 배분 검토안:** 기체 640MiB, 파티클·전투 이펙트 256MiB, 맵 96MiB, HUD 64MiB, ADV 128MiB, 오디오 64MiB, 공통 실행 상태·AI·충돌·탐색 256MiB, 임시 데이터·화면 버퍼·오버헤드·예비 544MiB로 나누어 합계 2,048MiB를 검토한다.
  - 이유·근거: 기존 추산보다 기체와 이펙트에 여유를 주면서 로딩 피크·실행 환경·미확인 할당 비용을 위한 예비를 확보하려는 제안이다. 실제 메모리 사용량이나 사용자 확정 배분은 아니다.
- **AI 제안 2 (A2), 검증 기준:** CPU/GPU 공유 메모리의 중복 보고에 주의하고 전환 중 피크를 확인한다. 다수 적·탄환·효과·반응형 HUD·전투 중 ADV를 함께 활성화해 시간·메모리를 확인한다.
  - 이유·근거: 같은 이미지의 공유로 줄어드는 상주량과 개별 갱신·그리기 비용을 구분하고, 메모리 목표만으로 프레임률을 보장하지 않기 위한 기준이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 앞선 AI의 2GiB 전체 목표 제안을 U1에서 사용자가 명시 수용했다. 적과 이펙트 우선 투자는 사용자 자신의 지시다.
- A1의 항목별 수치와 A2의 구체적인 검증·측정 방식은 이번 문서화의 검토안이다. 사용자 승인·구현 완료·실측 결과로 기록하지 않는다.

## 5. 반영 후 발견한 문제

- **발견한 문제 1 (I1), 목표 구분:** 기존 PRE-PRD에는 이펙트 예산 항목이 있었지만 전체 2GiB 목표와 적·효과 우선순위가 없었다. 새 실행 버그가 아닌 요구사항 구체화다.
- 세부 이미지 규격·동작 수·동시 기종·Live2D 자원·렌더 타깃과 최종 대상 기기는 아직 확정되지 않았다. 배분 검토안을 성능 보장으로 취급하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- I1 ↔ U1: 전체 메모리 목표와 투자 우선순위를 직접 지정했다. 기존 HUD·ADV 요구를 삭제하거나 적·파티클의 확정 개수를 임의로 늘리는 대신 자원 배분 원칙으로 기록한다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: PRE-PRD 7.6절에 확정 목표·우선순위·미확정 배분 표와 검증 항목을 분리해 기록한다. 항목별 합계가 2,048MiB인지 확인한다.
- 확인 범위: 예산 합계·문서 정합성·상대 링크·로그 형식·누락 인덱스·공백을 확인한다. 메모리 할당·계측·게임 실행·실제 내장 그래픽 기기의 성능은 검증하지 않는다.
