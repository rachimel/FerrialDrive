# Ferrial HUD Square 전체 각진 윤곽·가로 확장

- 출처: 현재 대화의 “폰트 전반적으로 각지게 만들고, 납작하게”, 후속 선택 응답 “글자 폭을 넓히기”.
- 사용자 요청·정정·AI 제안의 정확한 개별 시각은 모른다. [[FDLOG_MISSING_TIME:FDLOG-20261105-wide-angular-hud-font:scope]] 보완 시 위 검색 구절과 폭 20%/사선 모서리 안내의 원문 시각을 확인한다. 아래 U1~U2/A1에 공통 적용한다.
- 상태: 별도 폰트 생성·UI 비교 적용·전체 문자/메트릭 검사·SDL dummy 렌더링 확인. 사용자 직접 창 조작·최종 시각 승인·커밋·업로드는 미수행이다.

## 1. 사용자가 제안한 것

- U1: 숫자만 수정한 기존 Ferrial HUD Square에서 폰트 전반을 각지게 만들고 납작한 인상으로 바꾼다. 작업 시간이 걸려도 괜찮다고 설명했다.
  - 이유·의도·근거: 요청한 미술 방향은 전체 글꼴의 각진 형태와 납작한 비례다. 특정 자형별 수작업 방식이나 수치는 지정하지 않았다.
- U2: “납작하게”는 높이를 줄이기보다 **글자 폭을 넓히기**라고 명확히 했다.
  - 이유·의도·근거: AI가 높이 축소/폭 확장/양쪽 조정을 구분해 물었고 사용자가 폭 확장을 선택했다. 실제 처리는 이 후속 응답을 따른다.

## 2. AI가 제안한 것

- A1: 높이·줄 간격은 유지하고 가로만 20% 넓힌 별도 `Ferrial HUD Square Wide`를 첫 비교본으로 만들었다. 기존 원본과 숫자 수정본은 보존한다.
  - 이유·근거: 폭 확장이라는 U2를 반영하고 기존 시안과 바로 비교·복구할 수 있도록 별도 이름·경로를 사용했다. 20%와 모서리 비율 0.35는 구현상 판단이며 사용자 확정 수치가 아니다.
- 둥근 모서리는 직선·짧은 사선으로 처리해 `ㅇ`과 `ㅁ`을 구분하고, 복잡한 곡선은 원래 윤곽을 따라 직선 분할한다. 획/속공간을 우선 보존하는 기호별 보수적 처리도 추가한다.

## 3. 사용자 제안 중 AI가 수용한 것

- U1/U2를 수용해 숫자 외 한글·영문·기호까지 기존 윤곽 전체를 처리했다. 세로 배율은 1, 가로 배율은 첫 비교값 1.20이다. 숫자 0의 사선 제거를 유지한다.
- 현재 Ferrial HUD Square를 쓰던 전투 역할 11개를 Wide 파일에 연결했다. 메뉴 SUITE·탄약 가물치·무기 Paperlogy 등 다른 역할의 선택은 유지한다.

## 4. AI 제안 중 사용자가 수용한 것

- 사용자는 가로 확장 방향을 명시했다. A1의 20%·사선 비율·최종 형태에 대한 시각 승인은 아직 받지 않았다. 구현·검사 통과와 사용자 승인을 구분한다.

## 5. 반영 후 발견한 문제

- I1: 초기 전체 곡선 변환 뒤 128/256px 연결·속공간 비교에서 복잡 기호 17개에 변화가 감지됐다. 원인은 단순 모서리 변환이 복잡한 획 간격을 바꾸는 것이었다. 글자 소실 검사와는 별개의 문제다.
- I2: 원본 PUA 글리프 일부에 면적 0의 점 윤곽이 있었다. 처음에는 이를 소실로 판정해 생성을 중단했다. 원본의 무효 면적 표시를 보존하도록 처리했다.
- 남은 확인: 전용 기호 U+E038과 일부 저해상도 기호는 크기별 픽셀 연결이 달라진다. 원본 자체도 크기에 따라 결과가 변하며 모든 크기의 동일한 시각 품질을 보장하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2를 기준으로 높이를 줄이는 해석을 폐기하고 가로 확장으로 구현했다. I1/I2에 대한 별도 사용자 해결 방식은 제시되지 않았으며 AI가 실제 조치를 수행했다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 문제 기호 17개는 원래 곡선을 더 촘촘히 따라가는 직선 분할로 보정했다. 좁은 획을 위한 소수 좌표를 유지하고 외곽의 새 교차·감기는 방향·매핑/메트릭 보존을 검사했다. 세부 항목과 배율·원본/출력 해시는 새 폰트의 manifest에 남겼다.
- I2: 원본의 면적 0인 윤곽도 그 상태로 보존한다. 글리프 12,614개의 순서/매핑, 전체 윤곽 12,734개, 그 방향과 세로 메트릭을 확인했다. 곡선 명령은 모두 직선 윤곽으로 대체했다.
- 실제 윤곽 3,788개 중 문자에 매핑된 3,787개를 96px로 래스터화해 소실·세로 범위 이상이 없음을 확인했다. 기존 빈 글리프 8,826개는 그대로이며 새 문자를 보충하지 않는다.
- UI 검사 50개 통과. 실제 Pico2D(SDL dummy)에서 제목·작은 레이블·한글·긴 표적명 말줄임·HIT/누적 피해·개별 피해 팝업·일시정지 렌더링을 확인했다. 제목 `전투 HUD` 42px의 측정 폭은 기존 181px에서 Wide 218px로 바뀌었다.
- 로컬 비교 이미지: `output/font-preview/wide-font-comparison.png`, `hud-wide-text.png`, `hud-wide-long-name.png`. 전체 래스터·픽셀 연결 검사는 같은 폴더의 JSON에 기록했다. 원본과 이전 숫자 사본은 덮어쓰지 않았다.
- PRE-PRD·UI 명세·샘플/폰트 안내와 기록 인덱스를 갱신한다. 이전 다른 변경은 보존하며 실제 창 직접 입력과 최종 시각 승인은 확인 전이다. 커밋·업로드는 수행하지 않았다.
