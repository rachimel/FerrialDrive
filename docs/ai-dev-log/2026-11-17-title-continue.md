## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 타이틀의 CONTINUE로 일반 게임은 마지막 세이브부터 재개하고 테스트는 테스트로 복귀한다. 문맥상 재개 기능의 용도를 명시한 요청이다. 출처·시각은 scope를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1·U2를 수용해 테스트는 실행 중 상태를 보존한 복귀로 구현하고, 본편은 마지막 세이브 확인·로더를 주입하는 연결부로 준비했다. 실제 저장 형식·저장 시점·상태 복원 구현은 별도 범위다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 기존 실행 경로에 본편 세이브 기능이 없어 테스트 복귀와 본편 로더 연결부를 우선 구현하는 범위를 제안했다. 사용자 질문에 두 범위를 제시하고 확인했다. 시각은 scope를 따른다.
- **구현상 판단:** CONTINUE를 START 위에 추가하고 START 아래 행·서브 메뉴는 84px씩 내렸다. START 아코디언이 열려도 CONTINUE·START 위치는 고정한다.
- **구현상 판단:** `ContinueSession`은 본편 마지막 세이브 유무 확인과 실제 로더를 함께 받는다. 로더가 복원을 마치고 `True`를 반환해야 화면을 전환한다. 로더 미연결·세이브 없음은 비활성, 실패는 타이틀 유지다. 테스트 경로는 저장 파일을 읽지 않고 기존 상태로 복귀한다.
