# 플레이어 메카 PBR 표면과 가슴 패널

**기록 ID: player-mech-pbr-chest-panels.** 2026-11-09 KST의 이번 대화와 당일 실행 결과를 기록한다. 개별 발언의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:player-mech-pbr-chest-panels:scope]] 현재 대화의 원문 시각으로 보완한다.

## 1. 사용자가 제안한 것

**사용자 제안 1 (U1)**: 기존 1K 텍스처의 표면 품질을 지적하고 디테일 보강 또는 무료 1K 재질 적용을 요청했다. 기존 패널 복원 대신 새 재질과 UV에 맞춘 재생성을 선택했다. 최종 범위는 가슴만 현재 패널/숫자를 유지·확대하고 나머지는 숫자 없이 꺾이는 곳에 약한 돌출 효과를 주는 것이다. 픽셀이 크게 보인다는 관찰도 제시했다. 출처: 이번 대화의 “가슴에만 현재 패널 디테일 냅두고”, “가슴의 패널 텍스쳐 좀 키워”. 범위 선택의 별도 이유는 직접 제시되지 않았다. [[FDLOG_MISSING_REASON:player-mech-pbr-chest-panels:U1]] 해당 발언 전후의 사용자 설명으로 보완한다.

## 2. 사용자 제안 중 AI가 수용한 것

U1을 반영한다. 실루엣·리그·기존 UV/발광을 보존하며 가슴에만 별도의 패널 UV를 추가한다. 원본 모델 반영은 후보 저장·재로딩 검증 후 수행한다.

## 3. AI가 제안한 것

**AI 제안 1 (A1)**: 무료 외부 PBR 재질을 도장/노출 금속으로 구분하고 기존 표면에 적용한다. 라이선스를 확인할 수 있는 ambientCG Metal028·Metal032를 선택했다. PaintedMetal010은 녹이 과해 제외했다. 구현상 판단: 1K를 유지하면서 전면 UV 면적을 늘려 가슴 패널의 실제 텍셀 수를 확보한다. 출처: 이번 대화의 “전용 UV에서 차지하는 면적도 늘릴게” 및 로컬 재질 출처 기록.

## 4. AI가 제안한 것 중 사용자가 수용한 것

사용자는 새 재질/UV 기준 패널 재생성 방향을 직접 제시했다. 최종 외관에 대한 별도 수용은 아직 받지 않았다. 구현 완료를 외관 승인으로 취급하지 않는다.

## 5. 반영 후 발견한 문제

**문제 1 (I1)**: 첫 후보에서 새 재질로 표면 입력을 대체해 패널 디테일이 사라졌다. 사용자가 지적했다. 원본 모델 반영 전의 후보 문제다. 이후 전신 패널 후보를 검토한 사용자가 가슴만 남기도록 범위를 수정했다.

## 6. 사용자 해결 제안과 실제 해결 과정

I1에 대해 사용자는 기존 패널 복원 대신 새 재질/UV에 맞춘 재생성을 제안했다. 이후 가슴만 패널/숫자 유지, 나머지 모서리 효과, 가슴 패널 확대를 요청했다. 해당 지시를 최종 후보에 적용했다.

## 7. AI 해결 제안과 실제 해결 과정

공통 `apply_pbr_surface`, `generate_panel_detail`, `project_panel_uv` 연산과 독립 기본 도형 샘플을 추가했다. 외부 PBR 6개 맵과 새 가슴 패널 색/높이 2개를 적용했다. 가슴 전면은 1K 전용 UV의 넓은 영역을 사용하며 기존 UV_Paint는 유지한다. 나머지 부위는 새 패널/숫자 도안 없이 얕은 모서리 돌출 음영을 사용한다.

후보의 정면·사선·후면을 1024px/240px로 렌더해 확인했다. 기본 도형 샘플은 전용 UV 추가 시 기존 UV/활성 렌더 UV 보존, 발광 연결, 반복 적용, 저장·재로딩을 통과했다. 기존 제작 회귀 검사 15개, 가슴 UV 범위/면적 검사, 이미지/패킹 검사도 통과했다. 원본 반영 후 124개 이미지의 내용/상대 경로, 형상·기존 UV·리그·재질 슬롯·발광 입력/드라이버 보존을 확인했다. 모델과 텍스처는 Git 제외 대상이다.

형상/간섭을 수정하지 않았으며 전체 전투 모션·게임 실행/성능은 이번 검사 대상이 아니다. 렌더 검토와 사용자의 최종 외관 승인은 구분한다. 로컬 모델의 릴리스 정보·레지스트리·제작 기준 해시를 동기화했다. 재질 출처/체크섬은 로컬 `material_sources.json`, 실행 근거와 수정 전 복구 사본은 `output/player_mech_surface_rework/`에 있다.
