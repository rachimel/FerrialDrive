# 플레이어 화면 이탈 기준 록온 해제

- **기록 ID:** `FDLOG-20261117-lock-player-visibility`
- 원문 범위: 2026-11-17 현재 세션. 개별 발언·검증의 정확한 시각은 미제공이다. [[FDLOG_MISSING_TIME:FDLOG-20261117-lock-player-visibility:scope]] 검색 단서: `록온 소멸 거리는 없애고`, `플레이어 기체` 선택 응답.
- 상태: 구현·현행 명세·관련 자동 검사·실제 에셋 Combat 짧은 실행 완료. 직접 조작 사용감·최종 사용자 승인·커밋·업로드는 미수행.
- 후속 현재 기준: [화면 내 주변 적 획득·경계 반복 수정](2026-11-17-lock-visible-acquisition.md). 아래 200m·300m 획득과 중간점 기반 재허용은 이 작업 당시의 구현이며 후속 요청으로 교체했다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 거리 기준 소멸을 없애고 록온 중 플레이어가 완전히 보이지 않으면 해제한다. 가시성 기반으로 해제 기준을 바꾸는 요청이다. 추가 수치나 별도 이유는 제시하지 않았다. 출처·시각은 scope를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1을 이동·Combat 공통 `MovementHud` 경로에 연결했다. 획득 200m·조준 300m·후보 교체 1초는 유지한다. 기존 일반 UI 시연의 거리 유지 기본 동작은 보존했다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1):** 화면 이탈 대상이 플레이어인지 적인지 선택 질문으로 확인했다. 출처는 현재 세션 `해제 기준` 질문이다.
- **구현상 판단:** 기체 표시 사각형과 화면의 교차를 사용한다. 줌·현재 카메라 위치를 반영하고 피격 흔들림·그림자·잔상·VFX는 제외한다. 일부가 보이면 유지한다. 알파 픽셀별 검사·장애물 시야 검사는 추가하지 않았다.
- **구현상 판단:** 화면 이탈로 해제한 표적은 두 기체 중간점 카메라에서 플레이어가 보일 수 있을 때까지 재획득을 보류한다. 같은 먼 적의 획득·해제 반복을 막기 위한 선택이다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 사용자는 A1에 `플레이어 기체`를 선택했다. 사각형·흔들림 제외·반복 방지의 세부 구현과 최종 사용감은 별도 사용자 수용 전이다.

## 5. 반영 후 발견한 문제

- **I1:** 시작 중 HUD 연결 시점에는 재생기가 아직 없어 새 표시 영역 조회가 실패했다. 실제 Combat 실행에서 확인했다.
- **I2:** 기존 아틀라스 선적재 검사 자료에 클립 메타데이터가 없어 새 CPU 표시 영역 준비 경로가 실패했다. 자동 검사에서 확인했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1과 선택 응답에 따라 거리 해제 설정을 제거하고 플레이어 화면 이탈로 교체했다. I1·I2의 별도 사용자 해결 제안은 이 작업에서 요청하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- `MouseAutoTargeting.retain_outside_range=True`로 기존 표적의 거리 제한을 해제한다. 이동 HUD는 플레이어가 완전히 화면 밖이면 후보를 비우고 해제 표적을 기록한다. 초기화 시 이력을 비운다.
- `PicoPoseTable`이 이미 읽는 클립 메타데이터에서 논리 크기·피봇·배율만 보관한다. 가시성 검사로 GPU 적재를 유발하지 않는다. 기존 전신 경로는 프레임 범위, 도형 시연은 기체 영역을 사용한다.
- I1은 재생기 준비 전 기본 영역을 사용하도록 수정했다. I2는 검사 자료에 최소 클립 메타데이터를 추가하고 표시 영역 수치도 검증했다.
- 관련 검사 **34개 통과·선택적 GPU 1개 건너뜀**. 거리 제한 제거·부분 노출 유지·완전 이탈 해제·줌·흔들림 제외·반복 재획득 방지·기존 표적 선택·아틀라스 선적재 보존을 확인했다.
- 수정 후 실제 low Combat·SMG 자동 입력에서 준비 5·측정 30프레임 정상 종료했다. 근거는 `output/performance/lock_visibility_20261117/combat_fixed/report.json`이다. 짧은 실행이며 FPS 목표 충족이나 직접 조작 검수의 증거로 사용하지 않는다.
