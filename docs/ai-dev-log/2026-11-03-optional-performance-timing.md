# 게임·테스트 공통 성능 계측

- 작성일: 2026-11-03, 한국 시간
- 사용자 결정: 게임·유닛 테스트에서 재사용하고 필요할 때 AI가 병목 분석용 로그를 수집할 모듈로 둔다. 평소에는 비활성으로 사용한다.
- `ferrial_drive.diagnostics.TimingRecorder`를 추가했다. 함수 래퍼·구간 컨텍스트로 호출 수·실패 수·누적/평균/최소/최대 경과 시간을 집계한다. 반환값과 예외를 유지하고 매 호출 출력·파일 쓰기는 하지 않는다. 비활성 함수 래퍼는 원함수를 반환하며 구간 타이머·벤치마크·파일 저장도 동작하지 않는다.
- 반복 벤치마크는 prepare→예열→회차별 반복 순서다. 예열·준비는 제외하고 반복 수·원시 회차 시간·함수당 요약을 저장한다. timeit의 GC 정책을 결과에 명시한다.
- JSON에는 시계 구현·해상도·UTC 시각·Python 버전·포함 경과 시간 의미·GPU 미측정을 기록한다. 중첩 포함 시간을 합해 프레임 시간으로 해석하지 않는다. 집계·스냅샷은 잠금으로 보호하고 임시 파일 교체로 저장한다.
- UI 직접 실행에 `--profile [경로]`를 연결했다. 주요 입력/갱신/그리기·효과·렌더러 호출과 present·프레임 대기를 구분한다. 기본 실행·Runner 드롭은 비활성이며 정상 종료에 저장한다. 강제 종료·재드롭 저장은 보장하지 않는다.
- 게임·Pico2D 없이 실행할 정수 데이터 예제와 모듈 계약 검사 파일을 준비했다. 동기 함수만 자동 래핑하고 비동기·제너레이터의 오측정을 차단한다. 실제 게임 UI·설정값·렌더링 방식은 바꾸지 않았다.
- 소스·문서·연결부를 읽어 대조했다. 자동 검사·예제 실행·UI 실행·실제 성능 측정은 수행하지 않았다. 실제 로그 수집·정확성·계측 오버헤드는 실행 환경에서 확인할 항목이다. 이번 관련 변경만 커밋하고 기존 폰트 삭제는 별도로 남긴다.
