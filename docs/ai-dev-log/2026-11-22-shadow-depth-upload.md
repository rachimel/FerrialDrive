## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 2026-11-22 KST 대화에서 요청을 수용했다. 같은 600기 시나리오에서 각 GL 작업의 CPU 호출 경과와 GPU 타임스탬프를 기록했다. 성능 비교와 전체 화면 픽셀 검사는 별도로 실행했다.

## 3. AI가 제안한 것

- **A1** 2026-11-22 KST 대화에서 기존 패스의 같은 정점 버퍼 위치에 반복해서 쓰는 경로를 후보로 지목했다. 묶음 업로드, 오프셋을 늘리는 버퍼, 직접 매핑을 각각 시험해 어떤 변경에서 지연이 줄어드는지 비교했다.

- **A1** 구간 분해·조건부 수정·픽셀 및 P99 확인은 사용자 요청이다. 직접 매핑과 저장소 교체 방식은 실험 결과를 바탕으로 선택한 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 기존 타일 기록은 `glBufferSubData`로 정점 버퍼 오프셋 0을 덮은 뒤 드로우하는 순서를 타일마다 반복했다. 240개 프레임의 세부 계측에서 프레임 130의 GPU 깊이 쓰기 36.441ms 중 업로드 구간은 36.414ms, 클리어는 0.0036ms, 드로우는 0.0112ms였다. CPU의 업로드 호출 경과 합계는 0.0287ms였다. GPU 타임스탬프 구간에는 드라이버·큐 대기 등이 포함될 수 있다. [Khronos 타임스탬프 정의](https://registry.khronos.org/OpenGL-Refpages/gl4/html/glQueryCounter.xhtml)

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1 / I1** 기존 GPU 클리어·업로드·드로우의 P99는 각각 0.0231ms·31.1867ms·0.0635ms였다. 각 작업의 CPU 호출 경과 P99는 0.0901ms·0.2370ms·0.1292ms였다. 타일별 마커의 영향을 줄이기 위해 최종 A/B는 패스 단위로 계측했다.
- **U1** 변경 전→후→후→전 순으로 60프레임 예열 후 360프레임씩 재생했다. 네 실행 중 타일 수가 한두 개씩 달라진 5개 프레임 ID는 표에서 제외했다. 같은 인덱스·같은 타일 수로 각 버전 710개 샘플을 비교했다.

- **U1** 깊이 쓰기 GPU 구간이 1ms를 넘긴 횟수는 31회에서 0회로 줄었다. 전체 CPU 프레임 P99 변화는 교대 회차마다 방향이 달랐다. 두 변경 실행에서 전체 GPU 최대는 프레임 351에 잡혔고, 그때 타일 깊이 쓰기는 0.033ms였다.
- **U1** 600기 장면 전체 FHD RGBA 화면 44쌍에서 바뀐 픽셀은 0개, 최대 채널 차이는 0이다. 프레임 갱신을 고정하고 경로별 독립 깊이 타일 캐시를 같은 순서로 채웠다. 기존 지연 프레임을 포함해 비교한 화면에서 깊이 타일 총 2,177개와 근거리 그림자 인스턴스 3,969개를 경로별로 제출했다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1 / I1** 타일마다 저장소를 교체하거나 정점을 모아 `glBufferData`에 바이트를 넘기는 후보에서도 두 자릿수 ms 꼬리가 남았다. 같은 8MiB 저장소 안에서 서로 다른 범위를 쓰는 비교에서 `glBufferSubData`의 깊이 쓰기 P99는 41.016ms였고, 직접 매핑은 0.038ms였다. 이 실험은 업로드 경로까지 지연을 좁혔다. GPU 드라이버 내부에서 긴 대기를 만든 세부 기전은 확인하지 못했다.
- **A1 / I1** 근거리 타일 묶음마다 필요한 크기의 새 버퍼 저장소를 잡고 쓰기 매핑 한 번으로 정점을 기록한다. 타일별 드로우는 기존 인덱스와 각 포즈의 정점 시작점을 사용한다. 타일 클리어·드로우 순서, 바닥 합성, 패스 시작 상태 조회와 복구는 기존 경로를 유지한다. 추가 GL 함수는 기능 가드에 등록했다.
- **A1** 변경 후 세부 재계측의 같은 프레임 130에서 12타일의 업로드 구간은 0.0042ms였다. GPU 깊이 쓰기 전체는 0.0231ms였다.
- **A1** 실제 GPU 검사 4개를 통과했다. 매핑 호출 수와 포즈별 정점 오프셋, GL 상태 조회와 실패 시 복구, 타일 퇴출, 인스턴스 제출 제한을 확인했다.
- **A1** 기본 자동 검사 1,179개 중 1,090개를 통과했고 89개는 실행 조건에 따라 건너뛰었다.
