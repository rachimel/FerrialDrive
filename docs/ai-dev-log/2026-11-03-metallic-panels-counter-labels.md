- 시안 값: HIT 숫자 76→92px, 레이블 16px 유지, 숫자 아래 간격 4px, 글자 사이 추가 간격 2px. DAMAGE 숫자는 60px를 유지한다. 수치·레이블을 각각 오른쪽 정렬하고 두 카운터 묶음 사이 8px 여백의 중심은 화면 중앙 높이를 유지한다.

- 패널은 기존 Bezel 근사색·알파를 바탕으로 정적인 반사 명암 띠와 가로 브러시 결을 더한다. 실제 조명·환경 반사 셰이더나 Pantone 재질의 정확한 재현은 아니다.
- `panel_style.metallic`에서 사용 여부·명암 강도 0.22·결 강도 0.012를 조절한다. 없거나 비활성이면 단색을 사용한다. 128×256 텍스처를 색·강도별로 최대 8개 저장하고 위치·크기·알파 변화에는 재생성하지 않는다. 매 프레임 픽셀을 계산하지 않으며 패널마다 한 번 복사한다. 종료·교체 시 텍스처를 해제한다.
- 선택 계측에 `renderer.metallic_rect`를 연결했다. 최초 생성 비용도 포함하며 측정 결과를 수집한 것은 아니다.
