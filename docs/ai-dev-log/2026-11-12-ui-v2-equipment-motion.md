# UI v2 로드아웃 전환·동일 크기 사다리꼴 무기 카드

- **기록 ID:** `FDLOG-20261112-ui-v2-equipment-motion`

- 대화 범위: 2026-11-12 KST. 개별 제안·수용 시각 미확인 [[FDLOG_MISSING_TIME:FDLOG-20261112-ui-v2-equipment-motion:scope]] — 현재 대화에서 “로드아웃 01, 02 패널은 제외”, “제안을 채택”, “사다리꼴”, “위아래 두 행을 유지” 검색.
- 근거: 사용자 요청·제안 수용·형태 정정·배치 선택, 공통 시간 모듈·v2 뷰·독립 실행부와 실제 OpenGL 렌더.

## 1. 사용자가 제안한 것

- **U1:** v1 로드아웃 전환 애니메이션을 가져오되 01·02 패널은 제외하고 시험한다. AI는 번호 패널의 위치·표시 투명도를 고정하는 뜻으로 설명하고 반영했다.
- **U2:** 무기 교체 방식에 대한 AI 제안을 채택했다. 사용자 근거는 “현재 UI에서는 적합할 거 같음”이다.
- **U3:** 이후 같은 크기의 사다리꼴 카드로 정정했다. 활성 카드는 앞으로, 비활성 카드는 뒤로·화면 오른쪽에 가깝게 표현하고, 모양이 맞지 않으면 복원할 수 있게 한다. 배치 질문에서 “위아래 두 행을 유지하고 비활성 카드만 오른쪽으로 이동”을 선택했다.
- **U4:** 사다리꼴은 오른쪽 변이 수직인 형태라고 정정했다. 최종 시안은 오른쪽 수직·왼쪽 사선이다.
- 시각·출처는 위 대화 범위를 따른다. U1·U3의 추가 배경은 제시되지 않았다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1의 로드아웃 퇴장/등장·잔상은 공통 `LoadoutSlide`를 재사용했다. 번호 패널은 항상 별도로 그려 이동·페이드·잔상 대상에서 제외한다.
- U3의 동일 크기·사다리꼴·두 행 고정·위치/밝기 깊이 표현과 복원 가능성을 최종 구현 기준으로 삼았다.

## 3. AI가 제안한 것

- **A1:** 처음에는 위치를 고정한 채 크기·밝기를 0.2초 동안 전환하도록 제안했다. 현재 행 구성을 유지하면서 선택 변화를 읽기 쉽다는 판단이었다.
- **구현상 판단 A2:** U3에 맞춰 같은 배율, 좌우 차이 22 논리 px·불투명도 0.5↔1을 사용했다. 처음 대칭 사다리꼴로 만들었다가 U4에 따라 오른쪽 수직·왼쪽 사선으로 수정했다. 크기 변화는 최종 시안에서 제외했다. `weapon_card_shape=slanted`로 이전 사선·비활성 축소 형태를 복원한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1은 U2에서 명시 채택했지만, 크기 변화는 이후 U3의 동일 크기 요구로 대체했다. 최종 배치·형태는 U3와 배치 선택을 따른다. A2의 구체적 시안과 외관에 대한 최종 사용자 응답은 아직 없다.

## 5. 반영 후 발견한 문제

- 동일 크기 시안의 활성 카드가 왼쪽으로 확장되므로 기존 로드아웃 퇴장 거리 계산만으로는 카드의 왼쪽 끝을 충분히 포함하지 못했다. AI가 렌더/경로 검토 중 발견하고 전후 이동 거리 22px까지 퇴장 범위에 포함했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1: F로 0.5초 퇴장→세트 교체→등장을 수행한다. 01·02 위치와 투명도는 고정하며 논리 선택 강조는 즉시 바꾼다. 카드·무기 그림·구분·잔탄만 이동한다.
- U3: E로 0.2초 동안 같은 크기의 두 행에서 가로 위치·밝기를 전환한다. 근접 위·원거리 아래를 유지하며 활성 카드는 왼쪽, 비활성 카드는 기존 오른쪽 여백 안에 둔다. 설정·현행 명세·샘플 안내를 동기화했다.

## 7. AI 해결 제안과 실제 해결 과정

- 공통 `LoadoutSlide`·`WeaponSwap`을 실행부에서 갱신하고 표시값만 뷰에 전달한다. 뷰는 시간·선택 규칙을 소유하지 않는다. 일시정지·F5 초기화·최신 목표만 남기는 연속 입력을 확인했다.
- v2 자동 검사 78개, 기존 로드아웃 검사 13개 통과. 카드 교체 시점·번호 패널 고정·중간 밝기/위치·동일 크기·행 유지·기존 형태 복원·정지/초기화를 검사했다.
- 최종 시안으로 실제 OpenGL 가속 렌더 44프레임(로드아웃 31·무기 교체 13)을 생성하고 중간 프레임 모음과 기존/시안 비교를 직접 열었다. `output/ui_unit_test_v2/equipment_motion/`의 `loadout.gif`·`swap.gif`·`shape_comparison.png`는 재생성 가능한 결과다. 기본 도형을 사용하며 로컬 게임 에셋은 필수 입력이 아니다.
