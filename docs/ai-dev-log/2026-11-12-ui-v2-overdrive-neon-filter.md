# UI v2 OVERDRIVE 폭 75%·네온 강화와 본문 필터

- **기록 ID:** `FDLOG-20261112-ui-v2-overdrive-neon-filter`
- 기록 작성 시각: 2026-11-12 00:06:41 KST.
- 대화 범위: 2026-11-12 KST. 개별 요청 시각 미확인 [[FDLOG_MISSING_TIME:FDLOG-20261112-ui-v2-overdrive-neon-filter:scope]] — 현재 대화에서 “60%”, “깨지는 효과”, “75%로 해보자” 검색.
- 근거: 사용자 첨부 이미지·연속 요청·UI v2 렌더러와 자동 검사.
- 상태: 반영·자동 검사·화면 없는 실제 렌더 확인. 실제 GPU 창·최종 외관 수용 미확인.

## 1. 사용자가 제안한 것

- **사용자 제안 U1:** 문구 폭 60%, 첨부 화면의 깨짐 현상 확인, 네온 강화를 요청했다. 더 강한 발광과 깨짐 개선이 명시 목표이며 추가 배경은 제시되지 않았다.
- **사용자 제안 U2:** 작업 중 폭을 75%로 정정했다. 최종 구현 기준은 U2다. 시각·출처는 위 대화 범위를 따른다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1의 네온 강화·깨짐 점검과 U2의 최종 폭 75%를 반영했다. 중앙 정렬과 기존 호흡은 유지한다.

## 3. AI가 제안한 것

- **구현상 판단 A1:** 네온 본문은 3배 해상도에서 생성한 뒤 선형 축소하고, 번짐과 같은 소수점 좌표를 사용한다. 기존 본문의 정수 좌표 반올림·낮은 해상도와 광의 소수점 좌표 차이가 축소 표시의 불균일을 키울 수 있다고 판단했다. 사용자 GPU의 단일 확정 원인으로 단정하지 않는다.
- **구현상 판단 A2:** OVERDRIVE의 광 반경 6px는 유지하고 광 세기를 0.85→1, 겹침을 1→2회로 바꾼다. 공통 네온 본문의 필터 개선은 무장 문구에도 적용되며 강화 수치는 OVERDRIVE 전용이다. 작업 중 설명했다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- U2는 폭 비율 정정이며, A1·A2의 최종 외관 승인으로 확대하지 않는다. 수정 화면에 대한 최종 응답은 아직 없다.

## 5. 반영 후 발견한 문제

- 추가 검사에 필요한 `c_int` import가 처음 누락돼 검사 1개가 오류를 냈다. AI가 누락을 고친 뒤 74개 전부 통과했다. 제품 코드의 실패와 구분한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 60% 시험 후 U2에 따라 `overdrive_width_ratio=0.75`로 변경했다. 뷰는 실제 글자 폭을 바탕으로 자간을 계산하며, 샘플의 바 372px에서 문구 279px와 중앙 540.5px를 확인했다.

## 7. AI 해결 제안과 실제 해결 과정

- A1: 네온 본문은 캐시한 3배 텍스처를 소수점 사각형으로 그린다. 원래 글꼴 크기를 복원하며 생성 실패 때도 복원한다. 실제 텍스처 해상도·선형 필터·캐시 재사용·실패 후 글꼴 복원·해제를 검사했다.
- A2: 같은 문구·좌표·검정 배경에서 광만 비교한 RGB 합은 기존 대비 약 2.17배였다. 이를 사람의 체감 밝기 배수로 해석하지 않는다. 9개 글자에 18회 광을 그리며 한 주기 5개 시점의 광 알파는 1/0.825/0.65/0.825/1이었다.
- UI v2 자동 검사 74개 통과 후 비율만 75%로 정정했고 실제 렌더러에서 문구 폭·중앙을 다시 검사했다. `output/ui_unit_test_v2/overdrive_75_neon/detail.png`를 직접 열어 획·간격·광을 확인했다. 이전/수정 비교 렌더는 `output/ui_unit_test_v2/overdrive_60_neon/comparison.png`에 보존한다.

## 확인 상태

- 코드·설정·현재 문서·자동 검사와 화면 없는 실제 렌더 확인 완료. 사용자 첨부 화면과 같은 GPU 환경의 재현·직접 창 조작·최종 외관 승인은 미확인이다. 커밋·업로드 상태는 Git 기록을 따른다.
