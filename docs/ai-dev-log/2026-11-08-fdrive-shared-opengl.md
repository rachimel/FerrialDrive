# FDrive 공통 OpenGL 표시 기반

- 기록 ID: **FDLOG-20261108-fdrive-shared-opengl**
- 검증·정리 기준: **2026-11-08 23:20:27 KST 이후**. 현재 도구 확인 시각이며 원래 발언 시각과 구분한다.
- 출처: 현재 대화 “지금 뚫은 OpenGL렌더러는 정리해서 메인 게임에서도 사용하도록 하자”.
- 개별 발언·구현의 정확한 시각은 미확인이다. [[FDLOG_MISSING_TIME:FDLOG-20261108-fdrive-shared-opengl:scope]] 위 구절의 원문에서 확인한다. 아래 항목에 공통 적용한다.
- 상태: **공통 실행부·캔버스·Bicubic 모듈 분리와 기존 호출 호환 구현, 관련 자동 92개 통과, 도형/에셋 도구 실제 OpenGL 실행 확인**.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** 에셋 도구에서 연결한 OpenGL 렌더러를 정리해 메인 게임에서도 사용한다.
  - 이유·근거: 도구에서 확인한 표시 기능을 본편에도 재사용하기 위한 직접 요청이다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1: OpenGL 초기화와 Bicubic을 공통 렌더링 영역으로 옮기고 본편·독립 테스트·도구가 같은 실행부를 사용하도록 연결한다.

## 3. AI가 제안한 것

- **AI 제안 1 (A1), 구현 판단:** `runtime.run_application()`과 `rendering.PicoCanvas`로 실행 루프와 캔버스 수명을 분리한다. Bicubic 구현도 `rendering`에 모은다.
  - 이유·근거: 기존 실행 루프는 UI 미리보기 모듈에 있고 OpenGL 요청은 각 프로그램의 속성에 반복돼 있었다. 본편이 UI 도구나 테스트를 거치지 않고 연결할 공통 진입점이 필요하다.
- **AI 제안 2 (A2), 구현 판단:** 이전 실행/셰이더 import는 어댑터로 유지하고 공개 도형만 쓰는 독립 렌더링 테스트를 제공한다.
  - 이유·근거: 기존 UI 실행부·호출자를 깨뜨리지 않고 같은 구현의 합성과 필터를 확인한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 공통화와 본편 재사용은 사용자 직접 지시다. 모듈명·어댑터·도형 배치 예시·세부 API에 대한 별도 승인은 받은 것으로 기록하지 않는다.

## 5. 반영 후 발견한 문제

- **발견한 문제 1 (I1), 기존 구현 제약:** 현재 저장소에는 본편 게임 진입점이 없었다. 렌더러 공통화와 본편 장면/규칙 통합을 구분해야 한다.
- **발견한 문제 2 (I2), 자원 수명 위험 처리:** 렌더러보다 늦게 GPU 자원을 해제하거나 예외로 캔버스를 남기면 종료/재실행이 불안정해질 수 있다. Pico2D 원본은 종료 후 전역 포인터도 유지한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1에서 본편과 같은 렌더러를 사용하도록 방향을 지정했다. 구체적인 모듈 배치와 자원 정리 방식은 지정하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

- I1: 본편 장면을 임의로 만들지 않고 공통 진입점·프로그램 생명주기 규약·연결 문서를 제공했다. 에셋 로더와 Asset Load Test는 직접 공통 실행부를 호출하고 기존 UI 호출은 어댑터로 연결했다.
- I2: 프로그램 `exit()`에서 자원을 먼저 정리하고 캔버스를 닫는다. 초기화 실패·진입 실패·그리기 실패·종료 입력·프레임 제한에서 정리와 재실행을 검사했다. 캔버스 종료 후 전역 포인터를 비우고 드라이버 요청 힌트는 초기화 후 복원한다.
- 공통 실행부/캔버스 검사 **8개**, 기존 에셋 검사 **84개** 통과. 에셋 검사 중 실제 GPU 6개도 새 공통 캔버스를 통해 실행했다. import 시 Pico2D/도구/테스트 로딩 부작용이 없는 것도 확인했다.
- 공개 도형 15개와 SDL 글자/선을 합성하는 `tests/rendering_test.py`를 제공했다. 도형 테스트와 에셋 툴을 숨긴 실제 Windows OpenGL 창에서 각각 2프레임 실행하고 Bicubic·화면 합성·종료를 확인했다. 출력은 로컬 `output/rendering_review/`에 보관한다.
- 기존 UI는 SDL dummy에서 2프레임 실행을 확인했다. 본편 장면 관리·게임 규칙·Iris 기기의 수백 기/이펙트 동시 60FPS는 이번 검증 범위가 아니다.
