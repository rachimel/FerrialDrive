## 3. AI가 제안한 것

- **AI 제안 1 (A1), 구현상 판단:** 명중·폭발의 SDL 정점 배열과 하위 구조체 뷰를 재사용하고, 원형 16/24점의 삼각함수 표본을 공유한다. 카메라의 배율·평행이동을 한 번 평가해 각 정점에 적용한다. 효과 수·수명·색·정점 수·순서와 게임 판정은 유지한다.
- 이유·근거: 변경 전 8개 명중+폭발의 CPU 정점 준비가 평균 19.527ms였다. cProfile에서 정점별 카메라 변환과 SDL 구조체 생성·복사가 다수 호출됐다. 해당 결과를 현재 세션 진행 보고로 설명했다. 개별 보고 시각은 scope 누락 항목을 따른다.

## 5. 반영 후 발견한 문제

- **I1, 기존 비용:** 관통 후 명중과 폭발 수가 늘면 `PicoGunEffects.draw_contacts`의 정점 생성 비용이 증가한다. 실제 전투에서 관통 전후 체감 지연을 같은 조건으로 비교한 기록은 없으므로 관통이 전체 렉의 유일한 원인이라고 확정하지 않는다.
- **I2, 잔여 비용:** 최적화 후 도형 전투의 평균 처리 시간은 20.184ms로 60FPS 예산 16.667ms를 초과했다. 넓은 구간 계측에서 HUD 평균 8.508ms·월드 6.755ms·갱신 4.427ms다. 자동 측정의 계측·드라이버·운영체제 대기를 포함한다.
- 발견자: AI. 현재 세션 측정 결과이며 최적화로 생긴 회귀를 뜻하지 않는다.
