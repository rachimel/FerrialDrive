# 왼손 엄지 굽힘 방향 수정

- 기록 ID: `left-thumb-curl`
- 출처: 2026-11-10 현재 대화의 “왼손 주먹 쥘 때 엄지가 반대로 말려”, “이것만 고쳐줘”. 개별 발언의 정확한 시각은 확인하지 않았다.

## 1. 사용자가 제안한 것

U1: 주먹 쥐기에서 반대로 말리는 왼손 엄지만 수정한다. 다른 작업으로 확장하지 않는다.

## 2. 사용자 제안 중 AI가 수용한 것

왼손 엄지의 굽힘 축 부호만 보정했다. 다른 손가락·오른손·모델 원본은 유지했다.

## 3. AI가 제안한 것

A1: 기존 엄지 기준축을 왼손에서만 반전하고 주먹·증분 굽힘의 같은 경로에 적용한다. 실제 손바닥 방향 검사로 확인한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

U1의 직접 수정 요청 범위에서 적용했다. 추가 포즈나 모델 변경의 승인으로 해석하지 않는다.

## 5. 반영 후 발견한 문제

기존 손가락 검사는 네 손가락만 포함해서 엄지의 반대 굽힘을 놓쳤다. 왼손 엄지 검사와 반복 적용·저장 복구 검사에 엄지를 추가했다.

## 6. 사용자 해결 제안과 실제 해결 과정

사용자가 왼손 엄지의 역방향 굽힘을 특정했다. 사용자에게 수동 리깅이나 원본 수정을 요구하지 않았다.

## 7. AI 해결 제안과 실제 해결 과정

`PartEditing.finger_axis()`의 왼손 엄지 분기만 수정했다. 실제 기본 모델에서 주먹·증분 굽힘·반복 적용·저장 재로딩 검사를 통과했다. 손바닥·측면 렌더로 손바닥 쪽 굽힘을 확인했다. 이전 결과와 비교해 왼손 엄지 세 본만 달라지고 다른 손가락과 오른손의 포즈 행렬은 유지됨을 확인했다. 모델 원본은 보존했다. 검토 근거는 로컬 `output/pose_thumb_fix_20261110/`이다. 실제 GUI 조작 검증은 별도다.

기존에 열린 편집기에는 새 코드가 자동 반영되지 않는다. 실행기로 작업본을 다시 열고 주먹을 다시 적용한다.
