- **U3**: 애니메이션 후보정은 직접 수행하므로 방법만 안내하되 현재 작업은 계속.
- **U4**: 중간과정 애니메이션 후보 정리. 개별 시각은 위 scope 누락 항목에 포함하며 ‘중간과정 애니메이션 후보들 정리’로 보완한다.
- **U5**: 애니메이션 작업 지연 때문에 테셀레이션을 끈 간단한 포즈 요청, 모델 최적화 가능 여부 질문. 개별 시각은 위 scope 누락 항목에 포함한다.
- **U6**: 보관하지 말고 중간 산출물을 영구 삭제하며 v3와 수동 편집 모델만 유지하도록 정정. 개별 시각은 위 scope 누락 항목에 포함한다.
- **U7**: 사양을 MD로 정리하고 기본 포즈 제작. 4타 회수도 유효타이며 1타는 대기에서 시작, 4타는 같은 대기로 끝나야 한다. 사용자가 기존 pose_work 경로에 최신 칼집 각도/자세를 저장했다고 확인했다. 개별 시각은 위 scope 누락 항목에 포함한다.
- **U8**: Astra 리깅 수정 검토에 앞서 팔 들기·무릎 굽히기·골반 낮추기 영상 출력 요청. 개별 시각은 위 scope 누락 항목에 포함한다.
- **U9**: 골반 하강 돌출이 내부 조인트 장갑 리깅 문제인지 진단하고 검 발도·들기·대기까지 영상 출력 요청. 개별 시각은 위 scope 누락 항목에 포함한다.

## 3. 사용자 제안 중 AI가 수용한 것

- U4 반영. 현재 v3만 모델·편집 설정·검토 출력 폴더에 남기고 이전 후보는 삭제 없이 보관했다.
- U5 반영. 기본 서기 작업본을 별도 저장했다. 오브젝트 병합/메시 감축은 가능성을 설명했으며 실행하지 않았다.
- U6 반영. 이전 애니메이션 보관본과 진단·임시 실행 산출물을 영구 삭제했다.
- U7 반영. `basic_weapon_animations.md`에 최신 사양을 기록하고, 최신 사용자 파일을 변경하지 않은 별도 기본 포즈 묶음을 만들었다.

## 5. 반영 후 발견한 문제

- **I1**: 기존 WristSwivel의 고정 회전과 독립 손 목표가 과도한 손목 굽힘을 만들었다. 검 대기 표본은 팔꿈치 재계산만으로 약 154도에서 50도로 감소했다.
- **I2**: 발도/수납은 단순 손목 보정으로 해결되지 않는다. 검→총 469~475, 총→검 495~501 및 503 프레임의 왼손 굽힘이 남았다. 인출 길이와 연속 간섭도 승인하지 않았다.
- **I3**: 장시간 저장·재검사 호출은 전송 시간 제한에 걸렸지만 작업은 완료됐다. 재실행하지 않고 같은 인스턴스의 상태와 생성 메타데이터로 완료를 확인했다.
- **I4**: AI가 4타→다음 1타 준비로 직접 연결한다고 잘못 해석했다. 사용자 정정에 따라 시작·끝을 동일한 검 대기로 수정했다.
- **I5**: 돌출은 고관절 장갑이 아니라 `Skirt_Segmented_Shell_v076`의 493정점 중 본 가중치가 없는 125정점에서 발생했다. 골반 하강 전후 이 정점들의 월드 변위가 0이다. 색상 강조로 사진의 삼각형 돌출 부위와 일치함을 확인했다. 비교한 원래 스커트와 고관절 장갑은 가중치 누락이 없고 하강을 따라간다.
- **I6**: 고정된 현재 칼집에서 칼날 길이 1.3을 완전히 인출하는 목표는 이 진단 경로에서 팔 도달 범위를 벗어난다. 몸통을 크게 숙인 초안도 최대 손 목표 오차 0.0794장면 단위, 손목 굽힘 약 75도다. 완전 인출·연속 간섭 검증 완료로 취급하지 않는다.
