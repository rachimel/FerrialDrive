# UI Unit Test 구현 시작

- 작성일: 2026-11-03, 한국 시간
- 요청: 확정한 UI Unit Test 범위를 구현한다.

## 사용자 결정과 확인 대기

- 첫 실행 해상도는 **1280×720**으로 확정했다.
- HP 현재/최대·타겟 없음·최근 데미지·고정 방향 레이더·중앙 크로스헤어·샘플 변경 버튼으로 구성하는 제안은 확인 대기다.
- 전환 중 입력을 소비할지, Esc 재입력으로 방향을 반전할지는 확인 대기다. 대기 시간을 동의로 간주하지 않는다.

## 구현한 부분

- `ferrial_drive/animation.py`: UI에 의존하지 않는 SmoothStep 수치 애니메이션. 시간 단위는 초다.
- `ferrial_drive/ui/components.py`: 사각형·버튼·클릭 포획과 입력 소비 결과. 표시와 판정에 같은 이동 좌표를 사용한다.
- `ferrial_drive/ui/config.py`, `samples/ui_unit_test/ui_config.json`: 배치·색·문구·폰트·버튼 동작 ID 분리. 판정 영역이 겹치면 설정 오류로 알린다.
- `ferrial_drive/ui/pico_renderer.py`, `view.py`: Pico2D가 생성한 SDL 렌더러에 기본 도형·텍스트·메뉴 초안을 그린다. Pico2D 원본은 수정하지 않는다. import만으로 창이나 실행 루프가 시작되지 않는다.
- `assets/fonts/`: 공식 배포본의 에스코어 드림 200·300·400, 깍두기 도면체 Regular와 저작권·이용 조건을 보관했다.

## 확인 결과

- `game2d` 환경의 Python 3.11·Pico2D 1.5.1로 핵심 자동 검사 **9개 통과**.
- 30/60/144 FPS의 동일 경과 시간, 0초·긴 프레임 처리, 음수 시간 거부, 이동된 버튼 판정, 영역 밖에서 놓기, 포획 취소와 import 독립성을 확인했다.
- SDL dummy·software 경로로 **메뉴 렌더링 PNG 생성**을 확인했다. 결과는 `output/ui_unit_test/menu.png`이며 공개 샘플 원본과 분리한다.
- 실제 창의 입력·전환·사용감은 미검증이다. 전투 HUD·표시 데이터 규격·샘플 갱신·장면 전환·독립 실행 진입점은 아직 연결하지 않았다. 전체 UI Unit Test 완료를 의미하지 않는다.
