# UI Unit Test 범위 확정

- 작성일: 2026-11-03, 한국 시간
- 범위: 메뉴·전투 HUD의 독립 테스트 프로그램 명세

## 사용자 결정

- 장면은 **메뉴·전투 HUD 두 개**다. AI가 레이아웃 초안을 배치하고 실제 화면에서 디테일을 조정한다.
- 전투 구성 요소는 버튼·패널·텍스트·게이지에 레이더·원형 크로스헤어를 추가한다. 메뉴는 버튼·패널·텍스트다.
- **Esc로 메뉴와 전투 HUD를 전환**, **좌클릭으로 버튼과 상호작용**한다.
- HUD는 콤보 수·데미지·플레이어 HP·타겟 적 정보와 HP 게이지를 표시한다. 콤보·데미지 표시는 Baldr Sky를 참고한다.
- 애니메이션은 **SmoothStep 중심의 이동·투명도 변화**다. 취소·재입력 규칙은 레이아웃 확인 후 정한다.
- 실행은 `.python`이라는 표기를 **`.py`로 정정**했다. 별도 `.py` 진입점으로 독립 실행한다.
- 샘플 데이터는 게임에서 쉽게 연결할 수 있는 규격으로 설계한다. 실제 게임에 채택할지는 미정이다.
