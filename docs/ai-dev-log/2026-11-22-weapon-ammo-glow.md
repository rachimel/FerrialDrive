## 2. 사용자 제안 중 AI가 수용한 것

- **U1** 현행 `concept` 카드의 잔탄 숫자에서 바깥 네온 광을 제외했다.

## 3. AI가 제안한 것

- **A1** 잔탄 본문의 93% 세로 그라데이션은 현행 규격을 따른다. 글자 내부 마스크와 기존 배치 경로를 재사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 광 제외는 사용자 제안이다. 본문 마스크 재사용과 독립 렌더 캐시를 사용한 비교는 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 현재 카드도 잔탄을 그릴 때 구형 카드와 공유하는 `weapon_text_neon`을 사용하고 있었다. 잔탄 문자열이 달라질 때 새 네온 광 마스크를 생성했다. 앞선 HUD 계측에서 무기 카드의 간헐 지연이 이 경로에 잡혔다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** 현행 카드는 글자 내부 그라데이션 진입점으로 연결했다. 이전 카드와 별도 로드아웃 번호 탭은 기존 경로를 사용한다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1** 실제 게임 글꼴로 잔탄 숫자 세 종류와 배치 활성·비활성 합계 6쌍을 확인했다. 기존 네온에서 광을 끈 참조와 새 본문의 RGBA 차이는 0픽셀이며 광을 켠 기준과의 차이도 확인했다. 그라데이션의 테마 편집기 색상 귀속을 연결했다.
