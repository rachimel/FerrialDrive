# 현행 문서 정리

- 작성일: 2026-11-03, 한국 시간
- 요청: 현행 문서에서 레거시 파이프라인·오래된 정보를 갱신하고 GitHub에 반영한다.

## 반영 내용

- 현행 이미지 안내는 JANIMA 레퍼런스 생성 → GPT 디테일 보정으로 통일한다. LoRA 학습 범위·경로·내보내기 절차는 `legacy/lora/`의 과거 기록으로 유지한다.
- 사용자 추가 의견에 따라 손·발·겹침·사물 구조·비율·조명 기준을 [이미지 보정 체크리스트](../image_correction_checklist.md)로 분리해 현행 보정에도 활용한다.
- 과거 체크리스트에 레거시 안내를 붙이고 현재 없는 평가 문서의 링크를 당시 참조 이름으로 표시한다.
- README의 현재 목표를 독립 UI Unit Test로 갱신한다. 기존 PPT는 최신 명세와 구분되는 기존 초안·발표본으로 표시한다.
- AGENTS의 상세 UI 요구와 PRE-PRD의 중복 설명은 [UI 명세](../ui_unit_test.md)에서 관리하도록 압축한다. Unit Test 정의·모듈 분리·독립 샘플과 확정 입력·HUD·elastic 투명도 제외 규칙은 유지한다.
- 저장·출력·재열기 완료 조건은 해당 기능이 있는 툴에만 적용한다. 실행 파일명 등 내부 기본값은 불필요한 선결 확인 사항에서 제외한다.
- 첫 애니메이션 구현은 SmoothStep을 기준으로 하고, 추가 곡선은 비교 후보로 유지한다. 이전 추천 기록은 과거 로그에 남긴다.
- PRE-PRD의 별도 프로젝트 확장 문구와 현재 없는 원본 파일 참조를 정리한다.

## 작업·검증 범위

- 현재까지의 미커밋 기획·작업 규칙·로제 파일명·파이프라인·개발 로그 변경도 함께 검토한다.
- 공개 대상은 텍스트 문서와 규칙이다. AI 이미지·모델·로컬 보고서와 기존 작업 산출물은 제외한다.
- 로제의 생성·편집 프롬프트 원문은 유지한다. 로컬 전용 이미지 경로를 공개 저장소의 깨진 링크로 노출하지 않도록 안내를 정리하고 문서 해시를 갱신한다.
- 이 작업은 문서 갱신이다. 게임·UI Unit Test 실행 코드나 샘플 데이터 구현을 완료한 것으로 표시하지 않는다. 커밋·업로드 결과는 Git 기록으로 확인한다.
