# 파츠 아틀라스 바인딩·복원 단축

- **기록 ID** `FDLOG-20261122-part-atlas-binding`
- 2026-11-22 KST 계측. RTX 5070 Laptop, OpenGL 4.6, FHD·Medium·SMAA, 적 180기·15m 간격, 플레이어 HP 10만, 고정 60Hz 자동 검 입력, 무음, VSync와 프레임 제한 해제.

## 1. 사용자가 제안한 것

- **U1** `PartPainter.paint`의 아틀라스 바인딩·복원을 실제 GL 호출 단위로 먼저 계측하고 중복 호출을 줄인다. 같은 180기 입력·품질로 화면과 전후 함수 시간·FPS를 확인하고 별도 커밋을 남긴다. 정확한 요청 시각은 미확인이다. `[[FDLOG_MISSING_TIME:FDLOG-20261122-part-atlas-binding:U1]]`. 검색 단서는 `PartPainter.paint의 아틀라스 바인딩·복원 최적화`다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `bind_atlas_textures` 진입·종료를 분리하고, `glGetIntegerv`, `glActiveTexture`, `glBindTexture`, `SDL_GL_BindTexture`, 새 텍스처 상태 스택 호출을 각각 쟀다. 같은 프레임의 실제 RGBA와 GL 바인딩 복원을 함께 확인했다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 2026-11-22 KST 초기 계측에서 플레이어 아틀라스 진입의 2D 바인딩 조회가 프레임당 85.8회·0.613ms였다. 고정 기능 유닛 4개, 프래그먼트 유닛 32개로 보고된 실제 컨텍스트에서 32개 슬롯과 활성 유닛이 `GL_TEXTURE_BIT` 저장·복원 한 쌍으로 돌아오는지 확인했다. 복원 가능한 범위를 첫 사용 때 검사해 페인터별로 보관한다. [OpenGL 4.6 호환 프로파일 §21.6·표 23.17](https://registry.khronos.org/OpenGL/specs/gl/glspec46.compatibility.pdf)
- 독립 2D 파츠 패스에서는 유닛별 조회와 복원을 스택 한 쌍으로 처리한다. 검증 범위를 넘거나 다른 텍스처 타깃을 쓰는 호출은 개별 조회·복원 경로를 사용한다. 적 배치가 공유하는 `AtlasTextureBindings`는 기존대로 유닛·타깃별 값을 재사용한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 화면 보존, 동일 조건 계측과 별도 커밋은 사용자 요청이다. GL 상태 스택 선택, 런타임 복원 검사와 반복 회차는 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 개선 전에는 독립 패스마다 각 유닛으로 전환해 이전 `GL_TEXTURE_BINDING_2D`를 조회하고, 패스 종료 때 다시 유닛을 전환해 원래 텍스처를 묶었다. 상세 계측에서 조회는 평균 86.02회·0.628ms/프레임으로, 별도 계측한 네 API의 경과 시간 합계 중 약 82%였다. 프레임당 조회 P95는 0.939ms였다. 이 값은 호출 스레드가 관측한 경과 시간이며 내부 드라이버 대기를 분리한 수치가 아니다.
- **I2** 교전 상태·입력 해시 120개는 전후 일치했다. 비동기 아틀라스 준비가 따로 진행돼 상세 계측 회차 사이에 개별 제출 수가 조금 달랐다. 화면·상태 검사에서는 동일 호출을 두 경로에 전달했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** `9ac1131`과 기존 로컬 변경을 포함한 작업본에서 바인딩 구현만 교체했다. 회차당 30프레임 예열 뒤 120프레임을 측정했다. 계측 없는 전후 4회는 실행 순서를 교차했다. FPS 중앙값은 **33.83 → 35.41**(+4.7%)이다. 회차별 FPS는 전 32.79·35.49·32.92·34.73, 후 36.69·35.09·34.43·35.72다. 프레임 작업 P50은 27.42→27.68ms, P95는 38.27→38.74ms, P99는 42.41→44.42ms였다.
- 같은 배경을 복원하며 실제 GL 결과를 대조했다. 120프레임에서 본체 240회·깊이 120회·잔상 568회·독립 적 파츠 30회로 총 **958회·10,858,794픽셀**이 모두 일치했다. 같은 958회에서 활성 유닛과 6~25개 2D 바인딩이 모두 원래 값으로 돌아왔다.
