## 3. AI가 제안한 것

- **구현상 판단 (A1):** 일반 HUD 0.9→0.81, 미니맵/장비 0.9 유지로 배율을 나눴다. 레이더도 표시 치수를 10% 줄였다. 필살기 마름모 반경은 43 논리 px로 키워 0.81배에서도 이전보다 크게 보이게 했다.
- **구현상 판단 (A2):** HP 채움/외곽을 같은 도형으로 쓰고 큰 마름모 변의 높이별 접점을 계산했다. HP와 레벨/단축키 문구는 글꼴 치수에서 정렬 위치를 계산한다. 사전 수치 승인으로 취급하지 않는다.
- **구현상 판단 (A3):** U3의 아래 문구가 잘리지 않도록 HP/에너지/대시 묶음을 22 논리 px 위로 조정했다. 연결 관계와 다른 패널의 크기는 유지한다.
- **구현상 판단 (A4):** U4의 두 문구를 마름모 왼쪽 사선 바깥에 두고 오른쪽 끝을 맞췄다. 하단 위치는 `5c334a9`의 HP·에너지·대시 좌표로 복원해 A3의 22 논리 px 이동만 되돌렸다.
- **구현상 판단 (A5):** 기존 사선 패널을 재사용해 어두운 면과 얇은 외곽을 붙였다. 글자 크기에 가로 4/세로 2 논리 px 여백을 더하고, 전용 문구 그리기 함수에서 위치·투명도를 함께 적용한다. 기존 배치와 다른 패널 치수는 유지한다.
- **구현상 판단 (A6):** 기존 팔레트의 `panel_surface`(`#22343F`)를 재사용했다. 해당 면만 `panel`(`#101E27`)에서 변경하고 패널 그리기에 면 색상 선택을 추가해 다른 패널의 색상·투명도·배치를 유지했다.
- **구현상 판단 (A7):** 폭에 따른 카운터 축소를 제거하고 글자 배율 1과 오른쪽 원근 기준 폭 240/300 논리 px를 고정했다. 원근면 기준을 자릿수와 분리해 오른쪽 숫자 모양이 바뀌지 않도록 했다. 에너지 숫자/LV는 각각 `muted`/`ui_accent`로 낮추고 비활성 카드는 오른쪽 중앙 기준으로 내용까지 함께 축소했다.
- **AI 제안 (A8):** 긴 DAMAGE가 COUNTER와 겹칠 때 COUNTER를 왼쪽으로 밀어 간격을 확보할지 질문했다. 근거는 8자리 렌더에서 확인한 겹침이며, 시각은 scope 태그를 따른다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1~A4의 실제 수치·수정본 외관은 확인 대기다. A3의 위치 이동은 U4에서 복원을 요청했다. 요청 구현과 사용자 승인을 구분한다.
- A5의 패널 수치와 수정본 외관은 확인 대기다. U5는 패널 추가 요청과 향후 단계 언급이며 새 애니메이션 규칙의 승인으로 확대하지 않는다.
- U6의 밝기 시험 요청과 A6의 색상 값·렌더 결과 승인은 구분한다. 조정본 외관 승인은 확인 대기다.
- A7의 수치·표현 결과 외관은 확인 대기다. 사용자가 명시한 ＼ 방향·80%와 구현상 판단을 구분한다. A8은 U9에서 이번 범위에서 제외하도록 지정했다.

## 5. 반영 후 발견한 문제

- 기존 HP의 채움이 외곽보다 안쪽에 있어 빈 여백이 보였다. 사용자가 지적한 내용이며 이번에 채움/외곽 일치로 보정했다.
- 최초 기록 시점에는 새로운 외관 문제 제보가 없었다. 후속 U3은 배치 변경 요청으로 구분한다.
- 후속 U4에서 사용자는 하단 위치 복원과 필살기 표기 재배치를 요청했다. 왼쪽 아래 정정이 최종 기준이다.
- U8 조사에서 카운터 폭 제한에 따른 배율 변화와 자릿수에 종속된 원근 기준을 확인했다. 고정 글자 배율을 적용한 8자리 렌더에서는 DAMAGE와 COUNTER가 겹쳤으며, U9에 따라 이 겹침은 임시 샘플 배치의 알려진 상태로 남겼다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 유지 대상 세 그룹은 기존 크기로 분리했다. 필살기 문양/마름모를 키우고 나머지 전투 HUD는 추가 축소했다.
- U2에 따라 에너지 레벨 숫자를 오른쪽 끝에 맞췄다. HP 수치/HP를 바 위로, 단축키와 필살기 레벨을 아이콘 왼쪽 공통 오른쪽 끝에 두 줄로 배치했다.
- 후속 U3에 따라 왼쪽 배치를 대체하고 V/`LV. 01`을 위/아래 가운데에 배치했다.
- 최신 U4에 따라 가운데 배치를 대체했다. V는 왼쪽 위, `LV. 01`은 왼쪽 아래에 놓고 HP·에너지·대시는 U3 이전 위치로 복원했다.
- U5에 따라 두 문구 뒤에 각각 작은 사선 패널을 추가했다. 위치 변경이나 추가 HUD 재설계는 하지 않았다.
- U6에 따라 무기 행과 두 필살기 문구 패널의 배경을 밝게 바꿨다. 활성/비활성 투명도는 유지했다.
- U7에 따라 V와 `LV. 01` 패널의 외곽선 그리기만 비활성화했다. 면 색상·투명도·배치와 필살기 마름모·다른 패널의 테두리는 유지했다.
- U8에 따라 카운터를 숫자 오른쪽에 고정하고 받침판·잔상만 왼쪽으로 확장했다. 필살기 LV 패널만 ＼ 방향으로 바꾸고, 에너지 레벨 글자를 낮추고, 비활성 무기 카드를 80%로 줄였다. U9에 따라 COUNTER 위치는 유지했다.
