- 후속 U3도 수용해 위아래 가운데 정렬로 변경했다.

## 3. AI가 제안한 것

- **구현상 판단 (A1):** 일반 HUD 0.9→0.81, 미니맵/장비 0.9 유지로 배율을 나눴다. 레이더도 표시 치수를 10% 줄였다. 필살기 마름모 반경은 43 논리 px로 키워 0.81배에서도 이전보다 크게 보이게 했다.
- **구현상 판단 (A2):** HP 채움/외곽을 같은 도형으로 쓰고 큰 마름모 변의 높이별 접점을 계산했다. HP와 레벨/단축키 문구는 글꼴 치수에서 정렬 위치를 계산한다. 사전 수치 승인으로 취급하지 않는다.
- **구현상 판단 (A3):** U3의 아래 문구가 잘리지 않도록 HP/에너지/대시 묶음을 22 논리 px 위로 조정했다. 연결 관계와 다른 패널의 크기는 유지한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- A1~A3의 실제 수치·수정본 외관은 확인 대기다. 요청 구현과 사용자 승인을 구분한다.

## 5. 반영 후 발견한 문제

- 기존 HP의 채움이 외곽보다 안쪽에 있어 빈 여백이 보였다. 사용자가 지적한 내용이며 이번에 채움/외곽 일치로 보정했다.
- 최초 기록 시점에는 새로운 외관 문제 제보가 없었다. 후속 U3은 배치 변경 요청으로 구분한다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U1의 유지 대상 세 그룹은 기존 크기로 분리했다. 필살기 문양/마름모를 키우고 나머지 전투 HUD는 추가 축소했다.
- U2에 따라 에너지 레벨 숫자를 오른쪽 끝에 맞췄다. HP 수치/HP를 바 위로, 단축키와 필살기 레벨을 아이콘 왼쪽 공통 오른쪽 끝에 두 줄로 배치했다.
- 후속 U3에 따라 왼쪽 배치를 대체하고 V/`LV. 01`을 위/아래 가운데에 배치했다.
