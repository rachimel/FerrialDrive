# HP 감소 구간·진한 빨강·가속·재피격 재시작

- 작성일: 2026-11-03, 한국 시간
- 사용자 확정: 실제 HP는 즉시 줄고 새 HP와 이전 표시 끝 사이를 진한 빨강으로 남긴다. 처음 느리다가 점점 빨라지는 보간을 쓰고, 도중에 피해를 받으면 현재 표시 위치에서 t=0으로 다시 시작한다.
- 공통 보간에 `ease_in_quad(t)=t²`, UI 모듈에 `HealthTrail`을 추가했다. 실제 HP는 별도 표시 상태가 변경하지 않는다. 새 감소 때 현재 `trailing_ratio`를 시작값으로 보존하고 목표 비율·시간만 갱신한다. 같은 비율을 다시 전달할 때는 진행 시간을 유지한다.
- 플레이어 세로 HP 바와 타겟 가로 HP 바에서 현재 HP와 표시 끝 사이만 진한 빨강으로 그린다. `health_trail.duration_seconds=0.6`·`colors.health_loss=#8F2028`은 비교용 시안이다. 카운터·이번 피해 숫자의 보간과는 분리한다.
- 플레이어·타겟에 독립 상태를 두었다. 표시 초기화·회복은 즉시 맞추고, 타겟 유무 변경은 타겟 상태만 초기화한다. 메뉴에서도 표시 시간을 갱신한다. 본편의 타겟 교체 시에는 연결부가 해당 HealthTrail을 reset한다.
- 연결·경계·현재 설정을 읽어 검토하고 연속 피격 위치 보존·시간 재시작·가속·회복/초기화 검사 항목을 준비했다. 사용자 직접 테스트 방침에 따라 자동 검사·실행·렌더링·실제 창 조작은 수행하지 않았다.
- ui_test.py를 재드롭해 두 HP 바의 감소·진한 빨강 구간·연속 피격 시 t=0 재시작·HP 0·초기화·타겟 전환을 확인한다.
