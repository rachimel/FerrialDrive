# 근거리 적 키포즈 샘플 좌표 재사용

**기록 ID** `FDLOG-20261121-near-enemy-keypose-sample-cache`

2026-11-21 KST 구현·계측 기록. 양쪽 렌더 경로에 [공유 인스턴스 버퍼](2026-11-21-near-enemy-instance-upload.md)를 사용했다.

## 1. 사용자가 제안한 것

- **U1** 깊이 선행 패스가 구한 두 키의 샘플 좌표를 GPU에 저장해 재질 패스에서 재사용한다. 근거리 적의 보간을 두 패스에서 각각 실행하는 경로와 180기 프레임·GPU·메모리를 비교한다.
- 정확한 요청 시각은 [[FDLOG_MISSING_TIME:FDLOG-20261121-near-enemy-keypose-sample-cache:U1]]이다. 검색 단서는 `Pre-pass에서 구한 양쪽 키 샘플 좌표를 재질 패스에서 재사용`이다.

## 2. 사용자 제안 중 AI가 수용한 것

- **U1** `deferred_enemy_depth_cached_samples`를 추가했다. 기존 `deferred_enemy_depth`와 동일한 공유 인스턴스 전송, 아틀라스, 조명과 그림자를 사용한다.

## 3. AI가 제안한 것

- **A1 · 구현상 판단** 중간 포즈의 시트와 화면 픽셀이 1:1로 대응하고 시트 타일을 개별 기체만 쓰는 경우, 두 키의 파츠 좌표를 `vec4`로 GPU 저장 버퍼에 기록한다. 동일한 픽셀 중심과 할당 위치를 두 패스가 사용한다. 저장 버퍼 동기화 후 재질 패스는 좌표를 읽어 기존 표면 샘플링과 합성을 수행한다.
- **A2 · 구현상 판단** 키프레임 정각, 공유 타일, 확대 필터, 깊이 선행 패스 생략 및 버퍼 한도 초과 시 기존 보간 경로를 사용한다. 깊이 판정이 먼저 끝난 경우 나머지 파츠의 불투명도 조회는 생략하고 좌표만 기록한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- **U1** 키 좌표 재사용의 구현 및 180기 비교는 사용자 요청이다. **A1–A2**의 저장 형식과 적용 범위는 실험 구현상 판단이다.

## 5. 반영 후 발견한 문제

- **I1** 두 회차에서 적 GPU 구간이 각각 0.58 ms와 1.02 ms 증가했다. 좌표 기록, 조회와 패스 사이 동기화가 추가됐다. 각 비용은 분리 계측하지 않았다.
- **I2** 마지막 프레임의 25개 근거리 타일에 대한 좌표 버퍼 할당은 20.5 MiB였다. 프로세스 전체 커밋과 Intel 통합 GPU의 DXGI 로컬 표본도 증가했다.

## 6. 사용자 해결 제안과 실제 해결 과정

- **U1** Intel 통합 GPU, FHD·High·SMAA·검 자동 교전, 초기 180기로 실행했다. 독립 실행마다 준비 120프레임과 측정 240프레임을 사용했다. 전체 드로우와 적 GPU 구간을 별도로 기존→재사용→재사용→기존 순서로 측정했다. 두 경로가 같은 로컬 Hermite 카탈로그를 사용했다.

| 지표 | 깊이·재질 각각 보간 | 좌표 재사용 |
| --- | ---: | ---: |
| 평균 프레임 작업 시간 | 30.16~30.41 ms | 29.25~29.45 ms |
| 프레임 작업 p95 | 38.37~39.64 ms | 35.65~37.05 ms |
| 전체 GPU 드로우 평균 | 8.83~11.28 ms | 9.18~9.86 ms |
| 적 렌더 GPU 구간 평균 | 2.77~3.27 ms | 3.36~4.29 ms |
| 프로세스 커밋 피크 표본 | 1919.1~1937.9 MiB | 2060.6~2075.1 MiB |
| Intel DXGI 로컬 피크 표본 | 610.30~610.33 MiB | 723.18~723.37 MiB |
| Deferred·Box 논리 GPU 할당 | 18.63 MiB | 39.13 MiB |

- 일반 계측의 마지막 프레임에서 근거리 25기와 원거리 공유 아틀라스 128기를 그렸다. 양쪽 모두 깊이 11회, 재질 11회, 조명 1회를 제출했다. 프레임 작업은 표시까지의 경과 시간이며 OpenGL GPU 구간은 명령 제출 사이의 대기를 포함할 수 있다. 프로세스 커밋 피크는 전체 프로세스의 표본이다.

## 7. AI 해결 제안과 실제 해결 과정

- **A1 ↔ I1–I2** 별도 벤치마크 모드로 실험을 유지한다. 등록된 두 경로를 동일한 180기 조건에서 실행해 결과를 기록했다.
- **A2** 실제 OpenGL 검사 13개와 계측 검사 4개를 커밋 후보에서 통과했다. 겹침·반투명·공유 포즈와 화면 밖 경계 및 단독 기체를 대조했다. 같은 180기 High/Hermite 교전 상태에서 그린 1920×1080 적 렌더 캡처는 1픽셀의 8비트 채널 값이 1만큼 달랐다. 직접 조작 검증은 수행하지 않았다.
- 요약과 원자료는 `output/performance/enemy_depth_keypose_cache_180_20261121/`에 보관한다.
