# Overdrive 팔레트 캐시·탄약 반해상도

- **기록 ID:** `FDLOG-20261117-hud-palette-ammo-resolution`
- 대화·작업 범위: 2026-11-17 현재 세션. 개별 발언 시각은 미제공이다. [[FDLOG_MISSING_TIME:FDLOG-20261117-hud-palette-ammo-resolution:scope]] 검색 단서: `Overdrive 팔레트는 미리 캐싱`, `반해상도로 해볼래`.
- 선행 근거: [사격·Overdrive 병목 실측](2026-11-17-gun-overdrive-bottleneck.md).
- 상태: 구현·관련 자동 검사·실제 OpenGL 렌더 측정·캡처 직접 확인. 사용자 외관 승인·커밋·업로드는 별도다.

## 1. 사용자가 제안한 것

- **사용자 제안 1 (U1):** Overdrive 팔레트 사전 캐싱과 탄약 텍스처 저해상도 생성을 요청했다. 의도는 선행 대화에서 확인한 사격·Overdrive 지연 개선이다. 출처: 현재 세션의 첫 검색 문구.
- **사용자 제안 2 (U2):** 후속으로 탄약 반해상도를 요청했다. 출처: 두 번째 검색 문구. 54px 표시를 유지하고 27px 생성으로 적용한다고 AI가 보고했다.

## 2. 사용자 제안 중 AI가 수용한 것

- U1·U2를 구현했다. 다른 네온 본문의 3배 해상도·탄약 그라데이션·표시 크기는 유지했다.

## 3. AI가 제안한 것

- **구현상 판단:** 기본 빨간 팔레트를 초기화·테마 할당 때 준비하고, 전체 색상 값과 선택 Overdrive 색을 키로 최대 64개 결과를 재사용한다. 같은 테마 문서 내부 수정·무지개 변경도 오래된 결과를 쓰지 않도록 한다.
- 첫 구현은 탄약 1배 해상도였으며 U2에 따라 최종 0.5배로 조정했다. 1배 결과와 최종 결과는 출력 로그에서 구분한다.

## 4. AI가 제안한 것 중 사용자가 수용한 것

- 캐싱·저해상도·반해상도 자체는 U1·U2의 사용자 요구다. 캐시 크기·자료구조는 AI 구현 판단이며 사용자의 별도 승인을 추정하지 않는다. 최종 외관은 사용자 확인 전이다.

## 5. 반영 후 발견한 문제

- 새 오류는 관련 검사와 이번 실행에서 발견하지 못했다. 반해상도 숫자는 확대하면 더 부드럽게 보인다. 남아 있는 프레임 지연과 다른 HUD 텍스트 최초 생성 비용까지 해결했다고 판단하지 않는다.

## 6. 사용자 해결 제안과 실제 해결 과정

- U2에 따라 54px 글꼴을 27px에서 생성하고 54px 사각형에 선형 보간으로 표시했다. 숫자 폭·높이 계산은 원래 표시 글꼴 기준을 유지했다.

## 7. AI 해결 제안과 실제 해결 과정

- 변경: `ui/theme.py`의 위젯 색상 해석 공통화, `ui_v2/view.py`의 팔레트 사전 준비·제한 캐시, `ui_v2/pico_renderer.py`의 탄약 본문 0.5배 생성. 기존 사용자 변경을 보존하고 해당 부분만 수정했다.
- 검증: HUD 테마·미리보기·무지개 기존 검사 20개 통과 후 캐시 편집·재로딩·무지개 복원 검사를 추가했고, 최종 관련 검사 21개가 통과했다. 전체 자동 검사는 실행하지 않았다.
- 실제 에셋·FHD·medium·RTX 5070 Laptop·VSync와 제한 해제·60Hz 갱신·조건당 120프레임. 원본은 `output/performance/gun_od_probe_20261117/{before,after,half}.json`, 화면은 같은 폴더의 PNG다. before는 원래 3배, after는 1배+캐시, half는 최종 0.5배+캐시다.

- 수정 전·최종 전체 사격·Overdrive 캡처를 직접 열어 숫자 표시 크기와 테마·그라데이션을 확인했다. 실제 사용자 조작감·모든 UI 상태·전 하드웨어의 성능은 미검증이다. 초기 캐시·실행 순서·OS 부하가 있는 단기 측정이며 개선율을 보편적 수치로 해석하지 않는다.
