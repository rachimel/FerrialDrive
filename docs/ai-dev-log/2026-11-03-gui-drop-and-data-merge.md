# GUI 창 드롭으로 정정하고 에셋 폴더 통합

- 작성일: 2026-11-03, 한국 시간
- 최신 사용자 요청: `data`와 `assets`를 통합하고, 드롭 대상은 **Python으로 실행된 GUI 창**으로 한다.

## 변경

- 기존 아이콘 드롭 해석을 정정했다. `run.py`를 파일 인자 없이 실행하면 Pico2D 대기 GUI를 열고, 해당 창에 `.py`를 드롭해 테스트를 실행한다.
- GUI가 드롭 파일 로딩·교체·오류 표시를 담당한다. 테스트의 UI·입력·데이터·애니메이션은 계속 테스트 `.py`와 해당 재사용 모듈에 둔다.
- 실행 중 새 파일 드롭은 현재 테스트 정리 후 교체한다. 불러오기 실패는 현재 테스트를 유지하며, 초기화·실행 실패는 정리 후 대기 화면으로 복귀한다. 테스트의 `Stop()`도 GUI 모드에서는 대기 화면으로 복귀한다.
- 파일 인자 직접 실행은 기존 동작을 유지한다. 바로가기를 더블클릭하면 새 대기 GUI를 연다. 사용자 복사본 `tests/Unit Test Runner.lnk`는 이동·삭제하지 않았으며, 개인 경로가 포함된 `.lnk`는 Git 제외 규칙에 추가했다.
- Pico2D 원본 수정 없이 SDL 이벤트 어댑터에서 드롭 묶음과 일반 입력을 처리한다. SDL 파일명 포인터를 복사한 뒤 원래 포인터를 해제한다.
- `assets/fonts/`의 폰트·이용 조건 **9개**를 `data/fonts/`로 옮겼다. 기존 `data/fonts/`가 비어 있고 대상 파일 충돌이 없음을 확인한 뒤 이동했다. 이동 후 빈 `assets/`를 제거했다.
- UI 설정·문서의 활성 참조를 `data/fonts/`로 바꿨다. 공개 폰트의 지정 경로만 Git에 포함하고 AI 생성물을 포함한 나머지 data는 계속 제외한다.
