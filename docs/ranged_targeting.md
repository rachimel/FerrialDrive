# 원거리 자동 표적 선택

상태: **이동·UI 훈련장에 자동 획득·교체 대기·록온 방향 총 사격·중간점 카메라를 연결**했다. 기본 도형 1대1 전투 프로토타입의 사격과 구분한다. 승인된 상·하체 프리뷰를 입력용 자료로 확장해 검·총 비조준·정지 조준에 연결했다. 조준 이동/사격·부스트·무기 전환은 기존 전신 출력이며 직접 조작감 확인은 남아 있다.

## 확정한 규칙

- **현재 화면에 본체 표시 영역이 일부라도 보이는 주변의 활성 적**만 새 획득·교체 후보가 된다. 플레이어 중심 화면에서도 적이 보이는 범위로 제한해 록온 카메라가 비추는 먼 적을 연쇄 획득하지 않는다. 줌을 반영하고 피격 흔들림은 제외한다. 획득에 미터 거리 제한이나 조준별 거리 확장은 사용하지 않는다.
- 기존 표적은 화면 밖이어도 거리 제한 없이 유지하며, 플레이어 기체의 완전한 화면 이탈·표적 사망·비활성으로 해제한다. 우클릭 해제만으로 풀리지 않는다.
- 후보 중 **마우스 월드 좌표와 가장 가까운 적**을 고른다. 동률은 고유 ID 순으로 고정한다. 활성 상태이고 HP가 남은 적만 후보가 된다.
- 우클릭 조준 중에는 **탄 퍼짐이 감소**한다. 획득의 화면 조건은 같다.
- 표적을 획득해도 **탄 퍼짐을 유지**한다. 록온은 명중 보장이 아니다.
- 표적이 없으면 유효한 최우선 후보를 **즉시 획득**한다. 총알 명중을 획득 조건으로 사용하지 않는다.
- 다른 적을 이미 록온 중이면 새 최우선 후보가 처음 관측된 뒤 **연속 1초** 유지될 때 교체한다. 중간에 다른 후보가 우선되거나 현재 표적으로 돌아오면 대기를 초기화한다.
- **화면 거리 교체 실험:** `targeting.screen_distance_switch.enabled=true`에서 플레이어와 기존 표적의 화면 간격이 멀어지면 더 가까운 적을 우선한다. 가로 간격/화면 반폭·세로 간격/화면 반높이의 벡터 길이가 0.7 이상이면 거리 교체 상태에 들어가고, 0.55 이하이면 복귀한다. 기존보다 25% 이상 가까운 유효 후보가 0.25초 유지되면 교체한다. 대체 후보가 없으면 기존 표적을 유지한다. 가까운 표적을 잡은 뒤에는 간격 0.7 이상의 적을 평상시 마우스 자동 교체에서 제외해 왕복을 막는다. 최초 획득은 기존 화면 조건을 따른다.
- **Q:** 화면에 보이는 주변 후보 중 마우스와 가장 가까운 적으로 즉시 선택한다. 기존 교체 대기를 건너뛰고 대기 상태를 초기화하며, 후보가 없으면 기존 표적을 유지한다. 선택은 1초간 자동 교체로부터 보호한다. 사망·비활성·플레이어 완전 화면 이탈 해제는 그대로 적용한다. 반복 keydown·일시정지·메뉴·설정창에서는 작동하지 않는다. 종료 키는 F10이다.
- 교체 대기와 Q 보호 시간은 실제 초 기준이며 Overdrive 애니메이션 배율의 영향을 받지 않는다. 거리 교체 수치는 실험값이며 최종 밸런스 승인이 아니다.
- 현재 표적이 사망·비활성이거나 **현재 록온 카메라에서 플레이어 기체의 표시 사각형이 화면과 완전히 떨어지면** 즉시 해제한다. 중심점이 화면 밖이어도 일부가 보이면 유지한다. 줌·현재 카메라 위치를 반영하며 피격 흔들림·그림자·잔상·VFX는 해제 판정에서 제외한다. 알파 픽셀별 가림이나 장애물 시야 검사는 수행하지 않는다.
- 플레이어가 화면 밖인 동안 새 표적은 획득하지 않는다. 화면 이탈로 해제한 표적은 **플레이어 중심 화면에서도 적 본체가 보일 때** 다시 허용한다. 복귀 중인 록온 카메라나 기체 포즈 변화에 따른 반복 획득·해제를 방지한다. 다른 후보는 현재 화면 조건을 따른다.
- 총탄은 록온한 적의 현재 위치를 향해 발사한다. 미획득 상태에서는 마우스 방향으로 자유 사격한다. 탄 퍼짐과 연속 충돌 검사는 유지하며 앞의 다른 적이 대신 맞을 수 있다. 실제 피격 대상의 체력·피해 숫자·흡수는 갱신하지만 명중으로 록온을 바꾸지 않는다.
- 록온 중 카메라는 플레이어와 표적의 중간점을 추적한다. 해제하면 기존 플레이어 중심 시선 오프셋으로 부드럽게 복귀한다.
- 실제 시선·머리·팔·상체는 조준 목표 방향으로 보간하며 먼저 반응한다. 상체와 하체의 방향 차이가 좌우 ±45°를 넘으면 하체도 보간 추종을 시작하고, 시작각 안으로 돌아와도 정렬될 때까지 이어간다. 45°는 추종 시작 기준이며 유지할 차이나 강제 회전 제한이 아니다. 방향 차이는 월드 수평면 기준으로 계산한다. 연결한 동작·보간 상태와 8방향 출력의 차이·허리·파지·가림·그림자는 [분리 검토](unit-tests/upper_lower_aim.md)를 따른다.
- R 입력과 획득 이력 순환은 사용하지 않는다. UI 가림만으로 월드 후보를 제외하지 않는다.

## 미정

- 카메라 수치와 원거리 교전의 최종 밸런스. 록온 범위와 총탄 사거리는 별도다.
- 실제 월드 장애물의 가림 처리. 현재 훈련장은 총구 추적과 원형 표적의 연속 명중 검사만 연결한다.
- 탄 퍼짐 수치와 이동속도·연사속도 조정 여부. 획득의 화면 조건과 총탄 사거리는 별도다.

현재 `ferrial_drive/combat/simulation.py`는 조준 여부로 `hip_spread_degrees`/`aim_spread_degrees`를 선택한다. 기본 설정은 각각 5도/0.6도다. 이는 코드 확인이며 사용자 체감·최종 밸런스 검증을 뜻하지 않는다.

## 현재 연결

- `ferrial_drive/combat/mouse_targeting.py`의 `MouseAutoTargeting`은 `acquisition_ids`가 있으면 해당 가시성 후보를 거리 제한 대신 사용한다. 마우스 최근접 순위와 교체 대기는 유지한다. 기존 거리 기반 호출과 `TargetAcquisition`은 호환 경로로 보존한다.
- `ferrial_drive/combat/camera.py`의 `LookAheadCamera`는 투영 월드/화면 변환·줌·시선 오프셋을 담당한다. 기본 시선 값은 80px 데드존·변위 20%·최대 120 투영 월드 픽셀·응답 시정수 0.15초다. 범위 판정의 미터와 표시 좌표 단위를 구분한다.
- 기체·몸통·록온·레이더 접촉점·피해 숫자는 같은 카메라로 투영하고 HUD는 고정한다. 적별 위치·HP는 월드 좌표와 고유 ID로 보존한다. `LookAheadCamera.update(focus_world=...)`는 플레이어·표적의 중간점을 사용하며 충격 오프셋과 구분한다.
- 훈련장 기본 표적 배치는 비어 있다. 표적을 지정한 설정에서는 매 프레임 사격 전에 0초 갱신으로 첫 획득·유효성을 확인하고, HUD에서 실제 시간만 한 번 누적해 교체 대기를 처리한다.
- `samples/sword_movement/movement_config.json`의 `targeting.acquisition`은 `visible`이다. `MovementHud.bind_world`가 플레이어·표적의 월드 표시 사각형을 연결한다. Combat은 적 본체·다리를 포함한 보수적 영역을 사용하고 이름·HP·무기/VFX는 제외한다. 훈련장 원형 표적은 반경의 사각형을 사용한다. 상·하체 플레이어 출력은 클립의 논리 크기·피봇·배율을 사용하며 검사 때문에 새 GPU 텍스처를 적재하지 않는다. 초기화 시 화면 이탈 해제 이력도 지운다.
- `v2.targeting_sample`의 330/460 픽셀은 기존 UI 시연/레이더 표시 설정이며 훈련장 획득·유지 거리로 사용하지 않는다. 대기는 `v2.auto_targeting`의 1초를 유지한다. 각도 동률 설정은 자동 선택에 사용하지 않는다.
- 이동·UI 훈련장의 `MovementApplication`은 록온 표적 좌표를 조준·발사에 공유한다. `HudPreview.damage_target`은 피격과 선택을 분리한다. 도형 1대1 `CombatApplication`에는 이 자동 표적 선택을 연결하지 않았다.
