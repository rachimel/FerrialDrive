# 원거리 자동 표적 선택

상태: **월드 최근접 자동 선택·1초 대기·시선 카메라를 재사용 모듈과 UI v2에 구현 / 전투 프로토타입 발사 연결 미구현**. 현재 전투 프로토타입의 우클릭 탄 퍼짐 감소와 구분한다.

## 확정한 규칙

- 플레이어로부터 **획득 가능 거리 안에 있는 적**을 후보로 삼는다.
- 후보 중 **마우스 월드 좌표와 가장 가까운 적**을 고른다. 동률은 고유 ID 순으로 고정한다. 활성 상태이고 HP가 남은 적만 후보가 된다.
- 우클릭 조준 중에는 **표적 획득 가능 거리가 늘어나고 탄 퍼짐이 감소**한다.
- 표적을 획득해도 **탄 퍼짐을 유지**한다. 록온은 명중 보장이 아니다.
- 새 최우선 후보가 처음 관측된 뒤 **연속 1초** 유지되면 교체한다. 중간에 다른 후보가 우선되거나 현재 표적으로 돌아오면 대기를 초기화한다. 갑자기 출현한 적도 같은 대기를 거친다.
- 현재 표적이 사망·비활성·범위 밖이면 즉시 해제한다. 새 표적은 별도로 1초 확인한다. 후보가 없으면 표적과 대기 상태를 비운다.
- R 입력과 획득 이력 순환은 사용하지 않는다. UI 가림만으로 월드 후보를 제외하지 않는다.

## 미정

- 평상시/조준 중 획득 거리와 카메라 수치의 최종 밸런스.
- 실제 월드 장애물의 가림과 발사 기준점 처리. UI v2 선택/해제 표시와 실제 전투 연결은 구분한다.
- 탄 퍼짐 수치와 이동속도·연사속도 조정 여부. 조준 사거리 증가는 획득 거리의 증가이며 탄환 사거리 변경까지 확정한 것이 아니다.

현재 `ferrial_drive/combat/simulation.py`는 조준 여부로 `hip_spread_degrees`/`aim_spread_degrees`를 선택한다. 기본 설정은 각각 5도/0.6도다. 이는 코드 확인이며 사용자 체감·최종 밸런스 검증을 뜻하지 않는다.

## 현재 연결

- `ferrial_drive/combat/mouse_targeting.py`의 `MouseAutoTargeting`은 후보·플레이어 월드 위치·마우스 월드 위치·시간·조준 여부를 받아 선택 ID를 반환한다. 기존 `TargetAcquisition`은 호환 코드로 보존하지만 UI v2 입력에는 연결하지 않는다.
- `ferrial_drive/combat/camera.py`의 `LookAheadCamera`는 월드/화면 변환과 시선 오프셋을 담당한다. 샘플은 80px 데드존·변위 20%·최대 120 월드 단위·응답 시정수 0.15초다. 줌은 없으며 1 월드 단위는 1 화면 px다.
- 기체·몸통·록온·레이더 접촉점·피해 숫자는 같은 카메라로 투영하고 HUD는 고정한다. 적별 위치·HP는 월드 좌표와 고유 ID로 보존한다.
- 최초 A는 시연용 표적이며 첫 마우스 입력 전에는 유지한다. 선택이 없어지면 플레이어 위치를 기준으로 재획득 대기를 진행한다. 기본 적은 3기다.
- 샘플 거리는 기본 330·조준 460으로 `v2.targeting_sample`, 대기는 `v2.auto_targeting`, 카메라는 `v2.camera`에서 조절한다. 본편 밸런스 확정값이 아니다. 각도 동률 설정은 자동 선택에 사용하지 않는다.
- 실제 발사·명중·탄 퍼짐과 전투 프로토타입은 이 모듈에 아직 연결하지 않았다.
