# 원거리 표적 획득

상태: **거리·각도 획득과 R 이력 순환을 재사용 모듈·UI v2 샘플에 구현 / 전투 프로토타입 연결 미구현**. 현재 전투 프로토타입의 우클릭 탄 퍼짐 감소와 구분한다.

## 확정한 규칙

- 플레이어로부터 **획득 가능 거리 안에 있는 적**을 후보로 삼는다.
- 우선 **플레이어→커서 방향과 플레이어→적 방향의 각도 차가 가장 작은 적**을 고른다. 각도가 같거나 비슷하면 가까운 적을 우선한다.
- 우클릭 조준 중에는 **표적 획득 가능 거리가 늘어나고 탄 퍼짐이 감소**한다.
- 표적을 획득해도 **탄 퍼짐을 유지**한다. 록온은 명중 보장이 아니다.
- R을 누르면 **획득 이력에 없는 다른 현재 후보**를 같은 우선순위로 고른다.
- 현재 후보 중 미획득 후보를 다 돌면 획득 이력을 초기화하고 **같은 R 입력에서 우선순위상 첫 후보를 다시 선택**한다.
- 표적 획득 후보 자체가 없을 때도 이전 획득 이력을 초기화한다.

## 미정

- 평상시/조준 중 획득 거리와 각도 동률로 취급할 범위.
- 커서를 움직일 때 자동으로 대상을 바꾸는 조건과 R 선택을 유지하는 조건.
- 표적 사망·사거리 이탈·가림·획득/해제 순간의 표시·발사 기준점 처리.
- 탄 퍼짐 수치와 이동속도·연사속도 조정 여부. 조준 사거리 증가는 획득 거리의 증가이며 탄환 사거리 변경까지 확정한 것이 아니다.

현재 `ferrial_drive/combat/simulation.py`는 조준 여부로 `hip_spread_degrees`/`aim_spread_degrees`를 선택한다. 기본 설정은 각각 5도/0.6도다. 이는 코드 확인이며 사용자 체감·최종 밸런스 검증을 뜻하지 않는다.

## 현재 연결

- `ferrial_drive/combat/targeting.py`의 `TargetAcquisition`은 후보 ID·위치, 플레이어·커서 위치, 조준 여부를 받아 선택한 ID를 반환한다. 좌표계와 거리 단위는 호출자가 통일한다. 같은 입력에서 현재 후보의 미획득 대상을 고르고, 모두 획득했거나 후보가 없으면 명세대로 이력을 초기화한다.
- UI v2는 적 3기의 화면 좌표를 사용한다. 최초 A를 획득 이력에 넣고, 이후 R 입력에만 재선택한다. 표적의 몸통·HP·이름과 피해 위치를 같은 ID로 연결한다.
- 샘플 설정은 평상시 330px·우클릭 중 460px·각도 동률 1도다. 본편의 거리·밸런스 결정이 아니며 `v2.targeting_sample`에서 변경한다. 커서와 플레이어 위치가 같으면 거리로 선택하고, 최초 커서 입력 전에는 오른쪽을 기준으로 한다.
- 대화창은 표시 순서로 표적과 HUD 일부를 덮는다. 이 UI 가림만으로 획득 후보를 제외하지 않는다. 샘플은 HP가 남은 적만 후보에 넣으며, 사망·거리 이탈에 따른 자동 재획득과 커서 이동 중 자동 전환은 구현하지 않았다.
- 실제 발사·명중·탄 퍼짐과 전투 프로토타입은 이 모듈에 아직 연결하지 않았다.
