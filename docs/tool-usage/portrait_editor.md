# 표정 스튜디오

소스 위치: `Tools/portrait_editor/`. 실행 명령은 프로젝트 루트 기준이다.

너와 Codex가 함께 사용하는 첫 데스크톱 에디터다. 실제 `live2d-py 1.0.0`(import 이름 `live2d`)로 MOC3를 재생한다. 현재 프로젝트에서 부르던 pylive2d 재생 경로를 이 설치 패키지에 연결했다.

프로젝트 루트의 `run_portrait_editor.cmd`로 실행한다. 초기 창은 1600×940, 최소 크기는 1280×800이다.

## 현행 모듈

- `app.py`: 실행, 입력, 재생, 실제 Live2D 미리보기와 모델 교체.
- `core.py`: 프로젝트·곡선 데이터, 저장과 이력, 형태 컴파일.
- `workspace_ui.py`: 현재 레이아웃과 메뉴·곡선 컨텍스트 메뉴.
- `ui_primitives.py`: 글자·버튼·입력칸·대화상자의 공통 그리기 코드.
- `export_moc3.py`, `render_filters.py`: 에디터가 직접 사용하는 변환기와 셰이더 준비.
- `region_document.py`, `region_workspace.py`: AI 추출 영역 표시와 독립 작업 저장·전달 묶음 출력.
- `test_core.py`, `test_layout.py`: 현행 데이터와 UI 구조 검증.
- `requirements.txt`: 현재 에디터의 실행 의존성.

현재 Blender 원본 생성 경로는 `Tools/blender_pipeline/`에 있다. 예전
`Tools/capability_test`의 데모·진단·이전 생성기와 옛 실행 스크립트는 제거했다.
원본·생성 입력은 `data/portrait_editor/`, 저장 프로젝트·레이아웃·영역 작업은 툴 내부 `Tools/portrait_editor/workspace/`에 보관한다. 작업 폴더는 실행 시 생성하며 Git에서 제외한다. `output/`은 재생성 가능한 캐시·검증 결과에만 사용한다.

## Layout 02

- 로고와 상단 개별 작업 버튼을 제거하고 **파일 / 편집 / 보기** 메뉴로 정리했다. 곡선 복사·붙여넣기, 기준점 추가·삭제, 초기화는 **곡선 영역 우클릭 메뉴**에서 실행한다. 우클릭한 기준점이 삭제 대상으로 선택되고, 빈 곳의 [기준점 추가]는 우클릭한 가로 위치를 사용한다. 상단 편집 메뉴에는 곡선 전용 작업을 넣지 않는다.
- 공통 여백 16px, 간격 8px, 입력/버튼 높이 32~34px, 행 높이 28px를 기준으로 정렬했다.
- 좌우 패널 경계와 미리보기·곡선 사이 경계를 드래그할 수 있다. 배치는 `Tools/portrait_editor/workspace/layout.json`과 저장한 프로젝트의 작업 화면 상태에 보존된다. [보기 → 패널 배치 초기화]로 되돌릴 수 있다.
- 작은 창에서는 재생 버튼과 자세 버튼을 두 줄로 나눈다. 파츠와 속성 패널은 필요한 경우 휠로 스크롤한다.
- 속성에 **편집 대상(전체 시간 / 연결 트랙)**과 **선택 파츠**를 따로 표시한다. 표정 기준 자세는 **키포즈**, 시간에 따른 재생 단위는 **애니메이션**으로 표기한다. 현재 실행 모델은 애니메이션 하나와 연결 트랙 세 개를 지원하며, 임의 그룹/클립 생성과 파츠별 독립 시간은 후속 기능이다.
- 시간 곡선은 X축과 제어점 X를 **초**, 형태 곡선은 **선택 구간의 파라미터 값**으로 표시한다. 재생 막대의 키 표시도 시간 곡선을 역산한 실제 도달 시각을 사용한다.
- [+ 기준점]과 우클릭의 [기준점 추가]는 기존 곡선 모양을 유지하며 Bézier 구간을 분할한다. [점 삭제], Insert/Delete, 기존 더블클릭도 사용할 수 있다. 우클릭 메뉴는 Escape 또는 바깥 클릭으로 닫고, 창 경계 안에서 표시한다.
- **Ctrl+C/V**는 선택한 시간/형태 곡선 전체를 복사·붙여넣는다. 숫자 입력 중에는 해당 입력값을 복사·붙여넣는다. 붙여넣기도 되돌리기 대상이다.

## 화면

- 왼쪽: 파츠 선택, 파츠 표시/숨김, 눈·입 트랙, 표정 키 선택·추가·삭제.
- 가운데: 실제 Live2D 미리보기. 휠로 확대·축소, 마우스 가운데 버튼으로 이동, 얼굴/전신 전환, 선택 메시와 클리핑 마스크 표시.
- 오른쪽: 편도 재생 시간, 보간 프리셋, 제어점 수치, 형태 키 위치와 원본 자세 위치.
- 아래: 시간 곡선/형태 곡선 편집. 핸들을 드래그하거나 빈 곳을 더블클릭해 기준점을 추가한다. 내부 기준점을 선택하고 Delete를 누르면 삭제한다. 빈 그래프 클릭과 재생 막대 드래그로 위치를 탐색한다.

숫자 입력칸을 클릭한 뒤 새 값을 입력하고 Enter로 확정한다. Escape로 입력을 취소한다. 시간과 값이 뒤로 꺾이거나 범위를 벗어나지 않도록 제어점을 제한한다. 프리셋은 Linear, Smoothstep, Ease In, Ease Out, Ease In-Out이다.

## 두 곡선의 의미

1. **시간 곡선:** 정규화된 재생 시간 → `ParamSmile` 값. 수정 즉시 재생에 반영한다.
2. **형태 곡선:** 선택한 눈·입 트랙의 표정 키 구간 → 원본 자세 진행 비율. 원본 Blender의 33개 자세를 보존하면서 구간을 재매핑한다. 변경 후 잠시 기다리거나 [형태 적용]을 누르면 새 MOC3를 만들고 교체한다. 원본 키 자체에 이미 들어간 변형과 시간 곡선이 합성된다는 점에 유의한다.

형태 키를 선택하면 오른쪽에서 그 키의 파라미터 위치와 참조하는 원본 자세를 바꿀 수 있다. 원본 자세 0은 중립, 0.5는 다문 미소, 1은 웃음이다. 시작·끝 키의 위치는 고정이고, 중간 키를 추가·이동·삭제할 수 있다. 이 버전은 임의 정점/본을 직접 편집하는 리깅 에디터가 아니다.

눈의 개구부와 위·아래 속눈썹은 같은 트랙을 사용한다. 홍채 그림은 고정된 채 실제 개구부 마스크로 가려진다. 입 개구부와 입술선도 같은 트랙을 사용해 입술선의 투명도와 입의 움직임이 함께 이어진다.

## 재생

- [재생]: 현재 위치부터 정방향으로 이동하고 웃음에서 무기한 유지.
- [역재생]: 현재 위치부터 역방향으로 이동하고 중립에서 무기한 유지.
- [일시정지/계속], Space: 멈춤/재개. 끝에서는 반대 방향으로 재생.
- A/R: 정방향/역방향. Home: 시작 위치. Z: 얼굴/전신.
- 1/2/3: 중립/웃음/다문 미소 자세.
- 한 방향 이동 시간은 0.5~10초. 고정 시뮬레이션 갱신은 1/60초이고, 프레임 대기는 절대 시각 기준으로 처리한다.

## AI에 전달할 추출 영역 지정

**파일 → AI 영역 지정…**에서 리깅 화면과 별도의 이미지 작업 화면을 연다.

1. **원본 이미지 열기**로 PNG/JPG/WebP를 연다. 이미지 파일을 이 화면에 끌어 놓아도 된다.
2. 영역 이름을 클릭해 `머리카락`, `왼쪽 눈`처럼 지정한다. 브러시로 추출할 위치를 대략 칠하고 지우개로 수정한다.
3. **영역 추가**로 다른 파츠를 지정한다. 목록에서 선택한 영역만 분홍색으로 표시된다. 영역끼리 겹쳐도 된다.
4. **작업 저장**으로 원본과 모든 브러시 기록을 `.regions.zip` 하나에 보관한다. 이 파일은 원래 이미지 경로 없이도 다시 열린다.
5. **AI 전달 묶음 저장**으로 원본 `source.png`, 영역별 흑백 `*.mask.png`, 분홍 표시 `*.guide.png`, `manifest.json`, `request.txt`를 새 폴더에 저장한다. 이 파일들을 AI에 직접 전달한다.

마스크는 **흰색=추출 대상의 대략적인 위치, 검은색=그 밖의 위치**다. 정밀한 파츠 알파나 추출 완료 결과가 아니다.
모든 출력은 원본 캔버스 크기와 좌표를 유지한다. 요청문은 실제 경계 판단, 투명 PNG, 원본 위치 유지와 가려진 부분 복원을 요구한다.
빈 영역은 내보내기 전에 칠하거나 삭제해야 한다. 내보내기는 편집 작업 저장을 대신하지 않는다.

단축키는 B/E 브러시·지우개, [/ ] 크기 조절, Ctrl+Z/Y 되돌리기·다시 적용, Ctrl+S 저장,
Ctrl+Shift+S 다른 이름으로 저장, Ctrl+O 영역 작업 열기다. 휠 확대와 가운데 버튼 드래그 이동을 지원한다.
리깅 화면으로 돌아가거나 이미지를 바꿀 때 미저장 작업을 확인한다. 리깅 프로젝트와 영역 작업 파일은 독립적이다.

AI 자동 전송·추출·복원과 추출된 파츠의 Blender 자동 연결은 구현하지 않았다. PSD 출력은 이 흐름에 포함하지 않는다.
입력은 최대 64MB, 8192px / 16,777,216픽셀이고 영역은 최대 24개다.

## 프로젝트와 출력

- Ctrl+S 또는 [저장]: 기본 `Tools/portrait_editor/workspace/portrait.project.json`에 저장. 곡선, 표정 키, 파츠 표시 상태와 작업 화면 상태를 포함한다.
- [파일 → 다른 이름으로 저장]: 별도 프로젝트 파일에 저장.
- [파일 → 열기], Ctrl+O 또는 프로젝트 JSON 파일 드롭: 프로젝트 복원.
- Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z: 되돌리기/다시 적용. 한 번의 핸들 드래그를 한 작업으로 기록한다.
- [파일 → .moc3 내보내기], Ctrl+E: 선택한 폴더에 모델 설정, MOC3, 모든 텍스처를 함께 출력. 미적용 형태 변경이 있으면 최신 빌드를 기다린다.
- [파일 → 화면 저장], Ctrl+Shift+P: `output/portrait_editor/captures/`에 현재 편집 화면 저장.

리깅 원본은 `data/portrait_editor/rig/blender-keyforms.json`과 같은 폴더 아래 `textures/`다. 레이아웃은 `Tools/portrait_editor/workspace/layout.json`, 내보내기 기본 폴더는 `data/portrait_editor/exports/`다. 에디터는 리깅 원본과 `.blend`를 덮어쓰지 않는다. 생성되는 실행용 모델은 `output/portrait_editor/.runtime/`에 둔다. 프로젝트는 편집 데이터이고, MOC3는 파생 출력이다.

현재 모델 지원 범위는 `ParamSmile` 한 축과 왼눈·오른눈·입 세 트랙이다. ComfyUI/Anima 워크플로우 연결과 임의 Blender 리그 가져오기는 이 에디터 버전에 구현되어 있지 않다.

## 검증

```powershell
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\test_core.py
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\test_layout.py
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\test_regions.py
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\verify_regions.py
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\app.py --verify
.\.venv-capability-test\Scripts\python.exe Tools\portrait_editor\app.py --seconds 8 --measure --autoplay
```

단위 검증은 곡선 프리셋/역함수/범위, 프로젝트 저장·복원과 이력, 끝 표정 유지, 실제 형태 출력과 다른 트랙 보존을 확인한다. 창 검증은 실제 입력 처리기를 통해 곡선 드래그, 숫자 입력, 저장, undo/redo, 표정 키 조작, 모델 교체, 메시·마스크 표시와 프로젝트 재열기를 실행한다. MOC3 출력 후 실제 SDK의 정점 값도 비교한다.

결과는 `output/portrait_editor/qa/editor-verification.json`, 스크린샷은 같은 폴더에 저장한다. `editor-layout02.png`, `editor-menu.png`, `editor-compact.png`로 기본/메뉴/작은 창을 확인할 수 있다. GUI 검증은 복사·붙여넣기에 앱 내부 어댑터를 써서 기존 시스템 클립보드를 보존한다. 일반 실행은 시스템 클립보드를 사용한다. `editor-timing.json`은 모델 로딩 후 첫 1초와 변환 중 구간을 제외한 정상 재생 측정이다. GUI 검증에 포함된 FPS는 변환·PNG 저장·테스트 입력 시간을 포함하므로 정상 재생 성능과 구분해야 한다.

영역 지정의 실제 창 검증 결과는 `output/portrait_editor/qa/regions/verification.json`과 같은 폴더의 화면에 저장한다.
메뉴·브러시·지우개·Undo·저장/재열기·원본 크기 출력·미저장 확인을 실제 입력 처리기로 검사한다.
파일 대화상자에는 검증용 경로를 공급하며 실제 OS 마우스 조작이나 AI 추출 품질을 검사한 것은 아니다.

오류 기록은 `output/portrait_editor/editor-error.log`, 모델 로딩 기록은 `editor-session.log`에 남긴다.

MOC3 출력은 기존 GPL-3.0-or-later Ayatsuri2D 기반 변환기를 재사용한다. Live2D 셰이더는 원본 라이선스 헤더를 유지한다.
