# 메카 분리 시트·합성 미리보기

## 확정한 전달 구조

- 도구의 메카 모드는 분리 시트를 조립해 미리본다.
- 게임은 같은 합성 메타데이터와 공통 에셋 표시기를 사용한다.
- 내보내기는 색상·에너지 마스크 시트와 각 시트의 JSON을 **분리한 채로 유지**한다. 조립한 전체 메카를 하나의 PNG로 굽지 않는다.
- 동작·방향별 순서, 특정 Blender 프레임의 순서 예외, 전환 이벤트를 `mech.json`에 기록한다.

## 무기 수납 규칙

좌우는 **메카 자신의 기준**이다. 무기는 사용하는 손의 반대쪽 사이드 슬롯에 수납한다.

| 사용하는 손 | 수납 위치 | 슬롯 파츠 |
|---|---|---|
| 오른손 | 메카 왼쪽 슬롯 | `side_slot_l` |
| 왼손 | 메카 오른쪽 슬롯 | `side_slot_r` |

검·총이라는 무기 종류로 수납 방향을 고정하지 않는다. 사용하는 손을 기준으로 꺼내기·넣기의 대상 슬롯을 정한다. 전환 이벤트의 `side`는 **사용하는 손**을 뜻하므로, `side: right`의 수납 위치는 왼쪽 슬롯이다. 손의 좌우와 슬롯의 좌우를 같은 값으로 해석하지 않는다.

이 규칙은 장착·애니메이션 제작 기준이다. 현재 출력 파츠의 부착점은 명시적으로 연결하며 손 기준 슬롯 자동 배정·기존 장착/애니메이션 데이터의 일괄 전환은 구현하지 않았다. 분리 시트의 그리기 순서와 실제 인출 경로는 해당 동작·방향에서 별도로 검수한다.

## 출력 단위

출력 단위는 사용자가 정의하는 **출력 파츠**다. 고유 ID·표시 이름·표시 여부·부착점·오브젝트·색상 시트·에너지 마스크·상태를 갖는다. 장비·부위 판정 같은 게임 규칙은 이 데이터에 포함하지 않는다. 고유 ID는 생성 후 고정하며 이름을 변경해도 순서·시트·상태 연결을 유지한다.

메카 기본 구성은 본체·좌우 손+무기·수납 검/총·칼집·좌우 사이드 슬롯·분리된 검/총을 제공한다. NPC 기본 구성은 본체만 제공하며 장식을 자유롭게 추가한다. `body`는 공통 프레임 기준 파츠여서 삭제할 수 없다. 표시 이름과 시트는 변경할 수 있다. 사용하지 않는 파츠는 표시를 끄거나 삭제할 수 있고 시트 미연결 파츠는 내보내기에서 제외한다.

**추가 → 파츠 템플릿 → 등 스러스터**는 수직·수평·수직→수평·수평→수직 상태를 만든다. 다리 스러스터는 이 분리 대상에서 제외한다. 템플릿은 부착점과 상태 정의를 제공하며 실제 모델을 수정하거나 전환 이미지를 생성하지 않는다.

## 설정과 프리셋

**출력 파츠**에서 추가·복제·삭제하고 목록에서 파츠를 선택한다. 오른쪽의 부착·오브젝트 / 에너지 마스크 / 분리 시트에서 선택 파츠를 편집한다. 파츠 목록과 그리기 순서는 휠로 이동한다.

- 구성 프리셋은 파츠 목록·이름·상태·오브젝트·부착점·마스크 입력을 저장한다. 구성 적용 시 파츠 목록을 해당 프리셋으로 바꾸고 순서/상태 참조를 정리한다. 같은 파츠 ID·상태 ID의 시트 파일 경로는 보존하며 새 항목의 시트는 비워 둔다. 동작·전환 이벤트는 유지한다.
- 프리셋 저장에서 이름을 입력한다. 같은 이름으로 저장하면 해당 프리셋을 갱신한다. 보관 위치는 `Tools/asset_loader/workspace/mech_presets/`다. 이전 v1 매핑 프리셋도 읽는다.
- 기본 부착점 프리셋은 부착 기준만 기본 이름으로 돌린다.
- 분리 시트에서 선택한 파츠/상태의 색상·마스크 **SSheetCutil v1 JSON**을 연결한다. 상대 경로는 작업본 원본 파일의 폴더 기준이다.

## 파츠 상태

상태는 메카 전체 동작과 별도로 정의한다. 상태 목록 선택은 **현재 동작의 해당 파츠 상태**를 지정한다. 다른 동작의 선택은 바뀌지 않는다. `이 상태를 기본으로`는 상태 선택이 없는 동작의 기본값을 지정한다.

- 파츠와 상태의 표시 여부를 각각 설정한다. 상태 이름을 바꿔도 상태 ID는 유지한다.
- 상태의 색상 시트가 비어 있으면 파츠 기본 시트를 사용한다. 이 경우 마스크도 별도 입력이 없으면 기본 마스크를 사용한다. 새 색상 시트를 연결한 상태는 마스크도 별도로 연결한다.
- 상태 클립 접두사를 비우면 본체 동작과 같은 이름을 사용한다. 접두사를 지정하면 해당 접두사에 `/방향`을 붙인 클립을 읽는다.
- 선택한 상태의 FPS·프레임 수·이미지 크기·기준점은 본체와 같아야 한다. 현재 위치/부착은 같은 장면에서 렌더된 좌표를 사용한다. 임의의 시트를 부착점 이름만으로 실시간 재배치하지 않는다.
- 파츠 삭제는 기본 순서·프레임 예외·동작 상태 참조를 함께 제거한다. 상태 삭제는 이를 선택한 참조를 기본값으로 돌린다. 실제 파일은 삭제하지 않는다.
- v1 작업본은 읽을 때 v2 동적 파츠로 보완한다. 원본 JSON은 읽기만으로 덮어쓰지 않으며, v2에서 삭제한 기본 메카 파츠를 다시 삽입하지 않는다.

**동작·순서**에는 정면 / 후면 / 기본 8방향 순서 프리셋과 작은 조립 미리보기가 있다.

- 정면·후면 프리셋은 선택 방향의 편집 대상 순서를 바꾼다.
- 기본 8방향 프리셋은 **현재 동작에 한해** 방향별 기본 앞뒤 관계를 적용한다.
- 현재 동작 전체 방향 적용은 현재 순서를 8방향에 복사한다. 다른 동작은 유지한다. 기본 순서를 편집할 때는 기존 프레임 예외를 유지하며, 특정 프레임을 편집할 때는 해당 프레임의 예외만 8방향에 적용한다.
- 가림 처리 방식과 프레임 목록은 위 순서 적용에 의해 바뀌지 않는다. 정면/후면에 다른 관계가 필요하면 기본 8방향 프리셋을 사용하거나 방향별로 편집한다.
- 기본 순서 프리셋은 기본 메카 파츠의 상대 순서를 바꾸며 사용자 파츠의 위치·상대 순서는 보존한다.

## 미리보기

- 시트 연결 전에는 출력 단위의 겹침을 설명하는 순서 도식을 표시한다.
- 도형 예제는 독립된 분리 시트를 공통 재생부로 합성한다. 현재 작업본·매핑·시트 연결은 바꾸지 않는다. 실제 모델의 분리 완료를 뜻하지 않는다.
- 조립 미리보기에서는 동작·방향·재생/정지와 시트 갱신을 조작한다. 순서를 편집하면 미리보기의 가림도 즉시 바뀐다.
- 실제 시트는 각 동작의 클립 이름에 `/방향`을 붙인 이름을 사용한다. 시트의 프레임 수와 작업본의 Blender 프레임 목록 길이가 같아야 한다.
- 모든 색상·마스크 시트는 같은 원본 클립 FPS, 프레임 수, 프레임별 이미지 크기·기준점을 사용한다. 시트 안에 패킹한 위치는 달라도 된다.

## 내보내기와 게임

분리 시트 내보내기를 누르면 새 `data/catalog/prerender/<ID>/<버전>/` 폴더에 아래 파일을 기록한다.

| 파일 | 내용 |
|---|---|
| `mech.json` | `type: mech`, 출력 단위별 시트 참조·부착 이름·동작별 순서/프레임 예외/이벤트 |
| `color/<출력 단위>.json` 및 이미지 | 원본 색상 시트. 패킹 이미지 픽셀은 보존하고 참조 경로만 상대 경로로 갱신 |
| `energy/<출력 단위>.json` 및 이미지 | 연결한 원본 마스크 시트. 색상과 같은 방식으로 별도 보관 |

v2 패키지는 파츠 이름·표시 여부·상태 정의와 동작별 `part_states`를 포함한다. 별도 시트를 연결한 상태는 `color/<파츠>/<상태>.json` 및 이미지, `energy/<파츠>/<상태>.json` 및 이미지로 보관한다. 기본 시트를 재사용하는 상태는 참조를 공유한다.

출력 폴더가 이미 있으면 덮어쓰지 않는다. 저장한 패키지는 원본 경로 없이 다른 폴더에서 읽을 수 있다. 성공하면 도구의 메인 미리보기에서 내보낸 메카를 열며, 메카 설정을 다시 열면 분리 시트 연결과 순서를 복원한다.

게임은 `AssetDefinition`의 `kind="mech"` 또는 `detect_kind()`와 기존 `AssetManager`·`PicoAssetBackend`를 사용한다. `handle.resource.clips`에서 동작/FPS/프레임을 읽고 기존 `draw(clip_name, frame_index, x, y)`로 표시한다. 순서 예외는 해당 프레임에 공통 표시기가 적용한다. 게임은 `Tools`를 import하지 않는다. 기본 등록도 분리 패키지 전체를 보관한다.

개체별 선택이 필요하면 `draw()`의 `part_states={파츠 ID: 상태 ID}`와 `part_visibility={파츠 ID: 표시 여부}`를 사용한다. 공유 자원의 기본 설정을 변경하지 않는다. 사용할 상태와 동작의 정합은 처음 선택할 때 검증한다. v1 패키지도 기존 방식으로 읽는다.

## 현재 구현 범위

- 연결한 분리 색상 시트의 실제 합성 재생, 순서 프리셋/현재 동작 전체 방향 적용, 매핑 프리셋, 분리 시트 내보내기/재열기를 구현했다. 도구와 게임의 표시 경로는 공통이다.
- 에너지 마스크는 색상과 정합을 검사하고 별도 파일로 전달한다. 현재 합성 미리보기는 색상 시트를 표시하며, 선형 RGB 발광 합성과 색·강도·레벨 제어 셰이더는 후속이다.
- 실제 Blender 장면을 이 설정으로 레이어별 렌더하는 연결은 미구현이다. Blender 원본 모델·전체 전투 모션을 수정하지 않았다.
- 전환 이벤트는 메타데이터로 전달한다. 사출물의 독립 이동·장착 상태 전환의 게임 동작, 본편 전투 장면 연결은 이번 공통 색상 재생부의 구현 범위와 구분한다.
- 자동 검사와 SDL 화면 이미지를 확인했다. 실제 Windows 조작감·새 메카 합성의 OpenGL GPU 경로·실제 모델의 전체 전투 모션은 별도 검증 대상이다.
