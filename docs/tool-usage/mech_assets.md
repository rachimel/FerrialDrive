# 메카 분리 시트·합성 미리보기

## 확정한 전달 구조

- 도구의 메카 모드는 분리 시트를 조립해 미리본다.
- 게임은 같은 합성 메타데이터와 공통 에셋 표시기를 사용한다.
- 내보내기는 색상·에너지 마스크 시트와 각 시트의 JSON을 **분리한 채로 유지**한다. 조립한 전체 메카를 하나의 PNG로 굽지 않는다.
- 동작·방향별 순서, 특정 Blender 프레임의 순서 예외, 전환 이벤트를 `mech.json`에 기록한다.

## 출력 단위

본체·왼손+무기·오른손+무기·수납 검·수납 총·칼집·좌우 사이드 웨폰 슬롯·분리된 검/총을 각각 다룬다. 사이드 슬롯은 무기 종류에 따라 교체할 수 있도록 본체에서 분리한다. 슬롯의 실제 오브젝트·형상이나 호환 무기 목록을 이 도구가 자동 결정하지 않는다. 사용하지 않는 출력 단위는 시트를 연결하지 않아도 된다.

등 스러스터는 별도 레이어에 수직·수평·전환 동작을 두는 **AI 검토안**이다. 2D 이미지의 회전만으로 3D 깊이와 본체 가림을 재현할 수 없기 때문이다. 다리 스러스터는 이 검토 대상에서 제외한다. 사용자 확정 전이므로 등 스러스터 출력 단위·전환 프레임은 이번 구현에 추가하지 않았다.

## 설정과 프리셋

**출력 단위 → 색상·부착 / 에너지 마스크 / 분리 시트**로 관련 항목을 전환한다.

- 매핑 프리셋은 오브젝트·부착 기준·빈손·에너지 마스크 입력을 저장한다. 시트 파일 경로·동작·전환 이벤트는 바꾸지 않는다.
- 매핑 저장에서 이름을 입력한다. 같은 이름으로 저장하면 해당 프리셋을 갱신한다. 보관 위치는 `Tools/asset_loader/workspace/mech_presets/`다.
- 기본 부착점 프리셋은 부착 기준만 기본 이름으로 돌린다.
- 분리 시트에서 출력 단위별 색상·에너지 마스크의 **SSheetCutil v1 JSON**을 연결한다. 경로를 직접 입력하거나 행의 찾기 버튼을 사용한다. 상대 경로는 작업본 원본 파일의 폴더 기준이다.

**동작·순서**에는 정면 / 후면 / 기본 8방향 순서 프리셋과 작은 조립 미리보기가 있다.

- 정면·후면 프리셋은 선택 방향의 편집 대상 순서를 바꾼다.
- 기본 8방향 프리셋은 **현재 동작에 한해** 방향별 기본 앞뒤 관계를 적용한다.
- 현재 동작 전체 방향 적용은 현재 순서를 8방향에 복사한다. 다른 동작은 유지한다. 기본 순서를 편집할 때는 기존 프레임 예외를 유지하며, 특정 프레임을 편집할 때는 해당 프레임의 예외만 8방향에 적용한다.
- 가림 처리 방식과 프레임 목록은 위 순서 적용에 의해 바뀌지 않는다. 정면/후면에 다른 관계가 필요하면 기본 8방향 프리셋을 사용하거나 방향별로 편집한다.

## 미리보기

- 시트 연결 전에는 출력 단위의 겹침을 설명하는 순서 도식을 표시한다.
- 도형 예제는 독립된 분리 시트를 공통 재생부로 합성한다. 현재 작업본·매핑·시트 연결은 바꾸지 않는다. 실제 모델의 분리 완료를 뜻하지 않는다.
- 조립 미리보기에서는 동작·방향·재생/정지와 시트 갱신을 조작한다. 순서를 편집하면 미리보기의 가림도 즉시 바뀐다.
- 실제 시트는 각 동작의 클립 이름에 `/방향`을 붙인 이름을 사용한다. 시트의 프레임 수와 작업본의 Blender 프레임 목록 길이가 같아야 한다.
- 모든 색상·마스크 시트는 같은 원본 클립 FPS, 프레임 수, 프레임별 이미지 크기·기준점을 사용한다. 시트 안에 패킹한 위치는 달라도 된다.

## 내보내기와 게임

분리 시트 내보내기를 누르면 새 `data/catalog/prerender/<ID>/<버전>/` 폴더에 아래 파일을 기록한다.

| 파일 | 내용 |
|---|---|
| `mech.json` | `type: mech`, 출력 단위별 시트 참조·부착 이름·동작별 순서/프레임 예외/이벤트 |
| `color/<출력 단위>.json` 및 이미지 | 원본 색상 시트. 패킹 이미지 픽셀은 보존하고 참조 경로만 상대 경로로 갱신 |
| `energy/<출력 단위>.json` 및 이미지 | 연결한 원본 마스크 시트. 색상과 같은 방식으로 별도 보관 |

출력 폴더가 이미 있으면 덮어쓰지 않는다. 저장한 패키지는 원본 경로 없이 다른 폴더에서 읽을 수 있다. 성공하면 도구의 메인 미리보기에서 내보낸 메카를 열며, 메카 설정을 다시 열면 분리 시트 연결과 순서를 복원한다.

게임은 `AssetDefinition`의 `kind="mech"` 또는 `detect_kind()`와 기존 `AssetManager`·`PicoAssetBackend`를 사용한다. `handle.resource.clips`에서 동작/FPS/프레임을 읽고 기존 `draw(clip_name, frame_index, x, y)`로 표시한다. 순서 예외는 해당 프레임에 공통 표시기가 적용한다. 게임은 `Tools`를 import하지 않는다. 기본 등록도 분리 패키지 전체를 보관한다.

## 현재 구현 범위

- 연결한 분리 색상 시트의 실제 합성 재생, 순서 프리셋/현재 동작 전체 방향 적용, 매핑 프리셋, 분리 시트 내보내기/재열기를 구현했다. 도구와 게임의 표시 경로는 공통이다.
- 에너지 마스크는 색상과 정합을 검사하고 별도 파일로 전달한다. 현재 합성 미리보기는 색상 시트를 표시하며, 선형 RGB 발광 합성과 색·강도·레벨 제어 셰이더는 후속이다.
- 실제 Blender 장면을 이 설정으로 레이어별 렌더하는 연결은 미구현이다. Blender 원본 모델·전체 전투 모션을 수정하지 않았다.
- 전환 이벤트는 메타데이터로 전달한다. 사출물의 독립 이동·장착 상태 전환의 게임 동작, 본편 전투 장면 연결은 이번 공통 색상 재생부의 구현 범위와 구분한다.
- 자동 검사와 SDL 화면 이미지를 확인했다. 실제 Windows 조작감·새 메카 합성의 OpenGL GPU 경로·실제 모델의 전체 전투 모션은 별도 검증 대상이다.
