# 메카 동작 검토

현재 제작은 [Unreal 짧은 동작 초안 → 전체 재생 검수 → 수정](../ai-asset-pipeline/animation_workflow.md)이다. 별도 정지 KeyPose 승인·확정 대기 단계를 두지 않는다.

- 동작별로 Unreal Sequence·클립 이름, 전체 재생, 문제 프레임·부위·수정 의도와 현재 검수 상태를 연결한다.
- 자세 ID·이미지 목록은 문제를 찾기 위한 보조 자료다. 목록 생성·연결 유지·수치 검사나 기존 AI 통과만으로 정상 자세를 판정하지 않는다.
- 상박/하박의 지나치게 좁은 V자 접힘·굽힘 면·비틀림·장갑 간섭을 앞/옆/사선에서 실제로 확인한다.
- 새 Unreal 리그의 클립/프레임 매핑과 기존 파츠/레이어 출력은 [인계 조건](../ai-asset-pipeline/unreal_pipeline.md)을 따른다. 프리렌더는 Unreal, 2D 파츠 조립은 기존 툴에서 수행한다.
