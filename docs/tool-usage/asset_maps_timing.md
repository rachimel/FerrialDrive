# 맵 번들과 프레임 유지 시간

## 맵 작업

Asset Tool 상단 **맵 작업**에서 배경·바닥 이미지를 선택한다. 배경 선택 시 실제 이미지 크기를 입력한다. 두 이미지는 같은 크기여야 하며 투명 부분을 지원한다. 선택 후 **미리보기 갱신**으로 확인한다.

**표시 선택**은 배경, 바닥, 합성 결과, 이동 가능 구역을 제공한다. 합성 순서는 배경 위에 바닥이다. 이동 가능 구역은 합성 위에 반투명 녹색으로 표시한다. 모든 화면과 데이터는 동일한 bottom-left 픽셀 좌표를 사용한다.

**이동 가능 구역** 화면에서 꼭짓점을 차례대로 클릭하고 **구역 확정**으로 추가한다. **점 취소**는 작성 중인 마지막 꼭짓점, **마지막 구역 삭제**는 확정된 마지막 다각형을 제거한다. 꼭짓점은 3개 이상이며 맵 범위 안이어야 한다. 여러 구역은 합집합이고 경계도 포함한다. 빈 목록은 이동 구역이 없다는 뜻이다.

**내보내기**는 지정한 새 폴더에 이미지와 `bundle.json`을 함께 저장한다. 빈 출력 경로는 `data/catalog/prerender/<ID>/<새 버전>/`를 사용한다. 기존 출력 폴더와 원본은 덮어쓰지 않는다. 등록은 별도 **등록** 버튼으로 수행한다.

내보낸 `bundle.json`은 메인 **불러오기** 또는 패널의 **맵 불러오기**로 import한다. 폴더 전체를 이동해도 상대 경로로 읽는다. 메인 화면의 오른쪽 목록도 맵의 네 가지 표시를 제공하며 **배경·바닥** 버튼으로 각 레이어를 켜고 끈다.

```json
{
  "version": 1,
  "type": "map",
  "asset_id": "training_map",
  "coordinates": "bottom-left",
  "size": [320, 180],
  "background": "background.png",
  "ground": "ground.png",
  "composite": "composite.png",
  "walkable": [[[20, 12], [300, 12], [300, 96], [20, 96]]]
}
```

`composite`는 export 시 생성하는 합성 PNG이며 입력에서는 생략할 수 있다. 개별 레이어는 보존한다. 공통 `MapBundle.load()`와 `contains(x, y)`는 도구 창 없이 게임에서 사용할 수 있다. 게임의 실제 이동·충돌 처리 연결, 장애물 배치, 스폰 편집, Blender 장면의 맵 레이어 렌더는 이 기능에 포함하지 않는다.

## 프레임 유지 시간

**애니메이션 조립**은 선택 프레임의 `duration_ms`를 편집한다. 양수인 유한한 밀리초를 사용하며 프레임별로 다르게 지정할 수 있다. **전체 시간 적용**으로 동일 값을 한 번에 설정한다. 미리보기, 메인 재생, 프레임 앞뒤 이동, 공통 `SpritePlayback`은 같은 시간 규칙을 사용한다. 전체 동작 길이는 각 프레임 시간의 합이다.

각 시트의 `animations[].frames[]`에 `duration_ms`를 저장한다. 지정된 값이 FPS보다 우선한다. 기존 시트의 시간이 없으면 `1000 / fps`를 사용하며, 모든 프레임에 시간이 있으면 시트의 `fps`를 생략할 수 있다. 본체와 그림자에는 같은 시간과 프레임 순서를 적용한다. 신규 본체/그림자 번들은 `type: "character"`를 기록하며 기존 무타입 번들도 계속 읽는다. 분리 메카 시트에 기록된 유지 시간도 공통 재생기가 사용한다.

3D 렌더와 메카 제작의 기존 FPS 설정은 유지한다. 프레임별 시간 편집은 일반 이미지·시트·본체/그림자 번들의 **애니메이션 조립**에서 제공한다.

## 자동화

기존 [JSON 진입점](asset_tool_automation.md)을 사용한다.

- `map.import`: 필수 `source`, 선택 `output`. 메타데이터·실제 이미지 크기를 검증하여 절대 경로로 해석된 편집 `data`를 반환한다. `output`이 있으면 새 폴더로 복사한다.
- `map.export`: 필수 `output`, `source` 또는 `data` 중 하나. `data`의 이미지 경로는 요청 파일 기준이며, 원본 맵을 지정하면 원본 JSON 기준이다. 배경·바닥과 합성 PNG·좌표 데이터를 함께 출력한다.
- `sprite.assemble`: 편집 항목에 출력 순서와 같은 길이의 `durations_ms` 목록을 지정한다. 예: `{"source_clip":"idle/s","name":"attack","order":[0,1,1],"durations_ms":[100,40,180]}`. 기존 `fps` 요청도 호환한다.

시연 요청은 `samples/asset_loader/requests/import_map.json`, `export_map.json`을 사용한다. 같은 export 출력 폴더가 이미 있으면 새 경로를 지정한다.
