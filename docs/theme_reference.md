# Ferrial Drive Theme Reference

확정한 스틸 블루·Bezel 계열을 도구 전반에 적용하기 위한 기준이다. 프로그램이 읽는 값은 [공통 theme.json](../Tools/theme_reference/theme.json)에 둔다. Bezel `#39444A`는 현재 사용하는 근사색이며 Pantone의 공식 환산값으로 주장하지 않는다.

## 색상 역할

| 역할 | 값 | 적용 |
| --- | --- | --- |
| background | `#091217` | 창 바탕 |
| panel | `#101F27` | 목록·내용 영역 |
| panel_surface | `#39444A` | 상단·상태 영역, Bezel 근사색 |
| line | `#2D4B55` | 영역·행 구분선 |
| accent | `#91AEBB` | 스틸 블루 제목·포커스·짧은 강조 |
| text | `#D8E6ED` | 본문 |
| muted | `#B7CDDA` | 보조 문구·출처 |
| selected | `#1B3941` | 선택 행·사용자 요약 카드 |
| ai_bubble | `#172A35` | AI 요약 카드 |
| input | `#0B1920` | 입력 영역 |
| button | `#7E98A5` | 일반 버튼 |
| button_hover | `#A6C0CC` | 호버·선택된 조작 |
| button_text | `#17242B` | 밝은 버튼 위의 짙은 글자 |
| warning | `#E4B36C` | 누락·미확인 |
| error | `#F18775` | 실제 오류·저장 실패 |
| disabled | `#708894` | 실행/입력 불가 |

상태는 글자/배지로도 구분한다. 사용자/AI나 원문/요약/회고를 색상만으로 전달하지 않는다. 전투의 HP·피해·위험 상태색은 일반 도구의 포인트 역할과 구분한다.

## 글꼴과 정렬

| 역할 | 글꼴 | 크기 |
| --- | --- | ---: |
| title | Cafe24 써라운드 일반형 | 20px |
| body | 에스코어 드림 Regular, SCDream4 | 18px |
| small | 에스코어 드림 Regular, SCDream4 | 14px |

제목은 Air보다 굵은 일반형으로 구분한다. 없는 Bold를 합성하지 않는다. 전투의 숫자/잔탄 등 별도 지정 역할은 해당 UI 명세를 유지한다. 폰트 원본·이용 조건은 [폰트 안내](../data/fonts/README.md)에 둔다.

- 글자 너비와 말줄임은 실제 그리는 글꼴로 측정한다.
- SDL 텍스처는 위쪽 좌표, Pico2D Font.draw는 세로 중앙 좌표를 사용한다. 좌표 규약을 혼합하거나 반 크기를 중복 보정하지 않는다.
- 각 행의 좌우 패딩을 맞추고 긴 경로/제목은 말줄임하거나 줄바꿈한다.

## 간격·선·카드

- 창 바깥 16px, 영역 사이 12px, 내부 기본 패딩 12px, 본문 기본 줄 간격 24px, 구분선 1px.
- 카드/영역 테두리는 계층을 구분할 때만 쓴다. 작은 이름 플레이트는 바탕만 두고 윤곽선은 끈다.
- 웨폰 카드는 왼쪽 위·오른쪽 아래 모서리를 깎는 형태다. 도구의 모든 입력창/버튼에 이 장식을 강제하지 않는다.
- 비선택 항목과 호버·선택 상태의 명도 차를 확보한다. 밝은 버튼 글자는 짙게 표시한다.

## 적용 범위와 변경 절차

현재 대화 기록과 Unit Test Runner가 공통 JSON을 직접 읽는다. 새 도구도 같은 역할을 사용하고, 필요한 추가 역할은 이름·이유·사용 위치를 기록한다. 기존 표정 스튜디오 등 다른 도구의 외형 변경은 별도 작업이다. 게임 표현 설정을 이 도구 모듈에 의존시키지 않는다.

테마를 바꾸면 두 적용 도구의 글자 잘림·입력 포커스·누락/오류 표시·선택 명도를 확인한다. 색상값 확인과 실제 화면 사용감 확인을 구분한다.
