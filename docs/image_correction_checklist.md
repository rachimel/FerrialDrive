# 이미지 보정 체크리스트

JANIMA 레퍼런스와 GPT 보정 결과를 확인하는 공통 기준이다. 이전 LoRA 선별 기준에서 재사용했으며, 학습 세트나 특정 생성 날짜에 종속되지 않는다.

## 1. 손과 발

- [ ] 손·발의 형태와 손가락·발가락 개수에 명백한 오류가 없는가?
- [ ] 손목·발목과의 연결이 자연스러운가?
- [ ] 가려진 부분을 확인하지 못한 채 개수·구조 오류로 단정하지 않았는가?

## 2. 겹치는 사물

- [ ] 앞뒤 관계와 경계가 일관되는가?
- [ ] 신발끼리 붙거나 사물이 서로 관통하는 오류가 없는가?
- [ ] 가려졌다 다시 드러나는 부분의 구조가 이어지는가?

## 3. 손과 사물의 접촉

- [ ] 총 등을 잡는 손의 위치·방향이 자연스러운가?
- [ ] 손가락과 손잡이의 접촉·앞뒤 관계가 맞는가?
- [ ] 손과 사물이 합쳐지거나 관통하지 않는가?

## 4. 사물의 세부묘사

- [ ] 부품의 형태·연결이 일관되는가?
- [ ] 선이나 장식 때문에 구조가 모순되지 않는가?

## 5. 인체 비율과 관절

- [ ] 신체 비율과 팔다리 연결이 일관되는가?
- [ ] 자세·원근을 고려해도 불가능한 관절 각도나 뒤틀림이 없는가?
- [ ] 의도된 화풍의 과장과 구조 오류를 구분했는가?

## 6. 구도와 조명

- [ ] 광원 방향과 밝은 면·그림자가 일관되는가?
- [ ] 자세·겹침에 따른 가려짐과 접촉 그림자가 자연스러운가?
- [ ] 인물·사물의 조명이 서로 맞는가?
- [ ] 의도적인 연출광과 모순된 명암을 구분했는가?

## 결과 기록

- 문제 위치와 필요한 보정을 간결하게 기록하고, 보정 결과를 다시 확인한다.
- 가림·구도·해상도로 판단이 어려우면 보류한다. 확인하지 못한 내용을 정상으로 단정하지 않는다.
- 원본과 보정 버전·프롬프트는 구분해 보관한다. AI 생성 이미지·모델과 가공 에셋은 공개 Git에서 제외한다.

제작 흐름은 [이미지 파이프라인](image_pipeline.md), 로제의 기록은 [프롬프트 문서](rose_art_prompts.md)를 따른다.
